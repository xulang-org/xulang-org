FIPS-197 AES 高级加密标准（AES-128 / AES-192 / AES-256）单块加密。多分组与工作模式（CBC / CTR / GCM）见 #crypto/cipher。

模块概述

#crypto/aes 实现了国家标准与工业通用的 AES（Rijndael）对称分组加密算法。支持 128 位、192 位与 256 位密钥长度，具体实现取决于编译目标与后端：

  • 密钥与轮数规格：
    • AES-128：密钥长度 16 字节（128 位），10 轮加密。
    • AES-192：密钥长度 24 字节（192 位），12 轮加密。
    • AES-256：密钥长度 32 字节（256 位），14 轮加密。
  • 分组长度：固定为 16 字节（128 位），即 const BLOCK_SIZE = 16。
  • 硬件加速：可用性取决于编译目标与后端。Cipher.hw_accel 表示当前密码器是否使用硬件加速；CPU 支持相关指令不代表当前实现一定启用。
  • 工作模式与流扩展：本包专职处理严格的 16 字节底层单块加解密。处理变长明文时，请配合标准库 #crypto/cipher：
    • CBC 模式：支持 PKCS#7 自动填充（cipher.encrypt_cbc_pkcs7 / cipher.decrypt_cbc_pkcs7）。
    • CTR 模式：基于计数器的流加密（cipher.encrypt_ctr / cipher.decrypt_ctr）。

代码示例

1. 单块 AES-128 基础加解密

Xu示例
@main
#crypto/aes

fn main() int {
    // 16 字节密钥（AES-128）
    key := "0123456789abcdef"
    c := aes.new_cipher(&key) or (err) {
        println("初始化失败: " + err.msg())
        << 1
    }

    // 单块明文必须正好 16 字节
    block := "16_bytes_secret!"
    enc := c.encrypt(&block) or (err) {
        println("加密失败: " + err.msg())
        << 1
    }

    dec := c.decrypt(&enc) or (err) {
        println("解密失败: " + err.msg())
        << 1
    }
    assert(dec == block)
    println("单块加解密验证成功")
    << 0
}

2. 搭配 #crypto/cipher 进行变长 AES-CBC + PKCS#7 填充加密

Xu示例
@main
#crypto/aes
#crypto/cipher

fn main() int {
    key := "my-secret-key-16" // 16 字节密钥
    iv := "1234567890123456"  // 16 字节初始向量
    c := aes.new_cipher(&key) or (err) { << 1 }

    // 任意长度的业务数据（自动 PKCS#7 填充并分块加密）
    msg := "Xu systems language provides supersonic native AES encryption."
    enc := cipher.encrypt_cbc_pkcs7(&c, &iv, &msg) or (err) { << 1 }
    dec := cipher.decrypt_cbc_pkcs7(&c, &iv, &enc) or (err) { << 1 }

    assert(dec == msg)
    println("CBC PKCS#7 解密还原成功")
    << 0
}
