拆分并拼接文本

使用 strings 清理文本两端空白、按分隔符拆分，再拼接结果。

trim_space 与 split 借用输入；返回值由调用方持有。

将完整程序保存为 main.xu，在本机运行 xu run main.xu。

@main
#strings

fn main() {
    raw := "  xu,docs  "
    clean := strings.trim_space(&raw)
    parts := strings.split(&clean, ",")
    println(strings.join(parts, " / "))
}

预期输出：xu / docs。
