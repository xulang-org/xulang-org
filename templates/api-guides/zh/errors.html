为错误补充上下文

使用 errors 创建错误值，并为错误消息添加上下文。

wrap 将原因保存为消息文本；is_err 比较文本链，不判断对象身份或具体类型。

将完整程序保存为 main.xu，在本机运行 xu run main.xu。

@main
#errors

fn main() {
    cause := errors.new("missing file")
    wrapped := errors.wrap("load config", errors.Error(cause))
    println(wrapped.msg())
    target := errors.new("missing file")
    println(errors.is_err(errors.Error(wrapped), errors.Error(target)))
}

预期依次输出：load config: missing file 与 true。
