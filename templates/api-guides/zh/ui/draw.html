显式 Context / Frame 绘图，支持路径、渐变、文字、图像、DisplayList、Surface 和缓存。画布默认不平移；set_pan_enabled(1) 显式启用相机。Frame.scale 使用比例，包级 scale 使用百分比。push / pop 必须配对；资源活到 present / freeze / snapshot 接受后再释放。

绘图与游戏引擎边界

这是面向桌面工具、编辑器和小型原型的二维绘图层。平台后端使用 CoreGraphics、Cairo 和 GDI+；公共 API 没有提供游戏引擎所需的 GPU 渲染管线、着色器、绘制批处理和显示同步的帧调度契约。DisplayList 与 Surface 缓存可复用工作，但不能据此宣称达到游戏帧耗时预算；应按实际负载在目标平台测量。
