Button、Checkbox、Progress、Scroll、Input / TextArea 与保留 View。Styles 提供字体、密度、颜色、几何和组合状态规则；StyledLabel 缓存排版。局部主题是完整快照。set_style_measure 注册测量，文字变化后 mark_measure；layout_styled 后 place_editor，再 present_styled。样式回调借用主题，使用节点局部坐标，不能修改 View 或拓扑。

使用指南与生命周期

扩展控件与统一样式切换

Switch、Radio、Slider、Stepper、Tabs、Select、Badge、Divider、Card 与 ListBox 共享 Styles、组合状态绘制规则、阴影及图标位置。使用 widgets.style_switcher() 创建深色、浅色和高对比预设；调用 use_preset、set_text_scale、set_density 后，通过 apply 应用到保留 View，或用 cycle 切换并应用下一预设。这些方法可能失败，须处理错误。View 接收完整样式快照，控件的显式覆盖继续生效。

正式版示例（完整工程与源码下载）：widgets · editor_workbench · style_gallery · controls_gallery

将统一样式应用到保留 View：

@main
#ui/widgets

fn configure(view &mut widgets.View) int {
    mut themes := widgets.style_switcher()
    themes.use_preset(widgets.THEME_LIGHT) or >>
    themes.set_text_scale(1.2) or >>
    themes.set_density(0.85) or >>
    themes.apply(view) or >>
    // Call this from a theme-switch action to advance and apply the preset.
    themes.cycle(view) or >>
    << 0
}

组件工作坊：图文按钮、Tooltip 与密码

component_workshop 完整工程与源码提供 46 个入口，可切换主题、密度、100%/140%/200% 字号以及禁用、只读和错误状态。需要与源码配套的 Xu 0.10.11；Windows/Linux 的交叉构建不等于目标机器 GUI 验收。

Screen.button_with_icon() 创建图文按钮，icon_button() 创建纯图标按钮。每个按钮保存自己的样式快照；分别设置 icon_size 和 ICON_LEADING/TRAILING/ABOVE/BELOW，再用 measure_button() 获取内容尺寸并放置，避免示例按钮占满整行。资源随 --www 嵌入，下面的代码需要 www/logo.png。

Tooltip 默认上方居中；set_tooltip_placement() 设置四方向和边缘翻转。普通悬停约 500 ms 显示，键盘或显式焦点立即显示；移出、点击或滚动时收起。Escape 抑制当前这一轮提示，离开重入或重新聚焦后恢复。完全滚出裁剪区域的锚点不显示提示。

password_input() 是单行 Input 的真实密码模式，每个 Unicode 字素对应一个圆点。set_password_visible() 显隐切换保留值和选择；支持粘贴，显文时也禁止复制和剪切。原生周围文字查询和 XACP 节点文本不返回密码；text_value() 仍为应用返回实际值。应用应自行管理值的保存和日志，不应将掩码误认为内存加密。

@main
#ui/widgets

fn configure(screen &mut widgets.Screen, styles &widgets.Styles) int {
    button := screen.button_with_icon("logo.png", "Build project") or >>
    mut appearance := styles.button_variant(widgets.BUTTON_PRIMARY) or >>
    appearance.icon_placement = widgets.ICON_ABOVE
    appearance.icon_size = 32.0 * styles.text_scale
    screen.set_control_style(button, &appearance) or >>
    size := screen.measure_button(button) or >>
    screen.place(button, 24.0, 24.0, size.width, size.height) or >>
    tip := screen.tooltip(button, "Build project") or >>
    mut placement := widgets.overlay_placement()
    placement.side = widgets.OVERLAY_RIGHT
    placement.align = widgets.OVERLAY_CENTER
    screen.set_tooltip_placement(tip, &placement) or >>
    password := screen.password_input("") or >>
    screen.place(password, 24.0, 160.0, 320.0, 48.0) or >>
    << 0
}
