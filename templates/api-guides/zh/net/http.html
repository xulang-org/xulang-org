提供文本响应

使用 net/http 在请求处理函数中返回 HTTP 文本响应。

此原生示例监听本机回环地址；按 Ctrl-C 停止。在另一终端运行 curl http://127.0.0.1:8080/。

将完整程序保存为 main.xu，在本机运行 xu run main.xu。

@main
#net/http

fn hello(c http.Context) {
    c.text(200, "hello\n") or (err) {
        println(err.msg())
        <<
    }
}

fn main() int {
    http.listen_and_serve_handler("127.0.0.1:8080", hello) or (err) {
        println(err.msg())
        << 1
    }
    << 0
}

预期响应正文：hello，末尾有换行。

服务端在连接接收、缓冲区和超时限额内并发派发完整请求。处理器可以重叠执行，共享可变状态须同步，并显式传递请求所有权。使用 server_options() 获取默认值，通过 serve_with_options 配置限额；响应短写会重试，空闲或不完整请求不会无限占用处理器。
