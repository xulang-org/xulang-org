通过 SQLite 插入一行

使用 database/sql 配合具体驱动管理连接池并执行 SQL。

open 接收驱动对象与该驱动解释的 DSN，首次操作时才打开连接。此例使用 SQLite 内存数据库，处理操作错误，并显式关闭连接池。

前提：准备官方 packages 源码，并为目标平台构建 SQLite 原生桥。在工程的 xu.xun 中加入以下依赖，将路径替换为该源码目录：

require:
  "github.com/xulang-org/packages": file:/path/to/packages

服务端驱动与 DSN 参见 MySQL 快速示例；此处 MySQL 服务集成：待验。

将完整程序保存为 main.xu，用 xu check main.xu 检查。原生静态库的一步链接支持 macOS arm64/x64，可在这些目标上使用 xu run main.xu；Linux 需要输出对象文件后另行链接。此例已通过 SDK 检查；原生执行：待验。

@main
#database/sql
sqlite #github.com/xulang-org/packages/sqlite

fn main() int {
    $db := sql.open(sqlite.driver(), ":memory:")
    db.exec("CREATE TABLE notes (body TEXT)") or (err) {
        println(err.msg())
        << 1
    }
    result := db.exec("INSERT INTO notes VALUES ('hello')") or (err) {
        println(err.msg())
        << 1
    }
    println(result.rows_affected())
    db.close() or (err) {
        println(err.msg())
        << 1
    }
    << 0
}

预期输出：1（插入行数）。
