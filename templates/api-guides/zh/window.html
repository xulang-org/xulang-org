窗口生命周期与事件循环

#window 提供轻量化窗口创建、生命周期管理与输入事件轮询（键盘、指针、滚轮、文本/IME）。跨平台事件结构体与常量定义在纯 Xu 包 window/events 中。

每个主循环帧调用 window.pump() 抽取系统事件，并对各窗口调用 target.poll() 消耗事件直至 EVENT_NONE。窗口关闭请求通过 state().close_requested 捕获。

@main
#window
#window/events

fn main() {
    options := window.Options{
        title: "Hello Window",
        width: 640,
        height: 360,
        resizable: true,
        high_pixel_density: true,
        hidden: false,
    }
    $target := window.open(&options) or {
        println("Failed to open window")
        return
    }
    println("Window opened: id=", target.id())
    window.pump() or >>
    state := target.state() or >>
    println("Window size:", state.logical_width, "x", state.logical_height)
    target.close() or >>
}

预期输出包含窗口 ID 与初始逻辑分辨率尺寸。
