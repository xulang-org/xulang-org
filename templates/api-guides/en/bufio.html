Read lines through EOF

Use bufio to read buffered lines from an owned in-memory io.Buffer.

The buffer moves into the reader. read_line removes LF or CRLF, returns the final unterminated line, then throws EOF when no data remains; other errors exit with status 1.

Save the complete program as main.xu and run xu run main.xu locally.

@main
#bufio
#io

fn main() int {
    $reader := bufio.new_reader(io.buffer_from("first\nlast"))
    while true {
        line := reader.read_line() or (err) {
            if err.msg() == "EOF" { << 0 }
            println(err.msg())
            << 1
        }
        println(line)
    }
    << 0
}

Expected output: first, then last.
