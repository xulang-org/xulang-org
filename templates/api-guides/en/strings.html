Split and join text

Use strings to trim text, split it into fields and join the result.

The input is borrowed by trim_space and split; their results are owned values.

Save the complete program as main.xu and run xu run main.xu locally.

@main
#strings

fn main() {
    raw := "  xu,docs  "
    clean := strings.trim_space(&raw)
    parts := strings.split(&clean, ",")
    println(strings.join(parts, " / "))
}

Expected output: xu / docs.
