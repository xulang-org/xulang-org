Serve a text response

Use net/http to serve an HTTP text response from a request handler.

This native example listens on loopback; stop it with Ctrl-C. In another terminal run curl http://127.0.0.1:8080/.

Save the complete program as main.xu and run xu run main.xu locally.

@main
#net/http

fn hello(c http.Context) {
    c.text(200, "hello\n") or (err) {
        println(err.msg())
        <<
    }
}

fn main() int {
    http.listen_and_serve_handler("127.0.0.1:8080", hello) or (err) {
        println(err.msg())
        << 1
    }
    << 0
}

Expected response body: hello followed by a newline.

Servers dispatch complete requests concurrently with bounded connection intake, buffers and timeouts. Handlers may overlap; synchronize shared mutable state and transfer request ownership explicitly. Use server_options() for defaults and serve_with_options to configure limits. Short response writes are retried. Idle or incomplete requests do not occupy a handler indefinitely.
