Insert a row with SQLite

Use database/sql with a concrete driver to manage a connection pool and execute SQL.

open takes a driver object and a driver-specific DSN; it opens connections lazily. This example uses SQLite in memory, checks operation errors and closes the pool explicitly.

Prerequisite: use the official packages checkout and build the SQLite native bridge for your target. Add this dependency to your project’s xu.xun, replacing the path with that checkout:

require:
  "github.com/xulang-org/packages": file:/path/to/packages

See the MySQL quickstart for a server-backed driver and its DSN. MySQL service integration here: 待验 (not verified).

Save the complete program as main.xu and check it with xu check main.xu. One-step linking of native static libraries is supported on macOS arm64/x64, where you can use xu run main.xu; Linux requires object emission and a separate linker step. This example passed the SDK check; native execution is 待验 (not verified).

@main
#database/sql
sqlite #github.com/xulang-org/packages/sqlite

fn main() int {
    $db := sql.open(sqlite.driver(), ":memory:")
    db.exec("CREATE TABLE notes (body TEXT)") or (err) {
        println(err.msg())
        << 1
    }
    result := db.exec("INSERT INTO notes VALUES ('hello')") or (err) {
        println(err.msg())
        << 1
    }
    println(result.rows_affected())
    db.close() or (err) {
        println(err.msg())
        << 1
    }
    << 0
}

Expected output: 1 (the inserted row count).
