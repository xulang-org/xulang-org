GPU device and buffer transfer

#gpu provides low-level device, buffer, texture, and command recording abstractions in the Xu standard library. It supports windowless devices, buffers, 2D textures and mips, samplers, shaders, graphics and compute pipelines, command encoders, fence synchronization, and byte readback.

All GPU resources support explicit idempotent close and automatic drop. Keep devices, resources, and borrows on the main thread; texture formats and layout rules are defined in gpu/layout.

@main
#gpu

fn main() {
    $device := gpu.open(gpu.DeviceOptions{backend: gpu.AUTO, debug: false, shader_formats: 0}) or {
        println("GPU backend unavailable")
        return
    }
    $buffer := device.buffer(4, gpu.BUFFER_VERTEX) or >>
    input := [u8(0), u8(127), u8(128), u8(255)]
    device.upload(&buffer, 0, &input) or >>
    $result := device.download(&buffer, 0, 4) or >>
    result.wait() or >>
    $output := [u8(0), u8(0), u8(0), u8(0)]
    result.read($&output) or >>
    println("downloaded byte:", output[3])
}

Expected output: downloaded byte: 255.
