Button, Checkbox, Progress, Scroll, Input / TextArea and retained View. Styles provides fonts, density, palettes, geometry and combined-state rules; StyledLabel caches layout. Local themes are complete snapshots. Register measurement with set_style_measure, call mark_measure after text changes, then layout_styled, place_editor and present_styled. Callbacks borrow themes, use node-local coordinates and must not mutate View or topology.

Usage and lifetimes

Extended controls and style switching

Switch, Radio, Slider, Stepper, Tabs, Select, Badge, Divider, Card and ListBox share Styles, combined-state paint rules, shadows and icon placement. Create widgets.style_switcher() to select dark, light or contrast presets. Use use_preset, set_text_scale and set_density, then apply to the retained View; cycle advances and applies a preset. These methods can fail, so handle their errors. Each View receives a complete style snapshot; explicit control overrides remain in effect.

Release examples (complete projects and source downloads): widgets · editor_workbench · style_gallery · controls_gallery

Apply shared styles to a retained View:

@main
#ui/widgets

fn configure(view &mut widgets.View) int {
    mut themes := widgets.style_switcher()
    themes.use_preset(widgets.theme_light) or >>
    themes.set_text_scale(1.2) or >>
    themes.set_density(0.85) or >>
    themes.apply(view) or >>
    // Call this from a theme-switch action to advance and apply the preset.
    themes.cycle(view) or >>
    << 0
}
