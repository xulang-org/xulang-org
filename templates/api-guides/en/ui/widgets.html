Button, Checkbox, Progress, Scroll, Input / TextArea and retained View. Styles provides fonts, density, palettes, geometry and combined-state rules; StyledLabel caches layout. Local themes are complete snapshots. Register measurement with set_style_measure, call mark_measure after text changes, then layout_styled, place_editor and present_styled. Callbacks borrow themes, use node-local coordinates and must not mutate View or topology.

Usage and lifetimes

Extended controls and style switching

Switch, Radio, Slider, Stepper, Tabs, Select, Badge, Divider, Card and ListBox share Styles, combined-state paint rules, shadows and icon placement. Create widgets.style_switcher() to select dark, light or contrast presets. Use use_preset, set_text_scale and set_density, then apply to the retained View; cycle advances and applies a preset. These methods can fail, so handle their errors. Each View receives a complete style snapshot; explicit control overrides remain in effect.

Release examples (complete projects and source downloads): widgets · editor_workbench · style_gallery · controls_gallery

Apply shared styles to a retained View:

@main
#ui/widgets

fn configure(view $&widgets.View) int {
    $themes := widgets.style_switcher()
    themes.use_preset(widgets.THEME_LIGHT) or >>
    themes.set_text_scale(1.2) or >>
    themes.set_density(0.85) or >>
    themes.apply(view) or >>
    // Call this from a theme-switch action to advance and apply the preset.
    themes.cycle(view) or >>
    << 0
}

Component workshop: icon buttons, tooltips and passwords

The complete component_workshop project and source provide 46 entries with themes, density, 100%/140%/200% text, disabled, read-only and invalid states. Use the matching Xu 0.10.11 SDK. A successful Windows/Linux cross build does not establish target-machine GUI acceptance.

Screen.button_with_icon() creates an icon-and-text button; icon_button() creates an icon-only button. Each button owns its style snapshot. Set its own icon_size and ICON_LEADING/TRAILING/ABOVE/BELOW, then use measure_button() to place it at its content size. Embed resources with --www; the code below requires www/logo.png.

Tooltips default to top/center. set_tooltip_placement() selects a side with edge flipping. Ordinary pointer hover shows help after about 500 ms; keyboard or explicit focus shows it immediately. Leaving, clicking or scrolling dismisses it. Escape suppresses the current interaction until re-entry or refocus. Anchors fully outside their scroll clip do not show a tooltip.

password_input() enables a real single-line password Input, with one bullet per Unicode grapheme. set_password_visible() preserves value and selection. Paste works; copy and cut remain blocked when revealed. Native surrounding-text queries and XACP node text do not return the password. text_value() still returns the application value, so applications must manage storage and logging; masking does not encrypt memory.

@main
#ui/widgets

fn configure(screen $&widgets.Screen, styles &widgets.Styles) int {
    button := screen.button_with_icon("logo.png", "Build project") or >>
    $appearance := styles.button_variant(widgets.BUTTON_PRIMARY) or >>
    appearance.icon_placement = widgets.ICON_ABOVE
    appearance.icon_size = 32.0 * styles.text_scale
    screen.set_control_style(button, &appearance) or >>
    size := screen.measure_button(button) or >>
    screen.place(button, 24.0, 24.0, size.width, size.height) or >>
    tip := screen.tooltip(button, "Build project") or >>
    $placement := widgets.overlay_placement()
    placement.side = widgets.OVERLAY_RIGHT
    placement.align = widgets.OVERLAY_CENTER
    screen.set_tooltip_placement(tip, &placement) or >>
    password := screen.password_input("") or >>
    screen.place(password, 24.0, 160.0, 320.0, 48.0) or >>
    << 0
}
