0.11.4 parsing and serialization

Typed block lists inherit their scalar type, validate each element and preserve container/element tags when serialized. Safe homogeneous non-string scalar lists can use compact output; string lists retain block output. Serialization spelling may change: update text snapshots or compare parsed trees when spelling is not contractual. Legacy nonempty !s[...] scalar input remains accepted.

Collection nesting below the root is bounded by MAX_DEPTH (64), including inline, empty and typed containers. Duration validation rejects malformed or unitless input and always advances. Multiline parsing checks structural indentation separately from payload whitespace.
