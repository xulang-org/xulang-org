Add context to an error

Use errors to create error values and add context to their messages.

wrap stores the cause as message text; is_err compares that text chain, without checking object identity or concrete type.

Save the complete program as main.xu and run xu run main.xu locally.

@main
#errors

fn main() {
    cause := errors.new("missing file")
    wrapped := errors.wrap("load config", errors.Error(cause))
    println(wrapped.msg())
    target := errors.new("missing file")
    println(errors.is_err(errors.Error(wrapped), errors.Error(target)))
}

Expected output: load config: missing file, then true.
