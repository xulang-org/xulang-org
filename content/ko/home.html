AI 추론 가이드

초고속 네이티브 AOT 및 WASM

VM 없이 런타임 오버헤드를 제거했습니다. macOS, Linux, Windows, WebAssembly로 직접 컴파일하여 밀리초 미만의 콜드 스타트를 제공합니다.

제로 코스트 소유권과 RAII

GC 멈춤이 없습니다. 고유 소유권과 스코프 종료 시 결정론적 해제, 공유(&T) 및 배타적($&T) 대여 검사로 데이터 경합을 정적으로 방지합니다.

M:N 멀티코어 코루틴과 채널

xu f()로 경량 코루틴을 생성하고 Linux/macOS M:N 스케줄러 및 #sync/pool로 확장하며 타입 안전한 chan T로 안전하게 동기화합니다.

간결하고 표현력 있는 문법

세미콜론 없이 기본 불변성을 따릅니다. << 반환, >> 던지기, >>> 전파, >>> (err) {} 처리, <- break, -> continue로 흐름이 선명합니다.

올인원 표준 및 확장 도구 체인

빌드, 테스트, 의존성 관리(get), lsp, C 모듈(native)을 단일 xu CLI에 통합했습니다. 비동기 HTTP, 암호학, SQL, AI/GPU 패키지까지 포괄합니다.

결정론적 안전성과 UB 제거

C/C++의 암묵적 미정의 동작(UB)을 제거하고 컴파일 타임 null 안전성, 범위 검사 및 명시적 오류 전파로 견고한 시스템 소프트웨어를 보장합니다.

네이티브 데스크톱 UI 및 WebView

내장 2D 드로잉, 레이아웃, 네이티브 위젯, 테마, IME 입력과 함께 데스크톱 앱을 위한 WebView 통합을 제공합니다.

통합 CLI 및 에디터 지원

단일 xu 명령으로 빌드, 실행, 검사, 포매팅, 문서 생성이 가능하며 내장 테스트 러너와 LSP를 지원합니다.

C 상호운용과 네이티브 모듈

xu native로 C 모듈을 컴파일하고 다중 타겟 슬라이스를 포함한 이식형 .xulib 번들로 배포할 수 있습니다.

Frequently Asked Questions (FAQ)

What is the Xu programming language?

Xu is a statically typed systems language that compiles ahead of time to native code. It combines ownership and borrow checking with lightweight coroutines and typed channels, powering high-concurrency network services, native desktop applications, and unhosted bare-metal operating system kernels.

Does Xu use a garbage collector (GC)?

No. Compile-time ownership and borrow checking govern resource lifetimes, with deterministic cleanup at scope exit and no runtime garbage collector. See Ownership & Borrowing and the FAQ on shared-state synchronization and native/FFI safety boundaries.

Does Xu support native desktop UI?

Yes. The SDK includes native drawing, layout, controls, and desktop services, plus WebView for HTML/CSS/JavaScript interfaces. Native controls need no web page. See the UI FAQ and UI guide for capabilities and platform requirements.
