Leitfaden zur KI-Inferenz

Natives AOT und WebAssembly

Ohne VM und Laufzeit-Overhead. Kompiliert direkt in nativen Maschinencode und Standard-WASM für macOS, Linux und Windows mit Sub-Millisekunden-Kaltstart.

Eigentum ohne Laufzeitkosten & RAII

Keine GC-Pausen. Eindeutiges Eigentum mit deterministischer Freigabe am Bereichsende; geteilte (&T) und exklusive ($&T) Ausleihen verhindern Data Races statisch.

M:N Multi-Core-Coroutinen & Kanäle

Starten Sie Coroutinen via xu f(), skalieren Sie über den Linux/macOS M:N-Scheduler und #sync/pool auf mehrere Kerne und synchronisieren Sie per chan T.

Klare und ausdrucksstarke Syntax

Keine Semikolons, standardmäßig unveränderlich. Klare Kontrollsymbole: << return, >> throw, >>> propagate, >>> (err) {} catch, <- break und -> continue.

Frequently Asked Questions (FAQ)

What is the Xu programming language?

Xu is a statically typed systems language that compiles ahead of time to native code. It combines ownership and borrow checking with lightweight coroutines and typed channels for command-line tools, network services, and desktop applications.

Does Xu use a garbage collector (GC)?

No. Compile-time ownership and borrow checking govern resource lifetimes, with deterministic cleanup at scope exit and no runtime garbage collector. See Ownership & Borrowing and the FAQ on shared-state synchronization and native/FFI safety boundaries.

Does Xu support native desktop UI?

Yes. The SDK includes native drawing, layout, controls, and desktop services, plus WebView for HTML/CSS/JavaScript interfaces. Native controls need no web page. See the UI FAQ and UI guide for capabilities and platform requirements.
