Supersonic Native AOT & WASM

Zero VM, zero runtime bloat. Directly compiles to native machine binaries and standard WebAssembly (WASM). First-class cross-compilation (macOS, Linux, Windows, WASM) and sub-millisecond cold start.

Zero-Cost Ownership & RAII

No Stop-The-World GC pauses. Unique ownership with deterministic RAII scoping drop; shared &T and exclusive &mut T borrow semantics statically eliminate data races.

Native Coroutines & Channels

First-class language-level concurrency. Spawn lightweight user-space coroutines via xu f() and coordinate across type-safe chan T pipelines, designed for high-throughput modern servers.

Clean & Expressive Syntax

No semicolons, no redundant parens, immutable by default. Intuitive flow symbols: << return, >>> throw, >>> (err) {} catch, <- break, and -> continue for clear readability.

Batteries-Included Toolchain

Unified xu CLI for builds, tests, dependency management (get), editor services (lsp), and C modules (native) with native xu.xun manifests. Rich standard library covering async net/HTTP, cryptography & SM cipher suites, SQL, and desktop WebView.

Deterministic Safety & Zero UB

Eradicate C/C++ silent Undefined Behavior (UB). Strict compile-time null safety, memory bounds checking, and explicit error propagation ensure rock-solid, predictable systems software.

Native Desktop UI & WebView

Built-in 2D drawing, layouts, native widgets, theming, and IME input, alongside HTML/CSS/JavaScript WebView integration for desktop applications.

Unified Tooling & Editor Support

A single xu command line tool for build, run, check, format, and docs with built-in test runners and LSP support for modern editors.

C Interoperability & Native Modules

Compile and package C modules with xu native, using portable .xulib distribution bundles with multi-target slices.

Frequently Asked Questions (FAQ)

What is the Xu programming language?

Xu is a statically typed systems language that compiles ahead of time to native code. It combines ownership and borrow checking with lightweight coroutines and typed channels for command-line tools, network services, and desktop applications.

Does Xu use a garbage collector (GC)?

No. Compile-time ownership and borrow checking govern resource lifetimes, with deterministic cleanup at scope exit and no runtime garbage collector. See Ownership & Borrowing and the FAQ on shared-state synchronization and native/FFI safety boundaries.

Does Xu support native desktop UI?

Yes. The SDK includes native drawing, layout, controls, and desktop services, plus WebView for HTML/CSS/JavaScript interfaces. Native controls need no web page. See the UI FAQ and UI guide for capabilities and platform requirements.
