Легковесные корутины и каналы

Встроенное ключевое слово xu запускает корутины, а типизированные каналы chan обеспечивают надёжную передачу сообщений в стиле CSP.

Единый монолитный инструментарий

Сборка, запуск, форматирование, тесты, генерация документации и поддержка языкового сервера (LSP) встроены в один бинарный файл xu.

Почувствуйте язык в действии

@main
#errors

fn fetch_metric(task string) int {
    if task.len == 0 { >> errors.new("empty task name") }
    << task.len * 42
}

fn worker(task string, ch chan int) {
    val := fetch_metric(task) >>> (err) { << }
    ch <- val
}

fn main() int {
    ch := chan int{cap: 2}
    xu worker("latency", ch)
    xu worker("memory", ch)
    println(<-ch + <-ch)
    << 0
}

Часто задаваемые вопросы (FAQ)

Что такое язык программирования Xu?

Xu — это современный системный язык программирования без сборщика мусора (Zero-GC), разработанный для высоконагруженных и низколатентных сервисов. Он объединяет интуитивный синтаксис, вывод владения во время компиляции, нативную AOT-компиляцию и встроенную конкурентность в стиле CSP.

Использует ли Xu сборщик мусора (GC)?

Нет, в Xu полностью отсутствует сборщик мусора (Zero-GC). Управление памятью основывается на выводе владения и проверке заимствований (Ownership & Borrowing) во время компиляции с детерминированным освобождением ресурсов при выходе из области видимости. См. раздел Владение и заимствование и FAQ по синхронизации и безопасности FFI.

Поддерживает ли Xu нативный настольный UI?

Да. SDK включает нативную отрисовку, макеты, элементы управления и системные службы, а также компонент WebView для интерфейсов на HTML/CSS/JS. Нативным элементам управления не требуется веб-страница. См. FAQ по UI и руководство по UI.
