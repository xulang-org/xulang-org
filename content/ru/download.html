Установка и восстановление: Следующие команды подходят для чистой установки, обновления или восстановления поврежденных файлов. По умолчанию обновляется SDK в переменной PATH; если он не найден, установка производится в ~/.xu. Прежний SDK сохраняется в резервной копии, а замена завершается только после полной верификации.

Команды установки

macOS / Linux

curl -fsSL https://xulang.org/install.sh | bash -s -- --online --version {{xu_version}} --yes

Windows PowerShell

& ([scriptblock]::Create((irm https://xulang.org/install.ps1))) -Online -Version "{{xu_version}}"

Границы возможностей платформ

Генерация кода, загрузка архивов SDK и проверенное поведение в среде выполнения — это разные уровни готовности. Выбирайте SDK, соответствующий вашей рабочей системе; генерация кода под другую платформу не гарантирует работу сети, системных библиотек или GUI на целевой машине. Пути без записи о прохождении приемочных тестов считаются экспериментальными. См. Состояние и ограничения.

WebAssembly: Нативный SDK компилирует модули WASI командой xu build app.xu --target wasm32-wasi -o app.wasm. Онлайн-песочница в браузере работает на интерпретаторе WASM, собранном компилятором Xu {{playground_version}}. Нативные сокеты, библиотеки C, процессы и хост системного WebView требуют нативного SDK.

Локальные задачи: Раздел Матрица интеграций разделяет поддержку протоколов, аутентификации, TLS и непроверенные платформы. Для SQLite требуется соответствующий C-мост и тулчейн C; прямой путь сборки доступен на macOS ARM64 / x64. Нативный UI / WebView требует наличия системных библиотек и валидации на реальном оборудовании.

Установка и запуск

Для быстрой установки и автоматической регистрации переменных окружения рекомендуется использовать нативные установщики Setup:

  • Windows: Скачайте xu-setup-windows-x64.exe (или xu-v{{xu_version}}-windows-x64-setup.exe) и запустите двойным кликом (автономный графический мастер, не требует правки политик PowerShell, настраивает переменные PATH и XU_ROOT в реестре пользователя).
  • macOS: Загрузите xu-v{{xu_version}}-macos-arm64.pkg для установки через стандартный мастер macOS или скачайте xu-setup-macos-arm64 (запуск в терминале ./xu-setup-macos-arm64 -y).
  • Linux: Скачайте xu-setup-linux-x64 (или arm64), выдайте права на исполнение и запустите ./xu-setup-linux-x64 -y для автоматической распаковки и настройки PATH.

После установки откройте новое окно терминала для проверки:

xu --version
xu build hello.xu --output hello
./hello
