Нативные модули и взаимодействие с C (FFI)

Интероперабельность с C/C++ с нулевой стоимостью: прямой вызов внешних функций, линковка статических библиотек и безопасные заимствованные срезы.

Прямой вызов C-функций

Функции на C объявляются с префиксом extern:

extern fn puts(str &byte) int
extern fn getpid() int

@main
#fmt

fn main() int {
    pid := getpid()
    fmt.println("PID процесса: " + pid.to_string())
    << 0
}

Безопасные заимствованные диапазоны памяти (ABI xu-c-2)

Xu поддерживает передачу непрерывных срезов памяти &[]int и $&[]int в C-функции без копирования буферов и с сохранением гарантий безопасности памяти.
