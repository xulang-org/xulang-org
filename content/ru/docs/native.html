Нативные модули и взаимодействие с C (FFI)

Интероперабельность с C/C++ с нулевой стоимостью: прямой вызов внешних функций, линковка статических библиотек и безопасные заимствованные срезы.

Два взаимодополняющих подхода: extern "C" и xu native

В Xu одновременно поддерживаются два взаимодополняющих механизма взаимодействия с C: прямой FFI (extern "C" + #ffi) и статические нативные модули (xu native + include/xu_native.h):

Критерийextern "C" + #ffi (прямой FFI)xu native + include/xu_native.h (статический модуль)
Основной сценарийПрямой вызов готовых системных и сторонних динамических библиотек (libc, libsqlite3, libSDL3, GPU/AI)Упаковка собственного C / C++ / Objective-C кода в статический архив .a или кроссплатформенный контейнер .xulib
Накладные расходыОтдельный C-адаптер не требуется — достаточно объявить сигнатуру в XuТребуется тонкий C-мост и JSON-манифест, собираемые через xu native
Граница безопасностиВызовы выполняются внутри unsafe { }; указатели c_ptr контролирует вызывающая сторонаНа стороне Xu не требуется unsafe; xu-c-2 передаёт заимствованные срезы без копирования (&[]int / $&[]int / &[]u8 / $&[]u8) с защитой COW
Линковка и доставкаОбычно загружается динамически (через dlopen) и зависит от окружения целевой машиныСтатическая линковка в итоговый артефакт; .xulib включает срезы для разных платформ (включая iOS / Android) и проверку SHA-256
Возможности и инструментыПоддержка @repr("C"), c_callback, variadic-функций и любых C-структур через #ffiКонтролируемый ABI для скаляров и заимствованных span-срезов через bin/xu-native и include/xu_native.h
  • Готовые системные или динамические C-библиотеки → используйте extern "C" + #ffi.
  • Собственные мосты на C / C++ / ObjC, безопасные zero-copy срезы без unsafe или распространение в формате .xulib → используйте xu native + include/xu_native.h.

Прямой вызов C-функций

Функции на C объявляются с префиксом extern:

extern fn puts(str &byte) int
extern fn getpid() int

@main
#fmt

fn main() int {
    pid := getpid()
    fmt.println("PID процесса: " + pid.to_string())
    << 0
}

Безопасные заимствованные диапазоны памяти (ABI xu-c-2)

Xu поддерживает передачу непрерывных срезов памяти &[]int и $&[]int в C-функции без копирования буферов и с сохранением гарантий безопасности памяти.
