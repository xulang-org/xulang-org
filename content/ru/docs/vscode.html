Поддержка VS Code и Cursor

Официальное расширение vscode-xu для сред Visual Studio Code и Cursor.

Возможности

  • Семантическая подсветка синтаксиса Xu.
  • Языковой сервер (LSP): автодополнение кода, проверка типов на лету, всплывающие подсказки с документацией.
  • Переход к определению (Go to Definition) и поиск ссылок (Find References).
  • Форматирование при сохранении (Format on Save) через утилиту xu fmt.
  • Интеграция с отладчиком DWARF через команду xu debug.

Установка

Найдите расширение Xu Language Support в Marketplace VS Code или установите пакет .vsix из официального релиза.
