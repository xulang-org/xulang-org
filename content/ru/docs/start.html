Быстрый старт

Официальное руководство по началу работы с Xu {{xu_version}} · Современный системный язык без сборщика мусора (Zero-GC) · Статическая AOT-компиляция · Владение и заимствования · Интегрированный инструментарий

Xu — это современный высокопроизводительный язык системного программирования без сборщика мусора (GC-free). Он сочетает лаконичный и понятный синтаксис, детерминированную проверку владения и заимствований на этапе компиляции и быструю статическую AOT-компиляцию в машинный код. Исходные файлы Xu кодируются в UTF-8 и имеют расширение .xu.

Конвейер быстрого старта из 4 шагов
Стандартизированный рабочий процесс: от установки SDK до написания кода, тестирования и сборки релиза
1
Установка SDK и проверка среды
Используйте быструю установку или скачайте компилятор, затем выполните xu --version. Либо откройте онлайн-песочницу в браузере.
2
Инициализация манифеста и проекта
Создайте папку проекта и выполните xu init myapp, что создаст файлы xu.xun и main.xu.
3
Написание логики и точки входа
Укажите аннотацию @main на первой строке, подключите стандартные модули #fmt и пишите код.
4
Запуск, тестирование и сборка
xu run . для быстрого запуска · xu test для автотестов · xu build . для релизного бинарника.

1. Установка и настройка окружения

Установите официальный SDK Xu с помощью команды для вашей операционной системы:

macOS / Linux

curl -fsSL https://xulang.org/install.sh | bash

Windows (PowerShell)

irm https://xulang.org/install.ps1 | iex

2. Первая программа: Hello World

Создайте файл main.xu со следующим содержимым:

@main
#fmt

fn main() int {
    fmt.println("Hello, World! Добро пожаловать в Xu.")
    << 0
}

Запустите файл напрямую через компилятор:

xu run main.xu

3. Компиляция в нативный бинарный файл

Выполните статическую AOT-компиляцию:

xu build main.xu -o myapp
./myapp

Скомпилированный файл не требует виртуальных машин, интерпретаторов или внешних рантаймов.
