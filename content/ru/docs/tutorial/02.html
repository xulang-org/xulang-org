02 · Переменные и константы

По умолчанию все привязки неизменяемы. Для изменяемых переменных используйте префикс $. Константы объявляются в UPPER_SNAKE_CASE.

@main
#fmt

const MAX_RETRIES = 3

fn main() int {
    name := "Xu"          // Неизменяемая переменная
    $count := 0           // Изменяемая переменная ($)
    count = count + 1

    fmt.println(name)
    fmt.println(count)
    << 0
}

Ключевые правила

  • x := 10: неизменяемая переменная. Повторное присваивание вызовет ошибку компиляции.
  • $x := 10: объявление изменяемой переменной. После объявления префикс $ не пишется: x = 20.
  • const VALUE = 42: константа времени компиляции.
