06 · Владение и заимствование

В Xu отсутствует сборщик мусора (Zero-GC). Передача структуры или строки по значению перемещает владение. Разделяемые ссылки &T позволяют читать данные, а изменяемые ссылки $&T позволяют их модифицировать.

@main
#fmt

fn inspect(s &string) {
    fmt.println("Длина строки: " + s.len.to_string())
}

fn modify(s $&string) {
    s.append("!")
}

fn main() int {
    $msg := "Привет, Xu"
    inspect(&msg)
    modify($&msg)
    fmt.println(msg)
    << 0
}
