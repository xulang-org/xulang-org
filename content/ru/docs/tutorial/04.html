04 · Функции и методы

В Xu нет классов: используются структуры struct и привязанные методы. Приёмники по значению копируют или перемещают данные, а приёмники по ссылке (&self или $&self) обеспечивают доступ без лишних аллокаций.

@main
#fmt

struct Counter {
    val int
}

fn (c Counter) get() int {
    << c.val
}

fn (c $&Counter) inc() {
    c.val = c.val + 1
}

fn main() int {
    $c := Counter{val: 0}
    c.inc()
    fmt.println(c.get())
    << 0
}
