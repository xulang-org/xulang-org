01 · Структура программы

Цель

Создайте, проверьте и запустите первую программу на Xu, которая выводит приветствие в консоль.

Исходный код

@main
#fmt

fn main() int {
    fmt.println("Hello, World!")
    << 0
}

Разбор кода

  • @main: объявляет точку входа программы в исполняемый бинарный файл.
  • #fmt: импортирует модуль форматированного вывода стандартной библиотеки.
  • fn main() int: функция main возвращает код завершения типа int.
  • << 0: символьный оператор возврата значения (аналог return 0).

Команды сборки и запуска

xu run main.xu
xu build main.xu -o hello
./hello
