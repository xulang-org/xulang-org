09 · Обобщённое программирование (дженерики)

Xu поддерживает параметрический полиморфизм без искусственных ограничений. Мономорфизация генерирует эффективный машинный код для каждого типа.

@main
#fmt

struct Pair[T] {
    first T
    second T
}

fn (p Pair[T]) get_first() T {
    << p.first
}

fn main() int {
    p := Pair[int]{first: 100, second: 200}
    fmt.println(p.get_first())
    << 0
}
