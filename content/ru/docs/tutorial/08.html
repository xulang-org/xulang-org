08 · Перечисления и сопоставление (match)

Перечисления enum представляют собой размеченные объединения (tagged unions). Конструкция match проверяет все варианты на полноту во время компиляции.

@main
#fmt

enum Status {
    Idle,
    Running(int),
    Failed(string)
}

fn main() int {
    s := Status.Running(42)
    match s {
        Status.Idle => fmt.println("Ожидание")
        Status.Running(pid) => fmt.println("Работает PID: " + pid.to_string())
        Status.Failed(msg) => fmt.println("Сбой: " + msg)
    }
    << 0
}
