03 · Управление потоком выполнения

В условиях if и циклах for круглые скобки не требуются. Диапазоны задаются через .. или ..=. Для выхода из цикла используется <-.

@main
#fmt

fn main() int {
    $score := 85
    if score >= 90 {
        fmt.println("Отлично")
    } else if score >= 80 {
        fmt.println("Хорошо")
    } else {
        fmt.println("Удовлетворительно")
    }

    // Цикл по диапазону
    for i in 0..5 {
        if i == 3 {
            <- // выход из цикла (break)
        }
        fmt.println(i)
    }

    << 0
}

Символы потока управления

  • << value: возврат значения из функции.
  • >>> err: выброс ошибки.
  • <-: выход из текущего цикла (оператор break).
