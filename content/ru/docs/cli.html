Справочник по CLI компилятора

Полный справочник по командам утилиты xu: сборка, запуск, форматирование, тесты, языковой сервер и отладчик.

Основные команды

КомандаСинтаксисОписание
runxu run [файл|папка]Быстрая компиляция во временную память и немедленный запуск.
buildxu build [файл|папка] -o [имя]Статическая AOT-компиляция в нативный бинарный файл.
checkxu check [файл|папка]Проверка типов, владения и заимствований без генерации кода.
testxu test [шаблон]Сборка и выполнение встроенных тестов.
fmtxu fmt [файл|папка]Автоматическое форматирование исходного кода по стандарту Xu.
docxu doc [пакет]Генерация документации по аннотациям и сигнатурам функций.
initxu init [имя]Инициализация нового проекта и манифеста xu.xun.
getxu get [пакет@версия]Загрузка внешнего пакета и фиксация в xu.lock.
debugxu debug [бинарник]Запуск встроенного интерактивного отладчика с точками останова.
doctorxu doctorДиагностика окружения, путей SDK и системных библиотек.

Флаги компиляции

  • -o <file>: имя выходного бинарного файла.
  • --target <triple>: целевая архитектура (например, wasm32-wasi, x86_64-linux, arm64-macos).
  • --no-opt: отключение оптимизаций для ускорения отладочной сборки.
  • --phone: сборка мобильного проекта для iOS / Android.
  • --desktop: сборка настольного приложения с хостом оконной системы.
