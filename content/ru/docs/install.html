Установка SDK Xu

Установка официального компилятора и инструментов Xu {{xu_version}} для macOS, Linux и Windows.

Автоматическая установка через скрипт

macOS и Linux

curl -fsSL https://xulang.org/install.sh | bash

Windows PowerShell

irm https://xulang.org/install.ps1 | iex

Автономные графические установщики (GUI)

Для изолированных сред или ручной установки скачайте автономный установщик со страницы Скачать Xu:

  • Windows: Скачайте xu-setup-windows-x64.exe и запустите мастер установки.
  • macOS: Загрузите xu-v{{xu_version}}-macos-arm64.pkg для установки через системный установщик Apple.
  • Linux: Скачайте xu-setup-linux-x64, сделайте исполняемым (chmod +x) и запустите с флагом -y.

Проверка установки

Откройте терминал и проверьте доступность компилятора в PATH:

xu --version
xu doctor
