Функции и выражения

fn add(a int, b int) int {
    << a + b
}

fn (c $&Counter) inc() {
    c.val = c.val + 1
}

Функции объявляются ключевым словом fn. Символ << возвращает значение. Методы структур объявляются с приёмником перед именем метода: по значению (self Struct) или по ссылке (self $&Struct).
