Модель памяти

Xu использует статический вывод владения и детерминированную очистку ресурсов при выходе из области видимости — без сборщика мусора (Zero-GC). У каждого значения есть один владелец; операция заимствования предоставляет временный доступ без передачи владения.

ФормаПрава доступа / Время жизни
Владение string / []T по значениюПеремещение (Move): старая переменная становится недоступной.
&xРазделяемый доступ только для чтения (Shared Borrow).
$x, затем $&xИзменяемая привязка и эксклюзивное изменяемое заимствование (Mutable Borrow).
*rРазыменование скаляра через ссылку.
*raw TНизкоуровневый аппаратный контракт: разыменование требует блока unsafe, пропуская проверку заимствований.

Перемещение (Move)

Присваивание или передача аргументов по значению перемещает владение:

@main

fn main() int {
    text := "owned"
    next := text // владение перемещено в next
    println(next)
    << 0
}

Разделяемое заимствование (&)

Несколько неизменяемых ссылок могут существовать одновременно:

@main

fn main() int {
    $value := 1
    r1 := &value
    r2 := &value
    println(*r1 + *r2)
    << 0
}

Изменяемое заимствование ($&)

Для изменения данных требуется эксклюзивная изменяемая ссылка $& при отсутствии других активных заимствований.

Низкоуровневый аппаратный контракт (*raw T и unsafe)

В системном коде ядер операционных систем и драйверов (менее 5% кодовой базы) Xu предоставляет детерминированный низкоуровневый контроль:

  • Необработанные указатели *raw T могут создаваться из числовых адресов (addr as *raw u32);
  • Разыменование указателей (чтение *p или запись *p = val) разрешено исключительно внутри блоков unsafe { … };
  • Функции volatile_read(ptr) и volatile_write(ptr, val) исключают удаление оптимизатором операций ввода-вывода (MMIO);
  • Атрибуты @repr("C", align: 4096) обеспечивают строгое выравнивание страниц памяти.
@main

fn mmio_write(reg_addr usize, val u32) {
    p := reg_addr as *raw u32
    unsafe {
        *p = val
    }
}

fn main() int {
    $buf: [4]u8
    ptr := (&buf[0]) as *raw u8
    unsafe {
        *ptr = 42
    }
    println(buf[0])
    << 0
}
