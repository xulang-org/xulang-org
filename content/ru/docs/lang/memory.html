Модель памяти

Xu использует статический вывод владения и детерминированную очистку ресурсов при выходе из области видимости — без сборщика мусора (Zero-GC). У каждого значения есть один владелец; операция заимствования предоставляет временный доступ без передачи владения.

ФормаПрава доступа / Время жизни
Владение string / []T по значениюПеремещение (Move): старая переменная становится недоступной.
&xРазделяемый доступ только для чтения (Shared Borrow).
$x, затем $&xИзменяемая привязка и эксклюзивное изменяемое заимствование (Mutable Borrow).
*rРазыменование скаляра через ссылку.

Перемещение (Move)

Присваивание или передача аргументов по значению перемещает владение:

@main

fn main() int {
    text := "owned"
    next := text // владение перемещено в next
    println(next)
    << 0
}

Разделяемое заимствование (&)

Несколько неизменяемых ссылок могут существовать одновременно:

@main

fn main() int {
    $value := 1
    r1 := &value
    r2 := &value
    println(*r1 + *r2)
    << 0
}

Изменяемое заимствование ($&)

Для изменения данных требуется эксклюзивная изменяемая ссылка $& при отсутствии других активных заимствований.
