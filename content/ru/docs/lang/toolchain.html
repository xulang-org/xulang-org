Инструментарий

Единая утилита xu объединяет все инструменты сборки и проверки:

КомандаНазначение
xu run main.xuБыстрая компиляция и мгновенный запуск.
xu build main.xu -o appНативная статическая AOT-сборка бинарного файла.
xu check main.xuСтатический анализ типов и проверка заимствований.
xu testАвтоматический поиск и запуск тестов.
xu fmtАвтоматическое форматирование исходного кода.
xu docГенерация документации по аннотациям и сигнатурам.
