Конкурентность

Ключевое слово xu f(args) планирует запуск легковесной корутины. Каналы chan T используются для синхронизации и безопасного обмена данными между корутинами.

@main

fn worker(id int, ch chan int) {
    ch <- id * 10
}

fn main() int {
    ch := chan int{cap: 0}
    xu worker(1, ch)
    println(<-ch) // получение результата
    << 0
}

Микросопрограммы 16КБ с ограниченным стеком и рандеву без копирования (0.13.3+)

В Xu 0.13.3 представлены глубокие оптимизации для рандеву каналов и планирования задач:

  • Прямое рандеву между стеками без копирования (Zero-Copy Rendezvous): когда получатель ожидает на небуферизованном канале (cap: 0), адрес его слота стека назначения регистрируется непосредственно в канале; отправитель разыменовывает указатель и копирует значение напрямую в стек получателя, минуя промежуточный кучевой буфер.
  • Анализ ограниченного стека по графу вызовов и 16КБ Tiny Slab: компилятор вычисляет максимальную глубину стека вызовов и границы локальных фреймов; сопрограммы с доказанно ограниченным использованием стека автоматически выделяются из пула 16КБ Tiny Slab (task_spawn_tiny), сокращая потребление памяти на 98.4%.

Каналы: отправка и приём

  • ch <- val: отправка значения в канал. Если буфер полон, корутина переходит в режим ожидания.
  • <-ch: чтение значения из канала. Если канал пуст, корутина ожидает поступления данных.
  • close(ch): закрытие канала. Из закрытого канала вычитываются оставшиеся буферизованные элементы, затем возвращаются значения по умолчанию.
