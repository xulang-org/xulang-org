Грамматика EBNF

Формальное описание синтаксиса Xu в нотации Бэкуса — Наура (EBNF):

SourceFile   = { TopLevelDecl } ;
TopLevelDecl = [ "@main" ] ( VarDecl | ConstDecl | FuncDecl | StructDecl | EnumDecl ) ;

FuncDecl     = "fn" [ Receiver ] Ident Signature Block ;
Receiver     = "(" Ident [ [ "$" ] "&" ] Type ")" ;
Signature    = "(" [ ParameterList ] ")" [ Type ] ;

Block        = "{" { Statement } "}" ;
Statement    = VarDecl | Assignment | ReturnStmt | ThrowStmt | BreakStmt | IfStmt | ForStmt | ExprStmt ;

ReturnStmt   = "<<" [ Expression ] ;
ThrowStmt    = ">>" Expression ;
BreakStmt    = "<-" ;
