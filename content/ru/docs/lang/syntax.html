Синтаксис

Синтаксис верхнего уровня зафиксирован: >>/or для ошибок, << для возврата значений, <- для выхода из циклов или операций с каналами.

fn sum(a int, b int) int {
    << a + b
}

fn handle(val int) {
    if val < 0 {
        >> errors.new("отрицательное значение")
    }
}

Низкоуровневые аппаратные контракты

Для разработки ядер операционных систем, встраиваемых прошивок и драйверов устройств Xu предоставляет строго изолированные аппаратные средства:

  • Блоки unsafe { … }: изолируют разыменование необработанных указателей и прямые низкоуровневые операции;
  • Указатели *raw T: поддерживают арифметику указателей и приведение типов адресов (addr as *raw u32);
  • Встроенный ассемблер asm!(…): прямое выполнение привилегированных инструкций процессора;
  • Барьеры MMIO: функции volatile_read(ptr) и volatile_write(ptr, val) предотвращают удаление обращений к регистрам оптимизатором;
  • Атрибуты компоновки: @repr("C", align: N) (выравнивание структур в памяти) и @repr("C", packed) (упаковка без выравнивающих зазоров);
  • Профиль $freestanding: компиляция без зависимостей от системных вызовов ОС и libc.

Подробнее см. Грамматика EBNF и Лексика.
