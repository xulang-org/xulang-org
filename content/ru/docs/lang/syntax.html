Синтаксис

Синтаксис верхнего уровня зафиксирован: >>/or для ошибок, << для возврата значений, <- для выхода из циклов или операций с каналами.

fn sum(a int, b int) int {
    << a + b
}

fn handle(val int) {
    if val < 0 {
        >> errors.new("отрицательное значение")
    }
}

Подробнее см. Грамматика EBNF и Лексика.
