VS Code / Cursor 編輯器支援

官方 VS Code & Cursor 外掛 · 基於自舉語言服務協議 (xu lsp) · 語法高亮 · 實時診斷 · 智慧補全 · 跳轉定義與當前檔案重新命名

為了給開發者提供流暢、現代化的編碼體驗，Xu 官方在獨立倉庫 vscode-xu 中維護了官方編輯器擴充套件，原生深度相容 Visual Studio Code 與 Cursor IDE。擴充套件由高精度的 TextMate 語法高亮文法與基於 Xu 編譯器原生自舉的語言服務協議（Language Server Protocol / LSP）雙輪驅動。

1. 核心語言服務能力矩陣

基於編譯器內建的 xu lsp（伴生工具 xu-lsp），擴充套件在編輯器中提供以下語言服務；查詢與編輯範圍見各項說明：

功能特性 快捷鍵 (macOS / Win) 能力與技術細節說明
精細語法高亮 實時高亮 基於官方詞法規範定製的 TextMate 文法，精準著色控制流、所有權與型別（$、struct、chan 等）及特有符號語句（<<、>>>、<<<、->、<-）。
實時語法與型別診斷 編輯時波浪線 在後臺實時執行靜態型別檢查與所有權借用驗證，在程式碼行內直接標紅語法錯誤與型別推導不匹配，告別盲目除錯。
跨檔案跳轉定義 F12 / Cmd+Click 支援結構體、函式、全域性常量、方法及介面實現的瞬間穿透跳轉，甚至可無縫跳轉至標準庫（Stdlib）原始碼定義位置。
文件與型別簽名懸停 滑鼠懸停 (Hover) 懸停在任意變數、結構體欄位或函式呼叫上，立即浮現其準確型別簽名、可變性標記（$）以及 Markdown 格式註釋文件。
智慧上下文補全 Ctrl+Space 補全建議主要來自關鍵字、內建函式與當前檔案宣告。成員鏈和外部包的語義補全能力有限。
查詢所有引用 Shift+F12 按識別符號文字匹配當前檔案及同目錄的其他 .xu 檔案；結果可能包含同名但無關的符號。
當前檔案符號重新命名 F2 僅為當前檔案生成編輯，按識別符號文字匹配。請檢查編輯預覽中的同名符號，並另行更新其他檔案。
程式碼大綱與麵包屑 Cmd+Shift+O / Ctrl+Shift+O 按層級快速羅列當前檔案中的所有結構體定義、列舉以及函式符號，支援拼音或英文模糊搜尋秒級定位。
儲存時自動格式化 Cmd+S / Ctrl+S 儲存檔案時自動呼叫產品級 xu fmt 工具，嚴格規範縮排、括號佈局與運算子兩端留白，保持團隊程式碼風格 100% 統一。

2. 外掛安裝方式

方式 A：從官方 VSIX 離線包安裝（推薦）

解壓 Xu {{xu_version}} SDK 後，進入其 editors/vscode/ 目錄，使用其中的 xu-language-0.3.0.vsix。外掛版本獨立於編譯器版本，可透過終端或 IDE 介面安裝：

# 透過 VS Code 命令列一鍵安裝
code --install-extension xu-language-0.3.0.vsix

# 或者透過 Cursor 命令列安裝
cursor --install-extension xu-language-0.3.0.vsix

或者在 VS Code / Cursor 的擴充套件面板中，點選右上角 ... 選單，選擇 Install from VSIX...，選取下載好的 .vsix 檔案後執行 Reload Window 即可。

方式 B：從原始碼本地打包構建

若希望參與外掛開發或體驗倉庫最新提交特性，可自行拉取倉庫並打包：

# 克隆官方外掛倉庫
git clone https://github.com/xulang-org/vscode-xu.git
cd vscode-xu

# 安裝相依性並打包為 VSIX 安裝包
npm ci
npm run package

# 安裝剛剛生成的 VSIX
code --install-extension xu-language-*.vsix

3. 推薦編輯器配置 (settings.json)

在 VS Code 或 Cursor 中按下 Cmd+Shift+P（macOS）或 Ctrl+Shift+P（Windows/Linux），輸入 Preferences: Open User Settings (JSON)，新增以下推薦配置項：

{
  // 指定 Xu 編譯器二進位制路徑（若已加入系統 PATH，填寫 "xu" 即可）
  "xu.languageServerPath": "xu",

  // 語言伺服器除錯日誌級別（開發外掛時可設為 "messages" 或 "verbose"）
  "xu.trace.server": "off",

  // Xu 語言專用編輯器配置
  "[xu]": {
    "editor.defaultFormatter": "xu-lang.xu-language",
    "editor.formatOnSave": true,
    "editor.tabSize": 4,
    "editor.insertSpaces": true,
    "editor.suggestOnTriggerCharacters": true,
    "editor.quickSuggestions": {
      "other": true,
      "comments": false,
      "strings": true
    }
  }
}
