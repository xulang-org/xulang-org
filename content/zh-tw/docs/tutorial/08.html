08 · Enum 與 match

標籤聯合。構造 Color.Rgb(1, 2, 3)。match 須窮盡或帶 else。owning 載荷的 match 會消費主體。

原始碼

@main

enum Color {
    Red
    Green
    Rgb(int, int, int)
}

fn show(c Color) {
    match c {
        Color.Red {
            println("red")
        }
        Color.Green {
            println("green")
        }
        Color.Rgb(r, g, b) {
            println(r)
            println(g)
            println(b)
        }
    }
}

fn main() int {
    show(Color.Red)
    show(Color.Green)
    show(Color.Rgb(1, 2, 3))
    << 0
}
