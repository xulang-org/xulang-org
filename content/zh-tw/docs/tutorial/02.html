02 · 繫結與常量

預設不可變。要改寫必須寫 $。const 是編譯期常量。禁止全域性可變變數。

原始碼

@main

const MAX = 100

fn main() int {
    name := "Xu"
    $age := 20
    age += 1

    println(name)
    println(age)
    println(MAX)
    << 0
}

編譯（examples 倉庫根，使用已安裝的 xu）：

xu run examples/02_bindings/main.xu
# 或：xu build examples/02_bindings/main.xu
# mac/linux 預設寫出 ./main ；Windows 為 ./main.exe

在獨立的 examples 倉庫根執行；原始碼位於 examples/。
