16 · UI + WebView

對應 #ui 視窗/選單/托盤 + #ui/webview 內容槽。打包用產品 xu doctor / xu build <App> --desktop。

每個應用是獨立專案根：

獨立專案根目錄結構 (Project Root)
App/ 應用獨立根目錄
xu.xun 配置 模組清單與構建配置 (Module Manifest)
main.xu 必需 主程式入口原始碼 (Main Entry)
www/ 可選 本地 xu:// 靜態 Web 資源（當包含 WebView 時）
brand/ 必需 至少包含一張應用 PNG 圖示（桌面打包專用，不會回退到倉庫根）

本目錄下的應用：open 標準窗+WebView；shaped 異形窗；draw 直繪畫布 #ui/draw；remote 遠端 HTTP。

xu doctor --desktop --target macos-arm64
XU_UI_PACK=1 xu build examples/16_ui_webview/open --target macos-arm64 --desktop -o /tmp/XuOpen
open /tmp/XuOpen.app

macOS 產出 .app，Windows 產出 .exe，Linux 產出 ELF。桌面打包需要對應宿主工具鏈；Linux 使用 GTK4，WebView 另需 WebKitGTK 6.0。各平臺執行驗收範圍見 UI / WebView。

命令在獨立的 examples 倉庫根執行。
