10 · 協程與 chan

透過協程執行獨立任務，用 chan 傳遞值和彙總結果。這些完整程式使用本機 Xu 編譯器執行。

chan int{cap: 2} 建立緩衝容量為 2 的通道。ch <- value 傳送值，<-ch 接收值；這與單獨使用的 <-（退出迴圈）不同。

xu f(args) 啟動協程。不要把區域性變數的借用傳入協程；本例透過通道傳遞整數值。

這三個完整程式也已加入線上 Playground，可在 Xu 編寫並編譯的 WASM 執行器中直接執行。

1 · 帶緩衝的傳送與接收

@main

fn main() int {
    messages := chan int{cap: 2}
    messages <- 7
    messages <- 35
    first := <-messages
    second := <-messages
    println(first + second)
    << 0
}

下載原始碼

執行

xu run chan-buffered.xu

輸出

42

2 · 多個 worker 彙總結果

@main

fn worker(id int, results chan int) {
    results <- id * 10
}

fn main() int {
    results := chan int{cap: 3}
    xu worker(1, results)
    xu worker(2, results)
    xu worker(3, results)

    $total := 0
    for i in 0:3 {
        value := <-results
        total += value
    }
    println(total)
    << 0
}

下載原始碼

執行

xu run chan-workers.xu

輸出

60

3 · 生產者與處理流水線

@main

fn produce(output chan int) {
    for value in 1:6 {
        output <- value
    }
}

fn square(input chan int, output chan int) {
    for i in 0:5 {
        value := <-input
        output <- value * value
    }
}

fn main() int {
    numbers := chan int{cap: 2}
    squares := chan int{cap: 2}
    xu produce(numbers)
    xu square(numbers, squares)
    for i in 0:5 {
        value := <-squares
        println(value)
    }
    << 0
}

下載原始碼

執行

xu run chan-pipeline.xu

輸出

1
4
9
16
25

多個 worker 的完成順序不保證固定，因此先接收三個結果再求和；流水線則按生產者的傳送順序處理五個輸入。主函式接收完預定數量的結果後退出，不相依性 sleep 等待協程。
