06 · 所有權與借用

無 GC。按值傳 string 即 move。&x 共享借用；$&x 獨佔借用（x 須 $）。

原始碼

@main

fn take(s string) {
    println(s)
}

fn len_of(s &string) int {
    << s.len
}

fn append_bang(s $&string) {
    s.push_str("!")
}

fn main() int {
    msg := "hello"
    println(len_of(&msg))
    println(msg)

    $owned := "hi"
    append_bang($&owned)
    println(owned)

    take(owned)
    // owned 已 move，不可再使用
    << 0
}

編譯（examples 倉庫根，使用已安裝的 xu）：

xu run examples/06_ownership_borrow/main.xu
# 或：xu build examples/06_ownership_borrow/main.xu
# mac/linux 預設寫出 ./main ；Windows 為 ./main.exe

在獨立的 examples 倉庫根執行；原始碼位於 examples/。
