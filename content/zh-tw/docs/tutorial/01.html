01 · 程式骨架

目標

建立、檢查並執行一個 Xu 程式，列印問候語後成功退出。

前置條件

按照安裝指南安裝你選定的 Xu SDK，並將它的 xu 命令加入 PATH。在終端中驗證：

xu --version

只需一個空工作目錄和文字編輯器，完整原始碼見下文。

步驟

1. 建立原始檔

建立並進入一個空目錄：

mkdir xu-tut01
cd xu-tut01

將以下完整程式儲存為該目錄中的 main.xu：

@main

fn main() int {
    println("Hello, Xu!!!!!!!!!")
    << 0
}

@main 標記可執行程式入口。println 列印一行，<< 0 從 main 返回成功退出碼。Xu 使用 << 表示返回語句，不需要分號。

2. 檢查並執行

在同一目錄中先檢查檔案，檢查成功後再執行：

xu check main.xu
xu run main.xu

預期輸出

xu run main.xu 精確列印以下一行及末尾換行符，並以狀態碼 0 退出：

Hello, Xu!!!!!!!!!
