07 · 陣列與字串

動態陣列 push。字串切片 s[a:b] 採用半開區間 [a, b)，結果是複製。端點可省略：s[a:]、s[:b]、s[:]。插值 "hi $name"。

原始碼

@main

fn main() int {
    $nums := [1, 2, 3]
    nums.push(4)
    println(nums.len)
    for n in nums {
        println(n)
    }

    name := "Ada"
    println("hi $name")
    s := "hello"
    println(s.len)
    println(s[1:4])
    << 0
}

編譯（examples 倉庫根，使用已安裝的 xu）：

xu run examples/07_arrays_strings/main.xu
# 或：xu build examples/07_arrays_strings/main.xu
# mac/linux 預設寫出 ./main ；Windows 為 ./main.exe

在獨立的 examples 倉庫根執行；原始碼位於 examples/。
