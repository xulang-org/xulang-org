12 · HTTP FileServer

一行起靜態檔案服務：

http.listen_and_serve("127.0.0.1:8080", ".")

預設根目錄是示例下的 www/，也可把目錄當引數傳入。

原始碼

@main

#net/http

//   http.listen_and_serve("127.0.0.1:8080", ".")
//
// 引數：要對外的目錄。預設本示例的 www/（從倉庫根執行）。

fn main() int {
    $root := "examples/12_file_server/www"
    av := args()
    if av.len >= 2 {
        root = av[1] + ""
    }
    println("FileServer " + root)
    println("http://127.0.0.1:8080")
    http.listen_and_serve("127.0.0.1:8080", root) >>> (err) {
        println(err.msg())
        << 1
    }
    << 0
}

在獨立的 examples 倉庫根執行；原始碼位於 examples/。
