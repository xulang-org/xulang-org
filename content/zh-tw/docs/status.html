官網與對應 SDK 版本：Xu {{xu_version}}。Xu 仍處於 0.x 階段，已釋出產物以 GitHub Releases 為準。

子系統狀態支援範圍與邊界
記憶體與資源已實現單所有者、共享/獨佔借用、move 檢查與確定性 drop；File/Conn 資源在作用域退出時自動關閉。
安全邊界設計約束不開放 unsafe、reflect 和使用者可見的裸 runtime 指標；越界索引與除零明確失敗。
原生 AOT 與 WASM按目標驗證支援 macOS arm64/x64、Linux arm64/x64/loongarch64/riscv64、Windows x64/arm64、WebAssembly (wasm32-wasi) 及 Thumb/RISC-V 裸機目標；生成支援不代表全部庫均透過目標機執行驗收。
模組相依性已實現，保留邊界斜槓路徑身份、顯式 file/Git/tar 來源、SemVer 最低要求與 MVS、XUPROXY/私有路徑繞過、內容鎖、vendor 快照、離線/凍結構建與程序鎖。
獨立校驗日誌客戶端已實現0.8.4 新增固定公鑰 XUSUMDB 校驗與 XUNOSUMDB 策略；公共 Xu 服務和獨立見證仍待發布，未配置或 off 時保持首次使用信任。
網路與 I/O平臺差異Unix 支援 TCP/UDP IPv4/IPv6 與 Unix 域套接字；原生 epoll/kqueue/IOCP Socket 就緒等待；已提供流式 I/O 和明確進度結果。Windows TCP dial/listen 仍未支援，raw IP 與 TLS 另有平臺邊界。
SQL 與擴充套件包獨立模組database/sql 提供連線池、事務和驅動契約；SDK 內 packages 模組 1.0.2 提供 29 個服務整合包及共享 transport，MySQL/PostgreSQL 使用協議驅動，SQLite 使用原生 C 資源。
密碼學按包說明包含 SM2/SM3/SM4/SM9/ZUC/GMTLS 的 Xu 實現；API 可用不代表已取得商用密碼認證。
桌面 GUI需宿主工具鏈桌面打包已有 macOS .app、Windows .exe、Linux ELF 路徑；提供人體工學 Screen 螢幕上下文抽象與統一樣式控制元件；須有 GTK4/WebKitGTK 或 WebView2 及匹配工具鏈，並在目標機驗證。
GPU 與視窗系統已實現底層抽象包含 #gpu、#gpu/layout、#window、#window/events；支援無視窗 GPU 裝置、統一緩衝區/紋理傳輸、命令錄製、計算與渲染通道、柵欄回讀；獨立視窗生命週期與按視窗輸入事件佇列（鍵盤、指標、滾輪與文字/IME），需宿主平臺圖形驅動或 SDL 3.2+ 執行庫支援。
共享庫匯出基礎型別簽名--shared 支援 int、bool、string、f64、i32、u32、u8；原生 .a/.xulib 相依性有獨立資源邊界。
Map 容器已實現支援 int/string 鍵；缺鍵直接索引明確失敗，需要允許缺鍵時使用存在性檢查或庫 API。
XACP 控制通道API 已釋出；執行待驗#xacp 已包含在正式 {{xu_version}} SDK 提取結果中。hosted native 啟動控制使用 --xacp / --xacp-port，stdio 與 127.0.0.1 TCP 均採用 XACP/1 長度字首。宿主未設定令牌時 hello 至多授予 INFO；宿主令牌匹配後可請求 PERM_ALL 的子集。proc.status 提供 pid 響應；輸出/UI 操作需要相應許可權和介面卡。啟動控制不註冊 Screen。UI 附著需要註冊和輪詢，並有請求期限；呼叫方仍需程序/I/O 超時。沒有 TLS 或非迴環繫結；Windows 啟動器 record 不可用。原生會話、UI 控制、截圖和各平臺執行驗收仍待驗。匯入包不會安裝控制通道。
工具與編輯器完全實現提供開箱即用原生 Setup 離線安裝嚮導（支援 Windows/macOS/Linux 全域性環境變數自動配置）；優先可執行檔案探測標準庫消除全域性環境劫持；build/run/check/test/debug/install/get/fmt/map/doc/doctor/lsp 可用；up/update 支援直接下載官方二進位制 Release 自更新；VS Code 擴充套件提供語法高亮與基於原生 xu-lsp 的完整語言服務（跳轉定義、補全、懸停、實時診斷、大綱、重新命名與引用）。
