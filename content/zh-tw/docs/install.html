安裝

本文對應 Xu {{xu_version}}。安裝包是否可下載，以 GitHub Releases 的實際附件為準。

使用包含 bin/、src/ 和工具的完整 SDK。標準庫原始碼是編譯匯入的必要輸入；單獨把編譯器改名放進 PATH 不構成完整開發環境。

方案一：免安裝瀏覽器沙箱 (Zero Install)

無需安裝，即可進入 線上 Playground。它在瀏覽器中執行 WebAssembly 子集，經過掃描、解析、借用檢查和 MIR 解釋執行。完整的原生 AOT 工具鏈需使用下方的本地 SDK。

方案二：終端一行命令極速安裝 (推薦)

Xu 提供了開箱即用的自動化安裝指令碼，自動檢測作業系統與晶片架構（x86_64 與 ARM64）、下載對應的官方 SDK 並持久化配置全域性環境變數，安裝後在系統任意終端均可直接執行 xu。安裝與解除安裝指令碼全程採用標準 7-bit ASCII 英文輸出，杜絕不同語言終端（如 Windows 中文 GBK/CP936 內碼表）下的顯示亂碼：

macOS / Linux（終端一行執行）

# 自動檢測晶片架構（ARM64 / x86_64）、下載並持久化配置 Shell 環境變數
curl -fsSL https://xulang.org/install.sh | bash -s -- --online --version {{xu_version}} --yes

亦可直接從 GitHub Releases 下載各系統獨立的擴音權安裝程式（二進位制單檔案，無需任何第三方相依性）：

chmod +x xu-setup-linux-x64 && ./xu-setup-linux-x64 -y

Windows（PowerShell 或 GUI 圖形嚮導）

PowerShell 單行命令：

& ([scriptblock]::Create((irm https://xulang.org/install.ps1))) -Online -Version "{{xu_version}}"

原生自繪 GUI 圖形嚮導：
從 GitHub Releases 下載 xu-setup-windows-x64.exe 或 xu-setup-windows-arm64.exe，雙擊即可執行零相依性的原生圖形嚮導，自動配置系統登錄檔使用者 Path 與 XU_ROOT。

安裝完成後，開啟新的終端視窗輸入 xu --version，即可在系統任意位置全域性執行。

方案三：原生獨立安裝程式與離線 SDK 安裝

如需離線部署、內網分發或精確控制安裝包版本，可直接下載對應平臺的原生安裝包：

作業系統推薦安裝包說明
Windows 下載 xu-v{{xu_version}}-windows-x64-setup.exe
或 xu-setup-windows-x64.exe
（ARM64 裝置選擇 windows-arm64 對應包）		 原生單檔案離線安裝包，直接雙擊啟動自繪圖形嚮導，自動配置登錄檔使用者 Path 與 XU_ROOT，無指令碼執行策略攔截。終端亦可直接執行 .\xu-setup-windows-x64.exe -y 靜默安裝。
macOS 下載 xu-v{{xu_version}}-macos-arm64.pkg
或 xu-setup-macos-arm64		 macOS 原生圖形安裝嚮導，自動配置 /etc/paths.d/xu，系統所有終端全域性立即可用；亦可下載獨立安裝程式 xu-setup-macos-arm64 擴音權執行。
Linux 下載 xu-setup-linux-x64
或 xu-setup-linux-arm64		 原生單檔案二進位制程式，執行 chmod +x xu-setup-linux-x64 && ./xu-setup-linux-x64 -y，自動解壓 SDK 並寫入使用者 Shell 環境變數配置。

離線 SDK 歸檔包安裝

若從 下載頁 或 GitHub Releases 下載了完整的 SDK 壓縮包（Unix 為 .tar.gz，Windows 為 .zip），解壓後根目錄已內建原生安裝程式：

# Windows：解壓後在資源管理器中直接雙擊根目錄下的 xu-setup.exe
# 或在命令列中執行：
.\xu-setup.exe -y

# macOS / Linux：解壓後在終端執行根目錄下的 xu-setup
./xu-setup -y

預設更新 PATH 中已有的 SDK；未發現時安裝到使用者主目錄下的 .xu（macOS .pkg 預設為 /usr/local/xu）。如需自定義安裝目錄，可傳入引數 --prefix /custom/path。在自動化 CI 指令碼中，使用 ./xu-setup --yes 或 .\xu-setup.exe --yes 安裝全部工具；若只需臨時體驗，可在解壓目錄下執行 source env.sh（PowerShell 為 . .\env.ps1）。

驗證全域性環境

安裝完成後，開啟新的終端視窗（CMD、PowerShell、Terminal 或 VS Code 內建終端），驗證工具鏈全域性可用：

xu --version
xu env
xu doctor

升級、重複安裝與修復

重新執行上方安裝命令即可升級或修復當前 SDK，包括舊版更新器誤報版本不匹配或上次安裝未完成的情況。安裝器先在同一檔案系統準備新 SDK，核驗完整檔案清單與十個工具，再替換安裝目錄；原 SDK 保留在安裝器輸出的備份路徑。SDK 管理範圍以外的使用者資料會保留。

如需指定目標，Unix 命令末尾追加 --prefix /path/to/xu；PowerShell 追加 -Prefix "C:\Tools\Xu"。目標父目錄必須可寫；系統安裝可能需要管理員許可權。不修改終端配置時使用 Unix --no-modify-path、PowerShell -NoModifyPath 或原生 Setup --no-modify-path。

xu --version
xu env
xu update --check
# 已安裝 0.10.7 或更高版本後：
xu update
# 重新安裝當前版本並修復全部 SDK 檔案：
xu update --force

xu update 與 Setup 使用相同的完整 SDK 替換流程，更新編譯器、配套工具、標準庫、packages、示例和編輯器檔案。xu update --version <版本> 可選擇特定發行版本。版本變更請檢視發行記錄。

驗證編譯

xu check hello.xu
xu run hello.xu
xu build hello.xu --output hello

macOS / Linux 的可執行產物已有執行許可權。PowerShell 中建議使用 --output 指定路徑。

環境與原始碼構建

XU_ROOT 指向 SDK 或編譯器倉庫；XU_STDLIB_ROOT 可顯式指定標準庫 src/。XUPATH 追加搜尋目錄，不能替代外部模組的 require: 宣告。工具 xu-fmt、xu-doc、xu-map、xu-doctor、xu-desktop、xu-lsp 應與 xu 放在同一個 bin 目錄。

原始碼位於 xu 倉庫。make xu 使用已有 hosted 產品種子自舉，並重建工具；清潔檢出需要先準備產品種子及 bootstrap 伴隨倉庫，不能只憑原始碼直接執行編譯器。packages、examples、vscode-xu 分別維護在獨立倉庫。
