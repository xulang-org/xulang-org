起步

Xu {{xu_version}} 官方起步指南 · 現代化無 GC 系統級語言 · 靜態 AOT 編譯 · 所有權與借用 · 全功能輕薄工具鏈

Xu 是一門無執行時垃圾回收（GC-free）的現代化高效能系統級程式語言。它融合了輕薄直觀的語法設計、確定性編譯期所有權與借用檢查（Ownership & Borrowing），以及高效靜態 AOT 原生編譯。Xu 原始碼檔案均採用標準 UTF-8 編碼，副檔名為 .xu。

端到端 4 步極速上手流水線 (Quickstart Pipeline)
從安裝配置到專案初始化、編碼實現與構建測試的標準化工程開發路徑

安裝 SDK 與檢查編譯器環境

1. 安裝與開發環境準備

終端一鍵安裝 
curl -fsSL https://xulang.org/install.sh | bash -s -- --online --version {{xu_version}} --yes
& ([scriptblock]::Create((irm https://xulang.org/install.ps1))) -Online -Version "{{xu_version}}"

也可以下載編譯器，選擇適合本機系統和架構的安裝程式或 SDK 壓縮包。詳細的安裝和環境變數配置步驟見安裝指南。

安裝完成後，重新開啟終端並執行以下命令驗證：

# 驗證編譯器主版本與底層構建資訊
xu --version

# 檢視全命令與規範排版幫助手冊
xu --help

免安裝體驗：若暫未準備本地環境，可在瀏覽器中直接開啟 WebAssembly 互動演練場，在雲端直接編寫、編譯並執行體驗 Xu 程式碼。

2. 建立你的第一個專案 (xu init)

Xu 推薦以目錄作為模組單元進行工程化組織。先建立並進入目錄，再使用 xu init 初始化模組。該命令在當前目錄寫入 xu.xun 與 main.xu，不會建立子目錄：

# 先建立目錄，再在當前目錄初始化模組
mkdir myapp && cd myapp
xu init myapp

初始化生成的標準專案檔案結構如下：

檔案 / 目錄 型別 職責與規範說明
xu.xun 專案清單 宣告模組名稱、模組自身版本、所需編譯器版本以及外部相依性 require:
main.xu 可執行入口 程式的頂層主入口原始碼，以 @main 開頭幷包含 fn main() 函式
xu.lock 確定性校驗鎖 執行 xu get 或 xu install 後自動生成，鎖定相依性圖與 SHA-256 完整性摘要
vendor/ 本地相依性快照 外部第三方擴充套件包的本地原始碼快照，支援無網路離線構建（--offline / --frozen）

3. 編寫程式碼與語法速覽

開啟專案中的 main.xu，編寫經典問候程式與基礎錯誤處理：

@main
#fmt
#errors

fn calculate_ratio(a int, b int) int {
    if b == 0 {
        // 使用 >>> 丟擲結構化錯誤
        >> errors.new("division by zero")
    }
    // 使用 << 返回計算結果
    << a / b
}

fn main() int {
    fmt.println("Hello, Xu World!")

    // 呼叫可能返回錯誤的函式，使用 >>> (err) 捕獲降級
    val := calculate_ratio(10, 2) >>> (err) {
        fmt.println("Error:", err.msg())
        << 1
    }

    fmt.println("Result:", val)
    << 0
}

4. 一眼能認出來的核心記號

Xu 捨棄了冗餘樣板關鍵字，採用更加直觀、富有表現力的符號式語句設計：

記號 / 語法 功能分類 語義與設計規範
<< / << expr 控制流 函式返回語句（Return）。無運算元時返回空（void），有運算元時返回表示式值。
>> expr 錯誤處理 丟擲 errors.Error 結構化錯誤物件（Throw）。
>>> (err) { ... } 錯誤捕獲 尾隨錯誤接住塊（Catch），在表示式發生錯誤時執行分支降級或提前中斷。
<<< expr 程序控制 程序立即退出（Process Exit），向作業系統返回指定的整數退出狀態碼。
<- 迴圈控制 迴圈中斷跳出（Break，位於語句開頭且無運算元）。
-> 迴圈控制 迴圈繼續下一次迭代（Continue）。
$name := val 所有權繫結 宣告可變區域性變數（預設變數繫結為不可變常量，修改需顯式標記 $）。
xu f(args) 輕量併發 派生輕量級協程併發執行函式 f，由底層無棧/輕量執行時統一排程。
chan T 併發通訊 強型別通訊通道（如 chan int{cap: N}），配合 ch <- val 傳送與 val := <-ch 接收。
@main 包身份註解 位於檔案第一行，指示當前檔案屬於可執行入口包，編譯器將為其生成頂層 main 符號。
#pkg / alias #pkg 模組匯入 # 開頭匯入官方標準庫；外部第三方相依性使用 別名 #完整模組路徑 顯式匯入。

5. 模組相依性與官方擴充套件包 (xu get / xu install)

接入資料庫驅動和服務客戶端時，請在 xu.xun 的 require: 下宣告與 SDK 匹配的原始碼快照：

module: myapp
version: !ver 0.1.0
xu: !ver {{xu_version}}

require:
  "github.com/xulang-org/packages": git:https://github.com/xulang-org/packages.git@96693e6cce8d51eba45e4f68dc12ce06f7a2336b

安裝已宣告的原始碼，也可改用SDK 內建包作為本地相依性：

xu install

在原始碼中直接以明確的別名名稱空間引用具體功能模組（如 mysql、redis、s3）：

@main
#fmt
mysql #github.com/xulang-org/packages/mysql

fn main() int {
    _ := mysql.driver()
    fmt.println("MySQL driver initialized.")
    << 0
}

6. 日常高頻 CLI 常用工作流

Xu 提供了開箱即用的現代化命令列工具鏈，涵蓋從編碼檢查到生產編譯的全部環節：

命令示例 工作階段 功能作用說明
xu run . 日常除錯 自動分析當前目錄相依性、快速編譯並在記憶體中直接執行，開發體驗極為流暢。
xu check . 即時檢查 只執行語法、所有權生命週期和型別檢查，不生成機器二進位制，毫秒級快速反饋。
xu test test.example.xu 質量保障 遞迴發現並併發執行當前目錄下的所有 test_* 單元測試與基準驗證。
xu fmt . 團隊規範 自動格式化目錄內全部 .xu 原始碼，遵循官方統一程式碼風格與縮排規範。
xu build . -o bin/app 生產釋出 啟用最高階別機器碼最佳化，生成獨立且零相依性的原生靜態可執行二進位制。
xu lsp 編輯器整合 啟動原生語言服務守護程序，為 VS Code / Cursor 等 IDE 提供智慧輔助。

7. 下一步探索與進階閱讀

掌握了基礎概念之後，建議繼續閱讀以下進階主題：

  • 按主題系統化學習：跟隨 教程 01–16 從基礎資料結構逐步深入到併發程式設計與借用生命週期。
  • 配置高效開發工具：閱讀 VS Code / Cursor 配置指南，開啟程式碼補全、跳轉（F12）與儲存即格式化。
  • 瀏覽外部驅動：在 官方擴充套件包 (Packages) 中檢視 29 個服務整合包、匯入示例及各包的協議和平臺限制。
  • C/C++ 原生混合程式設計：查閱 原生模組與 .xulib 規範，學習零成本連結通用 .a 與便攜切片容器。
  • XACP 控制通道：閱讀命令列參考與 #xacp API。xu build --xacp 才會嵌入發現資訊；單獨匯入 #xacp 不會開啟 stdio 或本機迴環 TCP。API 已包含在對應正式 SDK 中；原生控制會話和 UI 執行驗收仍待驗。
  • 語言嚴謹語義規範：深入研讀 語言規範 與 {{benchmark_group_count}} 個專案組、{{benchmark_count}} 個變體的跨語言效能橫測。
