語法定稿

表面語法已定：>>/or、#path、控制流符號、struct@ / 名字#。語言面沒有 Result / Ok / Err / ?。

主題定稿不做
錯誤>> expr + or (err) {}；or >> 是重拋糖使用者程式碼 Result / 雙返回值
控制流出口<< 返回、<<< 退出、-> continue、<- breakreturn / break / continue / exit 關鍵字
import行首 #errors、#xu/ast；別名 json #encoding/jsonimport "…"
整數int = i64；i32/u32/u8/byte 獨立型別，無隱式拓寬，算術 wrap同槽別名
字串雙引號是主字面量單引號字串
底層與裸機unsafe { … } 塊隔離、裸指標 *raw T、asm!(…) 內聯組合語言、volatile_read / volatile_write常規程式碼顯式生命週期標註地獄 / 隱式解引用
佈局與屬性@repr("C", align: N)、@repr("C", packed)；#[no_mangle]、#[naked]、#[panic_handler]、#[section("…")]不可預測的結構體自動重排
裸機編譯標記檔案頭 $freestanding 或 xu.xun profile: freestanding 阻斷宿主依賴強綁定外部宿主 OS 與 libc

any / temp 是執行時盒子；# / @ / struct@ 是編譯期分流。無約束寫裸 名字# / 名字@，不要寫 名字# any。
