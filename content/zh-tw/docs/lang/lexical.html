詞法

副檔名 .xu，UTF-8。註釋 // 與 /* */。無分號。識別符號 [A-Za-z_][A-Za-z0-9_]*。

風格強制：型別 PascalCase；常量為 UPPER_SNAKE_CASE（例如 BLOCK_SIZE）；函式/變數/欄位為 snake_case。可見性用 pub，不用首字母大小寫當匯出。

關鍵字包括：fn struct enum const $temp let if else match for while in as is true false int bool string f64 i32 u32 u8 byte pub xu chan select map。沒有 interface / import / return / break / continue。

字面量：42、0xFF、0b1010、1_000_000、3.14、"hi"、反引號多行串、[1, 2, 3]。
