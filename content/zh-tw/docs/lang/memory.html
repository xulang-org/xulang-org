記憶體模型

Xu 採用所有權推斷與確定性的作用域清理，不使用垃圾收集器。每個 owning 值同一時刻只有一個所有者；借用提供臨時訪問權，不轉移所有權。這些規則不等於證明外部程式碼或原生宿主資源不會洩漏。

下列示例均使用官方 SDK v0.10.12 檢查。每個程式碼塊單獨儲存為一個 .xu 檔案；完整程式使用 xu check，僅含函式的示例使用 xu check --lib。下列診斷均為實際編譯器輸出的子串。含 fn main 的程式可執行；檔案示例須用本機 SDK。

寫法許可權 / 生命週期
按值傳遞 owning string / []T轉移所有權，原繫結不再可用。
&x共享只讀訪問；多個共享借用可以共存。
先宣告 $x，再取 $&x可寫繫結，再取得獨佔可寫訪問權。
*r透過引用讀取標量；寫入須有獨佔引用。
*raw T 裸指標底層硬體契約；僅允許在 unsafe 塊內解引用，跳過借用檢查。

int 等標量按值複製。Channel 值是指向同一個執行時通道的共享控制代碼，傳遞通道不會消耗傳送方的控制代碼。借用與傳送的邊界見併發。

Move：使用新的所有者

賦值、按值傳參、返回值、寫入 owning 槽都會轉移 owning 值。Move 後應使用目標繫結；只有 API 明確提供複製操作時才進行克隆。

@main

fn main() int {
    text := "owned"
    next := text
    println(next)
    << 0
}

預期 xu check：透過。 xu run 輸出（逐行）：owned.

@main

fn bad() {
    text := "owned"
    next := text
    println(text)
    println(next)
}

預期 xu check --lib：失敗，診斷包含 use of moved value 'text'.

共享：讀取時不改變所有者

共享引用可以共存。共享借用存活期間，不能修改、move 或獨佔借用所有者。借用可以在最後一次使用後結束，不必等到外層作用域結束：下例的賦值位於兩次讀取之後。

@main

fn main() int {
    $value := 1
    first := &value
    second := &value
    println(*first + *second)
    value = 2
    println(value)
    << 0
}

預期 xu check：透過。 xu run 輸出（逐行）：2 / 2.

@main

fn bad() {
    $value := 1
    view := &value
    value = 2
    println(*view)
}

預期 xu check --lib：失敗，診斷包含 cannot assign to 'value' because it is borrowed.

獨佔：同一時刻只有一個寫者

用 $value 宣告可寫所有者，再取 $&value。獨佔借用存活期間排斥對所有者的其他訪問。寫者最後一次使用後可以再共享讀取；兩個重疊的寫者會被拒絕。

@main

fn main() int {
    $value := 1
    writer := $&value
    *writer = 2
    println(*writer)
    view := &value
    println(*view)
    << 0
}

預期 xu check：透過。 xu run 輸出（逐行）：2 / 2.

@main

fn bad() {
    $value := 1
    first := $&value
    second := $&value
    println(*first)
    println(*second)
}

預期 xu check --lib：失敗，診斷包含 cannot borrow 'value' as mutable because it is also borrowed.

作用域釋放：所有者結束，借用不能逃逸

普通 owned 值離開作用域時釋放，正常返回也會清理；move 會轉移清理責任。os.File 等帶編譯器管理 drop 鉤子的資源型別會兜底關閉資源。若需要觀察關閉錯誤，應顯式呼叫 File.close()；兜底清理會忽略關閉錯誤。

僅限本機 SDK。 此程式會在當前目錄建立 scope-release.txt。write_once 透過借用寫檔案，本地檔案所有者在函式返回時清理。

@main

#os
fn write_once() int {
    file := os.create("scope-release.txt") >>>
    file.write("scope") >>>
    << 0
}
fn main() int {
    write_once() >>> (err) {
        println(err.msg())
        << 1
    }
    println("scope ended")
    << 0
}

預期 xu check：透過。 xu run 輸出（逐行）：scope ended.

返回引用必須關聯某個借用輸入，不能指向返回時結束的區域性值；即使函式另有一個引用引數，也不能返回該區域性值的引用。

@main

fn dangling(seed &int) &int {
    value := 1
    << &value
}

預期 xu check --lib：失敗，診斷包含 cannot return a reference to local data.

原生控制代碼：遵守顯式 dispose 契約

Xu 值的作用域清理不能替代所有原生資源 API。例如，呼叫方不再需要 ui/draw.Surface 時必須顯式 dispose，包括錯誤與取消路徑。已接受的幀在 dispose 後仍持有不可變畫素；釋放呼叫方控制代碼不會抹去已接受的幀。

原生整合片段，無瀏覽器執行按鈕。 對宿主提供的有效 surface，應傳播 dispose 錯誤。Dispose 會更新控制代碼，因此此輔助函式需要獨佔訪問。

@main

#ui/draw
fn retire(surface $&draw.Surface) int {
    << surface.dispose() >>>
}

預期 xu check --lib：透過。

共享引用不能呼叫這個可寫方法：

@main

#ui/draw
fn retire(surface &draw.Surface) int {
    << surface.dispose() >>>
}

預期 xu check --lib：失敗，診斷包含 through a shared reference.

漏掉 dispose 不一定編譯失敗：xu check 不是原生洩漏檢測器。待驗： 此輔助函式已做型別檢查，但尚未在真實原生渲染器上執行分配與釋放，也未實跑錯誤 / 取消清理路徑。

宿主排程器的協程棧與通道後設資料另有程序級生命週期策略；離開作用域不代表所有執行時分配立即回收。FFI 呼叫方還須遵守各外部 API 的所有權契約。

底層硬體契約：裸指標 (*raw T) 與 unsafe 隔離

常規業務程式碼嚴格遵循隱式所有權推導與借用檢查，零 GC 且無顯式生命週期標註。而在底層 5% 的作業系統核心、裝置驅動與 MMIO 暫存器互動中，Xu 透過顯式隔離的硬體契約提供零妥協的微架構控制：

  • 裸指標 *raw T：允許從實體整數型態位址強轉構造（如 base as *raw u32），支援指標算術與比較運算子（==, !=, <, >, <=, >=）；
  • unsafe { … } 隔離塊：解引用裸指標（讀 *p 或寫 *p = val）必須置於顯式 unsafe 塊內；未置於 unsafe 會觸發編譯期拒止。借用推導圖完全跳過裸指標；
  • Volatile 易失訪存屏障：內建 volatile_read(ptr) 與 volatile_write(ptr, val)，嚴密防範死儲存消除（DSE）與迴圈不變量外提（LICM），確保硬體暫存器讀寫準確直達匯流排；
  • 精確對齊與緊湊佈局：@repr("C", align: 4096) 保證頁表實體頁面對齊，@repr("C", packed) 消除網路封包標頭與控制塊內部填充。
@main

fn mmio_write(reg_addr usize, val u32) {
    p := reg_addr as *raw u32
    unsafe {
        *p = val
    }
}

fn main() int {
    $buf: [4]u8
    ptr := (&buf[0]) as *raw u8
    unsafe {
        *ptr = 42
    }
    println(buf[0])
    << 0
}

預期 xu check：透過。 xu run 輸出：42.
