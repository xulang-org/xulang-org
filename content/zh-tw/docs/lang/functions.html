函式與表示式

fn add(a int, b int) int {
    << a + b
}

fn (c $&Counter) inc() {
    c.n += 1
}

可變參寫末位 name <-> T，體內是 []T。錯誤不要多返回值，走 >> + >>> (err)。

運算子：表示式裡 << >> 仍是移位；寫成語句才是返回；>>> 用於拋錯與接錯。布林或用 ||。除零執行時 fail-loud。索引越界同樣 fail-loud。

泛型型別引數

函式名後的 # 宣告型別引數，呼叫時根據實參單態化。0.9.4 移除了泛型宣告最多 4 個型別引數的限制，例如：

fn fifth#A,B,C,D,E(a A, b B, c C, d D, e E) E {
    << e
}

// fifth(1, true, 3.0, "four", 5) 返回 5
