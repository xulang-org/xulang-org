標準庫與擴充套件包邊界

核心保留與編譯器耦合的操作，包括 println、args、read_file、xu_target_os。公開標準庫原始碼在 src/，不使用 std 字首：#fmt、#net/http、#crypto/sm2、#ui/webview。

標準庫已包含流式 I/O 與明確的讀寫進度契約、程序管道、HTTP/2、網路池、timer/rate 工具，以及 SQL 連線池和事務介面。生成的 API 頁列出實際公開宣告；存在 API 不代表所有目標平臺支援範圍相同。

具體服務驅動位於獨立的 packages 模組。MySQL 使用 mysql #github.com/xulang-org/packages/mysql 匯入，並在 require: 宣告根模組；database/sql 仍屬於標準庫。SQLite 使用原生 C 橋接。

語言不開放 unsafe、reflect、任意 runtime 指標或任意 syscall 地址。SM2/SM3/SM4/SM9/ZUC/GMTLS 包使用 Xu 實現，不代表已經取得商用密碼認證。

圖形與視窗層面，#gpu 與 #gpu/layout 提供了無視窗 GPU 裝置抽象、統一緩衝區/紋理傳輸、著色器與圖形/計算管線錄製以及精確回讀；#window 與純 Xu 事件包 #window/events 提供了原生視窗生命週期與按視窗輸入事件佇列（鍵盤、指標、滾輪與文字/IME 輸入法）。底層原生驅動依託宿主平臺（如 SDL 3.2+ 或 Metal/Vulkan/D3D12），無需在應用層編寫 C 繫結程式碼。#encoding/binary 則提供了跨平臺大端/小端顯式編碼與 binary32/binary64 浮點數存取。見 #gpu API 與 #window API。

#xacp 是 src/xacp 中與傳輸無關的安全核心：幀上限、許可權、會話生命週期和 UI 介面卡檢查。匯入它不會開啟 stdio 或 TCP。這些鉤子只在 hosted native 可執行程式使用 --xacp 或 --xacp-port 構建時插入。該包已包含在正式 {{xu_version}} SDK 提取結果與生成目錄中。原生會話和 UI 執行驗收仍待驗。見 #xacp API 與命令列參考。
