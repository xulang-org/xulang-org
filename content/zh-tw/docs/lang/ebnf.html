EBNF

當前語法濃縮（用於對照，不是 parser 逐字表）：

Xu 核心語法 EBNF 規範定義
文法規則 (Rule) 語法產生式結構 (Definition) 語義與說明
File "@" PackagePath { CompileTag } { Import } { Decl } . 原始碼檔案根結構，以包路徑宣告開頭
Import [ Ident ] "#" Path . 模組匯入；外部路徑必須使用別名（寫在 # 前）
ReturnStmt "<<" [ Expr ] . 函式返回值返回語句
ThrowStmt ">>" Expr . 丟擲錯誤或異常向上傳播
ExitStmt "<<<" Expr . 程序退出並返回狀態碼
BreakStmt "<-" . 跳出當前迴圈
ContinueStmt "->" . 跳至下一次迴圈迭代
RangeOp ":" . 半開區間運算子 [start, end)
XuStmt "xu" QualifiedName "(" [ Args ] ")" . 啟動輕量級協程併發呼叫
UnsafeBlock "unsafe" Block . 隔離不安全底層硬體操作塊（裸指標解引用、組合語言與 C ABI 互動）
RawPointerType "*raw" Type . 裸指標型別宣告，支援位址強轉與指標算術
AsmStmt "asm!" "(" StringLit { "," AsmOperand } ")" . 原生內聯組合語言語句（支援暫存器繫結與 options 說明）
Attribute ("#[" Ident [ "(" AttrArg ")" ] "]" | "@repr" "(" StringLit [ "," ReprArg ] ")") . 函式修飾屬性（#[no_mangle]、#[naked]）與結構體佈局屬性
Expr … | Expr "or" "(" Ident ")" Block | Expr "or" ">>" . 表示式、安全錯誤解包與向上傳播
點選展開原始 EBNF 純文字文法 
File         = "@" PackagePath { CompileTag } { Import } { Decl } .
CompileTag   = "$" ("freestanding" | "macos" | "linux" | "windows" | Ident) .
Import       = [ Ident ] "#" Path  .
ReturnStmt   = "<<" [ Expr ] .
ThrowStmt    = ">>" Expr .
ExitStmt     = "<<<" Expr .
BreakStmt    = "<-" .
ContinueStmt = "->" .
RangeOp      = ":" . // [start, end)
XuStmt       = "xu" QualifiedName "(" [ Args ] ")" .
UnsafeBlock  = "unsafe" Block .
AsmStmt      = "asm!" "(" StringLit { "," AsmOperand } ")" .
RawPointer   = "*raw" Type .
Expr         = … | Expr "or" "(" Ident ")" Block | Expr "or" ">>" .

PackagePath 使用斜槓路徑，域名身份可用引號包圍；域名中的點保留。匯入別名寫在 # 前，外部路徑必須有別名。
