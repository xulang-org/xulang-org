安裝命令

macOS / Linux

curl -fsSL https://xulang.org/install.sh | bash -s -- --online --version {{xu_version}} --yes

Windows PowerShell

& ([scriptblock]::Create((irm https://xulang.org/install.ps1))) -Online -Version "{{xu_version}}"

平臺邊界

程式碼可發射、SDK 可下載與執行行為已實測是不同層級。請選擇匹配宿主的 SDK；為其他目標發射程式碼，不能證明目標機網路、原生庫或 GUI 已可用。沒有驗收記錄的目標路徑仍屬待驗。參見狀態與限制。

WebAssembly：原生 SDK 可用 xu build app.xu --target wasm32-wasi -o app.wasm 生成 WASI 模組。瀏覽器演練場執行用 Xu {{playground_version}} 構建的 WASM 直譯器。原生套接字、C 庫、程序訪問和原生 WebView 宿主需要原生 SDK。

本機任務：整合狀態區分協議、認證、TLS 與未知的平臺驗收。SQLite 需要匹配的 C 橋接切片和 C 工具鏈，一站式連結路徑為 macOS ARM64 / x64。原生 UI / WebView 需要各系統的庫與目標機實測。

安裝與使用

推薦使用原生 Setup 安裝程式快速完成安裝並自動配置全域性環境：

  • Windows：下載 xu-setup-windows-x64.exe（或 xu-v{{xu_version}}-windows-x64-setup.exe）直接雙擊執行（自繪圖形嚮導，無需配置指令碼策略，自動持久化登錄檔 PATH 與 XU_ROOT）。
  • macOS：下載 xu-v{{xu_version}}-macos-arm64.pkg 雙擊圖形嚮導安裝，或下載獨立安裝程式 xu-setup-macos-arm64（命令列執行 ./xu-setup-macos-arm64 -y）。
  • Linux：下載對應架構的 xu-setup-linux-x64（或 arm64），賦予執行許可權後直接執行 ./xu-setup-linux-x64 -y，自動解壓並完成環境註冊。

安裝完成後重新開啟終端，驗證全域性可用：

xu --version
xu build hello.xu --output hello
./hello
