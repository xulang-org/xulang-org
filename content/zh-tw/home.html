AI 推論指南

原生 AOT 與 WebAssembly

直接編譯為原生機器碼或 WebAssembly，支援 macOS、Linux、Windows 等目標與跨平臺程式碼生成，無需虛擬機器。

所有權與確定性回收

透過所有權與借用檢查管理記憶體，在作用域結束時確定性釋放資源；沒有垃圾回收器，也無需顯式生命週期標註。

輕量協程與型別安全通道

使用 xu f() 啟動輕量協程，以 chan T 傳遞資料和同步任務，將併發直接融入語言。

簡潔語法與型別推導

預設不可變，支援區域性型別推導、結構體、列舉與泛型；無需分號，減少日常編碼中的樣板。

模組管理與擴充套件生態

以 xu.xun、xu.lock 與 vendor 管理相依性，支援離線與凍結構建；標準庫與官方擴充套件包覆蓋網路、密碼、資料庫和訊息服務。

顯式錯誤處理

<< 返回，>> 拋錯，or (err) {} 就地處理或傳播錯誤，讓失敗路徑與正常控制流一起清晰可見。

原生 UI 與 WebView

內建原生繪圖、佈局、控制元件、主題與 IME 輸入，也可使用 WebView 承載網頁；透過 Xu 構建桌面應用。

統一工具鏈與編輯器

統一 xu 命令整合構建、執行、檢查、格式化與文件生成，配套測試工具；透過 LSP 連線 VS Code、Cursor 等編輯器。

C 互操作與原生模組

以 xu native 編譯和打包 C 模組，.xulib 攜帶介面契約與多目標切片；連結流程按目標平臺選擇。

常見問題解答 (FAQ)

什麼是 Xu 程式語言？

Xu 是一門靜態型別、原生 AOT 編譯的系統程式語言，採用所有權與借用檢查，內建輕量協程和型別安全通道，既適用於高性能網路微服務與原生桌面 UI，也原生支援無宿主裸機韌體與作業系統微核心開發。

Xu 語言是否有垃圾回收（GC）？

沒有。Xu 透過編譯期所有權與借用檢查管理資源生命週期，在作用域結束時確定性釋放資源，無需執行時垃圾回收器。詳見所有權與借用及共享狀態同步與原生 / FFI 安全邊界 FAQ。

Xu 支援原生桌面 UI 嗎？

支援。SDK 提供原生繪圖、佈局、控制元件與桌面服務，也可透過 WebView 使用 HTML/CSS/JavaScript 構建介面。原生控制元件介面無需網頁；支援範圍與平臺相依性見 UI 常見問題和開發指南。
