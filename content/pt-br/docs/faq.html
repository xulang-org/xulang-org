Perguntas frequentes (FAQ)

Frequently Asked Questions & Answers

O que é a linguagem de programação Xu?

Xu é uma linguagem de sistemas de alto desempenho com segurança de memória em tempo de compilação. Une o modelo de concorrência simples de Go (corrotinas e canais) à performance determinística Zero-GC de C/Rust.

Quais são os principais objetivos de design do Xu?

Metas fundamentais: zero overhead em execução, inferência automática de propriedade, sintaxe moderna sem anotações complexas de tempo de vida, compilador nativo AOT e interoperação com C/C++.

Como o Xu garante a segurança de memória sem coletor de lixo (Zero-GC)?

Adoção de propriedade única e verificador de empréstimos, garantindo desalocação determinística ao sair do escopo (RAII), sem vazamentos nem ponteiros nulos.

Como funciona o verificador de empréstimos (Borrow Checker) no Xu?

Suporte estrito a empréstimos imutáveis &T e empréstimos mutáveis exclusivos &mut T validados na compilação.

Como é projetado o modelo de concorrência do Xu?

A palavra-chave xu inicia corrotinas leves que se comunicam através de canais tipados chan<T> de maneira segura e sem travas manuais.

Podem ocorrer condições de corrida (Data Races) no Xu?

A troca de dados entre corrotinas impõe transferência de propriedade (Move) ou cópia profunda imutável, eliminando condições de corrida.

Qual é o modelo de agendamento e execução das corrotinas do Xu?

Agendador híbrido M:N integrado com E/S assíncrona nativa (epoll, kqueue, IOCP) para escalabilidade massiva de conexões.

Como funciona o tratamento de erros no Xu?

Controle de fluxo de erros simbólico (<< sucesso, >> erro) associado a expressões catch claras e previsíveis.

O Xu oferece suporte à programação orientada a objetos?

Composição sobre herança através de struct, métodos estendidos e interface para polimorfismo robusto.

Como o Xu interage com bibliotecas nativas em C e C++?

FFI com C de custo zero, viabilizando o consumo direto de headers C e bibliotecas estáticas ou compartilhadas (.a, .so, .dylib, .dll).

Quais sistemas operacionais e arquiteturas de processador são suportados?

Compatibilidade nativa total com macOS (ARM64/x64), Linux (ARM64/x64/LoongArch/RISC-V) e Windows (x64/ARM64).

O Xu oferece suporte a WebAssembly?

Suporte pleno a WebAssembly gerando binários wasm32-wasi para navegadores e runtimes de servidor.

Como os módulos e dependências são gerenciados no Xu?

Gerenciamento claro de dependências via xu.xun e builds reprodutíveis garantidos por xu.lock com hashes criptográficos.

Existe um repositório central de pacotes para o Xu?

Ecossistema descentralizado via Git com catálogo oficial de pacotes homologados.

O que é o formato de distribuição estática .xulib?

O formato .xulib empacota bibliotecas binárias multi-arquitetura e assinaturas de tipos para integração direta.

Como funciona a arquitetura de interface nativa e WebView do Xu?

Framework de interface desktop nativa acelerada por GPU e suporte integrado a WebView com comunicação bidirecional.

Como o Xu oferece suporte ao desenvolvimento móvel para iOS e Android?

Desenvolvimento para plataformas móveis iOS e Android com o comando xu build --phone.

Quais ferramentas de desenvolvimento e integrações com IDE estão disponíveis?

Extensão oficial para VS Code e Cursor com o servidor de linguagem xu-lsp, diagnósticos ao vivo e suporte a depuração LLDB.

Qual é o status atual de estabilidade e lançamentos do Xu?

Em ciclo oficial de versões 0.x com sintaxe do núcleo congelada e validação contínua em 100% dos testes de CI nas seis plataformas.
