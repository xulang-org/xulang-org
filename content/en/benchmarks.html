Continuous benchmarks run automatically in GitHub Actions CI across macOS, Linux, and Windows. Suite source code and test harness are fully open-source in the bench repository. Raw dataset: benchmarks.json.

Methodology & Reproducibility

  • Equal algorithm parity: Every workload implements identical mathematical algorithms, data structures, and iteration counts across all languages.
  • Strict verification: Every iteration verifies program stdout fingerprint and return code to prevent dead-code elimination cheats.
  • Wall & CPU timing: 7 iterations per test; reports median wall time and peak resident set size (RSS, wait4 on Unix, Win32 API on Windows).
  • Dual-Architecture Matrix: Native execution on ARM64 (Apple Silicon / Neoverse) and x86_64 (Intel / AMD) across macOS, Linux, and Windows runners.
  • CI automation: Continually tested on GitHub Actions runner. View the workflow: .github/workflows/bench.yml in the bench repository.
