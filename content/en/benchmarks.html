Multi-Architecture Cross-Language Benchmarks

Rigorous, reproducible cross-language benchmarks comparing Xu v0.8.11 against C (best Clang O1–O3), Rust (best rustc O1–O3), Swift (swiftc -O), and Go (go build) across 13 measured workloads. Concurrently verified across dual architectures (ARM64 & x86_64) on macOS, Linux, and Windows.

Continuous benchmarks run automatically in GitHub Actions CI across macOS, Linux, and Windows (ARM64 + x86_64). Suite source code and test harness are fully open-source in the bench repository. Raw dataset: benchmarks.json. Source Actions run · Xu afd05ca35f5d6c270f4415af807fece5ce64bba8. Ratios use the lowest same-platform C/Rust O1–O3 median. A dash means no measurement. Different runner timings are not speedup evidence. SHA-256 uses hardware instructions when available on ARM64; x64 currently uses software. Cryptographic library paths may differ.

Methodology & Reproducibility

  • Seven whole-program samples per implementation; wall time is the median, including process startup.
  • C and Rust rows select the lowest measured median among O1/O2/O3 for that workload and platform. Go and Swift show only measured implementations.
  • Every Xu workload output and exit status passed the benchmark harness. All six compiler identities match the recorded commit, version, source closure and Gen2=Gen3.
  • Resource ranges do not establish an overall ranking. Linux peak RSS is collected in a separate post-exec run; tracing is excluded from wall time. macOS uses wait4 and Windows uses peak working set; these OS accounting methods differ. C/Rust footprint rows use O3 builds.
  • Runner hardware, libraries, startup costs and hardware acceleration differ. Compare ratios within one platform; do not interpret cross-machine timing changes as optimization speedups.
