The current source development candidate is Xu 0.8.3, with direct argument execution for dependency downloads and SHA-256 verification of sources, caches and vendor content. Module declarations and imports now use slash paths and preserve domain punctuation. Dotted local declarations and old lock identities require migration; Explicit transitive dependency closure, offline and frozen builds are available. Official package imports use the github.com/xulang-org/packages root module. MVS and proxy resolution remain in progress. The self-host build skips Gen4 when Gen2 and Gen3 are byte-identical, while retaining Gen4 confirmation after a warm-up transition. Candidate downloads require release packaging.

Compiler release files are distributed through GitHub Releases. Choose a published version and the matching platform asset. Development candidate downloads become available after release packaging.

Installation example

The compiler command is xu. After downloading the Apple Silicon macOS file:

chmod +x xu.macos.arm64
mv xu.macos.arm64 xu
# Place xu on PATH
xu build hello.xu
./hello

Default artifacts have no suffix on macOS / Linux and use .exe on Windows. Use --output to choose an output path.
