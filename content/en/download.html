Installation & Usage

We recommend using native Setup installer packages for automated global environment configuration:

  • Windows: Download xu-setup-windows-x64.exe (or xu-v{{xu_version}}-windows-x64-setup.exe) and double-click to launch the native GUI wizard (no PowerShell ExecutionPolicy restrictions, automatically configures user registry PATH and XU_ROOT).
  • macOS: Download xu-v{{xu_version}}-macos-arm64.pkg for standard GUI installation, or standalone xu-setup-macos-arm64 (run ./xu-setup-macos-arm64 -y).
  • Linux: Download xu-setup-linux-x64 (or arm64), run chmod +x xu-setup-linux-x64 && ./xu-setup-linux-x64 -y for zero-dependency automated installation and Shell PATH configuration.

Open a new terminal window after installation to verify:

xu --version
xu build hello.xu --output hello
./hello
