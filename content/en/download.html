Installation example

Use a complete SDK with its standard-library sources and tools. In an extracted Unix SDK directory:

source env.sh
xu --version
xu build hello.xu --output hello
./hello

For permanent installation run ./install.sh; Windows uses install.ps1 or env.ps1. Standard-library imports require src/ alongside the compiler or an explicit XU_STDLIB_ROOT.
