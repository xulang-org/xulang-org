Supersonic Native AOT

Zero VM, zero runtime bloat. Directly compiles to standalone native machine binaries with first-class cross-compilation support (macOS, Linux, Windows) and sub-millisecond cold start.

Zero-Cost Ownership & RAII

No Stop-The-World GC pauses. Unique ownership with deterministic RAII scoping drop; shared &T and exclusive &mut T borrow semantics statically eliminate data races.

Native Coroutines & Channels

First-class language-level concurrency. Spawn lightweight user-space coroutines via xu f() and coordinate across type-safe chan T pipelines, designed for high-throughput modern servers.

Clean & Expressive Syntax

No semicolons, no redundant parens, immutable by default. Intuitive flow symbols: << return, >> throw, or (err) {} catch, <- break, and -> continue for clear readability.

Batteries-Included Toolchain

Unified xu CLI (build, run, test, bench, fmt) with native xu.xun manifests. Rich standard library covering async net/HTTP, cryptography & SM cipher suites, SQL, and desktop WebView.

Deterministic Safety & Zero UB

Eradicate C/C++ silent Undefined Behavior (UB). Strict compile-time null safety, memory bounds checking, and explicit error propagation ensure rock-solid, predictable systems software.
