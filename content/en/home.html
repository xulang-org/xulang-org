Expressive Thin Syntax

No semicolons, no redundant parens on if/for. Intuitive flow operators: << zero-cost return, >> throw error, or (err) {} catch, <- break, -> continue. Immutable by default with lowest cognitive load.

Zero-Cost Ownership

Zero GC pauses. An owning value has exactly one owner, dropped deterministically at scope exit. &T shared borrows and &mut T exclusive borrows eliminate all data races at compile time.

Supersonic Native AOT

Static single-file native binaries with first-class cross-compilation support. xu build / xu run / xu check. Produces binaries without a suffix by default on macOS/Linux and .exe on Windows.

Try XU in Browser (WebAssembly Playground)

Choose an example or edit the code, then click Run Code to see the result. Xu parses and checks your program, then executes it in your browser. No installation or server upload is needed.
