Native AOT & WebAssembly

Compile directly to native machine code or WebAssembly, with targets including macOS, Linux, and Windows. Cross-platform code generation needs no virtual machine.

Ownership & Resource Lifetimes

Ownership and borrow checking govern memory lifetimes, with deterministic cleanup at scope exit. No garbage collector or explicit lifetime annotations.

Coroutines & Typed Channels

Start lightweight coroutines with xu f() and use chan T to exchange data and synchronize tasks. Concurrency is part of the language.

Clear Syntax & Type Inference

Immutable by default, with local type inference, structs, enums, and generics. Semicolon-free syntax keeps everyday code concise.

Modules & Library Ecosystem

Manage dependencies with xu.xun, xu.lock, and vendor, including offline and frozen builds. Standard and extension libraries cover networking, cryptography, databases, and messaging.

Explicit Error Handling

<< returns, >> raises an error, and or (err) {} handles or propagates it. Failure paths stay visible alongside normal control flow.

Native UI & WebView

Build desktop applications with native drawing, layout, controls, themes, and IME input. Use WebView to host web interfaces when needed.

Toolchain & Editor Support

Use xu for builds, running, checks, formatting, documentation, and test tooling. LSP connects the SDK to VS Code, Cursor, and other compatible editors.

C Interop & Native Modules

Compile and package C modules with xu native. Distribute interface contracts and multiple target slices in .xulib, with linking steps defined for each target.

Frequently Asked Questions (FAQ)

What is the Xu programming language?

Xu is a statically typed systems language that compiles ahead of time to native code. It combines ownership and borrow checking with lightweight coroutines and typed channels for command-line tools, network services, and desktop applications.

Does Xu use a garbage collector (GC)?

No. Compile-time ownership and borrow checking govern resource lifetimes, with deterministic cleanup at scope exit and no runtime garbage collector. See Ownership & Borrowing.

Does Xu support native desktop UI?

Yes. The SDK includes native drawing, layout, controls, and desktop services, plus WebView for HTML/CSS/JavaScript interfaces. Native controls need no web page. See the UI FAQ and UI guide for capabilities and platform requirements.

How does Xu perform?

The benchmark dashboard compares Xu, C, Rust, Go, and Swift across 47 workloads on six ARM64 / x86-64 platforms, with measured runtime, memory, binary size, and source records.
