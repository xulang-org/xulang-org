Release notes

Changes, fixes and migration notes by release. To install the SDK, visit downloads.

0.10.7 release

Repairs existing-SDK reinstalls and failures caused by read-only standard-library files. Setup and the updater verify and replace the full SDK, retain the original backup, and restore it on failure. Online scripts and macOS PKG share the same process; a legacy version line restores old-updater compatibility. See the release and upgrade notes and 0.10.7 checksums.

0.10.6 release

The complete SDK includes corrected UI, WebSocket and DNS examples and checks them after installation. Upgrade the full SDK; read the patch release notes and verify downloads with 0.10.6 SHA256SUMS.

Upgrading older installations: the updater in older versions such as 0.10.2 incorrectly rejects the new version banner. Run the complete Setup installer for your platform below, or use the online commands in the installation guide for a one-time upgrade. A complete installation also refreshes examples, xu-update, xu-lsp and editor files. See upgrade and migration.

0.10.5 release

Source debugging, native Setup installation and standard-library updates, plus compiler and LSP fixes. Constants now use UPPER_SNAKE_CASE; read the release and migration notes. All downloads below belong to the same official release; verify archives with SHA256SUMS.

0.10.2 release

Self-contained toolchain discovery, native socket readiness (epoll / kqueue / IOCP), RFC1951 DEFLATE compression, and ergonomic UI Screen abstractions. Read the release notes and download the official SDK assets and checksums.

0.10.1 release

Styled UI controls and theme switching, desktop requests, Thumb-2 code generation, cryptography and standard-library corrections. Regexp callers must handle budget errors; HTTP handlers may overlap. Read the migration notes and download the official SDK assets and checksums.

0.9.4 release

Compiler consistency and optimizer release: the borrow checker walks every expression kind and keeps loop borrows live across the back edge, so aliasing such as f(mut &v, &v) nested in casts or arithmetic is now diagnosed; generics accept any number of type parameters; XU_VERIFY=1 runs the full MIR verifier after every pass; scalar SSA promotion no longer depends on a shape whitelist and ARM64 loop kernels gain SSA-based matchers. See release notes and verified SDK assets.

0.9.3 release

Critical stability and code generation fixes: corrects callee-saved register allocation clobbering in multi-parameter self-recursive functions (enabling safe deep recursion and nested binary expression recursion); eliminates compiler out-of-bounds crash on undefined function symbols with clean diagnostics; passes 8 comprehensive syntax suites and full-matrix regressions across ARM64 and x86-64. See release notes and verified SDK assets.
