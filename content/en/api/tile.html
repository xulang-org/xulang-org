#tile

Xu {{xu_version}} API

import: #tile

counts: 33 fns, 0 methods, 5 types, 16 consts, 0 ifaces

Explicit 1D/2D tile movement, reduction, and matrix multiplication primitives. On hosted arm64 and x64 targets at -O1+, `gemm_i64` and canonical 1D loops are automatically lowered by `MirTilePlan` (`tile_gemm`) and the whole-loop SIMD matchers into L1-blocked 2D register-tile and vector micro-kernels; all other targets and -O0 execute the portable reference loops below with identical bounds and wrapping semantics. Submodules dlpack.xu: DLPack v0.8+ C-ABI compliant tensor descriptor and zero-copy view (TVM-FFI). profile.xu: Microarchitecture cache-hierarchy tuning profiles and dynamic tile bounds (TransTuning / MetaSchedule). lut.xu: Table Lookup GEMM (LUT-GEMM) for low-bit u4/s4/u2 weights (T-MAC). pipe.xu: Pipelined operator fusion and online algebraic softmax reduction (Neptune).
