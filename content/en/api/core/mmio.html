#core/mmio

Xu {{xu_version}} API

import: #core/mmio

counts: 8 functions, 24 methods, 12 types, 0 constants, 0 method sets

Strongly-typed volatile MMIO register wrappers for baremetal kernels and drivers. Each wrapper has exact C layout matching its scalar width (`u8`/`u16`/`u32`/`u64`).
