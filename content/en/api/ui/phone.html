Mobile UI

#ui/phone uses the #ui/draw frame protocol. Use available() to check for the mobile host and platform() to distinguish iOS and Android. host_insets() supplies viewport safe areas and keyboard inset in logical units for scaffold_with.

  • Touch handles tap targets, scrolling, edge-back gestures and pull-to-refresh. Register targets when recording each frame, then feed host events through Touch.event.
  • RouteStack keeps navigation state. TextField handles native IME sessions and uses UTF-8 byte offsets for anchor and focus.
  • light_theme() and dark_theme() supply shared design tokens for the phone controls. Read reduced_motion() when choosing transitions.

Package an app and configure the platform tools using the mobile app guide.
