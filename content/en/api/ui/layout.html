API

#ui/layout

Xu {{xu_version}} API

import: #ui/layout

counts: 11 fns, 29 methods, 10 types, 19 consts, 0 ifaces

Constraints, sizes, rectangles, row / column / stack / padding and retained layout trees. Constraints flow downward and measured sizes upward. BoxStyle width / height=-1 means natural size. Trees allow 4096 nodes and depth 64; removed node IDs never repeat. View in widgets handles painting and input.

Usage and lifetimes

const max_extent

XuAPI
pub const max_extent = 1000000000

Purpose

Layout uses logical pixels, with the same finite extent limit as draw.Frame. A parent supplies Constraints; children return a Size within those constraints. Value `1000000000`.
