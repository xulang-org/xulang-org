Modal

Complete a focused decision in a dialog

Run the Xu example ↗

The example executes in the browser using the Xu/WASM runtime.

What to try

Open a confirmation, cancel it and confirm it.

Usage notes

Keep interaction inside the dialog while open and restore focus to its trigger on close. Define confirm, cancel and dismiss behavior explicitly.

Create through Screen

The Screen constructor returns a node ID. Pass that ID to Screen layout, state and event APIs. It is separate from the standalone control object documented below.

Native Xu setup fragment: call configure during initialization of an existing Screen. See the complete example for window creation, event dispatch and cleanup.

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    id := screen.modal("Apply changes?","Review before confirming.") or >>
    << id
}

Standalone control object API

These types and methods support applications that manage control objects, input and painting directly. Their receiver is a control object, not a Screen node ID. For Screen usage, use the constructor above and the Screen methods in the Widgets module.

struct Modal

XuAPI
pub struct Modal {

}

Purpose

Modal owns the keyboard focus order, while the host owns the actual child controls. Use blocks_input as the dispatch gate, including the closing fade. Cancel background View input before open (cancel_input) to release capture and native editor focus. Apply focused_id after open/input, and restore take_restore_focus after tick reports the closing fade finished. Never dispatch to background while blocks_input first call input, honor consumed even when that input closes the modal, then dispatch only to modal children if allows_content.

Public fields

This type has no public fields.

($&Modal) set_focus_order

XuAPI
pub fn (m $&Modal) set_focus_order(ids &[]int) int

Purpose

Set the modal's Tab traversal order so keyboard focus cycles through the specified controls.

Parameters

m $&Modal
The Modal instance used by this call (exclusive borrow).
ids &[]int
Ordered content control IDs, at most 256; IDs must be positive, unique and different from the modal's own ID.

Returns

Returns 0 on success; failure throws rather than returning a nonzero status.

Usage notes

  • Retain the old focus when listed, otherwise select the first target; an empty list has no content focus target.

Error handling

  • An invalid count, ID or duplicate throws.

($&Modal) open

XuAPI
pub fn (m $&Modal) open(now time.Instant,reduced_motion bool,restore_focus int) int

Purpose

Open the modal and remember the focus restoration target.

Parameters

m $&Modal
The Modal instance used by this call (exclusive borrow).
now time.Instant
Current animation time.Instant; use the same time basis for opening, ticking and closing.
reduced_motion bool
Whether to reduce motion; true moves directly to the target state.
restore_focus int
Control ID to restore after closing; 0 means no target and negative values are invalid.

Returns

Returns 0 on success; failure throws rather than returning a nonzero status.

Usage notes

  • Advance animation with tick each frame and use is_visible to decide whether painting must continue.

Error handling

  • Invalid animation parameters or state throw. A negative focus restoration ID also throws.

(&Modal) allows_content

XuAPI
pub fn (m &Modal) allows_content(event &ui.InputEvent) bool

Purpose

Decide whether input may reach modal content after modal-first dispatch.

Parameters

m &Modal
The Modal instance used by this call (borrow).
event &ui.InputEvent
Input event for the same window, canvas and generation, with coordinates in the control's canvas space.

Returns

true when allowed; false when closed, mismatched, handling Tab/Escape, or hitting the close button.

Usage notes

  • Keyboard input also requires a content focus target; pointer input must be inside the panel.

($&Modal) input

XuAPI
pub fn (m $&Modal) input(event &ui.InputEvent) Action

Purpose

Handle modal dismissal and Tab focus cycling before deciding whether content can receive input.

Parameters

m $&Modal
The Modal instance used by this call (exclusive borrow).
event &ui.InputEvent
Input event for the same window, canvas and generation, with coordinates in the control's canvas space.

Returns

An Action: kind identifies the action, consumed marks a handled event, request_focus requests focus, and needs_paint requests repainting.
