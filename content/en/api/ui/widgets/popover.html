Popover

Show interactive content beside an anchor

Run the Xu example ↗

The example executes in the browser using the Xu/WASM runtime.

What to try

Open preferences and apply a choice.

Usage notes

Show temporary interactive content beside an anchor. Distinguish apply from cancel; dismissing the popover should not commit an unconfirmed edit.

Create through Screen

The Screen constructor returns a node ID. Pass that ID to Screen layout, state and event APIs. It is separate from the standalone control object documented below.

Native Xu setup fragment: call configure during initialization of an existing Screen. See the complete example for window creation, event dispatch and cleanup.

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    anchor := screen.button("Preferences") >>>
    screen.place(anchor,24.0,24.0,180.0,40.0) >>>
    id := screen.popover(anchor,"Preferences") >>>
    << id
}

anchor (int)
text string
text (string)

Returns

Placement, state and events

The application owns the component. Screen.place positions nodes; Screen.set_enabled and Screen.set_visible control availability and visibility. Present again after state changes, handle >>> errors, and keep topology changes outside paint callbacks. ToastHost uses its own queue API.

Standalone control object API

These types and methods support applications that manage control objects, input and painting directly. Their receiver is a control object, not a Screen node ID. For Screen usage, use the constructor above and the Screen methods in the Widgets module.

($&Popover) open

XuAPI
pub fn (p $&Popover) open(now time.Instant,reduced_motion bool) int

Purpose

Open the popover with its entrance animation; a disabled popover stays closed.

Parameters

p $&Popover
The Popover instance used by this call (exclusive borrow).
now time.Instant
Current animation time.Instant; use the same time basis for opening, ticking and closing.
reduced_motion bool
Whether to reduce motion; true moves directly to the target state.

Returns

Returns 0 on success; failure throws rather than returning a nonzero status.

Usage notes

  • Advance animation with tick each frame and use is_visible to decide whether painting must continue.

Error handling

  • Invalid animation parameters or state throw.

XuAPI
pub fn (p $&Popover) input(event &ui.InputEvent) Action

Purpose

Handle outside presses, Escape and cancellation according to the popover's dismissal settings.

Parameters

p $&Popover
The Popover instance used by this call (exclusive borrow).
event &ui.InputEvent
Input event for the same window, canvas and generation, with coordinates in the control's canvas space.

Returns
