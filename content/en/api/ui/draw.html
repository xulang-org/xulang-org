struct Point

XuAPI
pub struct Point {
    pub x int
    pub y int
}

Purpose

Immediate-mode canvas (Love2D / Raylib / Cairo-style) on `#ui` content_draw. No WebView. Origin is top-left, pixels. begin clears the display list and resets the pen; present paints. Clicks/prompt/scroll/drag: poll(app.event_ch) / poll_click / prompt `#ui` owns the host event pump; this package does not read the shell event file. Color: "#RRGGBB" or "#RRGGBBAA". "-" skips a fill or stroke. Pen (host-side, like love.graphics.setColor): set_color / set_fill set_stroke / set_width, then rect/circle/ellipse/triangle. Transform stack (CTM): push / pop / origin / translate / rotate / scale. scale(sx,sy) is percent (100 = 1x). rotate is degrees, clockwise.
