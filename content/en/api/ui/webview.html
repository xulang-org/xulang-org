    pub sim int

Purpose

Content backend for ui.Window: system WebView + IPC (`#ui/webview`). attach registers a ContentPlugin with per-OS host sources; #ui shell picks the current OS at App.run. Shell/window/menu/tray stay in #ui. two content modes (no local HTTP server in either) 1. Local — stage_www_root / bind_ipc_www + xu://app/ (scheme flag "xu"; host intercepts). Packed oneexe sets XU_UI_WWW=:mem: and serves www/icon from the binary (no TEMP extract). 2. Remote — load_url("http(s)://…"); we do not serve that origin. Adapted remote pages may still call xu://app/__xu/* (and optional xu://app/ static) into the app. UI host must be statically linked (pack_*ui_oneexe.py); no external host process.
