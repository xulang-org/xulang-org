texture_2d

XuAPI
pub fn texture_2d(format int, width int, height int, levels int, row_alignment int, level_alignment int) TextureLayout2D

Purpose

levels=0 means the full mip chain. Otherwise levels is 1...mip_count_2d. Alignments are in bytes; (1,1) returns tight logical storage. Device limits, resource budgets, allocation, row copies and mip generation are separate. All products, sums and rounding are checked before growing the result. Throws on failure; handle the error or propagate it to the caller.
