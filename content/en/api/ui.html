const content_none

XuAPI
pub const content_none = 0

Purpose

Desktop shell: App / Window / Icon / Menu / Tray / events / post queue. Owns the UI (shell) runtime event loop and host process. Content backends: register_content_plugin(ContentPlugin) with per-OS sources. Native open: compile-time `$macos` / `$linux` / `$windows` files (host_open_*.xu) each define open_native_window — App.run does not branch on OS. Host modes default → OS native host (macOS / Linux / Windows) XU_UI_SIM=1 → in-process sim (fixtures/CI) Value `0`.
