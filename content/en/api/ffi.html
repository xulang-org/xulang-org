C interoperation helpers for code that calls extern "C" functions. Pointers are c_ptr values: addresses of C memory that Xu cannot borrow check. Everything here that touches memory behind a c_ptr is an unsafe fn, callable only inside `unsafe { }`; the caller vouches that the address is valid for the access. Offsets are in bytes.
