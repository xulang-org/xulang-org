pub struct Reader {

    pub pos int

    pub lazy_quotes bool
    pub sticky string
    pub fields_per_record int
    pub trim_leading_space bool
    pub learned int
}

Purpose

CSV reader/writer aligned with `encoding/csv` (RFC4180 subset). Operates on owning strings (no io.Reader struct@ values). Errors never << a partial record. Default comma is ','; comment line support via `comment` rune (0 = off). Writes use '\n' (not CRLF).

Purpose
