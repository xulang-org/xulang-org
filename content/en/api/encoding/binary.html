struct Endian

pub struct Endian {

Purpose

`encoding/binary` (little_endian / big_endian Endian values with get_u16/32/64 and put_u16/32/64). models the byte orders as empty structs with methods; Xu has no methods on enums — the checker rejects any non-struct receiver ("method receiver must be a struct"), so Endian is a struct carrying a single `little bool` (behavior-identical, no enum is used). get_* assemble from a shared borrow `&[]int` after a full bounds check (Err, never a partial read); put_* write through an exclusive borrow `&mut []int` and validate the whole range before the first store (Err, never a partial write). All byte assembly/disassembly goes through masks (`& 0xFF`, `<< 8`, `>> 56`), so u64 bit patterns round-trip through i64 with no arithmetic-overflow path (put/get of the high bit are bit-exact via `& 0xFF` byte extraction).
