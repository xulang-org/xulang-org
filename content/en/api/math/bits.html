leading_zeros

XuAPI
pub fn leading_zeros(x int) int

Purpose

leading_zeros: number of zero bits before the highest set bit. Binary search: each `(v >> n) == 0` test is sign-agnostic (arithmetic shift yields 0 iff the top n bits are all zero, since the sign bit is in that window), then the low bits are shifted up.

pub fn trailing_zeros(x int) int

Purpose

trailing_zeros: number of zero bits after the lowest set bit. Binary search on the low bits; the arithmetic right shifts are safe because only the low (64-n) bits of the result are ever inspected, and those are identical for arithmetic and logical shifts.

ones_count

XuAPI
pub fn ones_count(x int) int

Purpose

ones_count: population count via SWAR parallel summing of adjacent bits ( `bits.OnesCount64`, from "Hacker's Delight" ch. 5). The three mask constants m0/m1/m2 zero the sign-extension bits after the arithmetic shifts, and after the `& m2` step the value is non-negative so the trailing `+ (v >> n)` folds are plain logical shifts.
