load_int

XuAPI
pub fn load_int(x &mut int) int

Purpose

===== sync/atomic ( sync/atomic, int-sized) ===== The runtime builtins are atomic_load / atomic_store / atomic_add atomic_cas — the `atomic_` prefix keeps them distinct from the wrapper names below (the same shadowing rule as the os package: a wrapper named `atomic_load` would shadow the builtin and self-recurse). Each builtin takes a mutable int location (`&mut int`; callers write `mut &x`). add returns the old value; cas returns a bool.

pub struct RWMutex {
    pub mu Mutex
    pub readers int
}

Purpose

===== RWMutex ( sync.RWMutex; reads do not run in parallel) ===== a single Mutex plus a reader count. Writers take the mutex; a reader takes it on entry (first-in) and releases it on exit (last-out), so reads serialize with each other and with writers — a documented divergence from parallel reads.
