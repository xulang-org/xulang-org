XuAPI
pub fn (c &mut Conn) set_deadline(t_ns int) int

Purpose

Conn.SetDeadline / SetReadDeadline / SetWriteDeadline. t_ns is absolute now_ns; 0 clears. Remaining time is applied as SO_RCVTIMEO/SO_SNDTIMEO before the next read/write so an in-flight syscall can return; 0 does not clear an already-armed kernel timeout until the next I/O path that sees t_ns==0 (set_deadline(0) does).

struct Dialer

XuAPI
pub struct Dialer {
    pub timeout_ns int
    pub dual_stack bool
    pub local_ip string
    pub local_port int
}

Purpose

Dialer / ListenConfig and -shaped Dial/Listen (network, address). Context is for Dial/Listen ( DialContext / ListenConfig.Listen), not for Conn.Read/Write — those use SetDeadline like. The fd-level dial(addr)/listen(addr) in mod.xu stay for http/smtp.

Parameters

timeout_ns int
timeout_ns is a relative connect bound (SO_SNDTIMEO). 0 means no extra bound; context.deadline_ns still applies. dual_stack local_ip / local_port are stored for API shape and ignored by the stream dialer; UDP callers pass explicit local addresses.
dual_stack bool
field (bool)
local_ip string
field (string)
local_port int
field (int)
