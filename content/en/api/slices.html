binary_search_ints

XuAPI
pub fn binary_search_ints(xs &[]int, v int) SearchResult

Purpose

Binary-search an ascending slice, returning both a match flag and an insertion position.

Parameters

xs &[]int
Elements to process.
v int
Element to find or insert.

Returns

SearchResult.index is the first position not less than the target, in 0..xs.len. Treat it as an existing element only when found is true.

Usage notes

  • Sort ascending with the same ordering first. An absent value does not return -1; an empty slice yields index = 0, found = false.

Call example

Find a duplicate and a missing value

XuLocal SDK example
@main
#slices

fn main() {
    values := [1, 3, 3, 7]
    hit := slices.binary_search_ints(&values, 3)
    println(hit.index)
    println(hit.found)
    absent := slices.binary_search_ints(&values, 4)
    println(absent.index)
    println(absent.found)
}

3
