IntHeap / StrHeap min-heaps.

struct IntHeap

XuAPI
pub struct IntHeap {
    pub a []int
    pub n int
}

Purpose

Binary min-heap aligned with `container/heap` Init/Push/Pop, specialized to `IntHeap` / `StrHeap` (no Interface / function values). Logical length `n` is separate from backing capacity so Pop is O(log n) and does not rebuild the array. Mutating API is methods (field `.push` on `&mut Struct` params does not write the descriptor back).
