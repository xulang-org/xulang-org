struct Ring

pub struct Ring {
    pub val []string
    pub next []int
    pub prev []int
    pub cur int
}

Purpose

Circular list aligned with `container/ring`, specialized to owning strings (no `temp`, no element pointers). a Ring owns a dense circular arena; element handles are indices. Unlink/link rebuild the active cycle (O(n)) — fine for the small rings this package targets. Do(fn) available since (fn values).
