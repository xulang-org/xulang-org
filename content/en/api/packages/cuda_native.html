counts: 7 functions, 36 methods, 4 types, 0 constants, 0 method sets

Pure-Xu dlopen backend for CUDA Driver API + NVRTC + cuBLAS. No C wrapper or compile-time link flags required: loads libcuda / libnvrtc / libcublas dynamically at runtime on Linux/Windows and allows XU_CUDA_LIBRARY / XU_NVRTC_LIBRARY XU_CUBLAS_LIBRARY overrides for custom driver paths or test mocks.
