counts: 7 fns, 4 methods, 2 types, 3 consts, 0 ifaces

Shared client transport for external drivers. A connection keeps the complete TLS state when secure is true. Callers must pass Conn values around instead of retaining only fd; an fd alone cannot represent a live TLS session.
