import: vulkan_native #github.com/xulang-org/packages/vulkan_native

counts: 9 functions, 19 methods, 4 types, 0 constants, 0 method sets

Pure-Xu dlopen backend for Vulkan 1.1 compute pipelines (Linux / Windows / MoltenVK). Uses SPIR-V 1.0 compute binaries generated directly in pure Xu (spirv.xu) and allows XU_VULKAN_LIBRARY override for custom ICD/loader paths or test harnesses.
