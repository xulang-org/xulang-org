with_cancel_parent

pub fn with_cancel_parent(parent &Context) Cancel

Purpose

with_cancel_parent is the parent-aware form of with_cancel. The returned context shares the parent's deadline and is canceled when the parent's Done channel closes. Parent and child Cancel values can still be canceled explicitly; close_once makes all three paths idempotent.
