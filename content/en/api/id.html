import: #id

counts: 5 fns, 1 methods, 1 types, 0 consts, 0 ifaces

Sortable identifiers for messages / files / sessions. ULID (Crockford base32, 26 chars): 48-bit ms timestamp + 80-bit random. UUIDv7 (RFC 9562): 48-bit unix ms + version/variant + 62-bit random, canonical 8-4-4-4-12 lowercase hex. Monotonic ULID: same-millisecond ids increment the random field so lexicographic order matches issue order on one process. Xu forbids package mutable globals — keep a Monotonic generator per producer.
