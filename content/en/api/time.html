Duration is int nanoseconds. now/sleep, Time, Timer/Ticker (xu+chan+sleep). No IANA zones.

nanosecond

XuAPI
pub fn nanosecond() int

Purpose

Duration is an int count of nanoseconds. now/since use the monotonic clock now_time/until use wall_time_ns (Unix epoch). sleep wraps the hosted sleep primitive. Freestanding rejects all hosted clock builtins at check time. Location is UTC or a fixed offset (`fixed_zone`). There is no IANA tzdata or DST. `load_location` accepts "", "UTC", "GMT", and `UTC±H[H][:MM]` `GMT±H[H][:MM]`. Time itself stays Unix UTC; `*_in(loc)` `format_rfc3339_in` apply offset.

Purpose

Location is a named UTC offset in seconds east of UTC, plus optional POSIX DST rules and TZif transition tables. IANA names are loaded from usr/share/zoneinfo (Unix TZif v2 64-bit transitions + POSIX footer). No bundled tzdata; Windows has no zoneinfo path in v1.
