High-density timers for heartbeats / TTL / file RTO. time.AfterFunc / Ticker spawn one sleeper task each. A gateway holding 5k heartbeats must not own 5k tasks. v1 Wheel is **poll-based**: the caller owns the list (no `&mut` across `xu`, S6). Typical use is one coordinator task w := timer.new w.after_ns(30 * time.millisecond) w.every_ns(time.second) for { id := w.run // sleeps until next deadline, returns due id... } A background `xu` wrapper can sit on top once channel-of-struct is proven on the self-host path.
