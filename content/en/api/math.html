abs

XUv0.1.0
pub fn abs(x f64) f64

Purpose

f64 helpers aligned with `math` (Abs / Min / max / Floor / Ceil Sqrt / Pow with integer exponent; pow_f64 is Pow; plus exp/log/trig). Pure f64 arithmetic; no tables, no pointers. Hosted emit replaces abs with a branchless hardware/sign-mask operation and arm64/x64 sqrt calls with hardware fsqrt; these bodies are the portable/function-value paths. sqrt(x<0) returns NaN (ieee, same policy as and Xu's ruling for f64); pow overflows to inf per ieee.
