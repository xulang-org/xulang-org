Protocol building blocks and device responsibility

This package supplies bounded beacon parsing, AP selection, association and a narrow PSK/CCMP pairwise handshake. It prepares protocol messages and validates received bytes; applications supply the controller event loop and manage key installation, replay counters and packet ownership. Verify hardware completion and RX status before parsing DMA data.

Use key_data for wrapped key-data validation, ccmp for authenticated protected frames, and ipv4 for DHCP/ARP/ICMP acquisition probes. Standard WifiDevice operations remain unavailable. Persistent station service, lease renewal, DNS/TCP, WPA3/PMF and BLE/Wi-Fi coexistence require further implementation.
