Xu Bluetooth Standard Library Package Portable Bluetooth Low Energy stack for bare-metal Xu targets. The package is split into a portable core and a thin chip binding backend.xu chip hook table (`BtBackend`) btdm.xu BTDM application layer: OSI table, controller lifecycle, sleep sequencing, VHCI host transport, work dispatch hci.xu H4 transport framing (command / ACL / SCO / event) ke.xu KE style event scheduler skeleton hogp.xu HOGP (HID Over GATT Profile) & Report Map for Mouse, Consumer & Keyboard att.xu Attribute Protocol (ATT) & Lightweight GATT Server The BTDM application layer is Espressif-generic: the same semantics serve esp32, esp32c3 and esp32s3. Only a few operations touch chip registers or ROM entry points, and those live behind `BtBackend`, so a chip package registers its implementation instead of the core importing a chip. Usage import bt #embedded/bluetooth $ctl := bt.btdm_controller_create bt.btdm_controller_init($&ctl, bt.btdm_config_mask_load, bt.ESP_BT_MODE_BLE) bt.btdm_controller_enable($&ctl) bt.api_vhci_host_register_callback($&ctl,...) $att := bt.att_server_create("XU-Agent-HID") $report := bt.hogp_build_consumer(bt.HID_CC_VOLUME_UP) $acl_pkt := bt.hogp_make_acl_notification(0x0000, bt.ATT_HANDLE_CONSUMER_REPORT, report) $wire_bytes := bt.hci_encode(&acl_pkt) bt.api_vhci_host_send_packet($&ctl, wire_bytes) The closed Espressif library this package replaces is `libbtdm_app.a` the recovered ABI contract is documented in `src/embedded/bluetooth/BTDM_XU_PORT.md` and the reverse engineering evidence in `docs/rea-btdm/BTDM_REA_DOSSIER.md`.
