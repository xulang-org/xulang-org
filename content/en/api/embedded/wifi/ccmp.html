next_pn

XuAPI
pub fn next_pn(pn &string) string

Purpose

Start with six zero bytes, consume next_pn BEFORE submitting a new frame, and retain the consumed value even when transmission fails. Empty means invalid input or exhaustion: install a fresh key; NEVER wrap or reset the counter while using the same key. Retransmit an already protected MPDU unchanged rather than encrypting different contents with its old PN.

protect

pub fn protect(key &string, header &string, payload &string, pn &string, key_index int) string

Purpose

Protect one MPDU using an explicitly consumed PN. Returns empty on invalid input or AES failure; sets Protected and inserts CCMP header plus 8-byte MIC. This stateless function cannot detect caller PN reuse; follow next_pn's per-key lifetime rules. key_index must select the actual installed key.

pub fn unprotect(key &string, frame &string, last_pn &string) CcmpPacket

Purpose

last_pn is exactly six LE bytes, scoped to installed key + transmitter + TID (a separate non-QoS replay domain). Reject PN <= floor before AES. Commit the returned PN after valid=true, before dispatching the payload. Caller selects the receive key from the CCMP Key ID and checks key_index the Key ID itself is not included in CCMP's authenticated data.
