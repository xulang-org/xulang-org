Select the measured raw protected-frame path for Wi-Fi interface zero. The caller owns the MAC, DMA arena, software keys and replay counters. It must already have configured raw RX routing and the station ACK address. This does not initialize the radio, install keys, or connect WifiDevice. Native hal_crypto_init's 0x30000 is not a software-CCMP receive profile with own-address matching enabled it suppresses the protected unicast path used by our raw receiver. Zero permits the complete encrypted MPDU to reach DMA, where the caller must verify CCMP MIC and PN before releasing plaintext. Preserve hardware RX status, frame bounds, and address validation as well.
