const iso

XuAPI
pub const iso = -2882303761517117440

Purpose

CRC-64 aligned with `hash/crc64` (iso / ecma). Pure i64 arithmetic carrying u64 lanes: arithmetic right shift is masked to logical (`>> 1` with 2^63-1, `>> 8` with 2^56-1). No mutable globals — each make_table owns a 256-entry table. Polynomials that set bit 63 are stored as two's-complement negatives (hex 0x8… literals have historically been lexer-hostile). Value `-2882303761517117440`.
