pub const ieee = 3988292384

Purpose

CRC-32 aligned with `hash/crc32` (ieee / castagnoli / koopman). Pure i64 arithmetic with 32-bit masks — no mutable globals (each make_table) returns an owning 256-entry table). checksum_ieee uses a precomputed ieee table so small checksums do not rebuild 256 entries from the poly.
