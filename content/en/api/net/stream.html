Stream wraps net.Conn with the same method names tls.Conn uses (read / write / set_*_deadline / close) so a service loop can be written once. Xu has no interfaces — tls.Conn already has this method set; branch on a bool at the dial site if you mix both. net/stream does not import crypto/tls (tls already imports net). read may throw (deadline/IO); write/close follow net.Conn.
