#net/poller

Xu {{xu_version}} API

import: #net/poller

counts: 1 fns, 7 methods, 2 types, 4 consts, 0 ifaces

Connection registry for long-lived peers (gateway / 5k sessions). Readiness is delegated to the hosted runtime. Linux uses an epoll registration, Darwin uses kqueue, and Windows uses an IOCP completion request. The low-level primitive is one-shot, so this registry keeps the stable ids and performs the fd-to-id mapping here.

pub fn (p $&Poller) wait(timeout_ns int) []Event

Purpose

wait returns the descriptors that became ready. A timeout of zero blocks a positive timeout is in nanoseconds. After the first descriptor has been checked, subsequent one-shot waits are non-blocking so a ready set cannot multiply the caller's deadline by the number of registered streams.

($&Poller) read_timeout

XuAPI
pub fn (p $&Poller) read_timeout(id int, max int, timeout_ns int) string

Purpose

read_timeout reads up to max bytes, applying a deadline of timeout_ns (0 = blocking). Empty string is EOF/timeout/error. The deadline is per operation. Conn applies it to SO_RCVTIMEO, so leaving it installed would make a later read inherit an already-expired timeout. Always clear it after the operation (including the error path). Throws on failure.
