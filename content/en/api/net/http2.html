#net/http2

Xu {{xu_version}} API

import: #net/http2

counts: 7 fns, 5 methods, 5 types, 1 consts, 0 ifaces

Minimal HTTP/2 client (RFC 7540 / HPACK RFC 7541 subset). v1 * frame codec (encode_frame / decode_frame) * GET headers HPACK (static table + raw literals, no Huffman) * h2c TcpClient (prior knowledge) * TlsClient via dial_tls (ClientHello ALPN offers h2 + http/1.1) Throw note: method may-throw is matched by caller-module name only (check_06_throw.ast_method_call_propagates_throw), so `conn.read` from net.http2 does not see tls.Conn.read's throw. tls_read_exact therefore absorbs errors with `or (err) { << got }` instead of `or >>`. Not in v1: POST/DATA out, HPACK Huffman, dynamic table, flow control, GOAWAY retry, server push. Default timeout in nanoseconds for an HTTP/2 TLS connection.
