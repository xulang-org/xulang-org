struct ResponseRecorder

pub struct ResponseRecorder {
    pub code int
    pub hdr string
    pub body string
    pub wrote int
}

Purpose

`net/http/httptest` subset: in-process ResponseRecorder, new_request, and a loopback Server (Listen + goroutine Accept). write_header after the first write is ignored. header_set is recorded until then. new_request keeps a path; `http://host/path` is stripped to `/path`. Server binds 127.0.0.1 on an ephemeral high port (no getsockname); close unblocks Accept.
