const ldate

XuAPI
pub const ldate = 1

Purpose

Minimal logger aligned with `log` (Logger + Print/Println/Printf). No package-global logger (Xu forbids mutable globals). Callers hold a Logger. Output defaults to eprintln; set_output_stdout switches to println. No io.Writer struct@ values. Time flags: ldate/ltime/lmicroseconds/lutc/lstd_flags. File flags: lshortfile/llongfile via output/println_at (explicit file:line). print/println/printf/fatal auto-inject callsite when those flags are set (compiler rewrites to *at with compile-time file/line). Value `1`.
