pub fn (r &mut Reader) peek(n int) string

Purpose

peek returns the next n bytes without consuming them. n must be in 1..buf_size; n > buf_size throws ( bufio.ErrBufferFull). At eof with fewer than n bytes buffered it returns what is available (or throws). Throws on failure.

(&mut Reader) read_slice

XUv0.1.0
pub fn (r &mut Reader) read_slice(delim int) string

Purpose

read_slice reads until delim (inclusive) in the current buffer ( ReadSlice). It does not accumulate across a full buffer: if the buffer fills with no delim, it returns that chunk ( also returns ErrBufferFull Xu returns the bytes and does not throw — caller sees no delim). eof with leftover returns the leftover; empty eof throws. Throws on failure.
