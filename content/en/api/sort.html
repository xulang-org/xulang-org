lookup_ints

XuAPI
pub fn lookup_ints(a &[]int, v int) Search

Purpose

Find the lower bound in a sorted slice, either to locate a value or to determine its ordered insertion position.

Parameters

a &[]int
Already ascending-sorted slice; this call does not sort it first.
v int
Value to locate.

Returns

Search.index is the first position not less than v, in 0..a.len; found indicates an exact match.

Usage notes

  • An empty slice yields position 0; duplicates yield the first position. Check the value or use lookup_*.found to distinguish a match from an insertion point.

pub fn reverse_ints(a $&[]int)

Purpose

Sort the entire slice in descending order in place by sorting ascending and then reversing.

Parameters

a $&[]int
Slice to process; sorting calls borrow it exclusively and modify it in place.

Returns

No return value; the sorted elements remain in a.

Usage notes

  • Use slices.reverse_* to reverse the existing sequence without sorting it.

Call example

Descending sort versus sequence reversal

XuLocal SDK example
@main
#sort
#slices

fn main() {
    $ordered := [2, 1, 3]
    sort.reverse_ints($&ordered)
    for value in ordered { println(value) }
    $flipped := [2, 1, 3]
    slices.reverse_ints($&flipped)
    for value in flipped { println(value) }
}
