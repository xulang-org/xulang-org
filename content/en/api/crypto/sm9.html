const g1_size

XuAPI
pub const g1_size = 65

Purpose

SM9 (GM/T 0044). Xu addition — has no crypto/sm9. Identifier signature hid=0x01 and KDF stream encryption hid=0x03. points 04||x||y (65). 04||x.u||x.y||y.u||y.y (129). Signature h||S (32+65). Ciphertext 04||C1||C3||C2 (C3=SM3). Key exchange hid=0x02 (GM/T 0044.4). H1/H2 take 40-byte Ha then (a mod (n-1))+1. Zero C, not a commercial-crypto certification. No ASN.1, not wired into GMTLS. XU-CT-CLASS: variable-time XU-CT-USE: fixed-shape-only math/big pairing/scalar arithmetic is variable-time; crypto/subtle covers only final fixed-shape integrity/equality checks. Value `65`.
