Compact JWS (JWT) signing — ES256 only (APNs / provider tokens). token := jwt.sign_es256(&p8_priv, &team_id, &key_id, iat) Header is `{"alg":"ES256","typ":"JWT","kid":"<key_id>"}`. Claims: `{"iss":"<team_id>","iat":<unix sec>}`. Signature is raw R||S (64 bytes) base64url, per RFC 7515 ES256.
