pad_pkcs7

XuAPI
pub fn pad_pkcs7(src &string, block_size int) string

Purpose

AES-CBC / AES-CTR / AES-GCM aligned with `crypto/cipher`. Bound to `aes.Cipher` (Xu has no cipher.Block interface). Bare CBC requires whole blocks; PKCS7 helpers pad/unpad. CTR is XOR of the AES keystream (big-endian counter). GCM: 96-bit nonce, 128-bit tag (seal_gcm / open_gcm). Throws on failure.
