GMTLS 1.1 subset (dual SM2 certs + SM4). In-process net.pipe; no Listen. Pure Xu, not commercial-crypto certified.

const version_gmtls11

XuAPI
pub const version_gmtls11 = 257

Purpose

GMTLS/TLCP (GB/T 38636) client subset. Xu addition — has no crypto/gmtls. Cipher suites ECC/ECDHE × SM4-GCM/CBC-SM3; dual SM2 certs. ECDHE uses GM/T 0003.3 (server=initiator) and requires client dual certs. CBC is TLS 1.1 style (explicit IV, HMAC-SM3 then SM4-CBC). Record/handshake are software; does not use crypto/tls platform ncall. In-process peer is server over net.pipe — not a Listen/Accept product API. After handshake, Conn.close sends an encrypted close_notify (warning, description 0); Conn.read throws "crypto/gmtls: close notify" on that record. Other alerts still throw "crypto/gmtls: alert". Does not close the pipe. ECC SKE is GM/T 0009 DER SEQUENCE{r,s}; CKE is DER SM2Cipher. ECDHE SKE/CKE carry named curveSM2 (41) + uncompressed point. Peers that still send raw r||s (64) or C1||C3||C2 (leading 0x04) are accepted on the ECC path. Zero C, not a commercial-crypto certification. Value `257`.

struct Config

pub struct Config {
    pub server_name string
    pub client_name string
    pub insecure_skip_verify bool
    pub sign_cert string
    pub sign_key string
    pub enc_cert string
    pub enc_key string
    pub cipher_suite int
}

Purpose

sign_key / enc_key: 32-byte raw d, PKCS#8/SEC1 DER, or PEM (PRIVATE KEY / EC PRIVATE KEY / SM2 PRIVATE KEY). sign_cert / enc_cert: DER or PEM CERTIFICATE / X509 CERTIFICATE. server_name: ClientHello SNI (RFC 6066) when non-empty; client also matches it against the server sign certificate DNS SAN / CN unless empty or insecure_skip_verify. client_name: ECDHE server matches it against the client sign certificate DNS SAN / CN unless empty or insecure_skip_verify (does not check the encryption certificate). ECDHE client Config.sign_cert/enc_cert are the client's dual certs and need not match the server. Conn.peer_sign_cert / peer_enc_cert are the peer's presented dual certs (DER). ECC server leaves them empty (no client certs).
