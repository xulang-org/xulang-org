const unknown_signature_algorithm

XuAPI
pub const unknown_signature_algorithm = 0

Purpose

`crypto/x509` subset: ParseCertificate, CheckSignatureFrom, Certificate.Verify with a CertPool. Signature check is Ed25519 , RSA PKCS1v15 SHA-256 (D4 rsa), ECDSA P-256/P-384/P-521 with the matching SHA-2 digest, and SM2-with-SM3 (, Xu additional). This is not a complete RFC 5280 implementation. Current path building is a bounded (≤8) candidate backtrack with BasicConstraints/pathLen, CA KeyUsage, AKI/SKI, EKU, DNS/IP NameConstraints, a partial policy set, and CRL-if-present. Missing: other NameConstraints types, a full policy tree, delta CRL/OCSP, and certificate/key issuance APIs. Do not treat Verify passing as "full RFC 5280". Value `0`.

append_certificates

XuAPI
pub fn append_certificates(p &mut CertPool, pem_data &string) int

Purpose

append_certificates adds every CERTIFICATE PEM block that can be parsed. Unknown or malformed blocks are skipped, matching the useful part of AppendCertsFromPEM contract while keeping the subset's explicit count for diagnostics. The scanner keeps an offset into the original bundle and only copies one PEM block at a time. In particular, it does not repeatedly copy encoding/pem.Block.rest, which would make large system bundles quadratic.

system_cert_pool

XuAPI
pub fn system_cert_pool() CertPool

Purpose

system_cert_pool probes the environment override first, then the native platform trust source, then conventional Unix PEM bundles. The native adapter only supplies opaque DER records; parsing and trust policy remain in this package. An empty pool is returned when no source is readable, so TLS callers fail closed instead of silently disabling verification.
