FIPS-197 AES (Advanced Encryption Standard: AES-128 / AES-192 / AES-256) block cipher. Modes and multi-block operations (CBC / CTR / GCM) live in #crypto/cipher.

Overview

#crypto/aes implements the standard AES (Rijndael) symmetric block cipher. It supports 128-bit, 192-bit, and 256-bit key sizes, with automatic hardware CPU acceleration and pure-software fallback:

  • Key Sizes and Rounds:
    • AES-128: 16-byte (128-bit) key, 10 encryption rounds.
    • AES-192: 24-byte (192-bit) key, 12 encryption rounds.
    • AES-256: 32-byte (256-bit) key, 14 encryption rounds.
  • Block Size: Strictly 16 bytes (128 bits), defined as const block_size = 16.
  • Hardware Acceleration: Automatically detects host CPU instruction support (AES-NI on x86_64, ARMv8 Cryptography Extensions on ARM64). When hardware acceleration is active, Cipher.hw_accel is set to true.
  • Cipher Modes & Streaming: This package operates strictly on single 16-byte blocks. For arbitrary-length messages and modern cipher modes, use standard library #crypto/cipher:
    • CBC Mode: Supports PKCS#7 padding (cipher.encrypt_cbc_pkcs7 / cipher.decrypt_cbc_pkcs7).
    • CTR Mode: Counter-based keystream streaming (cipher.encrypt_ctr / cipher.decrypt_ctr).

Examples

1. Single-Block AES-128 Encryption & Decryption

XuExample
@main
#crypto/aes

fn main() int {
    // 16-byte key for AES-128
    key := "0123456789abcdef"
    c := aes.new_cipher(&key) or (err) {
        println("Cipher init error: " + err.msg())
        << 1
    }

    // Single block must be exactly 16 bytes
    block := "16_bytes_secret!"
    enc := c.encrypt(&block) or (err) {
        println("Encryption error: " + err.msg())
        << 1
    }

    dec := c.decrypt(&enc) or (err) {
        println("Decryption error: " + err.msg())
        << 1
    }
    assert(dec == block)
    println("Single-block roundtrip passed!")
    << 0
}

2. Variable-Length AES-CBC with PKCS#7 Padding via #crypto/cipher

XuExample
@main
#crypto/aes
#crypto/cipher

fn main() int {
    key := "my-secret-key-16" // 16-byte key
    iv := "1234567890123456"  // 16-byte initialization vector
    c := aes.new_cipher(&key) or (err) { << 1 }

    // Arbitrary length payload with automatic PKCS#7 padding
    msg := "Xu systems language provides supersonic native AES encryption."
    enc := cipher.encrypt_cbc_pkcs7(&c, &iv, &msg) or (err) { << 1 }
    dec := cipher.decrypt_cbc_pkcs7(&c, &iv, &enc) or (err) { << 1 }

    assert(dec == msg)
    println("CBC PKCS#7 decrypted successfully!")
    << 0
}

pub fn new_cipher(key &string) Cipher

Purpose

Creates and returns a new Cipher instance from the given symmetric key. Selects algorithm based on key.len: 16 bytes for AES-128, 24 bytes for AES-192, 32 bytes for AES-256. Throws "crypto/aes: invalid key size" if the key length is not 16, 24, or 32 bytes.

Parameters
