struct Config

XUv0.1.0
pub struct Config {
    pub server_name string
    pub insecure_skip_verify bool
}

Purpose

`crypto/tls` Client subset. Handshake is hosted platform TLS (SecureTransport on macOS; Linux/Windows throw). Not a record-layer implementation. System trust store; Config.root CAs from x509 are not wired (D5 is a soft dependency). Dial handshakes before return; Client is lazy until Handshake/Read. Xu v1: both Client and Dial handshake immediately (the builtin does).
