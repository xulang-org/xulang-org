const version_tls12

XuAPI
pub const version_tls12 = 771

Purpose

`crypto/tls` Client subset. Handshake is a software TLS 1.2/1.3 record layer: RSA, ECDHE-RSA, and ECDHE-ECDSA AES-128-GCM for TLS 1.2, plus TLS_AES_128_GCM_SHA256 with P-256 key shares for TLS 1.3 (supporting RSA, ECDSA P-256/P-384/P-521, and Ed25519 certificates). No platform TLS. RootCAs defaults to the system pool when empty. Config.insecure_skip_verify explicitly disables certificate chain, time, and DNS verification. server is for in-process tests (pipe or tcp). XU-CT-CLASS: variable-time ECDH, RSA, AES and GHASH are variable-time on current XU backends. Value `771`.
