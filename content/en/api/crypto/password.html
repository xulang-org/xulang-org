Password hashing & Key Derivation (PBKDF2-HMAC-SHA256 + HKDF-SHA256). Self-describing encoded hash for login $pbkdf2-sha256$<iterations>$<salt_b64>$<dk_b64> Inner PBKDF2 loop accumulates XOR in a mutable []int buffer rather than allocating a new string per iteration. XU-CT-USE: fixed-shape-only verify compares digests with crypto/subtle. Maximum PBKDF2 derived key length, including verified stored keys.
