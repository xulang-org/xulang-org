Password hashing. Public PBKDF2-HMAC-SHA256 (the primitive that lived only inside the postgres SCRAM path) plus a self-describing encoded hash for login $pbkdf2-sha256$<iterations>$<salt_b64>$<dk_b64> Argon2id is the preferred long-term KDF; it needs a runtime ncall and is not in this package yet. Use a high iteration count until then. XU-CT-USE: fixed-shape-only verify compares digests with crypto/subtle. Maximum PBKDF2 derived key length, including verified stored keys.
