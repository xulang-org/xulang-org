HKDF (RFC 5869): HMAC-based Extract-and-Expand Key Derivation Function using SHA-256. Aligned with `.org/x/crypto/hkdf`. Key derivation proceeds in two steps 1. Extract: PRK = HMAC-Hash(salt, IKM) to extract a pseudorandom key. 2. Expand: OKM = HKDF-Expand(PRK, info, L) to expand to desired length.
