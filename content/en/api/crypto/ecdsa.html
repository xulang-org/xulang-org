#crypto/ecdsa

counts: 15 fns, 0 methods, 0 types, 9 consts, 0 ifaces

crypto/ecdsa verification subset. Public keys use SEC1 uncompressed P-256/P-384/P-521 form (0x04 || X || Y); signatures use ASN.1 DER SEQUENCE{r,s}. The curve is selected explicitly for key generation and by canonical raw-key length for public/sign operations. Signing uses the platform-independent CSPRNG exposed by crypto/rand. XU-CT-CLASS: variable-time Point/scalar arithmetic is math/big based. ECDSA and ECDH therefore have no constant-time contract even where final equality uses crypto/subtle.
