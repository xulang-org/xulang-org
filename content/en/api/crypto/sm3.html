pub fn sum_prefix_bytes(s &string, n int) string

Purpose

Hash the first n bytes while reading/compressing a fixed shape determined solely by s.len. n and the bytes may be secret; 0 <= n <= s.len is required. CBC callers must also gather the received MAC without secret-indexed reads. Throws on failure.
