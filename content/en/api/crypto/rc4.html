Purpose

RC4 stream cipher aligned with `crypto/rc4` NewCipher + XORKeyStream. Key 1..256 bytes. State is a 256-byte S-box plus i/j. XOR produces a new owning string ( writes in place). Not constant-time; RC4 is cryptographically broken — this is for protocol interop only.
