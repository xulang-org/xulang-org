`crypto/ed25519`: GenerateKey / NewKeyFromSeed / Sign / Verify. Private key is 64 bytes (seed || public), public 32, signature 64. Curve arithmetic uses math/big ( uses crypto/internal/edwards25519). Field ops take p as an argument so scalarmult can hoist 2^255-19 and 2d. XU-CT-CLASS: variable-time XU-CT-USE: fixed-shape-only math/big curve arithmetic is variable-time; crypto/subtle covers only the final encoded-point equality check. Value `32`.
