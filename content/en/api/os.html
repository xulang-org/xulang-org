argv

XUv0.1.0
pub fn argv() []string

Purpose

Process and file helpers aligned with `os` (Args / ReadFile / WriteFile ReadDir / File / DirFS). Exit stays the language builtin `exit` — naming a wrapper `exit` would shadow it. File holds an fd; close is explicit (v1). layering: kernel → os.File/Open/socket → io/fs (FS helpers) and net. DirFS (dirfs.xu) is os.DirFS. Socket is os.socket (socket.xu), not a top-level socket package. Public API is >>/or. Hosted builtins return the same private throw slot as ordinary may-throw functions; wrappers preserve package-level naming.

struct DirFS

XUv0.1.0
pub struct DirFS {
    pub dir string
}

Purpose

`os.DirFS`: a rooted tree that implements the io/fs.FS method set (Open / Stat / ReadFile / ReadDir / Sub). os imports io/fs; DirFS is `fs.FS` via interfaces. Xu: no interface values, so this concrete type lives here; io/fs helpers take `&os.DirFS`. This package does not import io/fs (no cycle).
