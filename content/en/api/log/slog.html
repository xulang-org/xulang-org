const level_debug

XuAPI
pub const level_debug = -4

Purpose

`log/slog` text + JSON handler subset. No default logger (Xu has no mutable globals). Attributes via with or on debug/info/warn/error/log as trailing string pairs (odd leftover is !BADKEY, same as ). Levels match slog.Level*. Context methods exist for the D1 hook; v1 does not extract trace IDs. JSON is new_json_logger ( NewJSONHandler shape, no io.Writer). with_group nests subsequent attrs (text: dotted keys; JSON: objects). Empty group name is a no-op (same as ). No syslog. Value `-4`.
