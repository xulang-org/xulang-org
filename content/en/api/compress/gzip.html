pub fn copy_stream#W:StreamWriter,R:StreamReader(dst &mut W, src &mut R) int

Purpose

Emit a gzip member directly to dst using legal non-final stored deflate blocks, then an empty final block and CRC32/ISIZE trailer. No input or output is accumulated. Returns the uncompressed byte count and closes neither endpoint. Failed copies leave an incomplete member; discard it, don't retry. Throws on failure.
