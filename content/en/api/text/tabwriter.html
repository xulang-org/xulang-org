XUv0.1.0
pub const align_right = 4

Purpose

Elastic tabstops aligned with `text/tabwriter` (Write + Flush). ASCII cell width = byte length. No HTML filter, no Escape, no formfeed flush. padchar tab (tabwidth alignment) is not implemented. flush returns the formatted owning string (no io.Writer). Cells store (start,len) into the raw buffer — not owning strings. read); widths stay intact. Offsets avoid that (see text_tabwriter). Value `4`.
