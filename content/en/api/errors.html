struct@ Error

XuAPI
struct@ Error {
    fn msg() string
}

Purpose

Error values: struct types + `struct@ Error` constraint. Dynamic boxing is language syntax: `errors.Error(concrete)` (not defined here). Scope: message text, typed error structs, wrap chain, is_err. wrap stores the inner message as text (not a boxed Error), so is_err walks that text chain: exact match, or a suffix ": " + target.msg. Not in this package: string join, logging, generic dynamic boxing. Typed tests use language `is`/`as`, not this package (`is` is a keyword).
