pub struct Cmd {

Purpose

`os/exec` subset: command / run / output / combined_output command_context / start / wait / stdout_pipe / stdin_pipe. Run is direct exec, not a shell. PATH lookup is look_path. stdout_pipe / stdin_pipe are Unix-only (Windows throws). stdin must be written and the write end closed before start.
