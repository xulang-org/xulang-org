struct NamedValue

XuAPI
pub struct NamedValue {
    pub name string
    pub ordinal int
    pub value temp
}

Purpose

`database/sql/driver`. Value is Xu `temp` ( `driver.Value` = empty interface). Conn / Driver / Connector / Stmt / Tx are struct@ ( interfaces). Connector.Connect is `connect(&context.Context)` (borrowed context). reset_session / is_valid are SessionResetter / Validator (closed-world Conn has no optional interfaces). has no iface defer (Driver would name Connector and vice versa). Same concrete type implements Driver and Connector; call open_db. Exec/Query take `[]NamedValue` like QueryerContext/ExecerContext (closed-world struct@ has no optional Queryer). Boxed methods cannot `>>` (dynamic dispatch is not may_throw), so outcomes carry `err`. v1 query path is a concrete snapshot `RowsResult` (columns + flat cells + ncols + err), not streaming `driver.Rows`. sql.Rows iterates the snapshot; ColumnType* defaults live in the sql layer. itables were the C8 known-fail.) Declare result structs and Stmt/Tx before Conn/Driver so method
