Install

The user-facing binary is named xu. Prebuilt files:

File--targetFormat
xu.macos.arm64macos-arm64Mach-O arm64
xu.macos.x64macos-x64Mach-O x86_64
xu.linux.arm64linux-arm64ELF aarch64
xu.linux.x64linux-x64ELF x86_64
xu.linux.loongarch64linux-loongarch64ELF LoongArch
xu.linux.riscv64linux-riscv64ELF RISC-V
xu.windows.x64.exewindows-x64PE32+ x86-64
xu.windows.arm64.exewindows-arm64PE32+ ARM64

See /en/download. After it is on PATH:

xu build hello.xu
./hello

On mac/linux the default artifact has no suffix and already has the executable bit set. Windows writes .exe. In PowerShell use --output (-o is swallowed).

From source (secondary)

In the language repo root: make xu, which produces ./bin/xu. Day-to-day, rename the matching download to xu and put it on PATH.
