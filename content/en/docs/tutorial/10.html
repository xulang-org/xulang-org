10 · Concurrency

xu f(args) spawns a coroutine. xu.pkg.f with a dot is a package path. Channels move ownership; do not send borrows into a coroutine.

Source

@main

fn worker(id int, ch chan int) {
    ch <- id * 10
}

fn main() int {
    ch := chan int{cap: 1}
    xu worker(1, ch)
    x := <-ch
    println(x)
    << 0
}

Build (from the language repo root; swap the binary for your platform):

xu run examples/10_concurrency/main.xu
# or: xu build examples/10_concurrency/main.xu
# default artifact is ./main on mac/linux, ./main.exe on Windows

Run from the separate examples repository root; source files live under examples/.
