01 · Program skeleton

Smallest program: print a line and exit with << 0. No return keyword. No semicolons.

Source

@main

fn main() int {
    println("Hello, Xu!!!!!!!!!")
    << 0
}

Build (from the language repo root; swap the binary for your platform):

xu run developer/examples/01_hello
# or: xu build developer/examples/01_hello/main.xu
# default artifact is ./main on mac/linux, ./main.exe on Windows
