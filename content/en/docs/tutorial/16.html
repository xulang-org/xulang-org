16 · UI + WebView

#ui is the window/menu/tray shell; #ui/webview is the content slot. Pack with the product compiler: xu doctor / xu build <App> --desktop.

Each app is its own project root:

Independent Project Root Layout
App/ Standalone application root
xu.xun Config Module manifest & dependencies
main.xu Required Primary application entrypoint
www/ Optional Local xu:// static assets (when WebView enabled)
brand/ Required At least one PNG icon for desktop packaging (no fallback)

Apps in the example: open standard window + WebView; shaped shaped window; draw immediate-mode canvas #ui/draw; remote remote HTTP.

xu doctor --desktop --target macos-arm64
xu build examples/16_ui_webview/open --target macos-arm64 --desktop -o /tmp/XuOpen
open /tmp/XuOpen.app

macOS produces .app, Windows .exe, and Linux ELF. Desktop packaging needs matching host tools; Linux uses GTK4 and WebView additionally needs WebKitGTK 6.0. See UI / WebView for platform boundaries.

Run the commands from the separate examples repository root.
