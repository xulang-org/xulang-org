CryptographyPer-package limitsXu implementations include SM2/SM3/SM4/SM9/ZUC/GMTLS. API availability does not imply commercial-cryptography certification.

Shared-library exportsPrimitive signatures--shared exports int, bool, string, f64, i32, u32, and u8; native .a/.xulib dependencies are a separate resource boundary.
MapImplementedint/string keys; missing-key indexing fails loudly. Use membership checks or library APIs when absence is expected.
Tools and editorPartialbuild/run/check/test/install/fmt/map/doc/doctor are available. doc --serve previews locally; up/update can self-host an update from GitHub sources; hosted lsp remains unimplemented. VS Code 0.2.7 provides syntax highlighting.

Recent progress and remaining work

The 0.8.x series adds module paths, transitive dependencies, offline/frozen builds, MVS, proxies, and trusted-key checksum verification. The website API now covers 128 standard-library/UI packages and 29 external packages.

Remaining work includes public Xu proxy/checksum services, independent witnesses, vanity repository discovery, complete target-platform runtime validation, shared-filesystem locks, and power-loss durability. Existing target emission and API declarations do not replace those checks.
