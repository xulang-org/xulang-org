XACP controlPublished API; runtime unverified#xacp is included in the published {{xu_version}} SDK extract. Hosted native startup control uses --xacp / --xacp-port, with XACP/1 length-prefixed stdio or 127.0.0.1 TCP. Hello grants at most INFO without a host token; a matching host token permits a requested subset of PERM_ALL. proc.status has a pid response; output/UI operations require their permissions and adapters. Startup control does not register a Screen. UI attachment requires registration and polling, and has a request deadline; callers still need process/I/O timeouts. No TLS or non-loopback bind; Windows launcher record is unavailable. Native sessions, UI control, screenshots, and platform runtime acceptance remain unverified. Importing the package does not install a control channel.

Recent progress and remaining work

Xu 0.14.3 ships the Linux/macOS M:N multi-core coroutine scheduler and #sync/pool, finalized >> throw + >>> propagate/catch syntax, llm_engine --threads N multi-threaded inference with K-quant SIMD / mmproj.gguf / GBNF Trie, Phase 5–7 optimizer passes, built-in Mach-O signing & ELF/PE hardening, UEFI/ACPI/PCI/FDT OS primitives, and UI Rounds 12–14.

Xu 0.14.2 lands vectorized SLP, Ext-TSP hot/cold code layout, and SwissTable core data structure upgrades.

Xu 0.14.1 delivers pure-Xu local LLM inference, streaming P4K4 GGUF packing, paged attention tensor fusion, loop/GVN/regalloc & TLS 1.3/X25519 speedups, and the six-platform 72-workload benchmark dataset.

Xu 0.14.0 introduces --profile=freestanding bare-metal kernels, *raw T, volatile_read/volatile_write, @repr("C"), and #core/{arch,sync,task,virtio,mem,alloc}.

Xu 0.13.3 lands ownership GVN alias invalidation, call-graph bounded stack analysis with 16KB slab micro-coroutines, 1:1 SPSC channel elision with zero-copy rendezvous, MEMOIR GEMM loop tiling with SROA, and PGO layout reordering.

Xu 0.13.2 bounds HTTP buffers, decodes chunked responses incrementally, reads only the requested static file range, and batches socket waits.

Xu 0.13.1 completes the standard library zero-stub audit across all core modules: fixes compress/zstd truncation validation, re-engineers sync.Cond registered waiter queue notification semantics, implements cross-platform os/exec streaming pipes (stdin_pipe/stdout_pipe/stderr_pipe) and native console signal dispatching, introduces net/http HTTPS connection reuse, native Windows WSAPoll zero-latency batch socket polling, HTTP/2 HPACK Huffman decoding, real SOCK_RAW IP sockets, and external IANA TZif database loading via $env:ZONEINFO. All six native platform SDKs passed full verification. See the release notes.

Xu 0.12.6 completes cross-architecture C FFI with unions, bitfields, extern globals, closure callbacks, and xu cbind; adds the native Phone game host (--phone-profile game) and #app; hardens borrow/move/unsafe/MIR drop checks with the 67-check memsafe-gate; and delivers x64 XMM/SSE2, ARM64/x64 select/lea fusion, GVN/BCE/ifconv optimizer gains, and runtime Base64/MD5/string optimizations. All six native platform SDKs passed full verification. See the release notes.

Xu 0.12.5 introduces a pure-Xu #internal/sdl dynamic FFI backend and a hostless #ui/font font stack, adds the #gpu SoftBlob CPU data safety model, XDF1 frame export for headless replay, multi-touch touch_id support, and enhanced Zero-GC holder tracking. The six native platform SDKs passed installation and protocol verification. See the release notes.

Xu 0.12.4 extends typed-MIR and ARM64/x64 optimization and adds mobile project generation and #ui/phone. The six native SDKs passed installation and execution checks. Mobile validation covers project generation and ARM64 object formats. See the release notes.

Xu 0.12.3 restores typed-MIR inlining, integer tail recursion, and periodic loop folding. String repetition allocates its output once. Hardware AES, ARM64 SHA-256, bit operations and hex encoding use native instructions where supported. Linux and macOS I/O waiters share each idle poll round. Standard library adds GPU render/compute passes, typed window surfaces and per-window input events. See the release and migration notes.

Xu 0.12.2 uses typed MIR and enables optimization by default. --no-opt disables optimization. Installed SDK acceptance covered Linux, macOS and Windows on ARM64 and x64. See the release and migration notes.

Xu 0.11.4 adds eligible ARM64 sibling tail calls, pure scalar additive-recursion loops and bounded byte-processing optimizations, and repairs XUN duration, depth, multiline and typed-list behavior. ESP32 Wi-Fi/BLE coexistence is experimental; external full-MTU acceptance and the documented network/security features remain incomplete. See the release notes and migration details.

Xu 0.11.3 adds checked synchronous i64 spans and ESP32 protocol building blocks, and repairs numerical edges and owned string slices. Windows SDK installers declare current-user execution. The ESP32 standard Wi-Fi device remains unavailable; see the release notes and implementation limits.

0.10.7 repairs complete SDK reinstalls and shares verification, backup and failure recovery between Setup and the updater. See the patch notes.

0.10.6 bundles corrected official examples and checks UI, WebSocket and DNS examples after installation, fixing incomplete imported-constant migrations in 0.10.5. See the patch release notes for upgrade and validation details.

0.10.5 adds xu debug source debugging, compiler and standard-library corrections, and LSP diagnostics that preserve document URIs, alongside native installation and standard-library update progress. Migrate constants, including imported constants, to UPPER_SNAKE_CASE; functions, variables and fields remain snake_case. See the release and migration notes.

0.10.2 fixes compiler self-discovery to eliminate ambient environment hijacking; brings native nonblocking socket readiness waiting (epoll / kqueue / IOCP), RFC1951 DEFLATE compression, and ergonomic UI Screen abstractions. See the release notes.

0.10.1 adds styled UI controls and style switching, desktop requests and Thumb-2 register allocation, and fixes cryptography, HTTP intake, regexp work limits, checked JSON conversions and DEFLATE compression. Migration: handle errors from regexp match/find/split/replace calls; synchronize mutable state shared by concurrent HTTP handlers. Draw panning requires explicit opt-in. See the release and migration notes.

0.9.4 completes borrow-checker expression traversal and loop-back-edge liveness, removes the four-type-parameter limit on generic declarations, and adds per-pass MIR verification, MIR dumps, and backend pattern-hit counters. ARM64 loop kernels use SSA matching and loop rotation. See the CLI reference for diagnostic commands.

Migration note: programs that previously compiled because of gaps in borrow checking now receive diagnostics. Separate conflicting borrows, or finish mutable use before taking a shared borrow.

Module dependencies retain transitive resolution, offline/frozen builds, MVS, proxies, and trusted-key checksum verification. Native single-file Setup installers and the WebAssembly playground are available.
