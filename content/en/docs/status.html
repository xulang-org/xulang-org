SubsystemStatusSupport and boundaries
Memory and resourcesImplementedSingle ownership, shared/exclusive borrows, move checks, and deterministic drop. File/Conn resources close on scope exit.
Safety boundaryBy designNo unsafe, reflect, or user-visible raw runtime pointers. Out-of-bounds indexing and division by zero fail loudly.
Native AOT & WASMTarget support variesmacOS arm64/x64; Linux arm64/x64/loongarch64/riscv64/arm32; Windows x64/arm64; WebAssembly (wasm32); Thumb and RISC-V bare-metal targets. Emission support does not imply all libraries have passed runtime tests.
DependenciesImplemented with limitsSlash-path identities; explicit file/Git/tar sources; SemVer minimum requirements and MVS; XUPROXY/private bypass; content locks, vendor snapshots, offline/frozen builds and process locks.
Checksum logsClient available0.8.4 adds trusted-key XUSUMDB verification and XUNOSUMDB policy. Public Xu service and independent witnesses remain pending; unset/off retains first-use trust.
Network and I/OPlatform differencesUnix TCP/UDP IPv4/IPv6 and Unix sockets; stream I/O and explicit progress results. Windows TCP dial/listen remains unsupported; raw IP and TLS support have separate platform limits.
SQL and external packagesSeparate moduledatabase/sql supplies pools, transactions, and driver contracts. The packages root module 0.1.1 contains 29 packages; MySQL/PostgreSQL use protocol drivers, SQLite uses native C resources.
CryptographyPer-package limitsXu implementations include SM2/SM3/SM4/SM9/ZUC/GMTLS. API availability does not imply commercial-cryptography certification.
Desktop GUIHost tools requiredDesktop packaging has macOS .app, Windows .exe, and Linux ELF paths. GTK4/WebKitGTK or WebView2 and matching host tools are required; verify on the target machine.
Shared-library exportsPrimitive signatures--shared exports int, bool, string, f64, i32, u32, and u8; native .a/.xulib dependencies are a separate resource boundary.
MapImplementedint/string keys; missing-key indexing fails loudly. Use membership checks or library APIs when absence is expected.
Tools and editorFully implementedStandalone native Setup installers available (automatic global PATH & XU_ROOT setup across Windows/macOS/Linux). build/run/check/test/install/get/fmt/map/doc/doctor/lsp are available. up/update supports direct GitHub binary release upgrades; VS Code 0.3.0 provides syntax highlighting and full native language server integration via xu-lsp (definitions, completion, hover, live diagnostics, outline, rename, and references).

Recent progress and remaining work

The 0.8.x series adds module paths, transitive dependencies, offline/frozen builds, MVS, proxies, and trusted-key checksum verification. Now featuring 47 measured cross-language workloads, standalone native Setup installers, and WebAssembly playground support. Website API covers 128 standard-library/UI packages and 29 external packages.

Remaining work includes public Xu proxy/checksum services, independent witnesses, vanity repository discovery, complete target-platform runtime validation, shared-filesystem locks, and power-loss durability. Existing target emission and API declarations do not replace those checks.
