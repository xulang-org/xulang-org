Status & Limitations

XU v0.1.0 Official Honest List · Engineering Boundaries & Roadmap

XU adheres strictly to engineering transparency and honesty. Below is a comprehensive audit matrix of v0.1.0 subsystem statuses, known platform limitations, and intentional design invariants.

Subsystem Status & Implementation Matrix

Subsystem Module Status Specification & Boundary Description Roadmap
Memory & Ownership Stable & Complete Zero GC overhead. Single-owner model, &T shared borrows, &mut T exclusive borrows, deterministic drop upon scope exit. Long-term syntax frozen
Safety Boundaries By Design Language core has no unsafe, no reflect, no exposed raw pointers, preventing implicit memory corruptions. Core safety invariants permanent
Supersonic AOT Stable & Complete Native cross-compilation for macOS (arm64/x64), Linux (arm64/x64/loongarch64/riscv64), Windows (x64/arm64) single binary. Continuous binary size optimization
Network & Sockets (Net/IO) Platform Matrix Unix (macOS / Linux) fully supports IPv4 TCP, UDP, HTTP & File Server; Windows TCP dial/listen returns error placeholder stub. WinSock native backend in v0.2.0
Database drivers Pure XU + External database/sql provides the driver contract; PostgreSQL and MySQL/MariaDB are pure Xu protocol packages. SQLite and other embedded drivers are external require: modules.
Cryptography & GM/T Pure XU Native SM2 / SM3 / SM4 / SM9 / ZUC / GMTLS implemented purely in XU with zero runtime dependencies; not commercial-crypto certified. Hardware acceleration intrinsics
Desktop GUI macOS Native xu build --desktop produces native macOS .app bundles (integrating #ui/webview and #ui/draw); Linux/Windows stub. Linux GTK & Windows WebView2 wrapper
Shared Library FFI Primitives Supported --shared dynamic library export supports: int, bool, string, f64, i32, u32, u8. Exporting structs and slices across FFI
Map Container Deterministic Key types currently support int and string; missing-key access fails loud defensively. Support for custom Hashable struct keys
Toolchain & Language Server In Development xu build / xu run / xu check / xu fmt / xu doc available; xu doc --serve previews XUDOCS locally; LSP remains in development. Language server bundle for VS Code plugin
