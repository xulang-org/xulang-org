Recent progress and remaining work

0.10.5 adds xu debug source debugging, compiler and standard-library corrections, and LSP diagnostics that preserve document URIs, alongside native installation and standard-library update progress. Migrate constants, including imported constants, to UPPER_SNAKE_CASE; functions, variables and fields remain snake_case. See the release and migration notes.

0.10.2 fixes compiler self-discovery to eliminate ambient environment hijacking; brings native nonblocking socket readiness waiting (epoll / kqueue / IOCP), RFC1951 DEFLATE compression, and ergonomic UI Screen abstractions. See the release notes.

0.10.1 adds styled UI controls and style switching, desktop requests and Thumb-2 register allocation, and fixes cryptography, HTTP intake, regexp work limits, checked JSON conversions and DEFLATE compression. Migration: handle errors from regexp match/find/split/replace calls; synchronize mutable state shared by concurrent HTTP handlers. Draw panning requires explicit opt-in. See the release and migration notes.

0.9.4 completes borrow-checker expression traversal and loop-back-edge liveness, removes the four-type-parameter limit on generic declarations, and adds per-pass MIR verification, MIR dumps, and backend pattern-hit counters. ARM64 loop kernels use SSA matching and loop rotation. See the CLI reference for diagnostic commands.

Migration note: programs that previously compiled because of gaps in borrow checking now receive diagnostics. Separate conflicting borrows, or finish mutable use before taking a shared borrow.

Module dependencies retain transitive resolution, offline/frozen builds, MVS, proxies, and trusted-key checksum verification. Native single-file Setup installers and the WebAssembly playground are available. The API reference is extracted from the matching official SDK and covers 131 standard-library/UI packages and 30 external packages. The benchmark dashboard records the measured version, date, and six-platform source run for its 47 workloads.

Remaining work includes public Xu proxy/checksum services, independent witnesses, vanity repository discovery, complete target-platform runtime validation, shared-filesystem locks, and power-loss durability. Existing target emission and API declarations do not replace those checks.
