An executable package starts with @main. Entry is fn main() int (exit code) or fn main(). Dependencies are #path at the start of a line; the package name is the last path segment.

@main

#errors

fn main() int {
    println("hello")
    << 0
}
xu build hello.xu
./hello

Directory mode: xu build . compiles every *.xu in the directory (not recursive). xu run hello.xu builds and runs the file, host target only.
