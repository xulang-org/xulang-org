VS Code / Cursor

Highlighting only (TextMate grammar + brackets/comments). No language server, not on the Marketplace. Use xu check for diagnostics.

Aligned with the lexer, including statement symbols << >> <<< -> <-. Not keywords: interface import return break continue Ok Err.

Package a VSIX from the independent vscode repository with npm ci and npm run package, then Install from VSIX in Cursor or VS Code, and Reload Window. Associate *.xu with xu. Do not rely on symlinks.

MIT.

The separate vscode repository currently uses extension version 0.2.7, independently of Xu 0.8.4. The hosted compiler still reports xu lsp as unimplemented; the configuration entry alone does not enable a language server.
