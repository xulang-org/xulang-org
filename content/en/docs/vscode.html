VS Code / Cursor

The extension provides syntax highlighting (TextMate grammar + brackets/comments) and language server support (via the built-in xu lsp). Maintained in the independent vscode-xu repository.

Aligned with the lexer, including statement symbols << >> <<< -> <-. Not keywords: interface import return break continue Ok Err.

Package a VSIX from the independent vscode-xu repository with npm ci and npm run package, then Install from VSIX in Cursor or VS Code, and Reload Window. Associate *.xu with xu.

Language Server capabilities: Xu natively self-hosts xu lsp (companion tool xu-lsp), providing live diagnostics, document formatting, cross-file/stdlib go-to-definition (F12), hover tooltips, document symbols/outline, completion, find all references (Shift+F12), and rename symbol refactoring (F2). Configure "xu.languageServerPath": "xu" in editor settings.
