Build options

Build, run, and test optimize automatically. Use --no-opt to disable optimization or --debug-build for an unoptimized build with DWARF line tables. --debug adds debug information without changing optimization; --timings prints phase statistics.

xu build hello.xu --output hello
xu run hello.xu -- arg1
xu build hello.xu --debug-build --output hello-debug
xu check app/main.xu --offline
xu build app/main.xu --frozen --output app/program
xu test app/ -v
xu doc src/net --public --output net.md
xu doc src/net --public --serve --addr 127.0.0.1:6060

Directory build/check skip test files. Test options include -run, -v, -count, -failfast, -list, -short, -bench, and --cover. xu lsp is not implemented.

Update the toolchain

xu up --check
xu up
xu update --ref main
xu update --version {{xu_version}}
xu update --source /path/to/xu --prefix /path/to/sdk

The default is the latest GitHub release, falling back to main when no release exists. The updater pins a source commit, verifies the self-host fixed point and builds the tools before replacing the installation. --check only checks versions; --force permits rebuilding or downgrading. Development checkouts require --prefix to install a separate SDK. On Windows replacement finishes after the invoking xu.exe exits; see .xu-update.log in the install directory.

--target > XUOS + XUARCH > the running compiler’s host target。In PowerShell prefer --output。

--offline / --frozen: Modules and dependencies。--desktop: UI / WebView。

xu doc --serve serves /、/docs.md、/health。Use xu check for diagnostics.
