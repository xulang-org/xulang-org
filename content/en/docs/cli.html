Build options

Build, run, and test optimize automatically. Use --no-opt to disable optimization or --debug-build for an unoptimized build with DWARF line tables. --debug adds debug information without changing optimization; --timings prints phase statistics. Target --target wasm32 compiles directly into standard WebAssembly modules.

xu build hello.xu --output hello
xu run hello.xu -- arg1
xu build hello.xu --debug-build --output hello-debug
xu build app/main.xu --target wasm32 --output dist/app.wasm
xu check app/main.xu --offline
xu build app/main.xu --frozen --output app/program
xu test app/ -v
xu doc src/net --public --output net.md
xu doc src/net --public --serve --addr 127.0.0.1:6060

Directory build/check skip test files. Test options include -run, -v, -count, -failfast, -list, -short, -bench, and --cover. xu lsp is not implemented.

Dependency Management (xu install)

xu install is the built-in, zero-config package installation command. It parses the require: block in your project's xu.xun, resolves the dependency graph via MVS, verifies SHA-256 integrity digests, downloads sources into vendor/, and creates or updates xu.lock:

xu install                      # Resolve xu.xun in current directory and install to vendor/
xu install app                  # Target a specific project directory
xu install --offline            # Offline mode: use local caches only without network calls

Once installed, no manual paths or build configurations are needed. Simply run xu check main.xu --offline or xu build main.xu. See Official External Packages and Modules and Dependencies.

Update the toolchain

xu up --check
xu up
xu update --version {{xu_version}}
xu update --prefix /path/to/sdk

The default selects the latest official GitHub Release and downloads the release package matching the host architecture. The installation is atomically replaced after download and verification succeed. --check only checks versions; --force permits reinstalling or downgrading. Development checkouts require --prefix to install to a separate directory.

--target > XUOS + XUARCH > the running compiler’s host target。In PowerShell prefer --output。

--offline / --frozen: Modules and dependencies。--desktop: UI / WebView。

xu doc --serve serves /、/docs.md、/health。Use xu check for diagnostics.
