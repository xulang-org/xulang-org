CLI

The product entry is xu. Commands: build run check test fmt map doc doctor up.

CommandRole
xu build <file|dir>AOT compile. A directory compiles every *.xu (not recursive). No default suffix on macOS / Linux; .exe on Windows
xu run <file|dir> [-- args]compile and run, host target only
xu checkparse + type + borrow; lists loop risk and exit sites
xu testonly fn test_* in test.*.xu
xu fmt [-w]format
xu mapsource flowchart (Mermaid; --graph for canvas apps)
xu doc [path...] [-o file] [--public] [--serve] [--addr A]generate declaration Markdown; --public filters private API and --serve starts a local XUDOCS page
xu doctorhost tools for desktop pack
xu upprints the toolchain version
xu build file.xu --output out
xu build file.xu -O0
xu run dir -- args
xu test file.xu -v
xu doc src/net --public -o net.md
xu doc src/net --public --serve --addr 127.0.0.1:6060

In PowerShell use --output. Test flags: -run -v -count -failfast -list -short -bench. Directory build/check skip test.*.xu.

xu doc --serve exposes /, /docs.md, and /health; the language server is still not implemented. Use xu check for diagnostics.

Target order: --target > XUOS+XUARCH > the running binary.
