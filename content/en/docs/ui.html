UI / WebView

#ui is the desktop shell: App / Window / Icon / Menu / Tray / event loop. Content is pluggable: WebView, immediate-mode canvas #ui/draw, or none.

#ui/webview: attach to a window; load_html / load_url, eval, on/emit. Local xu:// (packed into the binary) or remote http(s).

App layout: tutorial 16.

xu doctor --desktop --target macos-arm64
xu build App --target macos-arm64 --desktop -o /tmp/XuOpen
open /tmp/XuOpen.app

brand/ must contain a PNG icon inside the app directory. XU_UI_SIM=1 is an in-process sim. Missing host throws ui: host not available.
