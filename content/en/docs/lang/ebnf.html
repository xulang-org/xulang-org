EBNF

Planning grammar (for review, not a byte-for-byte parser table):

File         = "@" DottedPath { CompileTag } { Import } { Decl } .
Import       = [ Ident ] "#" Path [ "as" Ident ] .
ReturnStmt   = "<<" [ Expr ] .
ThrowStmt    = ">>" Expr .
ExitStmt     = "<<<" Expr .
BreakStmt    = "<-" .
ContinueStmt = "->" .
RangeOp      = ":" . // [start, end)
XuStmt       = "xu" Ident "(" [ Args ] ")" .
Expr         = … | Expr "or" "(" Ident ")" Block | Expr "or" ">>" .
