EBNF

Planning grammar (for review, not a byte-for-byte parser table):

Xu Core Grammar EBNF Specification
Grammar Rule Production Syntax (Definition) Description & Semantics
File "@" PackagePath { CompileTag } { Import } { Decl } . Root structure of source files starting with a package declaration
Import [ Ident ] "#" Path . Module import; external paths require an alias before #
ReturnStmt "<<" [ Expr ] . Function return statement with optional expression
ThrowStmt ">>" Expr . Throw error or exception propagating upward
ExitStmt "<<<" Expr . Terminate process with exit code
BreakStmt "<-" . Break from loop immediately
ContinueStmt "->" . Advance to next loop iteration
RangeOp ":" . Half-open interval range operator [start, end)
XuStmt "xu" QualifiedName "(" [ Args ] ")" . Spawn lightweight goroutine concurrent invocation
Expr … | Expr "or" "(" Ident ")" Block | Expr "or" ">>" . Expressions, safe error unwrap & propagation

File         = "@" PackagePath { CompileTag } { Import } { Decl } .
Import       = [ Ident ] "#" Path  .
ReturnStmt   = "<<" [ Expr ] .
ThrowStmt    = ">>" Expr .
ExitStmt     = "<<<" Expr .
BreakStmt    = "<-" .
ContinueStmt = "->" .
RangeOp      = ":" . // [start, end)
XuStmt       = "xu" QualifiedName "(" [ Args ] ")" .
Expr         = … | Expr "or" "(" Ident ")" Block | Expr "or" ">>" .

PackagePath is a slash path, optionally quoted for domain-based identities. Dots in domain names are preserved. An import alias precedes #; external paths require an alias.
