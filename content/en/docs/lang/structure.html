Structure

A directory is a package: #util loads util/*.xu (not recursive), else util.xu. One package per directory. Only the project directory may use @main. Export with pub.

#path is file-scoped: declarations are package-wide, but each file must import to use qualified names.

Platform sources use header tags $macos / $linux / $windows / $unix, not _linux.xu suffixes.

Top level allows only: package decl and $ tags, # imports, const, struct/struct@/enum, fn. No globals, no top-level statements.
