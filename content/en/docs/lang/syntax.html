Syntax freeze

Surface syntax is frozen: >>/or, #path, control-flow symbols, struct@ / name#. There is no user-facing Result / Ok / Err / ?.

any / temp are runtime boxes; # / @ / struct@ are compile-time splits. Unconstrained form is bare name# / name@, not name# any.
