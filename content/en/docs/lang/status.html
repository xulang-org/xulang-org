XU v0.1.0 Implemented Surface Feature Matrix

Language Feature Implemented Grammar & Mechanics
Functions & Modules Top-level fn, receiver methods on structs, @main entry, multi-file unified packages
Variables & Mutability := inferred binding, explicit mut declaration, immutable-by-default, compound assignment
Literals & Radix Decimal integers, hexadecimal 0x, binary 0b, underscore number separators 1_000_000
Built-in Type System int bool string f64 i32 u32 u8 byte temp struct enum []T map chan
Control & Flow Operators if / else, for, while, match, << zero-cost return, >> throw, or (err) {}, <- break, -> continue
Concurrency & Channels xu f(args) coroutine dispatch, chan typed communication, lock-free scheduling
AOT Cross-Compilation 5+ primary target architectures (macOS arm64/x64, Linux x64/arm64/loongarch64/riscv64, Windows x64/arm64)
