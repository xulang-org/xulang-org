Language snapshot — Xu {{xu_version}}

Xu {{xu_version}} implemented language and toolchain surface

Functions and packagesTop-level fn, methods, @main, multi-file packages, pub visibility, slash-path declarations/imports and domain module identities.
Variables and numeric typesImmutable-by-default := bindings, $name, compound assignment; int/bool/f64/i32/u32/u8/byte; hexadecimal/binary literals and numeric separators.
Aggregate typesstring, []T, [N]T, struct, enum, map, chan, any/temp, and struct@ method sets.
Generic codeCompile-time #/@ parameters, constraints and monomorphized function/method implementations; 0.9.4 removes the four-type-parameter limit on generic declarations.
Control and errorsif/else, for, while, match; << return, <<< exit, >> throw, or handling/rethrow, <- break, -> continue, and colon ranges.
Ownership and resourcesMoves, shared &T and exclusive $&T borrows, affine File/Conn resources, deterministic scope cleanup; 0.9.4 completes borrow checking for nested expressions and loop back edges.
Concurrencyxu f(args), typed channels, buffered/unbuffered communication, close, and select. Platform runtime support is checked separately.
Toolchain and dependenciesNative AOT, WebAssembly (wasm32) emission, standalone native Setup installers, module manifests, MVS, proxies, locks/vendor, offline/frozen builds and trusted-key checksum-log verification.

XACP stdio and loopback TCP control is specified for language repository 0.10.10-dev.1. It is documented on the CLI reference and the #xacp API, outside this {{xu_version}} snapshot. Importing #xacp does not install the control channel.
