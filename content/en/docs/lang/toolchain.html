Toolchain

Xu 0.8.4 provides build, run, check, test, install, fmt, map, doc, and doctor. Product builds self-host with the Xu compiler; the frozen Rust bootstrap serves as a primer and correctness oracle.

The default target is the host. Use --target linux-arm64 or XUOS/XUARCH for cross-compilation. XUPATH uses : on Unix and ; on Windows, independently of the target. External imports still require xu.xun mappings.

Ordinary AOT builds emit native output directly. Desktop host code and native extensions such as SQLite require their platform toolchains. --emit-obj emits XUOBJ; --shared exports primitive int/bool/string/f64/i32/u32/u8 signatures.
