Toolchain

The language experience is these product commands: build run check test fmt map doctor up.

Default target is the host. Cross-compile with --target linux-arm64 or XUOS / XUARCH. XUPATH uses : on Unix and ; on Windows (host OS, independent of --target).

--shared export types are only int / bool / string / f64 / i32 / u32 / u8. Self-contained AOT: no external toolchain is a hard rule.
