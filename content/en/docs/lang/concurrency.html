Concurrency

fn worker(id int, ch chan int) {
    ch <- id * 10
}

fn main() int {
    ch := chan int{cap: 1}
    xu worker(1, ch)
    println(<-ch)
    << 0
}

xu f(args) starts a coroutine. xu.pkg.f is a package path. Channels move ownership; do not send borrows. Buffered and unbuffered channels, close, and select exist.
