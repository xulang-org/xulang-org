Goals

Xu {{xu_version}} language documentation. Current implementation and platform boundaries are described throughout these pages.

Xu is a GC-free systems language. Three goals:

GoalLanguage consequence
Fast compile and deployStatic AOT, single-file binaries, first-class cross-compile, simple packages
GC-free memory and thread safetyOwnership + borrow; deterministic drop at end of scope. Conflicts are compile errors. Optimizations must not turn unproven bounds/div-zero into silent UB
Very small syntaxImmutable by default, no semicolons, no extra parens on conditionals/loops, symbolic control-flow exits, mandatory error handling, no mutable globals

Light to write, controllable at runtime, with safety closed at compile time where possible.

Deliberately not (or later)

  • Full dynamic OOP / open-world reflection
  • JIT peak throughput as the first goal
  • Syntax sugar that breaks ownership checking
  • User-visible Result / Ok / Err / ?
  • unsafe / reflect
