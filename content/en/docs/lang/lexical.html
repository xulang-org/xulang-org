Lexical

Extension .xu, UTF-8. Comments // and /* */. No semicolons. Identifiers [A-Za-z_][A-Za-z0-9_]*.

Style is checked: types PascalCase; constants UPPER_SNAKE_CASE (for example, BLOCK_SIZE); functions/variables/fields snake_case. Visibility is pub, not letter case.

Keywords include fn struct enum const mut temp let if else match for while in as is or true false int bool string f64 i32 u32 u8 byte pub xu chan select map. Not keywords: interface / import / return / break / continue.

Literals: 42, 0xFF, 0b1010, 1_000_000, 3.14, "hi", raw backtick strings, [1, 2, 3].
