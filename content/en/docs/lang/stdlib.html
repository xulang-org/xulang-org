Stdlib boundary

The language kernel keeps only what a library cannot express cleanly, or what is coupled to the compiler: println / args / read_file / xu_target_os and similar. The standard library uses the ownership model.

The standard library sits under src/ — no std. prefix. Imports: #fmt, #net/http, #crypto/sm2, #ui/webview.

Rejected: unsafe, reflect, user-visible runtime pointers, arbitrary syscall addresses. Chinese GM algorithms (SM2/SM3/SM4/SM9/ZUC/GMTLS) are Xu packages: pure Xu implementations, not commercial-crypto certified.

LANGUAGE.md §9 tables cover 104 packages. Eleven more exist in src and are included in this site’s API: crypto/rand, crypto/tls, crypto/x509/pkix, io/fs, net/http/cookiejar, net/http/httptest, net/netip, os/exec, os/signal, os/user, testing/fstest.
