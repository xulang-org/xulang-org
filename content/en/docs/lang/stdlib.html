Standard library and package boundaries

The language kernel retains operations coupled to the compiler, including println, args, read_file, and xu_target_os. Public standard-library sources live in src/, without a std prefix: #fmt, #net/http, #crypto/sm2, #ui/webview.

The library now includes stream I/O and explicit read/write progress contracts, process pipes, HTTP/2, network pools, timer/rate utilities, and SQL pooling and transaction interfaces. Generated API pages list the actual public declarations; API presence does not imply identical support on every target.

Concrete service drivers live in the separate packages module. Import MySQL as mysql #github.com/xulang-org/packages/mysql, with its root module in require:. database/sql remains in the standard library. SQLite uses a native C bridge.

The language does not expose unsafe, reflect, arbitrary runtime pointers, or arbitrary syscall addresses. SM2/SM3/SM4/SM9/ZUC/GMTLS packages are implemented in Xu; this does not imply commercial-cryptography certification.

#xacp is the transport-neutral safety core in src/xacp: frame limits, permissions, session lifetime, and UI adapter checks. Importing it does not open stdio or TCP. Those hooks are inserted only when a hosted native executable is built with --xacp or --xacp-port. The package is included in the published {{xu_version}} SDK extract and generated catalog. Native sessions and UI runtime acceptance remain unverified. See the #xacp API and the CLI reference.
