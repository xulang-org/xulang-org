Get started

Xu 0.1.0 snapshot. These pages describe the product compiler named xu (rename the matching download to xu and put it on PATH).

Xu is a GC-free systems language: thin syntax, ownership and borrow, static AOT. Sources are UTF-8 .xu files.

  1. Install a native xu
  2. Write Hello
  3. Work through tutorials 01–16
  4. Open the language spec when you need the rules
