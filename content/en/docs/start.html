Get started

Xu {{xu_version}} documentation. Install a complete SDK and check the compiler with xu --version.

Xu is a GC-free systems language: thin syntax, ownership and borrow, static AOT. Sources are UTF-8 .xu files.

  1. Install native xu via native Setup installers or SDK archives (or try the WebAssembly Playground in browser without installing)
  2. Work through tutorials 01–16 (starting from 01 hello)
  3. Inspect the 13 Measured Cross-Language Benchmarks
  4. Open the language spec when you need the rules

Modules and external packages

Projects manage dependencies using xu.xun. To use third-party service drivers, you don't need manual build setups: simply declare "github.com/xulang-org/packages": v0.1.1 in require: and run xu install to fetch everything automatically into vendor/. See Official External Packages Guide, Modules and Dependencies Specification, and Native Modules & .xulib Specification.

Tutorial commands run from the separate examples repository; paths start with examples/.
