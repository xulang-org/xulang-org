What can I run here?

Basic types, strings, control flow, recursion, structs, enums, borrow diagnostics, and cooperative chan communication. Xu source files in the root directory run together. Use folders to organize files; cross-directory imports and native UI require the local SDK. Learn about coroutines and chan.

The online sandbox covers fundamental types, string manipulations, flow control, recursion, structs, pattern matching, compile-time borrow diagnostics, and channel communication modeled through cooperative coroutine scheduling. UI examples include real #ui/widgets Button, Checkbox, Switch, and Slider controls: their measurement, state, hit testing, focus rings, and activation execute in Xu. Click a control or use Tab, Enter/Space, and arrow keys; Esc leaves the canvas. playground.next_click() replays up to 64 clicks deterministically: each click reruns Xu and displays the last draw.present() frame. playground.next_input() replays up to 64 pointer/key events for widgets. Down and up each count as one event. Run Code resets the session. The three-page control gallery adds Radio, ListBox, Scroll, Tabs, StyledLabel, Card, Badge, Progress and a display-only Editor. Wheel scrolls the data page. Text uses single-line monospace metrics; native shaping, editable text/IME and the full styled control suite are unavailable. The fixed memory budget is 128 MiB. Desktop windows, WebView, system services, and the full widgets library require the native toolchain. Individual sandbox runs have a 10-second safety budget.
