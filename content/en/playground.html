XU Interactive Playground (WebAssembly)

Write, typecheck, and execute XU code directly in your browser without local installation or cloud execution dependencies.

The execution engine is written entirely in Xu and compiled to native WebAssembly bytecode, running securely within your browser sandbox. It includes lexical parsing, borrow checking, MIR code generation, and VM execution.
