Xu 0.8.8: 47 Cross-Language Benchmarks, Native Setup Installers, and WebAssembly Support

This post highlights key capabilities and ecosystem updates in Xu 0.8.8. Official release binaries and SHA-256 signatures are available on GitHub Releases.

Xu reaches an important milestone with 0.8.8. While continuing its core promise of zero GC, single ownership, and deterministic resource lifetimes, this release delivers a dedicated 47-workload cross-language benchmark suite across dual architectures, self-contained native offline Setup installers, native WebAssembly (wasm32) compilation with a zero-backend interactive playground, and a refined website navigation experience.

47 Full Cross-Language Benchmarks Across Dual Architectures

To objectively demonstrate Xu's real-world execution speed and physical memory footprint in systems programming, the official site launches the 47 Full Cross-Language Benchmarks suite, tested across both Apple Silicon ARM64 and Intel/AMD x86_64 against C++20, Rust, Go, Java, Node.js, and Python:

  • Comprehensive Scenarios: Covering arithmetic microbenchmarks, recursion, string parsing, hash tables and trees, JSON/binary codec, high-frequency prime and matrix algorithms, coroutine/thread concurrency scheduling, and streaming file I/O.
  • Dual-Metric Measurement: Accurately reporting wall-clock execution time alongside real-world peak Resident Set Size (RSS Peak Memory). The data confirms Xu's compile-time ownership advantages in latency-critical and memory-constrained workloads.
  • Reproducible and Open Source: All benchmark sources and harness scripts are fully open source for local cross-verification on your own hardware.

Standalone Native Setup Offline Installers

Xu 0.8.8 introduces zero-dependency native Setup installer packages (powered by companion xu-setup), eliminating past reliance on Python, bash scripts, or pre-existing environments:

  • Windows: Standalone xu-setup-windows-x64.exe. Double-click to launch the native GUI wizard and configure user registry Path and XU_ROOT without PowerShell script execution policy errors. Run .\xu-setup-windows-x64.exe -y for silent command-line installation.
  • macOS: Native GUI package installer xu-macos-arm64.pkg configuring /etc/paths.d/xu for immediate system-wide terminal availability, alongside unprivileged CLI installer xu-setup-macos-arm64.
  • Linux: Standalone binary packages xu-setup-linux-x64 and xu-setup-linux-arm64 that self-extract and update user Shell environment profiles automatically.
  • In-place Upgrades: Execute xu up or xu update at any time to pull verified matching official binaries from GitHub and atomically update the toolchain.

WebAssembly (wasm32) Target and In-Browser Playground

The compiler now supports native AOT emission for --target wasm32, producing standard WebAssembly modules (.wasm) directly without heavy external bundlers:

xu build app/main.xu --target wasm32 --output dist/app.wasm

Building on this foundation, we launched the interactive WebAssembly Playground. Running entirely client-side inside the browser without backend dependencies, it supports live execution of coroutines, channels, borrow checks, and pattern matching with a collection of curated examples.

Concurrency and Runtime Hardening

Version 0.8.8 refines the semantics of xu f(args) coroutines and typed chan communication:

  • Optimized handshake mechanics for both unbuffered and buffered channels, lowering synchronization overhead and context switching;
  • Improved deterministic error reporting and deadlock detection across close and select multiplexing;
  • Hardened runtime boundaries on multicore schedulers across all supported platforms.

Refined Experience: Streamlined Navigation, Light Theme, and Full Docs

Alongside the 0.8.8 release, the official website received a comprehensive navigation and visual upgrade:

  • Focused Top Navigation: Streamlined into 6 core sections: Docs, API, Playground, Benchmarks, Download, and Blog, with a responsive mobile slide-out drawer on smaller screens;
  • Default Light Theme: Switched to a clean Stone Paper Light theme by default while retaining smooth toggle and persistent preferences for Dark mode;
  • Full Documentation Sync: Updated guides for Install, CLI, Modules, Language Snapshot, and API references across 157 standard library and external packages.
