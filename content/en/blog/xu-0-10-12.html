Xu 0.10.12: mutable markers and Windows networking fixes

2026-10-29 · Xu v0.10.12

Xu 0.10.12 is available as a stable release. It standardizes the documented spelling of mutable bindings and writable borrows and fixes Windows socket readiness and TCP/UDP error handling. Upgrade the compiler, standard library and product tools together.

Mutable bindings and writable borrows

Use $name := for mutable bindings, $&value for writable borrow expressions and $&T for writable reference types. Product sources, examples (including XACP) and compiler diagnostics now use these markers. Diagnostics for immutable assignment and mutable borrowing suggest $x := value and $&owner, respectively.

When migrating, review declarations, borrow expressions and parameter types together. See the getting started guide and the examples bundled with the SDK.

Windows networking fixes

Socket readiness checks now initialize every WSAPOLLFD event field and reject zero-extended SOCKET_ERROR results. Stale stack flags could previously make a nonblocking check report a large positive count, causing the HTTP intake loop to block in accept before serving connected clients.

Winsock adapters now sign-extend 32-bit status and byte-count results while preserving pointer-width SOCKET handles. TCP/UDP errors can no longer turn into successful byte counts or oversized received strings. Public APIs and ABIs remain compatible.

Installation and benchmarks

Use the download page to upgrade the complete SDK and verify release assets against SHA256SUMS. Read the full release notes for details.

The official benchmarks now cover 48 workloads on Xu 0.10.12 across macOS, Linux and Windows on ARM64 and x64. Compiler identities, source closures and stdout are verified for each platform; the benchmark page records the environments and methodology.
