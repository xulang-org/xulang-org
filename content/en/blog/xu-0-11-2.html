Xu 0.11.2: standalone @ui/chart, self-host reproducibility, scale stability, and unified target constraints

2026-11-01 · Xu v0.11.2

Xu 0.11.2 is now available as a stable release. This release decouples the chart engine into a standalone @ui/chart package, fixes XUN config parsing loops to restore multi-seed 3-generation self-hosting, introduces an optimization scale stability governance framework, and standardizes target machine register footprint constraints. Upgrade the compiler, standard library, and product tools together.

Standalone @ui/chart Package

The 30 chart series types (line, bar, bubble, radar, candlestick, sankey, treemap, and more) previously residing within @ui/widgets have been decoupled into an independent @ui/chart package. Applications and sample suites (such as component_workshop) now import #ui/chart directly, eliminating circular package dependencies, reducing core widget compilation overhead, and providing clear architectural boundaries.

Compiler Robustness and Reproducible Self-Hosting

Parser deadlocks on empty configuration keys and block bodies in XUN manifests have been eliminated, accompanied by regression coverage for invalid syntax diagnostics and zero-sized array allocations. Three-generation self-hosting fixed point verification (Gen2 == Gen3) has been fully restored across supported seed toolchains and target platforms.

Optimization Scale Stability Governance

A new scale stability testing harness evaluates compiler optimization behavior by embedding identical functions across varying translation unit sizes. Comparing analysis admission, CSE invariants, inlining decisions, and generated assembly across unit sizes prevents threshold-induced divergences and ensures predictable, robust optimization outcomes.

Unified Target Register Constraints and Analysis Summaries

The code generation pipeline unifies target machine register home constraints (td_extra_gpr_home) across all calling conventions and platform backends, preventing conflicts with coroutine stack checks. A new function-level analysis summary abstraction (mir_fn_summary_ro / MFn.summary()) paves the way for fine-grained incremental compilation caches.

Installation and Benchmarks

Use the download page to upgrade the complete SDK and verify release assets against SHA256SUMS. Read the full release notes for details.

The official benchmarks continue to provide verified dual-architecture performance metrics across macOS, Linux, and Windows.
