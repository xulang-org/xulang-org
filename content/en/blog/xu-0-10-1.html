Xu 0.10.1

2026-10-23 · Official release

Xu 0.10.1 brings the current development work into the official SDK: retained desktop UI and styled controls, Thumb-2 code generation, cryptography corrections, bounded concurrent HTTP intake, regexp work limits, checked JSON conversions and DEFLATE compression.

Download SDKs and checksums

Desktop UI

Drawing supports recorded frames, display lists, paths, text and image resources. Retained Views provide layout, input routing, focus and repaint boundaries. Editors use native text sessions, selection, caret and IME geometry. Menus, screen queries, clipboard, dialogs and WebView queries follow the asynchronous request lifecycle.

Switch, Radio, Slider, Stepper, Tabs, Select, Badge, Divider, Card and ListBox join the styled controls. The shared Styles API covers fonts, density, state rules, shadows, icon geometry and dark, light and contrast palettes. StyleSwitcher applies presets and scaling to a retained View. See the UI guide and released widget API.

Compiler and libraries

Thumb-2 gains virtual-register allocation, compact T16 encodings and branch relaxation. Compiler changes also cover owned argument handling and 32-bit lowering. Cryptography corrections include fail-closed RSA blinding, authenticated JWT header validation, TLS certificate/signature compatibility and GMTLS CBC authentication work.

HTTP intake polls incomplete requests with bounded connection, buffer and timeout limits; complete requests are dispatched concurrently. Responses handle short writes. Regexp execution uses explicit stacks and a shared work budget. DEFLATE uses bounded LZ77 matching with fixed Huffman codes and an incompressible-data fallback. JSON as_int and as_f64 propagate conversion errors; legacy numeric accessors retain their zero fallback.

Migration

  • Handle errors from regexp matching, finding, splitting, expansion and replacement. Budget exhaustion returns an error; a valid nonmatch still returns an empty or false result. Expressions are limited to 65,536 bytes and 64 nested groups. See regexp.
  • HTTP handlers may overlap. Synchronize shared mutable state and use server_options() and serve_with_options for limits. See HTTP.
  • Draw canvases remain fixed by default. Enable camera panning explicitly with draw.set_pan_enabled(1).
  • After retained layout, call widgets.place_editor before presentation to synchronize native text geometry. Native UI tools and platform libraries remain required.

Validation and scope

Compiler identity is checked against VERSION and build provenance; hosted compilation requires a confirmed self-host fixed point. Release CI verifies SDK packaging and host installation. The benchmark dashboard records the measured compiler commit, six platforms, verified output and measurement date. Target emission and API availability do not imply complete runtime validation or certification; consult status and limitations.

The historical 0.11.0-dev.3 preview remains available separately. The selected official release is 0.10.1; its website API and playground are generated from this released SDK.
