Xu 0.10.5: source debugging, native installation and compiler fixes

2026-10-25 · Official release · SDK assets and SHA-256 checksums

Xu 0.10.5 is available for macOS ARM64/x64, Linux ARM64/x64/LoongArch64/RISC-V 64, and Windows x64/ARM64. The website API and browser Playground use the same released SDK. The release points to 2a635a6.

Changes since 0.10.2

  • Source debugging: xu debug builds a DWARF-enabled executable and launches LLDB or GDB. Set source/function breakpoints, inspect stacks and local variables, or use batch mode. A host debugger must be installed.
  • Compiler and standard library: expanded record SSA promotion and tile planning, low-bit lookup-table and pipelining APIs; corrections to map, string, encoding, flag and cryptographic code; ARM32 integer/ABI and STM32F4 board support.
  • Installation and updates: native Setup installers, automatic SDK destination selection, Windows current-user/all-users scopes, and standard-library download/extraction progress. xu up and xu update remain aliases.
  • Editor diagnostics: LSP diagnostics preserve the document URI. The compiler version banner now omits the former “self-hosted” suffix.

Migration: uppercase constants

Constant declarations and references now use UPPER_SNAKE_CASE. Rename const max = 100 to const MAX = 100 and update references, including imported standard-library constants. Functions, variables and fields retain snake_case.

@main
const MAX = 100
fn main() int {
    println(MAX)
    << 0
}

Keep the compiler, bundled tools and standard-library sources from the same SDK. Do not overlay the new compiler onto an older source tree. See the platform downloads and installation guide.

Release verification

The release build passed hosted fixed-point verification (Gen2 = Gen3), packaged all eight SDK targets, and exercised the installed macOS ARM64 SDK and native installer. The Windows hosted build/check and full product delivery workflow also passed. Download SHA256SUMS beside the selected archive to verify its contents.

Available cross-compilation targets do not imply complete runtime validation of every library on every target. The status page records remaining boundaries; the benchmark dashboard retains the compiler version actually used for each published measurement.

Companion example correction

Some UI, WebSocket and DNS examples in the original 0.10.5 bundles still reference lowercase imported constants. The corrected official sources pass compilation checks for all 54 examples referenced by this website, using the 0.10.5 compiler. SQLite examples require the native bridge build described in their README.
