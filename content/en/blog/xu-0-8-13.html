Xu 0.8.13

Xu 0.8.13 is the stable release of the pure Xu self-hosted toolchain. Download the SDKs, installers, checksums, and release notes.

A pure Xu build chain

Start from a published Xu SDK seed. Every generation builds the original source and manifest and confirms a fixed point. Product builds, platform packaging, and safety checks no longer depend on Rust Gen0 or a sibling bootstrap checkout. The historical repository remains a private read-only archive. Official 0.8.12 and 0.8.11 seeds have been verified.

Correctness and internal cleanup

Fixes cover floating-point call preservation, element-address copies, x64 map adapters, and assembly symbol resolution. Squared-norm and loop optimizations retain their admission proofs and side-effect checks. MIR operands, links, and destination IDs use direct field updates; actual instruction copies retain independent string ownership. Backend label forwarding is unified.

Installation and migration

Run xu --version to confirm 0.8.13. Set xu: !ver 0.8.13 in project manifests while maintaining each module's own version: independently. Existing slash module paths, dependency locks, and vendor workflows remain compatible.

Validation and benchmarks

The development candidate passed the complete regression suite, five-profile fixture matrix, ownership checks, and cross-platform safety checks. The final release additionally verifies self-host fixed points and SDK installation. The benchmark page keeps the actual measured version: existing 0.8.12 results are not 0.8.13 performance claims.
