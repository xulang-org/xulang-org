Xu 0.10.11: shared reborrows, XACP and native widgets

2026-10-28 · Xu v0.10.11

Xu 0.10.11 integrates the validated development branch with the 0.10.10 native widget baseline. It includes shared-reborrow checks, framed XACP transport and Screen marshalling, Windows UI boundary fixes, WASM smoke coverage, and terminal progress for SDK installation and updates.

Shared reborrows and migration

A writable local reference can be passed to a shared-reference parameter with the same direct pointee type. Aliasing a shared reborrow and its writable parent within one call is rejected in either argument order. Split the operations or end the shared loan before mutation. This does not add recursive container conversions or automatic reborrows of arbitrary values.

Native widgets and XACP

The release retains native password input and monotonic pointer-clock fixes. Its inherited widget baseline includes public Chart, RangeSlider, SplitView and structured-menu APIs for the bundled component workshop. XACP clients must use framed control transport and matching companion examples.

SDK bundle inputs are pinned to complete companion commits, with compiler, native UI, WASM and installed-SDK checks. Platform-specific binary availability is recorded with the release assets; cross-built targets do not imply native GUI acceptance.

Installation and the next release
