Xu 0.14.1 Released: Pure-Xu Local LLM Inference, P4K4 & Paged Attention Fusion, and Cross-Platform Compiler Speedups

2026-11-25 · Xu v0.14.1

Xu 0.14.1 is officially released! Following 0.14.0's bare-metal OS kernel foundation, Xu 0.14.1 brings major advances in pure-Xu local AI inference, opt-in MIR tensor fusion and core compiler optimizations, cryptography/TLS/short-string runtime performance, and macOS code-signing reliability. Every target has passed the six-platform native SDK gate and the complete 72-workload cross-language benchmark suite with zero failures.

1. Pure-Xu Local LLM Inference (examples/llm_engine/main.xu)

examples/llm_engine/main.xu demonstrates end-to-end local language-model inference in pure Xu without external inference runtimes:

  • Streaming GGUF Loading & Internal P4K4 Weight Packing: Loads F32 Safetensors and compatible Llama- and Qwen2-architecture GGUF v2/v3 models, packing Q4_0 and Q8_0 weights in memory into the internal P4K4 layout for grouped GEMV4 and M=12 GEMM kernels while keeping GGUF files unchanged on disk;
  • Paged KV Cache & Continuous Batching: Provides a paged key/value cache and coroutine continuous-batching scheduler for batched prefill and autoregressive decoding;
  • ABI-Safe Standard Library Additions: Adds slice.reserve(n int), slice.resize_zero(n int), and math.float16_to_f32(h int) f32 without altering the frozen core runtime ABI.

2. Opt-In MIR Tensor Fusion & Paged Attention Kernels

With XU_TENSOR_FUSION=1 (and optional XU_TENSOR_FAST_MATH=1), the compiler lowers eligible Xu numerical loops in optimized native ARM64 and x64 builds:

  • Paged Attention Fusion: Recognizes paged attention score calculation (__xu_tensor_attn_scores_paged*), scaled softmax (__xu_tensor_softmax_scaled*), and value weighted accumulation (__xu_tensor_attn_vsum_paged*), dispatching to available scalar or ARM64 NEON/DotProd and x86-64 SSE kernels;
  • Quantization & Activation Kernels: Covers Q4_0/Q8_0 pack/quantization, RMSNorm, RoPE, SwiGLU, argmax, and P4K4/signed grouped matrix operations.

3. Compiler Optimizer, Standard Library & macOS Signing

  • Middle-End & Codegen Improvements: Adds loop constant hoisting (opt_hoist_loop_consts), slice descriptor vs. element-buffer disjointness proofs, loop unrolling and pointer strength reduction, GVN direct-call effect modeling, blk_noreturn liveness pruning with register coalescing, and ARM64 FMADD/FMSUB/TST and x64 TEST lowering;
  • Runtime & Stdlib Speedups: Accelerates short-string paths, X25519 scalar multiplication, and Montgomery big.exp; completes additional TLS 1.3 handshake combinations; enforces JSON parser node-count bounds;
  • Complete macOS Signing: macOS SDK binaries and standalone installers ship ad-hoc signed, and the CLI signs temporary Apple Silicon executables generated during native xu run and xu test.
