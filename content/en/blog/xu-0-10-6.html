Xu 0.10.6: corrected SDK examples and stronger installation checks

2026-10-25 · Patch release · Full SDK downloads and checksums

Xu 0.10.6 packages the corrected official examples with the compiler, tools and standard library. Upgrade the complete SDK from the download page. This patch follows 0.10.5, retaining its source debugger, native installer and compiler/standard-library changes.

What is fixed

Some examples in the original 0.10.5 SDK still used lowercase imported constants after the libraries switched to UPPER_SNAKE_CASE. That caused UI, WebSocket and DNS examples to fail with the SDK's own compiler. The 0.10.6 release pins the corrected example sources, including shared UI helpers.

Installed-SDK validation now checks the actual draw, widgets and style-gallery examples, plus WebSocket and DNS examples when the packages module is bundled. This catches incomplete imported-constant migrations after extraction and installation. The new check reproduces the original 0.10.5 failure.

Offline extraction timeout correction

Intel macOS installation validation also exposed repeated large-buffer copies across DEFLATE blocks and TAR entries. The patch reuses one DEFLATE output buffer and reads each TAR entry directly from the archive, avoiding a whole-prefix or whole-archive copy per block or file. Format validation, checksums and error boundaries are preserved; timeout diagnostics retain captured installer output.

The complete release also includes the built VS Code/Cursor extension VSIX, retaining its independent version 0.3.0. Install it offline from the SDK’s editors/vscode/ directory.

Upgrade and migration

xu update --version 0.10.6
xu --version

Alternatively, download the matching platform archive or native Setup installer. Compiler, companion tools and standard-library manifests use 0.10.6. Keep constant declarations and imported references in UPPER_SNAKE_CASE; functions, variables and fields remain snake_case.

The complete corrected example set referenced by the website passes compilation checks. SQLite examples additionally require the documented native bridge build; interactive UI and external-service examples need their host dependencies or running services. See Status & Limitations.

The original 0.10.5 tag and published assets remain intact. Use the new 0.10.6 archive and its SHA256SUMS together. Historical benchmark results retain the compiler version used to measure them.
