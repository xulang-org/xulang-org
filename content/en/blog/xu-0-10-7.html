Xu 0.10.7: reliable SDK reinstall and legacy upgrades

2026-10-26 · Xu v0.10.7

Xu 0.10.7 repairs unreliable reinstalls over an existing SDK. Older installers could stop at a read-only standard-library file after replacing binaries, leaving mixed versions. This release stages a complete new directory, verifies its full file inventory and ten tools, then replaces the SDK while retaining the original backup. Failed replacement or verification restores the original installation.

Install and update

Upgrade or repair with the commands on the download page. Online scripts prefer the SDK selected by PATH; an explicit prefix selects another destination. Bash, PowerShell, native Setup and macOS PKG share the complete replacement process. User data outside managed SDK components is preserved. Installation output records the original backup path.

The updater now refreshes tools, standard library, packages, examples and editor files together. After installing 0.10.7, use xu update --force to download and repair the current full SDK. An unwritable parent causes failure before replacement; select a writable destination or use the appropriate administrator permissions.

Legacy updater compatibility

The compiler keeps its canonical version line and adds the compatibility line needed by the 0.10.2 updater. If an earlier install failed, run the full installation command again. The installation guide covers destinations, environment configuration and verification.

CI build and publication

CI builds and verifies every platform bundle. Jobs that compile or execute installers have read-only repository permissions. An isolated publication job validates the artifact receipt and uploads those same files using GitHub’s temporary token, without running SDK tools or dependencies. Previously published tags and assets remain intact.
