Xu 0.12.2: typed MIR, default optimization, and six-platform SDKs

2026-11-11 · Xu v0.12.2

The compiler lowers type-checked programs to typed MIR and self-hosts from the published 0.12.2-seed.1 compiler. Upgrade the compiler, standard library, and SDK tools together.

Optimization and migration

xu build, xu run, and xu test optimize by default. Remove -O1 through -O3 from scripts and replace -O0 with --no-opt.

xu build main.xu -o app
xu run main.xu --no-opt
xu test test.example.xu --no-opt

SDKs, packages, and tools

Native SDK acceptance passed on Linux, macOS, and Windows on ARM64 and x64. Linux LoongArch64 and RISC-V SDKs are cross-built. Windows ARM64 supports native executable and COFF object emission, and Linux ARM64 and x64 support desktop packaging. xu get and xu install resolve pinned dependencies. --xacp and --xacp-port enable startup discovery and control on supported native builds.

For WebAssembly, use --target wasm32-wasi with a WASI runtime. The browser Playground uses an interpreter built with its pinned Xu {{playground_version}} SDK.
