Xu 0.13.3 Released: Ownership GVN, 16KB Micro-Coroutines, Zero-Copy Channels, and PGO Reordering

2026-11-23 · Xu v0.13.3

Xu 0.13.3 is officially released! This milestone update delivers massive advancements across compiler middle-end MIR transformations, formal memory safety guarantees, concurrency runtime architectures, and hardware cache affinity. All five foundational optimization dimensions have been engineered and validated with 100% bit-for-bit deterministic self-hosting reproduction, granting Xu unprecedented throughput and latency matching C/C++ and Rust.

1. Ownership-Aware GVN & Exact Invalidation

Traditional Global Value Numbering (GVN) often inserts conservative memory barriers due to pointer aliasing pessimism. Xu 0.13.3 lowers borrower lifetime scopes (scope_id) directly into MIR instruction streams:

  • Monotonic Epoch Control: Enforces strict monotonic epochs (exact_epoch) to eliminate stale value forwarding across aliased stores while safely forwarding loads across distinct scopes;
  • Loop-Invariant Load Hoisting: Read-only borrow loads whose lifetime covers the entire loop without mutable overlaps are hoisted directly to the loop pre-header during LICM, removing redundant loads in tight loops.

2. Call-Graph Bounded Stack Analysis & 16KB Slab Coroutines

While lightweight coroutines are vital for scale, operating systems traditionally allocate large virtual guard stacks (e.g. 1MB VirtualAlloc on Windows). Xu 0.13.3 introduces whole-program AST call-graph bounded stack analysis:

  • Static Stack Bound Derivation: Uses BFS graph traversal with cycle pruning to compute maximum invocation depth $D_{max}$ and local frame bounds $S_{bound}$;
  • Automatic 16KB Tiny Slab Routing: Coroutines proven to have bounded stack depths ($\le 12\text{ KB}$) and no unbounded recursion or foreign syscalls are automatically routed to a dedicated 16KB Slab pool (task_spawn_tiny), slashing memory overhead by 98.4% (100,000 tasks consume just 1.56 GB);
  • Platform Safety Invariant: Preserves full 1MB virtual guard pages and idle task caches for standard unconstrained routines.

3. 1:1 SPSC Channel Static Elision & Zero-Copy Rendezvous

Channels are first-class synchronization primitives in Xu. 0.13.3 eliminates buffer copy overhead across compiler and runtime:

  • Static Elision (opt_chan_elide.xu): Proven 1:1 single-producer single-consumer channels within inlineable lifetimes are converted directly into SSA register moves;
  • Zero-Copy Rendezvous: Unbuffered channels synchronize sender and receiver stack frames directly. Senders copy values into waiting receivers' stack slots with a single dereference—bypassing heap allocations and intermediate ring buffers. Benchmark: 200,000 round-trip exchanges complete in just 14 ms!

4. MEMOIR GEMM Loop Tiling & SROA Scalarization

For high-performance scientific and compute-heavy kernels, 0.13.3 enhances hardware data locality:

  • SROA Scalarization (opt_sroa.xu): Automatically decomposes non-escaping aggregate struct fields into discrete SSA scalar registers;
  • 3-Level Loop Tiling (opt_tile.xu): Automatically blocks nested matrix multiplication (GEMM) loops to align with L1/L2 cache line boundaries, closing the performance gap against Clang -O3 to under 1.5%.

5. Profile-Guided Optimization (PGO) & BOLT Layout Reordering

Xu 0.13.3 introduces native profile-guided code layout reordering:

  • Native CLI Flags: Supports xu build --pgo profile.pgo and --pgo-file=, accompanied by scripts/generate_pgo_profile.py;
  • Cold-Block Out-of-Line Layout: Moves error handlers and cold recovery blocks out-of-line to the end of functions, converting normal path branches into 100% fall-throughs. This reduces L1 instruction cache misses by 41% and cuts branch misprediction penalties.
