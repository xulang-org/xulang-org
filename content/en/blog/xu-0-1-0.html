Xu 0.1.0

Xu 0.1.0 is the first snapshot shaped as a product compiler: per-platform xu.<os>.<arch>, a thin tutorial, and runnable examples 01–16.

The bet is unchanged: no GC; thin syntax, ownership, AOT. So are the marks: << to return, >> + or for errors, xu f(args) to spawn, #errors to import.

What you can do: host and cross builds, check/fmt/test/map, HTTP and some desktop packing, the standard library (#fmt, #net/http, …), plus SM2 and other Chinese algorithms (pure Xu implementations, not commercial-crypto certified).

What we will not pretend is done: Windows TCP still returns an error; sqlite is macOS-only; xu up prints a version; there is no unsafe/reflect; docs generation and the language server are not on the product compiler.
