Xu 0.11.4: bounded tail calls, byte processing and XUN correctness

2026-11-06 · Xu v0.11.4

Xu 0.11.4 improves eligible recursive and byte-processing code and repairs XUN parser and serializer boundaries. Upgrade the compiler, standard library and product tools together.

Compiler and string operations

Eligible ARM64 integer/bool sibling calls restore the current stack frame and saved registers before a tail jump. Pure scalar self recursion with one wrapping addition per recursive result can become an accumulator loop. Checked arithmetic, bounded readonly byte scans, selected string operations and proved eight-round CRC loops retain their specialized paths. Ownership, address, ABI, debugging and instrumentation exclusions preserve ordinary fallbacks.

XUN compatibility

Duration validation advances through its input; collection nesting is limited to 64 below the root. Multiline parsing preserves payload whitespace after the required structural indentation. Typed lists validate inherited scalar types and preserve container and element tags through serialization.

Migration: typed-list serialization can use a different spelling while preserving the parsed value. Update textual snapshots and compare parsed trees where spelling is not part of the contract. Legacy nonempty !s[...] scalar input remains accepted. See the XUN API.

Experimental ESP32 source

The fixed-profile Wi-Fi/BLE coexistence and CYD status application are included as experimental source. Final external full-MTU ICMP reply acceptance remains pending after a host LAN EHOSTUNREACH. This SDK release does not certify the board application for production and distributes no flashed firmware.

The profile supports WPA2-PSK/CCMP and one legacy SMP Just Works peer. DHCP renewal/rebinding, Group Rekey, DNS/TCP, SoftAP, WPA3/PMF and Wi-Fi reconnection during an active BLE connection are unavailable. Just Works provides neither MITM protection nor LE Secure Connections. Changing networks requires a joint restart.

Downloads and validation

Native acceptance covers macOS, Linux and Windows on ARM64/x64. LoongArch64 and RISC-V SDKs are cross-built. Get the complete SDK from Downloads and verify SHA256SUMS. The full change history and limits are in the release notes.

The benchmark dashboard retains the actual 0.11.3 compiler identity and source run of its measurements. Those results are not relabelled as 0.11.4 measurements; no general speedup is claimed.
