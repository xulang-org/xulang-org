Xu 0.14.3 Released: Full Binary Hardening, 128-bit SLP Vectorization, and 121-Workload Benchmarks

2026-11-27 · Xu v0.14.3

Xu 0.14.3 is officially released! Combining the engineering milestones of 0.14.2 and 0.14.3, this release finalizes >> throws with >>> / >>> (err) {} error handling and multi-error checker recovery, standardizes hardened Windows PE32+, Linux ELF, macOS Mach-O (including built-in ad-hoc signing), and WASM binary emission, lands 128-bit SLP auto-vectorization, Ext-TSP layout, SwissTable SWAR core/map, Phase 5–7 general optimizer passes, and M:N multi-core coroutine scheduling, and expands #core OS/UEFI primitives, #tensor/llm_engine, #ui/widgets, and xu doctor/#ui/phone. All six native platforms passed self-hosted fixed-point builds and the expanded 121-workload cross-language benchmark matrix (11 engineering domains).

See the Xu 0.14.2 release notes for the compiler and runtime changes that preceded 0.14.3. The AI guide, OS development guide, and #sync/pool reference cover the new APIs in more detail.

1. Finalized Error-Handling Syntax & Multi-Error Checker Recovery

  • Clean Separation of Throw vs. Handle: Across the compiler, CLI tools, standard library, documentation, and examples, >> expr explicitly throws errors while expr >>> and expr >>> (err) { ... } propagate and handle errors cleanly alongside disambiguated nested >>> generic closing.
  • Cross-Function Multi-Error Recovery: The checker continues across declarations and functions (up to MAX_DIAG_ERRORS = 25) using ERROR_TY and fn_failed() cascade suppression, guarded by scripts/test_checker_multi_error.py.

2. Standardized Binary Formats & Modern Platform Hardening

  • Windows PE32+ (windows-arm64 / windows-x64): Strict W^X sections (.text RX, .rdata R, .data RW), .reloc base relocations, PE Load Config / Security Cookie (IMAGE_GUARD_CF_INSTRUMENTED / _load_config_used), and OS .pdata/.xdata unwind tables.
  • Linux ELF32/ELF64 (linux-x64 / linux-arm64 / linux-riscv64 / linux-loongarch64 / linux-riscv32): Strict W^X, ET_DYN PIE, Full RELRO (DF_BIND_NOW), .note.gnu.build-id, Intel CET IBT (endbr64), CFI unwind frames, and full section headers.
  • macOS Mach-O (macos-arm64 / macos-x64): Adds __DATA_CONST, LC_UUID, LC_BUILD_VERSION, and built-in ad-hoc LC_CODE_SIGNATURE across both release and debug builds; hardened COFF/ELF/Mach-O .xuobj emitters and WASM output ship alongside.

3. Compiler Optimizer, SwissTable Runtime & M:N Multi-Core Scheduling

  • 128-bit SLP Auto-Vectorization & Ext-TSP Layout (0.14.2): opt_slp (opt-out XU_NO_SLP=1) packs unrolled isomorphic array ops and 4-way integer reductions into ARM64 NEON and baseline x86-64 SSE2 lanes; paired with Wu–Larus + Ext-TSP basic-block layout, correlated jump threading, lifetime-hole register allocation, and zero-spill constant rematerialization.
  • Phase 5–7 General Passes & Codegen Parity (0.14.3): Adds single-caller inlining, 1-block and countdown-loop unrolling, non-negative GVN value-range propagation across div/mod/guarded subtraction, canonical-offset state promotion, cold-call constant hoisting, ARM64 CCMP/CCMN fusion and shift-add constant multiplication, and x86-64 mul_const/imul/madd parity.
  • SwissTable core/map & M:N Coroutines: Upgrades core/map to 8-slot SWAR CTRL_LANE_MUL probing (7/8 load factor); adds thread-safe heap/FFI locking, the M:N multi-core coroutine scheduler (#sync/pool) on Linux and macOS, hardware u8/u16/u32/u64 atomic intrinsics, and fixes for resize_zero heap zeroing and net/poller wakeups.

4. OS Substrate, AI/Tensor, UI & Release Tooling

  • Bare-Metal & UEFI Substrate: Adds @interrupt, @weak, @naked, @section/@align/@export, extern static, usize/isize, packed/union/bitfield C structs, sizeof/alignof/offsetof, strict --no-sse, --stack-size, relocatable DWARF, x64-uefi and arm64-uefi targets, parameterized inline asm across x64/ARM64/RV64, #core/{acpi,addr,ds,elf,fdt,fmt,mmio,pci,uefi}, VirtIO 1.0 Modern MMIO, HPET, and UEFI MemMap.
  • AI / Tensor & Companion Ecosystem: Expands #tensor and examples/llm_engine with Q4_K/Q6_K/Q4_1/Q5_1/Q2_K/Q3_K/Q5_0 kernels, M=12 GEMM, paged SIMD attention, --threads N CPU parallelism, training backward ops, GBNF Trie/Schema, and mmproj.gguf VLM support; accompanied by github.com/xulang-org/packages v1.17.0 (50 packages, adding llm_metal, cuda_native, vulkan_native, unified gpu facade, and Redis distributed gateway state).
  • UI, Diagnostics & Bootstrap Policy: Upgrades #ui/widgets through Rounds 12–14 (responsive rules, style classes, FLIP transitions, DnD, virtualization, forms, inspector tools), hardens xu doctor and #ui/phone P0–P3, and enforces seeding every release directly from its immediately preceding published release.
