Xu 0.10.2

2026-10-24 · Official release

Xu 0.10.2 is officially released! This update completely resolves toolchain path discovery and ambient environment hijacking, brings native nonblocking socket readiness waiting (epoll / kqueue / IOCP) across all major platforms, integrates a compliant RFC 1951 fixed-Huffman DEFLATE compressor, introduces ergonomic high-level UI Screen abstractions, and achieves full three-generation bootstrap fixed-point verification.

Download SDKs and checksums

Toolchain Discovery and Environment Isolation

Previously, global configuration (e.g. ~/.xu/env.sh) could hijack xu env and internal standard library resolution in standalone local checkouts or workspace builds. Xu 0.10.2 refactors path discovery:

  • Probes the companion standard library src/ relative to the running binary (argv[0]) and verifies directory readability first;
  • Binds XU_ROOT strictly to the parent directory of the verified standard library root, ensuring perfect consistency between the toolchain and stdlib;
  • Completely prevents unintended path crosstalk across multi-version cohabitation, CI workflows, and local checkouts.

Native Socket Readiness (epoll / kqueue / IOCP)

At the runtime and system call layer, 0.10.2 introduces native nonblocking socket readiness waiting (sys_socket_wait and os.socket_wait):

  • Linux: Powered by epoll event loops and readiness dispatch;
  • macOS / BSD: Powered by kqueue kernel event filters;
  • Windows: Powered by IOCP completion ports and WS2 primitives;
  • Provides a unified, lightweight nonblocking readiness abstraction for high-concurrency servers and low-latency clients.

RFC 1951 DEFLATE Compression

The standard library compress/flate now includes a fully compliant bounded LZ77 and fixed-Huffman DEFLATE compressor:

  • Uses a 32 KiB bounded circular history buffer with fast 3-byte hash table lookup;
  • Automatically evaluates compressibility and falls back to stored blocks for incompressible or short streams;
  • Ensures high throughput and predictable memory residency with zero undefined behavior across targets.

UI Screen Abstractions and Widget Expansion

Desktop UI gains an ergonomic Screen abstraction, eliminating boilerplate in view setup, event loops, and state management. The styled widget suite now includes Breadcrumbs, ColorPicker, ComboBox, DatePicker, TimePicker, MultiSelect, Pagination, Spinner, Table, Toast, Tooltip, and TreeView, alongside hardened map value struct slot layout calculation.

ARM32 / Thumb-2 Code Generation

Thumb-2 incorporates virtual register allocation, compact 16-bit T16 narrow encodings, and branch relaxation, boosting code density and execution efficiency on 32-bit ARM and embedded environments.

Verification and Bootstrap Convergence

The compiler has completed a full 3-generation self-bootstrap (Gen1 → Gen2 → Gen3) achieving bit-for-bit convergence (fixed point confirmed (Gen2 == Gen3)). All 8 companion tools (xu-doctor, xu-fmt, xu-map, xu-doc, xu-desktop, xu-setup, xu-lsp, xu-native) and 8 cross-compilation targets pass comprehensive contract verification.
