Compiler Code Generation & Diagnostic Fixes

In complex numerical computations and deep recursion scenarios, Xu 0.9.3 resolves key compiler backend and type checker defects:

  • Callee-Saved Register Allocation Protection: Previously, when a self-recursive call appeared as the right operand of a binary expression (such as << n * fact(n - 1)) or in multi-parameter self-recursive functions (such as the Ackermann function ack(m, n) or accumulators helper(n, acc)), the backend register allocator did not account for registers assigned to preceding parameters, overwriting earlier parameter values in the same callee-saved register (ARM64 x19/x20, x64 RBX/R12). With the fix, each scalar parameter receives a distinct register home, guaranteeing correctness in nested binary expressions and deep recursion.
  • Robust Diagnostics on Undefined Symbols: Fixed a compiler internal out-of-bounds crash (c.fns[-1] indexing error) triggered when encountering undefined or misspelled function names, providing clean and actionable compile-time diagnostics.

Installation & Migration

Native single-file Setup installers are recommended for quick setup with automatic environment configuration:

  • macOS / Linux One-Line Online Install: curl -fsSL https://xulang.org/install.sh | bash
  • Windows PowerShell One-Line Online Install: irm https://xulang.org/install.ps1 | iex
  • Standalone Setup Binary: Run ./xu-setup-<target> -y (or double-click xu-setup-windows-x64.exe for GUI wizard on Windows).

In your project manifest xu.xun, declare:

module: myapp
version: !ver 0.1.0
xu: !ver 0.9.3

Run xu --version to verify compiler version 0.9.3.
