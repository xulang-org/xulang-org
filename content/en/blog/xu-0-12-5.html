Xu 0.12.5: pure-Xu SDL backend, hostless font stack, SoftBlob safety, and zero-GC stability

2026-11-17 · Xu v0.12.5

Xu 0.12.5 delivers major architectural upgrades for graphics rendering, game engine integration, and headless replay testing. It replaces external C driver shims with a pure-Xu SDL backend and dynamic FFI, introduces a hostless font parser and glyph atlas, and hardens Zero-GC memory safety across the board.

Pure-Xu SDL backend and native FFI

The standard library #internal/sdl is now implemented entirely in pure Xu, binding dynamically to the SDL shared library via the reworked ffi package. External C driver shims have been retired. Added Win64 calling convention support, c_callback trampolines, and accurate platform scalar widths (Windows LLP64 c_long/c_ulong alignment), simplifying cross-platform desktop and game runtime packaging.

Hostless font stack and headless replay

The new official #ui/font package provides pure-Xu TrueType parsing, glyph metrics, a dynamic glyph atlas, and a text layout engine without relying on system font daemons or platform text APIs. Combined with Frame.export_xdf() and phone.Canvas.export_xdf(), draw calls can be serialized into sealed XDF1 binary buffers for headless replay, testing, and cross-process streaming.

SoftBlob CPU safety and graphics enhancements

The #gpu module adds SoftBlob and SoftBlobRef to provide safe, bounds-checked CPU views of mesh and texture data buffers, eliminating dangling pointers and segmentation faults across FFI boundaries. In addition, Window.present_rgba enables direct software bitmap presentation, while Event.touch_id and contact queue tracking deliver precise multi-touch input handling.

Zero-GC compiler and memory safety

The compiler refines reference ownership tracking: strict holder counts for closure environments, interface boxes, temporary channels, and channel messages; arrays explicitly act as holders for pushed references; run-time drop flags track conditionally moved variables across branches; and maps adopt owned deep-copy semantics, guaranteeing safety and deterministic cleanup without garbage collection pauses.

Upgrade the full SDK

Native production SDKs and unified offline setup installers for all six primary platforms (Linux x64/arm64, macOS arm64/x64, Windows x64/arm64) have completed multi-tier verification and are now available.
