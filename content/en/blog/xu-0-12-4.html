Xu 0.12.4 introduces mobile app projects and new MIR optimizations

2026-11-15 · Xu v0.12.4

Xu 0.12.4 adds xu build --phone and the #ui/phone kit. It also expands compiler optimizations for typed MIR and ARM64 and x64 machine code.

Generate an iOS or Android project

The compiler emits a native ARM64 application object and bundles it with an iOS or Android shell. The app executes native code and sends Draw frames to a local Canvas. Mobile controls support safe areas, navigation, native IME editing, haptics and clipboard. Start with the mobile app guide and the #ui/phone API.

Project generation and object formats were validated for iOS devices, the ARM64 iOS Simulator and ARM64 Android. Signing, physical-device behavior and app-store submission require the platform toolchain and separate acceptance.

Typed-MIR and code generation

Global value numbering removes redundant computations. Loop-invariant code motion moves eligible work out of loops, and bounds-check elimination and store-to-load forwarding handle more loop patterns. ARM64 and x64 code generation improves constant division, conditional selection, integer rotates and floating-point square roots. Inspect optimized MIR with XU_DUMP_MIR and compare measured workloads on the benchmark dashboard.

Upgrade the full SDK

Update the compiler, standard library and tools together. The full SDK includes xu-phone, its templates and native host sources. Installer and uninstaller scripts now use ASCII text. Native SDK installation and execution were verified on Linux, macOS and Windows on ARM64 and x64.
