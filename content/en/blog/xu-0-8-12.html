Xu 0.8.12

Xu 0.8.12 is the stable release delivering substantial performance improvements, compiler optimization upgrades, and dependency management enhancements. Download the SDK, installers, checksums, and release notes.

What changed

  • New xu get command: Add or update dependencies with explicit versions (e.g., xu get github.com/xulang-org/packages@v0.1.1), automatically resolving modules into vendor/ and updating xu.lock. Failed resolutions preserve existing project manifests and vendor trees safely.
  • Register allocation and IR optimizations:
    • RegPlan block budget expanded from 64 to 128 blocks;
    • GPR call-crossing interval splitting enabled on x86_64;
    • Frame-type-contract barrier eliminated, admitting strings, slices, and general maps into the VReg pipeline;
    • Strength reduction added for constant integer multiplication and division; closed-world single-target interface devirtualization supported;
    • SROA aggregate scalarization threshold expanded, with staged AST and typechecker memory reclamation drastically reducing self-compilation peak RSS.
  • Standard library performance:
    • Hex decoding accelerated using ARM64 NEON SIMD routines;
    • Base64 codecs streamlined with compact hot loops and string byte count prefiltering;
    • Optimized AES-128 key schedule and MD5 chained hashing;
    • Inlined integer map hash mixing and zero-frame scalar lookup paths.

Validation and bootstrap reliability

The release passed compiler fixed-point validation (gen2_gen3 reproducibility), native multi-platform setup packaging, and full test suites across architectures. The benchmark page reflects verified performance profiles.

Next development cycle

Development continues with 0.8.13-dev.1. The website and default downloads remain on the published 0.8.12 stable SDK.
