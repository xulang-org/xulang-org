安装与修复：以下命令可用于全新安装、升级或重复安装修复。默认更新 PATH 中已有的 SDK；没有时安装到 ~/.xu。原 SDK 会保留为备份，完整校验通过后才完成替换。

安装命令

macOS / Linux

curl -fsSL https://xulang.org/install.sh | bash -s -- --online --version {{xu_version}} --yes

Windows PowerShell

& ([scriptblock]::Create((irm https://xulang.org/install.ps1))) -Online -Version "{{xu_version}}"

WebAssembly 支持：任意平台的 xu 编译器均内置 WebAssembly 后端，支持通过 xu build --target wasm32 app.xu 直接编译为标准 .wasm 模块，无缝运行于现代浏览器与 WASI 沙箱。

安装与使用

推荐使用原生 Setup 安装程序快速完成安装并自动配置全局环境：

  • Windows：下载 xu-setup-windows-x64.exe（或 xu-v{{xu_version}}-windows-x64-setup.exe）直接双击运行（自绘图形向导，无需配置脚本策略，自动持久化注册表 PATH 与 XU_ROOT）。
  • macOS：下载 xu-v{{xu_version}}-macos-arm64.pkg 双击图形向导安装，或下载独立安装程序 xu-setup-macos-arm64（命令行运行 ./xu-setup-macos-arm64 -y）。
  • Linux：下载对应架构的 xu-setup-linux-x64（或 arm64），赋予执行权限后直接运行 ./xu-setup-linux-x64 -y，自动解压并完成环境注册。

安装完成后重新打开终端，验证全局可用：

xu --version
xu build hello.xu --output hello
./hello
