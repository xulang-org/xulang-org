下载 Xu

当前源码开发候选为 Xu 0.8.3，修复依赖下载参数的 shell 执行路径，并启用来源、源码缓存与 vendor 的 SHA-256 校验。模块声明与导入统一使用斜杠路径，保留域名标点；旧点式声明和锁条目身份需迁移，已支持显式来源的传递依赖闭包、离线与冻结构建；官方包统一使用 github.com/xulang-org/packages 下的完整路径。MVS 与代理解析仍在实施中。产品自举在 Gen2 与 Gen3 字节一致时省去 Gen4 编译，预热转换后仍保留 Gen4 确认。开发候选的安装包需完成发行打包后才能下载。

编译器发布文件通过 GitHub Releases 提供，请选择已发布版本及适合本机的平台文件。开发候选的安装包在完成发行打包后提供。

安装示例

面向用户的编译器命令为 xu。下载 Apple Silicon macOS 对应文件后：

chmod +x xu.macos.arm64
mv xu.macos.arm64 xu
# 将 xu 放入 PATH
xu build hello.xu
./hello

macOS / Linux 默认产物无后缀，Windows 为 .exe。使用 --output 可指定输出路径。
