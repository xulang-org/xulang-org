chan：用信道连接协程

chan T{cap: n} 创建带缓冲的信道；ch <- value 发送，<-ch 接收；xu f(args) 启动协程。下面的三个 worker 将结果送回主函数，汇总后输出 60。

这三个 chan 示例已可在上方浏览器运行器中执行，也可下载源码在本机运行。浏览器通过协作调度模拟协程。

@main

fn worker(id int, results chan int) {
    results <- id * 10
}

fn main() int {
    results := chan int{cap: 3}
    xu worker(1, results)
    xu worker(2, results)
    xu worker(3, results)

    mut total := 0
    for i in 0:3 {
        value := <-results
        total += value
    }
    println(total)
    << 0
}
