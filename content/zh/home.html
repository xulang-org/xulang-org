常见问题解答 (FAQ)

什么是 Xu 编程语言？

Xu 是一门现代静态强类型、超音速 AOT 编译的原生系统级编程语言，专为高并发云原生后端、网络基建与低延迟系统软件而设计。它在无需垃圾回收（零 GC）的前提下，通过编译期确定性 RAII 所有权、轻量级原生协程（xu f()）与类型安全通道（chan T）实现卓越的内存安全与并发吞吐。

Xu 语言是否有垃圾回收（GC）？

没有。Xu 完全不依赖任何运行时垃圾回收器（Zero GC），没有 Stop-The-World (STW) 暂停。内存由编译期唯一所有权跟踪与 RAII 作用域析构确定性释放，并通过 &T 共享借用与 &mut T 独占借用在编译阶段彻底消除数据竞争。

Xu 相比 Rust 与 Go 有哪些区别？

相比 Rust，Xu 在提供同等确定性零成本内存安全的同时，去除了显式生命周期标注的心智负担，并将用户态协程与通信通道作为语言一等公民内置；相比 Go，Xu 保持了轻快直观的并发体验，但采用原生超音速 AOT 编译与确定性内存管理，彻底规避了运行时 GC 停顿与内存占用膨胀。

Xu 的执行性能与 C / Rust 相比如何？

在双架构（ARM64 / x86_64）多系统的 13 项经典基准评测中，Xu 在绝大多数计算密集型任务中达到 C (Clang -O3) 与 Rust (rustc -O3) 1.0x~1.2x 的极致执行速度，且峰值物理内存开销显著低于含 GC 运行时的语言。
