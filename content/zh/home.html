极简清晰的薄语法

无分号、条件/循环无冗余括号。特色流控符号直观表达：<< 零成本返回、>> 抛错、or (err) {} 接住、<- break、-> continue。默认不可变，心智负担极低。

零运行时开销所有权

无 GC 暂停时间。owning 值同一时刻拥有唯一所有者，离开作用域确定性析构 drop。&T 共享借用、&mut T 独占可变借用，所有数据竞争在编译期彻底排除。

超音速原生 AOT 编译

静态单文件原生可执行机器码，跨平台交叉编译一等公民支持。xu build / xu run / xu check。产物 macOS / Linux 默认无后缀，Windows 为 .exe。
