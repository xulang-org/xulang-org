三个 worker，汇总一个结果

三个协程通过类型化信道传值；以下两个完整文件与演练场项目源码一致。

main.xu

@main

fn main() int {
    results := chan int{cap: 3}
    xu worker(1, results)
    xu worker(2, results)
    xu worker(3, results)

    $total := 0
    for i in 0:3 {
        value := <-results
        total += value
    }
    println(total)
    << 0
}

worker.xu

@main

fn worker(id int, results chan int) {
    results <- id * 10
}

输出： 60 · 退出码： 0

演练场运行 WASM 解释器子集，与原生 AOT 分开。此例展示协程调度和信道通信，不衡量 CPU 并行吞吐。要在本机运行，将两个文件保存在同一目录，先执行 xu check main.xu worker.xu，再执行 xu run main.xu worker.xu。详见并发边界。

原生 AOT 与 WebAssembly

直接编译为原生机器码或 WebAssembly，支持 macOS、Linux、Windows 等目标与跨平台代码生成，无需虚拟机。

所有权与确定性回收

通过所有权与借用检查管理内存，在作用域结束时确定性释放资源；没有垃圾回收器，也无需显式生命周期标注。

轻量协程与类型安全信道

使用 xu f() 启动轻量协程，以 chan T 传递数据和同步任务，将并发直接融入语言。

简洁语法与类型推导

默认不可变，支持局部类型推导、结构体、枚举与泛型；无需分号，减少日常编码中的样板。

模块管理与扩展生态

以 xu.xun、xu.lock 与 vendor 管理依赖，支持离线与冻结构建；标准库与官方扩展包覆盖网络、密码、数据库和消息服务。

显式错误处理

<< 返回，>> 抛错，or (err) {} 就地处理或传播错误，让失败路径与正常控制流一起清晰可见。

原生 UI 与 WebView

内置原生绘图、布局、控件、主题与 IME 输入，也可使用 WebView 承载网页；通过 Xu 构建桌面应用。

统一工具链与编辑器

统一 xu 命令集成构建、运行、检查、格式化与文档生成，配套测试工具；通过 LSP 连接 VS Code、Cursor 等编辑器。

C 互操作与原生模块

以 xu native 编译和打包 C 模块，.xulib 携带接口契约与多目标切片；链接流程按目标平台选择。

常见问题解答 (FAQ)

什么是 Xu 编程语言？

Xu 是一门静态类型、原生 AOT 编译的系统编程语言，采用所有权与借用检查，内置轻量协程和类型安全信道，可用于命令行工具、网络服务与桌面应用。

Xu 语言是否有垃圾回收（GC）？

没有。Xu 通过编译期所有权与借用检查管理资源生命周期，在作用域结束时确定性释放资源，无需运行时垃圾回收器。详见所有权与借用及共享状态同步与原生 / FFI 安全边界 FAQ。

Xu 支持原生桌面 UI 吗？

支持。SDK 提供原生绘图、布局、控件与桌面服务，也可通过 WebView 使用 HTML/CSS/JavaScript 构建界面。原生控件界面无需网页；支持范围与平台依赖见 UI 常见问题和开发指南。
