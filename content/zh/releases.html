版本记录

按版本查看发布变更、修复与迁移说明。需要安装 SDK，请前往下载页。

0.10.7 正式版

修复 SDK 覆盖重装与只读标准库导致的安装中断。安装器和更新器在完整校验后替换目录，保留原 SDK 备份，失败时恢复；在线脚本与 macOS PKG 共用此流程，并恢复旧版更新器需要的版本横幅兼容。详见发布与升级说明及 0.10.7 校验摘要。

0.10.6 正式版

完整 SDK 已包含修正后的 UI、WebSocket 与 DNS 示例，并加入安装后的示例编译验收。请升级整个 SDK，参阅修正版说明，并使用 0.10.6 校验摘要核对下载。

旧版升级提示：0.10.2 等旧版 xu update 会因版本横幅变化误报版本不匹配。请运行下载页中对应平台的完整 Setup 安装器，或使用安装说明中的在线脚本完成一次升级。完整安装也会刷新配套示例、xu-update、xu-lsp 和编辑器扩展；详见升级与迁移。

0.10.5 正式版

源码调试、原生 Setup 安装与标准库更新、编译器和 LSP 修复。常量统一使用 UPPER_SNAKE_CASE；请阅读发布与迁移说明。该原始发行版本的校验摘要见 SHA256SUMS。

0.10.2 正式版

工具链路径自感知与环境隔离、原生非阻塞 Socket 就绪等待（epoll / kqueue / IOCP）、RFC1951 DEFLATE 压缩与人体工学 UI Screen 抽象。请阅读发布说明，并下载正式 SDK 附件与校验摘要。

0.10.1 正式版

统一样式控件与主题切换、桌面异步请求、Thumb-2 代码生成，以及密码学和标准库修复。正则调用须处理预算错误；HTTP 处理器可以并发执行。请阅读迁移说明，并下载正式 SDK 附件与校验摘要。

0.9.4 正式版

编译器一致性与优化器版本：借用检查器遍历全部表达式种类，循环内借用在回边上保持存活，嵌套在类型转换或算术表达式中的 f(mut &v, &v) 这类别名现在会被诊断；泛型不再限制类型参数个数；XU_VERIFY=1 在每个优化 pass 之后运行完整 MIR 验证器；标量 SSA 提升不再依赖形状白名单，ARM64 循环内核改用基于 SSA 的匹配器。查看发布说明与 SDK 附件。

0.9.3 正式版

关键稳定性与代码生成修复：修复多参数自递归函数在调用处与入口处的非易失寄存器分配覆盖缺陷（支持深度自递归与复杂表达式左/右递归调用）；修复类型检查器在未定义函数符号上的越界崩溃并提供规范诊断；通过 8 套极限语法套件与全矩阵回归验证。查看发布说明与 SDK 附件。
