评测准则与环境公开

  • 同算法等价实现：所有横测均采用相同的数据结构、数学算法与循环迭代规模，拒绝峰值特化。
  • 全量最高编译优化：所有原生对比语言均开启官方最高级别优化（Clang -O3、rustc -O3 / --release、Swift -O 即等价 -O3、Go 原生编译优化），统一处于激进优化水平。
  • 严苛输出指纹校验：每次运行均严格比对 stdout 黄金校验码与退出码，杜绝无意义的死代码剪除与假跑。
  • 稳健采样方法：每个程序重复运行 7 次，取 wall 耗时与 CPU 耗时中位数；通过 Unix wait4 与 Windows 原生 API 捕获真实峰值常驻内存（RSS）。
  • 双架构完整覆盖：原生覆盖 ARM64（Apple Silicon / Neoverse / Snapdragon X Elite）与 x86_64（Intel / AMD）硬件，并在 macOS、Linux、Windows 环境下全面实测。
  • CI 自动化测试：由 GitHub Actions CI 全程自动运行与出具报告。流水线配置见 bench 仓库 的 .github/workflows/bench.yml。
