lookup_ints

XuAPI
pub fn lookup_ints(a &[]int, v int) Search

用途

在有序切片中二分查找目标的下界，适合查找元素或确定保持有序的插入位置。

参数

a &[]int
已按升序排列的切片；调用不会先替你排序。
v int
要查找的值。

返回值

Search.index 是第一个不小于 v 的位置，范围为 0..a.len；found 表示该位置是否确实等于目标。

使用时注意

  • 空切片返回位置 0；重复值返回第一次出现的位置。只看索引不能判断命中，还需检查值或使用 lookup_* 的 found。

reverse_ints

XuAPI
pub fn reverse_ints(a $&[]int)

用途

把整个切片原地排成降序。它会先升序排序再翻转，适合取最大值在前的排序结果。

参数

a $&[]int
要处理的切片；排序接口使用独占借用，直接修改原切片。

返回值

不返回值；排序结果保存在 a 中。

使用时注意

  • 只想把当前元素次序倒过来、保留原来的相对排列时，使用 slices.reverse_*。

调用示例

降序排序与单纯反转的区别

Xu本机 SDK 示例
@main
#sort
#slices

fn main() {
    $ordered := [2, 1, 3]
    sort.reverse_ints($&ordered)
    for value in ordered { println(value) }
    $flipped := [2, 1, 3]
    slices.reverse_ints($&flipped)
    for value in flipped { println(value) }
}
