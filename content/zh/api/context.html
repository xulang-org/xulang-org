struct Context

XuAPI
pub struct Context {
    pub done chan int
    pub deadline_ns int
    pub keys []string
    pub vals []string
}

用途

`context` 最小面：Background / WithCancel / WithTimeout。 Done 是 chan；cancel 即 close。副本共享同一条 chan（与 sync.Mutex 相同）。 `with_cancel_parent` adds cancellation propagation without requiring a runtime interface value: a small watcher goroutine waits on the parent's done channel and closes the child exactly once.
