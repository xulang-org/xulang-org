ComboBox

结合输入与候选项选择

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

输入文字筛选候选项。

使用要点

输入与候选选择相结合。明确是否允许不在列表中的自定义值，过滤只影响候选展示。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    options := ["Design","Develop","Review"]
    id := screen.combo_box(&options,"Design") or >>
    screen.place(id,24.0,24.0,320.0,80.0) or >>
    << id
}

($&Screen) combo_box

XuAPI
pub fn (s $&Screen) combo_box(options &[]string,value string) int

用途

在 Screen 中创建 ComboBox，返回组件节点 ID；创建失败时抛出错误。

参数

s $&Screen
本次调用使用的 Screen 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
options &[]string
options（只读借用，调用方仍持有原值；类型 &[]string）
value string
value（string）

返回值

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。

Action · Styles · 界面生命周期与样式指南

Screen.place · Screen.set_enabled · Screen.set_visible

XuAPI
pub fn (combo $&ComboBox) set_open(open bool)

用途

控制下拉选项列表的打开状态。

参数

combo $&ComboBox
本次调用使用的 ComboBox 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
open bool
true 请求打开，false 关闭；禁用或只读时请求打开也会保持关闭。

($&ComboBox) input

XuAPI
pub fn (combo $&ComboBox) input(event &ui.InputEvent) Action

用途

处理可输入下拉框的菜单选择、展开按钮和编辑器输入。

参数

combo $&ComboBox
本次调用使用的 ComboBox 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
event &ui.InputEvent
同一窗口、画布和代次的输入事件；坐标按控件所在的画布空间传入。

返回值

Action 描述本次交互：kind 是动作类型，consumed 表示事件是否已处理，request_focus 请求焦点，needs_paint 表示需要重绘。

使用时注意

  • 选中菜单项时返回 ACTION_CHANGE，value 为原选项列表中的索引；输入法组合期间把 Enter/方向键留给编辑器。

($&ComboBox) paint_popup_styled

XuAPI
pub fn (combo $&ComboBox) paint_popup_styled(frame $&draw.Frame,styles &Styles) int

用途

绘制展开的选项列表；与输入框本体分开绘制，以便选项覆盖后面的控件。

参数

combo $&ComboBox
本次调用使用的 ComboBox 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
frame $&draw.Frame
当前绘制帧；本调用向其中记录绘制命令。
styles &Styles
当前生效的样式；提供颜色、间距、字体和状态外观。

返回值

成功返回 0；失败时抛错，不以非零返回码表示失败。

使用时注意

  • 在画布坐标空间中绘制，通常放在普通控件之后；不要沿用输入框内部的局部变换或裁剪，否则列表可能被截掉。

错误处理

  • 绘制帧、文字或样式操作失败时继续抛出错误。
