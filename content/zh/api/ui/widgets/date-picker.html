DatePicker

选择日历日期

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

更改预约日期并查看结果。

使用要点

日期值与显示格式分开处理。按地区设置日期格式、周起始日及可选范围，避免只依赖占位文字说明格式。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets
#time

fn configure(screen $&widgets.Screen) int {
    value := time.date(2026,10,28,14,30,0,0)
    id := screen.date_picker(value) or >>
    screen.place(id,24.0,24.0,320.0,80.0) or >>
    << id
}

($&Screen) date_picker

XuAPI
pub fn (s $&Screen) date_picker(value time.Time) int

用途

在 Screen 中创建 DatePicker，返回组件节点 ID；创建失败时抛出错误。

参数

s $&Screen
接收者 $&Screen（独占借用）
value time.Time
value（time.Time）

返回

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。
