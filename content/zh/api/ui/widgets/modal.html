Modal

在独立对话框中完成当前决策

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

打开确认框，分别取消与确认。

使用要点

模态期间将交互限制在对话框，关闭后将焦点返回触发位置。确认、取消及关闭需要明确的业务含义。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    id := screen.modal("Apply changes?","Review before confirming.") or >>
    << id
}

($&Screen) modal

XuAPI
pub fn (s $&Screen) modal(title string,message string) int

用途

在 Screen 中创建 Modal，返回组件节点 ID；创建失败时抛出错误。

参数

s $&Screen
本次调用使用的 Screen 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
title string
title（string）
message string
message（string）

返回值

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。

($&Modal) set_focus_order

XuAPI
pub fn (m $&Modal) set_focus_order(ids &[]int) int

用途

设置模态层内部的 Tab 遍历顺序，让键盘焦点在指定控件中循环。

参数

m $&Modal
本次调用使用的 Modal 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
ids &[]int
内容控件 ID 的有序列表，最多 256 项；ID 必须为正数、不能重复，也不能等于模态层自身 ID。

返回值

成功返回 0；失败时抛错，不以非零返回码表示失败。

使用时注意

  • 原焦点仍在新列表中时保留它，否则选第一项；空列表表示没有内容焦点目标。

错误处理

  • 数量、ID 或重复校验失败时抛错。

($&Modal) open

XuAPI
pub fn (m $&Modal) open(now time.Instant,reduced_motion bool,restore_focus int) int

用途

打开模态层并记录关闭后的焦点恢复目标。

参数

m $&Modal
本次调用使用的 Modal 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
now time.Instant
当前动画时间 time.Instant；打开、更新和关闭应使用同一时间基准。
reduced_motion bool
是否减少动态效果；为 true 时直接到目标状态。
restore_focus int
关闭完成后需要恢复的控件 ID；0 表示没有恢复目标，不能为负数。

返回值

成功返回 0；失败时抛错，不以非零返回码表示失败。

使用时注意

  • 每帧调用 tick 推进动画，用 is_visible 决定是否继续绘制。

错误处理

  • 动画参数或状态无效时抛错。焦点恢复 ID 为负数也会抛错。

(&Modal) allows_content

XuAPI
pub fn (m &Modal) allows_content(event &ui.InputEvent) bool

用途

判断当前输入能否交给模态面板内部的控件，用于模态层优先分发后的下一步。

参数

m &Modal
本次调用使用的 Modal 实例；以只读借用传入，调用方仍持有实例。
event &ui.InputEvent
同一窗口、画布和代次的输入事件；坐标按控件所在的画布空间传入。

返回值

允许时为 true；未打开、身份不匹配、Tab/Escape 或落在关闭按钮上的输入为 false。

使用时注意

  • 键盘输入还要求存在内容焦点目标；指针输入需要落在面板内。

($&Modal) input

XuAPI
pub fn (m $&Modal) input(event &ui.InputEvent) Action

用途

先处理模态层的关闭和 Tab 焦点循环，再决定是否把输入交给面板内容。

参数

m $&Modal
本次调用使用的 Modal 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
event &ui.InputEvent
同一窗口、画布和代次的输入事件；坐标按控件所在的画布空间传入。

返回值

Action 描述本次交互：kind 是动作类型，consumed 表示事件是否已处理，request_focus 请求焦点，needs_paint 表示需要重绘。

使用时注意

  • 先于背景控件分发；用 allows_content 判断内容输入。退出动画尚未结束时仍阻止背景交互。
