ToastHost

统一呈现短暂通知

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

显示通知，再手动关闭。

使用要点

短暂通知由统一宿主管理。重要错误不应只显示为自动消失的通知，撤销或关闭操作需要可访问。

创建通知队列

ToastHost 是通知队列对象，由应用保存并驱动显示。

#ui/widgets

fn notifications() widgets.ToastHost {
    $host := widgets.toast_host()
    value := widgets.notice(&"Workspace saved")
    host.enqueue(&value) or >>
    << host
}

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。
