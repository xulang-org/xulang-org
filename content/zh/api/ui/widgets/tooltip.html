Tooltip

为锚点补充简短说明

在演练场体验预览 ↗

演练场中的预览用于体验交互，不执行 Xu；原生行为以本页 API 和完整 Xu 示例为准。

体验什么

悬停或聚焦帮助按钮。

使用要点

补充说明而不承载必须执行的操作。鼠标悬停与键盘焦点都应能触达提示，重要信息不能只存在于提示中。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen &mut widgets.Screen) int {
    anchor := screen.button("Preferences") or >>
    screen.place(anchor,24.0,24.0,180.0,40.0) or >>
    id := screen.tooltip(anchor,"Project name") or >>
    << id
}

(&mut Screen) tooltip

XuAPI
pub fn (s &mut Screen) tooltip(anchor int,text string) int

用途

在 Screen 中创建 Tooltip，返回组件节点 ID；创建失败时抛出错误。

参数

s &mut Screen
接收者 &mut Screen（可变借用）
anchor int
anchor（int）
text string
文本（string）

返回

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。

Action · Styles · 界面生命周期与样式指南

Screen.place · Screen.set_enabled · Screen.set_visible
