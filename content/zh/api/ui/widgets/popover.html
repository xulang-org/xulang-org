Popover

在锚点附近展示可操作内容

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

打开偏好设置并应用选择。

使用要点

依附于锚点展示短暂、可交互的内容。明确应用与取消的区别，关闭浮层不应自动提交尚未确认的编辑。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    anchor := screen.button("Preferences") or >>
    screen.place(anchor,24.0,24.0,180.0,40.0) or >>
    id := screen.popover(anchor,"Preferences") or >>
    << id
}

($&Screen) popover

XuAPI
pub fn (s $&Screen) popover(anchor int,text string) int

用途

在 Screen 中创建 Popover，返回组件节点 ID；创建失败时抛出错误。

参数

s $&Screen
本次调用使用的 Screen 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
anchor int
anchor（int）
text string
文本（string）

返回值

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。

Screen.place · Screen.set_enabled · Screen.set_visible

($&Popover) open

XuAPI
pub fn (p $&Popover) open(now time.Instant,reduced_motion bool) int

用途

打开弹出层并启动入场动画；禁用的弹出层保持关闭。

参数

p $&Popover
本次调用使用的 Popover 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
now time.Instant
当前动画时间 time.Instant；打开、更新和关闭应使用同一时间基准。
reduced_motion bool
是否减少动态效果；为 true 时直接到目标状态。

返回值

成功返回 0；失败时抛错，不以非零返回码表示失败。

使用时注意

  • 每帧调用 tick 推进动画，用 is_visible 决定是否继续绘制。

错误处理

  • 动画参数或状态无效时抛错。

pub fn (p $&Popover) close(now time.Instant,reduced_motion bool) int

用途

请求关闭并启动退场动画；逻辑关闭之后可能还需要继续绘制几帧。

参数

p $&Popover
本次调用使用的 Popover 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
now time.Instant
当前动画时间 time.Instant；打开、更新和关闭应使用同一时间基准。
reduced_motion bool

返回值

成功返回 0；失败时抛错，不以非零返回码表示失败。

使用时注意

($&Popover) input

XuAPI
pub fn (p $&Popover) input(event &ui.InputEvent) Action

用途

处理弹出层的外部点击、Escape 和取消输入，按关闭策略更新打开状态。

参数

p $&Popover
本次调用使用的 Popover 实例；以独占借用传入，方法可修改它，调用方仍持有实例。
event &ui.InputEvent
同一窗口、画布和代次的输入事件；坐标按控件所在的画布空间传入。

返回值

Action 描述本次交互：kind 是动作类型，consumed 表示事件是否已处理，request_focus 请求焦点，needs_paint 表示需要重绘。

使用时注意

  • 锚点和面板内部的点击不会作为外部点击关闭；面板内容的业务交互由调用方继续分发。
