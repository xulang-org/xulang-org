FieldArea

为多行文本提供标签与校验

在演练场体验预览 ↗

演练场中的预览用于体验交互，不执行 Xu；原生行为以本页 API 和完整 Xu 示例为准。

体验什么

填写说明并观察字数。

使用要点

通过 text_field_area 创建带装饰的多行字段。设置合理行数与字数提示，错误信息需指出如何修正。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    decoration := widgets.field_decoration(&"Project name")
    id := screen.text_field_area("",&decoration) or >>
    screen.place(id,24.0,24.0,320.0,80.0) or >>
    << id
}

($&Screen) text_field_area

XuAPI
pub fn (s $&Screen) text_field_area(value string,decoration &FieldDecoration) int

用途

在 Screen 中创建 FieldArea，返回组件节点 ID；创建失败时抛出错误。

参数

s $&Screen
接收者 $&Screen（独占借用）
value string
value（string）
decoration &FieldDecoration
decoration（借用，调用方仍持有；类型 &FieldDecoration）

返回

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。
