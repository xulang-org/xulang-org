SplitButton

组合默认操作与备选命令

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

使用默认动作，再展开备选项。

使用要点

使用 Menu 的分离按钮模式。默认命令与展开备选菜单是两个操作，需要分别命名和处理。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    items := [widgets.menu_item(1,"Save"),widgets.menu_item(2,"Export")]
    id := screen.menu("Save",&items,widgets.MENU_SPLIT,1) or >>
    screen.place(id,24.0,24.0,320.0,80.0) or >>
    << id
}

($&Screen) menu

XuAPI
pub fn (s $&Screen) menu(label string,items &[]MenuItem,mode int,primary_key int) int

用途

在 Screen 中创建 Menu / ContextMenu / SplitButton，返回组件节点 ID；创建失败时抛出错误。

参数

s $&Screen
接收者 $&Screen（独占借用）
label string
label（string）
items &[]MenuItem
元素列表（借用，调用方仍持有；类型 &[]MenuItem）
mode int
模式（int）
primary_key int
primary_key（int）

返回

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。
