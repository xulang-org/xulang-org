ButtonGroup

将相关操作或选择组合成一组

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

切换分组按钮，查看当前选项。

使用要点

根据用途选择独立操作、单选或多选模式。选项使用稳定的 key，显示标签变化不应改变其业务身份。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen $&widgets.Screen) int {
    items := [widgets.button_group_item(1,"Save"),widgets.button_group_item(2,"Export")]
    id := screen.button_group(&items,widgets.BUTTON_GROUP_SINGLE) or >>
    screen.place(id,24.0,24.0,320.0,80.0) or >>
    << id
}

($&Screen) button_group

XuAPI
pub fn (s $&Screen) button_group(items &[]ButtonGroupItem,mode int) int

用途

在 Screen 中创建 ButtonGroup，返回组件节点 ID；创建失败时抛出错误。

参数

s $&Screen
接收者 $&Screen（独占借用）
items &[]ButtonGroupItem
元素列表（借用，调用方仍持有；类型 &[]ButtonGroupItem）
mode int
模式（int）

返回

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。

Action · Styles · 界面生命周期与样式指南

Screen.place · Screen.set_enabled · Screen.set_visible
