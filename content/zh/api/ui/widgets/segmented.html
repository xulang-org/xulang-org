Segmented

在少量同级视图间快速切换

在演练场运行 Xu 示例 ↗

示例由浏览器中的 Xu/WASM 运行器执行。

体验什么

切换分段，观察选中项编号。

使用要点

适合少量同级视图或模式。与 Tabs 共用选择逻辑，文案应简短，不要承载过长的选项列表。

通过 Screen 创建

下面的 Screen 构造方法返回节点 ID。将 ID 交给 Screen 的布局、状态与事件接口；它不是下方独立控件类型的实例。

原生 Xu 创建片段：在已有 Screen 的初始化阶段调用 configure；窗口创建、事件循环与资源释放参见完整原生示例。

#ui/widgets

fn configure(screen &mut widgets.Screen) int {
    options := ["Design","Develop","Review"]
    id := screen.segmented(&options,0) or >>
    screen.place(id,24.0,24.0,320.0,80.0) or >>
    << id
}

(&mut Screen) segmented

XuAPI
pub fn (s &mut Screen) segmented(options &[]string,selected int) int

用途

在 Screen 中创建 Segmented，返回组件节点 ID；创建失败时抛出错误。

参数

s &mut Screen
接收者 &mut Screen（可变借用）
options &[]string
options（借用，调用方仍持有；类型 &[]string）
selected int
selected（int）

返回

int — 组件节点 ID，供 place 和其他 Screen 方法使用。

放置、状态与事件

组件由应用拥有。Screen.place 放置节点，Screen.set_enabled 和 Screen.set_visible 管理可用性与显示。状态变化后重新呈现；创建和修改时处理 or 错误，不在绘制回调中修改拓扑。ToastHost 使用自己的队列接口。
