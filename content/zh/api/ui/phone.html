移动界面

#ui/phone 使用 #ui/draw 的帧协议。用 available() 判断移动宿主是否可用，用 platform() 区分 iOS 和 Android。host_insets() 以逻辑单位报告安全区和键盘边距，可直接传给 scaffold_with。

  • Touch 处理点击区域、滚动、侧滑返回及下拉刷新。录制每帧时注册点击区域，再通过 Touch.event 处理宿主事件。
  • RouteStack 保存导航状态。TextField 管理系统输入法会话，选区起止使用 UTF-8 字节偏移。
  • light_theme() 和 dark_theme() 为移动控件提供统一的设计令牌。根据 reduced_motion() 选择动效。

打包应用和配置平台工具链的步骤见移动应用指南。
