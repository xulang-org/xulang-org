FIPS-197 AES 高级加密标准（AES-128 / AES-192 / AES-256）单块加密。多分组与工作模式（CBC / CTR / GCM）见 #crypto/cipher。

模块概述

#crypto/aes 实现了国家标准与工业通用的 AES（Rijndael）对称分组加密算法。支持 128 位、192 位与 256 位密钥长度，底层具备硬件指令自动加速与纯软件无分支查表自适应能力：

  • 密钥与轮数规格：
    • AES-128：密钥长度 16 字节（128 位），10 轮加密。
    • AES-192：密钥长度 24 字节（192 位），12 轮加密。
    • AES-256：密钥长度 32 字节（256 位），14 轮加密。
  • 分组长度：固定为 16 字节（128 位），即 const block_size = 16。
  • 硬件加速：运行时自动嗅探底层 CPU 指令集（x86_64 平台的 AES-NI 或 ARM64 平台的 ARMv8 Cryptography Extensions）。启用硬件加速时，Cipher.hw_accel 为 true，可在不占用 CPU 常规算力的情况下达到线速性能。
  • 工作模式与流扩展：本包专职处理严格的 16 字节底层单块加解密。处理变长明文时，请配合标准库 #crypto/cipher：
    • CBC 模式：支持 PKCS#7 自动填充（cipher.encrypt_cbc_pkcs7 / cipher.decrypt_cbc_pkcs7）。
    • CTR 模式：基于计数器的流加密（cipher.encrypt_ctr / cipher.decrypt_ctr）。

代码示例

1. 单块 AES-128 基础加解密

Xu示例
@main
#crypto/aes

fn main() int {
    // 16 字节密钥（AES-128）
    key := "0123456789abcdef"
    c := aes.new_cipher(&key) or (err) {
        println("初始化失败: " + err.msg())
        << 1
    }

    // 单块明文必须正好 16 字节
    block := "16_bytes_secret!"
    enc := c.encrypt(&block) or (err) {
        println("加密失败: " + err.msg())
        << 1
    }

    dec := c.decrypt(&enc) or (err) {
        println("解密失败: " + err.msg())
        << 1
    }
    assert(dec == block)
    println("单块加解密验证成功")
    << 0
}

2. 搭配 #crypto/cipher 进行变长 AES-CBC + PKCS#7 填充加密

Xu示例

#crypto/aes
#crypto/cipher

fn main() int {
    key := "my-secret-key-16" // 16 字节密钥
    iv := "1234567890123456"  // 16 字节初始向量
    c := aes.new_cipher(&key) or (err) { << 1 }

    // 任意长度的业务数据（自动 PKCS#7 填充并分块加密）
    msg := "Xu systems language provides supersonic native AES encryption."
    enc := cipher.encrypt_cbc_pkcs7(&c, &iv, &msg) or (err) { << 1 }
    dec := cipher.decrypt_cbc_pkcs7(&c, &iv, &enc) or (err) { << 1 }

    assert(dec == msg)
    println("CBC PKCS#7 解密还原成功")
    << 0
}

用途

已初始化的 AES 密码算法实例结构体，包含已编排的轮密钥扩展表、S 盒映射表以及硬件加速特征标识。

rk []int
扩展密钥表（32 位整数格式）。
rk_bytes string
硬件加速轮密钥字节序列。
drk_bytes string
硬件加速逆轮密钥字节序列。

new_cipher

XuAPI
pub fn new_cipher(key &string) Cipher

用途

基于提供的对称密钥创建并初始化 Cipher 实例。根据 key.len 自动选择加密强度：16 字节启用 AES-128，24 字节启用 AES-192，32 字节启用 AES-256。若密钥长度不是 16、24 或 32 字节，则抛出异常（throw "crypto/aes: invalid key size"）。

参数

key &string
密钥字符串借用，长度必须严格等于 16、24 或 32 字节。

返回

Cipher — 已就绪的 AES 加密器实例。

(&Cipher) encrypt

XuAPI
pub fn (c &Cipher) encrypt(src &string) string

用途

加密单个 16 字节分组。若 src.len != 16，抛出异常（throw "crypto/aes: invalid block size"）。若支持硬件加速，则直接调用底层 CPU 向量指令完成；否则执行高度优化的 32 位 Te 查表置换。

参数

c &Cipher
密码器实例借用。
src &string
待加密的单块明文字符串借用，长度必须严格为 16 字节。

返回

string — 16 字节密文结果字符串。
