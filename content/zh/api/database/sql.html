用途

`database/sql` user API over `database/sql/driver`. Open takes a Driver value, not a registry name: Xu has no mutable package global (same constraint as slog.SetDefault), so there is no `Register`. `OpenDB(Connector)` is `open_db`. DriverContext OpenConnector on Driver: iface forward-ref). `prepare_context` on driver.Conn is ConnPrepareContext. The pool matches `sql.DB`: lazy Open/OpenDB, idle list, get/put around Query/Exec/Ping. Query puts the conn back after the driver returns (v1 Rows is a snapshot; holds the conn until Rows.Close for streaming cursors). Tx holds a conn until Commit/Rollback. DB.Prepare does not pin (: release after prepare, re-prepare on the borrowed conn). Idle conns live on a channel because `[]driver.Conn` cannot move an element by runtime index. Open stores Driver+DSN and calls Driver.open ( `dsnConnector` is inlined: a second Connector impl next to the user's would collide sql.Conn is a pool handle (per-op get/put), not a checked-out exclusive box: struct@ cannot live in Conn and return to idle without a dup that aliases the unique box. Close only marks done. `raw` dups a checkout; drop that dup before the next pool op. SetMaxOpenConns(0)=unlimited; default max idle is 2. Lifetime/idle-time expire on get/put (no background cleaner). Idle reuse calls is_valid + reset_session ( Validator SessionResetter). Invalid conns are closed, not returned to idle. Idle queue cap is 64. DB Ping/Exec/Query retry `driver.ErrBadConn` up to 3 attempts ( `maxBadConnRetries` + alwaysNewConn). Args are snapshotted as cloneable wire strings because `temp` cannot be reused. Tx/Stmt do not retry (bound to one conn / one prepare). Exec/Query take `...temp` like (int/string/bool/f64/time.Time/[]u8/NamedArg (`temp` 拒借用); `Rows.next` + `take` returns a local `[]temp` of Values. Prepare is `Conn.Prepare` → `driver.Stmt`. Begin is `Conn.Begin` → `driver.Tx`. Tx holds a dup handle to the same conn (struct@ is move-only; dup shares the driver object). Isolation is the driver's rollback restores the snapshot taken at Begin. QueryRow is -shaped: it does not throw; `Row.take` surfaces ErrNoRows query errors ( `QueryRow` + `Scan`). sql.Rows owns a v1 snapshot from `driver.RowsResult` (not streaming `driver.Rows`); next/take walk flat cells. ColumnType* stubs return "" / ok=false at this layer. Context methods borrow `&context.Context`, check `context.err`, then forward ( `PingContext` &c). BeginTx with non-default isolation/read-only errors like when the driver has no ConnBeginTx. Driver.dup is Xu-only (struct@ is move-only). `Conn` is `sql.Conn` (dedicated pooled handle). Field `dc` is the driver conn so `conn(ctx)` can match `DB.Conn`. Exec/Query args become `[]driver.NamedValue` ( QueryerContext). NamedArg fills Name+Value; others are ordinal-only. Stmt.NumInput ≥ 0 must match argc. Connector.Connect borrows context. `raw` returns a dup of the dedicated driver conn. ColumnType.decimal_size is DecimalSize. 值为 `0`。
