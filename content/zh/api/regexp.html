匹配、查找、分割、展开和替换使用共享工作预算及显式堆栈。调用时须处理错误，例如 matched := re.match_string(&text) or (err) { << 1 }。预算耗尽返回错误，正常未匹配仍返回空值或 false。表达式最多 65,536 字节、64 层分组。quote_meta、num_subexp 与 literal_prefix 不执行匹配。
