逐行读取直到 EOF

使用 bufio 从其持有的内存 io.Buffer 中缓冲读取文本行。

缓冲区移入 reader。read_line 去除 LF 或 CRLF，先返回末尾无换行的数据，耗尽后抛出 EOF；其他错误以状态码 1 退出。

将完整程序保存为 main.xu，在本机运行 xu run main.xu。

@main
#bufio
#io

fn main() int {
    $reader := bufio.new_reader(io.buffer_from("first\nlast"))
    while true {
        line := reader.read_line() or (err) {
            if err.msg() == "EOF" { << 0 }
            println(err.msg())
            << 1
        }
        println(line)
    }
    << 0
}

预期依次输出：first 与 last。
