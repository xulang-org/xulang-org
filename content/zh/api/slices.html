binary_search_ints

XuAPI
pub fn binary_search_ints(xs &[]int, v int) SearchResult

用途

在已升序排列的切片中二分查找，并同时给出命中状态和插入位置。

参数

xs &[]int
待处理的元素切片。
v int
要查找或插入的元素值。

返回值

SearchResult.index 为第一个不小于目标值的位置，范围是 0..xs.len；found 为 true 才能把它当作已存在元素的索引。

使用时注意

  • 调用前必须按相同规则升序排列；未找到时不返回 -1，空切片得到 index = 0、found = false。

调用示例

查找重复值和不存在的值

Xu本机 SDK 示例
@main
#slices

fn main() {
    values := [1, 3, 3, 7]
    hit := slices.binary_search_ints(&values, 3)
    println(hit.index)
    println(hit.found)
    absent := slices.binary_search_ints(&values, 4)
    println(absent.index)
    println(absent.found)
}

预期输出：

1
true
3
false
