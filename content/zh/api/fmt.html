sprintf

XuAPI
pub fn sprintf(f string, args <-> Arg) string

用途

按格式串组装字符串。支持标志 - + # 0 与空格、宽度、精度（* 会再吃一个 int Arg）。动词含 %v %s %d %b %o %x %X %c %q %f %g 以及 %%。未写精度的 %f/%g/%v 用最短十进制。

参数

f string
格式串（支持 %- + # 0 宽 精度，与本包实现一致）
args <-> Arg

返回
