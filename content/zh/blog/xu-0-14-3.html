Xu 0.14.3 发布 · 二进制格式全平台加固、128-bit SLP 自动向量化与 121 项工作负载跨语言横测

2026-11-27 · Xu v0.14.3

Xu 0.14.3 正式发布！本版本汇集 0.14.2–0.14.3 两个里程碑的核心工程成果：在语言前端确立 >> 抛错与 >>> / >>> (err) {} 接错语法及跨函数多错误恢复；在编译优化层落地 128-bit SLP 自动向量化、Ext-TSP 布局、相关跳跃线程化、SwissTable core/map 与 Phase 5–7 通用 MIR/后端优化；在目标格式层完成 Windows PE32+、Linux ELF、macOS Mach-O 与 WASM 全平台安全加固；同时大幅拓展 #core 裸机/UEFI 原语、#sync/pool 多核 M:N 调度、#tensor/llm_engine、#ui/widgets 与 xu doctor/#ui/phone。全版本已通过六大目标平台自举不动点与 121 项标准工作负载（覆盖 11 大工程领域）跨语言基准横测。

有关 0.14.3 之前的编译器和运行时改进，见 Xu 0.14.2 发布说明。新增 API 的用法见 AI 研发指南、操作系统研发指南和 #sync/pool 参考。

1. 语言语法定型与跨声明多错误恢复

  • 错误处理语义清晰分界：全面统一编译器、CLI 工具链、标准库、官网与测试集——>> expr 用于显式抛出错误，expr >>> 与 expr >>> (err) { ... } 用于错误传播与接住处理，并在解析器中消歧三重泛型闭合 >>>。
  • 跨声明多错误检查与借用恢复：检查器支持跨声明与跨函数持续收集诊断（单轮上限 MAX_DIAG_ERRORS = 25），通过 ERROR_TY / fn_failed() 抑制单函数内级联误报，配套回归套件 scripts/test_checker_multi_error.py。

2. 全平台二进制格式标准化与安全加固

  • Windows PE32+ (windows-arm64 / windows-x64)：严格分离 W^X 节权限（.text RX、.rdata R、.data RW），发射 .reloc 基址重定位、PE Load Config / Security Cookie（IMAGE_GUARD_CF_INSTRUMENTED / _load_config_used）与 .pdata/.xdata 系统栈展开表。
  • Linux ELF32/ELF64 (linux-x64 / linux-arm64 / linux-riscv64 / linux-loongarch64 / linux-riscv32)：默认开启严格 W^X、ET_DYN PIE、Full RELRO（DF_BIND_NOW）、.note.gnu.build-id、Intel CET IBT（endbr64）、CFI 栈展开帧与完整节头表。
  • macOS Mach-O (macos-arm64 / macos-x64)：新增 __DATA_CONST 只读数据段、LC_UUID、LC_BUILD_VERSION，并在发布/调试全模式下内建原生 LC_CODE_SIGNATURE Ad-hoc 代码签名，开箱直接运行；同步加固 COFF/ELF/Mach-O .xuobj 转换与 WASM 产物。

3. 编译器优化、SwissTable 运行时与 M:N 多核调度

  • 128-bit SLP 自动向量化与 CFG 重排（0.14.2）：引入块内 SLP 自动向量化（opt_slp，XU_NO_SLP=1 可关闭），将同构数组访存/算术树与 4 路关联整数归约打包为 ARM64 NEON 与 x86-64 SSE2 向量指令；引入 Wu–Larus + Ext-TSP 基本块布局（opt_cfg）、相关跳跃线程化（opt_jump_thread）、寄存器空洞复用与常量重物化。
  • Phase 5–7 通用优化与代码生成对齐（0.14.3）：新增单调用点内联、单块与递减计数循环展开、面向 div/mod/受护减法的非负 GVN 值域传播、规范偏移标量提升、冷调用常量外提、ARM64 CCMP/CCMN 与移位加常量乘法、以及 x86-64 mul_const/imul/madd 对齐。
  • SwissTable core/map 与 M:N 多核协程调度：core/map 升级为 8 槽 SWAR CTRL_LANE_MUL 分组探测（7/8 负载因子）；新增线程安全堆/FFI 锁、Linux/macOS M:N 多核协程调度器（#sync/pool）及硬件 u8/u16/u32/u64 原子原语，并修复 resize_zero 堆清零与 net/poller 唤醒调度。

4. 裸机、UEFI、AI/Tensor、UI 与工程体系升级

  • 操作系统与 UEFI 原语：新增 @interrupt、@weak、@naked、@section/@align/@export、extern static、usize/isize、紧缩/联合/位域 C 结构体、sizeof/alignof/offsetof、严格 --no-sse、--stack-size、可重定位 DWARF、x64-uefi 与 arm64-uefi、多架构参数化内联汇编，以及 #core/{acpi,addr,ds,elf,fdt,fmt,mmio,pci,uefi}、VirtIO 1.0 Modern MMIO、HPET 与 UEFI MemMap。
  • AI / Tensor 与配套生态：扩展 #tensor 与 examples/llm_engine，支持 Q4_K/Q6_K/Q4_1/Q5_1/Q2_K/Q3_K/Q5_0 内核、M=12 GEMM、分页 SIMD 注意力、--threads N 多线程推理、训练反向算子、GBNF Trie/Schema 与 mmproj.gguf VLM；配套 github.com/xulang-org/packages 同步演进至 v1.17.0（50 个包，含 llm_metal、cuda_native、vulkan_native、统一 gpu 外观与 Redis 分布式网关状态）。
  • UI、诊断与发布策略：升级 #ui/widgets 第 12–14 轮能力（响应式布局、样式类、FLIP 动画、拖拽、虚拟列表、表单、检查器等），加固 xu doctor 与 #ui/phone P0–P3 移动运行时，确立每轮发布强制选用上一正式版作为自举种子的长期策略。
