Xu 0.10.1

2026-10-23 · 正式发布

Xu 0.10.1 将当前开发成果纳入正式 SDK：保留式桌面 UI 与样式控件、Thumb-2 代码生成、密码学修复、有界并发 HTTP 接收、正则工作预算、JSON 数字检查转换与 DEFLATE 压缩。

下载 SDK 与校验摘要

桌面 UI

绘图支持帧记录、DisplayList、路径、文字和图片资源；保留 View 提供布局、输入路由、焦点与重绘边界。编辑控件使用原生文字会话、选区、光标与输入法几何。菜单、屏幕、剪贴板、对话框及 WebView 查询统一使用异步请求生命周期。

新增 Switch、Radio、Slider、Stepper、Tabs、Select、Badge、Divider、Card 与 ListBox 样式控件。统一 Styles API 覆盖字体、密度、状态规则、阴影、图标几何及深色、浅色、高对比调色板；StyleSwitcher 将预设和缩放应用到保留 View。详见 UI 指南及正式版控件 API。

编译器与标准库

Thumb-2 加入虚拟寄存器分配、紧凑 T16 编码与分支跳转调整；编译器同时修正拥有型参数处理和 32 位降级。密码学修正包括 RSA 盲化失败时拒绝继续、JWT 认证头校验、TLS 证书与签名兼容性，以及 GMTLS CBC 认证计算。

HTTP 接收对不完整请求进行轮询，并限制连接、缓冲区与超时，完整请求并发派发；响应会重试短写。正则执行使用显式堆栈与共享工作预算。DEFLATE 使用有界 LZ77 匹配、固定 Huffman 编码及不可压缩数据回退。JSON as_int 与 as_f64 传播转换错误，旧数字访问器仍保留零值回退。

迁移要求

  • 处理正则匹配、查找、分割、展开和替换的错误。预算耗尽返回错误，正常未匹配仍返回空值或 false；表达式最多 65,536 字节、64 层分组。详见正则 API。
  • HTTP 处理器可以并发执行，共享可变状态须同步；使用 server_options() 和 serve_with_options 配置限额。详见 HTTP API。
  • Draw 画布默认固定；需要相机平移时显式调用 draw.set_pan_enabled(1)。
  • 保留布局后、提交绘制前调用 widgets.place_editor 同步原生文字几何。原生 UI 仍需对应宿主工具链和平台库。

验证与范围

编译器身份与 VERSION、构建来源记录一同检查，产品自举须达到确认的固定点。发布 CI 验证 SDK 打包与宿主安装。横测页面记录实际编译器提交、六个平台、输出核验与测量日期。目标生成及 API 可用不代表所有运行时能力均已完成验收或认证，具体边界见限制与现状。

历史 0.11.0-dev.3 预览版继续单独保留。官网选定的正式版本为 0.10.1，正式 API 与演练场从该发行 SDK 生成。
