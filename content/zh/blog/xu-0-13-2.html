Xu 0.13.2 发布 · HTTP 缓冲区、套接字调度与文件 I/O

2026-11-22 · Xu v0.13.2

Xu 0.13.2 改进了 HTTP 请求经常经过的网络与文件路径，也调整了协作式调度器在没有可运行任务时等待套接字的方式。

HTTP 与文件读写

HTTP 服务端限制待处理请求缓冲区的增长。客户端限制接收缓冲区的增长，并随数据到达逐步解码分块响应。静态文件处理可以根据元数据响应 HEAD，处理字节范围请求时只读取所需范围。

DirFS 复用已有缓冲区容量。整文件读取会先确认是否到达文件末尾，再决定是否扩容。Windows 目录枚举无论成功还是失败都会释放搜索缓冲区。

运行时与字符串

当可运行队列为空时，调度器在一次轮询中等待多个套接字。本版还减少了哈希表内存占用，并复用 AES 初始化表。ARM64 和 x64 可以按机器字扫描较短的字节序列，前缀和后缀判断增加了单字节路径。分割结果的切片扩容后，各片段依然独立拥有其字节。

升级 SDK

请一起升级编译器、标准库和 SDK 工具。Linux、macOS 和 Windows 的 ARM64 与 x86-64 SDK 已通过原生安装和执行检查。Linux LoongArch64 与 RISC-V SDK 通过交叉构建提供。
