Xu 0.10.5：源码调试、原生安装与编译器修复

2026-10-25 · 正式发布 · SDK 附件与 SHA-256 摘要

Xu 0.10.5 已提供 macOS ARM64/x64、Linux ARM64/x64/LoongArch64/RISC-V 64，以及 Windows x64/ARM64 的发行包。官网 API 与浏览器 Playground 使用同一份正式 SDK。发行标签指向 2a635a6。

相对 0.10.2 的更新

  • 源码调试：xu debug 构建带 DWARF 信息的程序并启动 LLDB 或 GDB，支持源码/函数断点、调用栈与局部变量查看，以及批处理模式。需在宿主系统安装调试器。
  • 编译器与标准库：扩展结构体 SSA 提升与 Tile 规划，加入低比特查找表和流水线 API；修正 Map、字符串、编码、flag 与密码学代码；加入 ARM32 整数/ABI 和 STM32F4 开发板支持。
  • 安装与更新：原生 Setup 安装器、自动识别 SDK 位置、Windows 当前用户/所有用户范围，以及标准库下载、解包与进度反馈。xu up 与 xu update 继续互为别名。
  • 编辑器诊断：LSP 发布诊断时保留文档 URI；编译器版本横幅去掉原有的 “self-hosted” 后缀。

迁移：常量使用大写命名

常量声明及引用统一使用 UPPER_SNAKE_CASE。将 const max = 100 改为 const MAX = 100，并同步修改引用，包括导入的标准库常量。函数、变量和字段继续使用 snake_case。

@main
const MAX = 100
fn main() int {
    println(MAX)
    << 0
}

编译器、配套工具与标准库源码应来自同一份 SDK，升级时不要仅用新编译器覆盖旧源码目录。参见各平台下载与安装说明。

发行验证

发布构建通过宿主自举固定点验证（Gen2 = Gen3），完成全部 8 个平台的 SDK 打包，并通过 macOS ARM64 SDK 与原生安装器的安装验收。Windows 宿主构建/检查和完整产品交付工作流也已通过。下载所选归档旁的 SHA256SUMS 核对内容。

目标代码生成支持不代表每个库都已完成所有目标机的运行验收；剩余边界见限制与现状。基准页面继续保留各次测量实际使用的编译器版本。

配套示例修正

0.10.5 最初打包的部分 UI、WebSocket 和 DNS 示例仍使用旧的小写导入常量。修正后的官方示例已通过全部 54 个官网引用示例的编译检查。使用该修正版源码时仍可保留 0.10.5 编译器；SQLite 示例须按其说明先构建原生桥接库。
