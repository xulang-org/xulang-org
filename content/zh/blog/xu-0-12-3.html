Xu 0.12.3：MIR 优化恢复、硬件指令加速、GPU 通道与窗口事件

2026-11-13 · Xu v0.12.3

Xu 0.12.3 恢复了带类型 MIR 的编译器内联、尾调用递归与周期循环折叠，为密码学核心算法引入硬件指令加速，并在标准库中加入 GPU 渲染与计算通道及窗口输入事件。升级时请一起更新编译器、标准库和 SDK 工具。

编译器与运行时优化

恢复带类型 MIR 的内联、整数尾递归和周期循环折叠。字符串重复只分配一次输出缓冲区。支持的平台使用原生指令加速 AES、ARM64 SHA-256、位运算和十六进制编解码。Linux 和 macOS 的多个 I/O 等待者共享每轮空闲轮询。

正确性与安全边界

修复变量初始化和重新绑定时的隐式只读借用，恢复原生链接和资源清理，并限制 DEFLATE 压缩输出缓冲区的增长。增加显式字节序的 binary32/binary64 存储和位转换，以及供编译器工具使用的 WASI 宿主。

GPU 与窗口基础架构

标准库增加 GPU 渲染与计算通道、经过校验的非拥有资源引用、窗口呈现表面和逐窗口输入事件。原生 GPU 支持取决于平台后端。

下载与校验

请下载完整 SDK，核对 SHA256SUMS 校验摘要，并查看 GitHub 上的完整版本说明。
