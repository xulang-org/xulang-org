核心编译器代码生成修复

在复杂数学计算与递归场景中，Xu 0.9.3 彻底修复了自递归多参数寄存器分配的底层冲突缺陷：

  • 自递归多参数寄存器保护：此前，当自递归调用作为二元表达式右操作数（如 << n * fact(n - 1)）或在多参数自递归函数（如阿克曼函数 ack(m, n)、尾递归累加器 helper(n, acc)）中，后端寄存器分配器未排查前序已分配参数位置，导致后序参数在入口将前序参数值覆盖在同一个非易失寄存器（ARM64 x19/x20，x64 RBX/R12）中。修复后，每个标量参数均获得唯一独立的寄存器槽位，多参数深层递归与复杂嵌套表达式计算完全正确。
  • 未定义符号诊断健壮性增强：修复当调用未声明或拼写错误的函数符号时，类型检查器在输出错误后因未阻断执行继续索引 c.fns[-1] 导致编译器内部越界崩溃（index out of bounds）的缺陷，规范为干净的编译期诊断。

全语法覆盖与极端场景回归验证

本次版本伴随 8 大类极限语法与并发场景的全量矩阵回归：

  • 类型安全与所有权：编译期严格拦截常量数组越界、除零保护、双重可变借用（&mut）冲突与 move 后再次使用。
  • 高级语法特性：全面验证柯里化闭包、泛型结构体（struct Box#T）、结构体 RAII 析构（drop()）、多参数泛型实例化与错误自动传播。
  • 高并发与通道通信：全面压测无缓冲通道汇合（chan int{cap: 0}）、带缓冲流水线、带 close() 通道消费及 100 协程高压并发求和，在 macOS 与 Linux 干净容器中表现出零偏差的一致性。

安装与迁移

推荐使用免提权单文件 Setup 安装器快速安装：

  • macOS / Linux 一键在线安装：curl -fsSL https://xulang.org/install.sh | bash
  • Windows PowerShell 一键在线安装：irm https://xulang.org/install.ps1 | iex
  • 单文件 Setup：直接运行 ./xu-setup-<target> -y（Windows 下双击 xu-setup-windows-x64.exe 弹出图形向导），自动注册系统全局环境变量。

在工程 xu.xun 中声明：

module: myapp
version: !ver 0.1.0
xu: !ver 0.9.3

运行 xu --version 确认当前编译器版本为 0.9.3。
