Xu 0.13.1 发布：标准库全面加固与零桩审计、网络体系升级与 Cond/WSAPoll 精确唤醒

2026-11-20 · Xu v0.13.1

Xu 0.13.1 是一个聚焦于标准库全面工程化加固与生产级网络、并发、系统调用能力的重要版本。本轮更新彻底完成了全模块零桩（Zero-Stub）审计，重构了条件变量登记通知模型，大幅增强了网络套接字与 HTTP/HTTPS 协议栈能力，并补全了跨平台进程双向管道与系统信号处理。

标准库零桩审计与完整性加固

  • compress/zstd：修正帧头内容尺寸编码与解析，严格校验最后一个数据块完整性以拦截截断输入，并通过 bsdtar libzstd 外部参考实现跨格式校验。
  • sync.Cond：重构条件变量登记唤醒机制。采用有序队列追踪等待协程，实现单通知（signal()）严格仅唤醒单个等待者、广播（broadcast()）唤醒全部等待者（验证覆盖 4097 个协程并发），彻底消除无等待者时的假通知泄漏。
  • os/exec：实现 Windows 与 Unix 跨平台标准流双向管道（stdin_pipe、stdout_pipe、stderr_pipe），在 Windows 平台正确配置句柄继承标志，并在进程启动失败时自动回收泄漏句柄。
  • os/signal：接入操作系统原生控制台信号捕获（Windows 基于 SRWLock+Event 实现，Unix 接入内核信号挂钩），严格校验信号编号有效性并在参数异常时完整保留通知通道所有权。
  • time：消除 Windows 平台硬编码时区偏移，支持通过环境变量 $env:ZONEINFO 动态加载并解析外部 IANA TZif 时区数据库。
  • crypto/cipher 与 encoding/json：增加 AES-CFB 与 AES-OFB 流密码加解密模式；JSON 解析器缓冲区动态扩容至 64 MiB，新增 parse_max 支持大文本解析。

网络协议栈与 I/O 多路复用升级

  • HTTPS 连接复用与连接池：net/http 客户端支持基于 Host/SNI 及 TLS 配置维度的连接复用与生命周期池化，遵循 Connection: close 自动淘汰失效连接，提供 close_idle_connections() 手动释放接口，并实现安全的幂等重试。
  • Windows 原生 WSAPoll 批量就绪检测：网络轮询器 net/poller 消除死循环轮询与休眠开销，底层直接复用 EventSet 机制，Windows 原生对接 WSAPoll 实现微秒级零延迟批量事件分发。
  • HTTP/2 HPACK 哈夫曼解码：net/http2 完整实现 RFC 7541 规范的 HPACK 响应头哈夫曼解码器（decode_huffman），支持解析主流 HTTP/2 服务端返回的压缩响应头。
  • 原生 SOCK_RAW 与 IPv6 数据报：net 模块接入原生底层原始套接字创建（dial_ip、listen_ip、listen_packet），支持指定协议号的数据包监听与分发，并扩展 IPv6 UDP 数据报。

WebAssembly 与移动端支持

  • WebAssembly 顶层导出：新增 --wasm-export 编译器标志，允许向 WebAssembly 宿主环境直接导出顶层函数供 JavaScript 调用。
  • ARM64 移动端游戏链接：在 iOS 与 Android 应用原生归档中补齐 C 桥接与静态库链接支持。

升级完整 SDK

六个主流平台（Linux x64/arm64、macOS arm64/x64、Windows x64/arm64）的原生产品级 SDK 均已通过完整自举不动点校验、运行时协议测试与标准库零桩回归套件，现已正式发布。
