Xu 0.12.4 发布移动应用生成和新的 MIR 优化

2026-11-15 · Xu v0.12.4

Xu 0.12.4 新增 xu build --phone 和 #ui/phone，并扩展类型化 MIR 优化及 ARM64、x64 机器码生成。

生成 iOS 或 Android 项目

编译器将 ARM64 原生应用目标文件和 iOS 或 Android 宿主一起放入生成的项目。应用运行原生代码，将 Draw 帧交给本地 Canvas 绘制。移动控件支持安全区、路由、系统输入法文本编辑、触觉反馈与剪贴板。入门请看移动应用指南和 #ui/phone API。

已验证 iOS 真机、ARM64 iOS 模拟器和 ARM64 Android 的项目生成和目标文件格式。签名、真机行为及应用商店提交需要相应的平台工具链和独立验收。

类型化 MIR 与代码生成

全局值编号消除重复计算，循环不变量外提将可移动的工作移出循环，循环边界检查消除和存储到加载转发覆盖更多循环形式。ARM64 和 x64 改进了常量除法、条件选择、整数循环移位和浮点平方根的代码生成。可用 XU_DUMP_MIR 查看优化后的 MIR，并在横测看板查看实测负载。

升级完整 SDK

请一同升级编译器、标准库和工具。完整 SDK 包含 xu-phone、项目模板和原生宿主源码。安装和卸载脚本统一使用 ASCII 文本。Linux、macOS 和 Windows 的 ARM64 与 x64 原生 SDK 已通过安装和运行验收。
