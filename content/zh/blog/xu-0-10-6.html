Xu 0.10.6：修正 SDK 示例并加强安装验收

2026-10-26 · 补丁发布 · 完整 SDK 下载与校验摘要

Xu 0.10.6 将修正后的官方示例与编译器、工具和标准库一起打包。请从下载页升级完整 SDK。本补丁版接续 0.10.5，保留其源码调试、原生安装器及编译器和标准库改进。

修复内容

标准库迁移到 UPPER_SNAKE_CASE 后，0.10.5 最初发行包的部分示例仍使用旧的小写导入常量，导致 UI、WebSocket 和 DNS 示例无法通过 SDK 自带编译器的检查。0.10.6 固定使用修正后的示例源码，包括共享 UI 辅助模块。

安装验收现在直接检查实际的绘图、控件与样式展厅示例；发行包含 packages 模块时，还会检查 WebSocket 与 DNS 示例，覆盖解包、安装后的导入常量兼容性。新增检查可复现并拦截原始 0.10.5 发行包的问题。

修复离线解压超时

Intel macOS 安装验收还暴露了多块 DEFLATE 与多文件 TAR 解包中的重复大块复制。0.10.6 改为复用 DEFLATE 输出缓冲区，并直接读取 TAR 归档中的当前条目，避免每个压缩块或文件都复制已有数据。解压格式、校验和与错误边界保持一致；超时诊断也会保留安装器已输出的信息。

完整发行包还会包含已构建的 VS Code/Cursor 插件 VSIX，插件版本保持独立的 0.3.0，可从 SDK 的 editors/vscode/ 目录离线安装。

升级与迁移

xu update --version 0.10.6
xu --version

也可下载适合本机的归档或原生 Setup 安装器。编译器、配套工具与标准库清单统一使用 0.10.6。常量声明和导入引用使用 UPPER_SNAKE_CASE；函数、变量和字段继续使用 snake_case。

官网引用的整套修正示例已通过编译检查。SQLite 示例还需构建其说明中的原生桥接库；交互式 UI 和外部服务示例需要对应宿主依赖或运行中的服务。具体边界见限制与现状。

原有 0.10.5 标签与已发布附件保持原样。请将新 0.10.6 归档与同版本的 SHA256SUMS 配套使用；历史基准结果继续保留实际测量时的编译器版本。
