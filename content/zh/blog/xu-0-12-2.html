Xu 0.12.2：类型化 MIR、默认优化和六平台 SDK

2026-11-11 · Xu v0.12.2

编译器将类型检查后的程序降低为类型化 MIR，并可用已发布的 0.12.2-seed.1 种子编译器完成自举。升级时请一起更新编译器、标准库和 SDK 工具。

优化参数迁移

xu build、xu run 和 xu test 默认开启优化。请从脚本中删除 -O1 至 -O3，并用 --no-opt 替换 -O0。

xu build main.xu -o app
xu run main.xu --no-opt
xu test test.example.xu --no-opt

SDK、包和工具

Linux、macOS 和 Windows 的 ARM64 与 x64 原生 SDK 已通过验收，Linux LoongArch64 与 RISC-V SDK 由交叉构建提供。Windows ARM64 可生成原生可执行文件和 COFF 对象，Linux ARM64 和 x64 支持桌面打包。xu get 和 xu install 可解析固定版本依赖。支持的原生程序可通过 --xacp 和 --xacp-port 启用启动发现和控制。

WebAssembly 程序可用 --target wasm32-wasi 构建并交给 WASI 运行时。浏览器演练场使用固定的 Xu {{playground_version}} SDK 构建解释器。

下载和横测

请下载完整 SDK，核对 SHA256SUMS，并查看完整版本说明。

横测看板已导入实测工作流在六个平台上运行的 72 项负载。横测重建了已合入 main 的编译器，其源码树与正式版标签一致。各项结果对应各自的负载和运行环境。
