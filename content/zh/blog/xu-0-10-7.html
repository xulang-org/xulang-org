Xu 0.10.7：修复 SDK 覆盖重装与旧版升级

2026-10-26 · Xu v0.10.7

Xu 0.10.7 修复了已有 SDK 无法可靠覆盖重装的问题。旧版逐文件复制遇到只读标准库时可能中断，留下新旧文件混合；本版本会准备完整的新目录，核验全部文件和十个工具，再替换 SDK，并保留原目录备份。替换或校验失败时会恢复原安装。

安装与更新

请使用下载页上的安装命令升级或修复。在线脚本会优先选择 PATH 中已有 SDK，也可显式指定安装目录；Bash、PowerShell、原生 Setup 和 macOS PKG 使用相同的完整替换流程。SDK 管理范围以外的用户数据会保留。备份路径会显示在安装输出中。

更新器现在同时刷新编译器、工具、标准库、packages、示例和编辑器文件。安装 0.10.7 后，xu update --force 可以重新下载当前版本并修复完整 SDK。若目标父目录不可写，安装会在替换前报错；请使用可写目录或相应管理员权限。

旧版更新器兼容

编译器保留规范版本行，并增加旧更新器需要的兼容版本行，使 0.10.2 能正确识别新版本。经历过失败安装的用户请优先重新运行完整安装命令。安装说明包含目录、环境配置和验证命令。

CI 构建与发布

全部平台的发行包由 CI 构建并验证。构建和执行安装器的作业只有仓库读取权限；独立发布作业校验产物清单后，使用 GitHub 临时令牌上传同一批文件。发布作业不执行 SDK 或依赖。已发布的历史标签和附件不覆盖。
