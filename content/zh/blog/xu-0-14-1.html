Xu 0.14.1 发布 · 纯 Xu 本地 LLM 推理、P4K4/分页注意力融合内核与全平台编译器提速

2026-11-25 · Xu v0.14.1

Xu 0.14.1 正式发布！继 0.14.0 确立裸机与操作系统内核开发能力之后，0.14.1 在 纯 Xu 本地 AI 推理、MIR 张量融合与通用优化器、密码学/TLS/短字符串运行时 以及 macOS 签名体验 上实现全面推进。本版本已通过六大目标平台原生 SDK 验收与 72 项标准工作负载的跨语言基准横测（0 失败）。

1. 纯 Xu 本地 LLM 推理引擎（examples/llm_engine/main.xu）

examples/llm_engine/main.xu 展示了在不引入外部推理运行时的情况下，仅用 Xu 即可完成端到端语言模型加载与生成：

  • 流式 GGUF 加载与内部 P4K4 权重打包：支持 F32 Safetensors 以及兼容的 Llama / Qwen2 架构 GGUF v2/v3 模型；在流式读取过程中将 Q4_0 和 Q8_0 权重转换为内部 P4K4 布局，匹配分组矩阵向量乘（GEMV4）与 M=12 矩阵乘（GEMM）内核，不改变磁盘 GGUF 文件格式；
  • 分页 KV 缓存与连续批处理：内置分页 Key/Value 缓存与基于协程的连续批处理调度器，支持批量预填充（Prefill）和自回归逐 Token 解码；
  • 标准库零 ABI 破坏新增原语：在保持核心运行时 ABI 冻结的前提下，新增 slice.reserve(n int)、slice.resize_zero(n int) 与 math.float16_to_f32(h int) f32，服务高性能张量缓冲区与半精度解码。

2. 可选 MIR 张量融合与分页注意力内核

通过 XU_TENSOR_FUSION=1（以及允许浮点重排/乘加融合的 XU_TENSOR_FAST_MATH=1），编译器可在优化后的原生 ARM64 与 x64 构建中自动识别常规 Xu 数值循环：

  • 分页注意力端到端融合：识别分页注意力打分（__xu_tensor_attn_scores_paged*）、缩放 Softmax（__xu_tensor_softmax_scaled*）与 Value 加权累加（__xu_tensor_attn_vsum_paged*），按目标平台自动选择标量或 ARM64 NEON/DotProd、x86-64 SSE 内核；
  • 量化打包与矩阵内核：覆盖 Q4_0 / Q8_0 量化与反量化、RMSNorm、RoPE、SwiGLU、argmax 及 P4K4/signed 分组矩阵乘。

3. 通用编译器优化、标准库与 macOS 签名

  • 中端优化与代码生成：新增循环常量外提（opt_hoist_loop_consts）、切片描述符与元素缓冲区不相交性证明、循环展开与指针强度折减、跨直接调用的 GVN 副作用分析、blk_noreturn 冷块活跃性剪枝与寄存器合并，以及 ARM64 FMADD/FMSUB/TST 与 x64 TEST 融合指令；
  • 运行时与标准库加速：短字符串操作采用更快的路径；X25519 与 Montgomery big.exp 算术显著提速；TLS 1.3 支持更多握手组合；JSON 解析器补充节点数量上限校验；
  • macOS 签名完备性：macOS SDK 二进制与独立离线安装器默认附带 Ad-hoc 签名，CLI 亦会为 Apple Silicon 本机 xu run 与 xu test 产生的临时可执行文件自动签名。
