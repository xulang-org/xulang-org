Xu 0.10.11：共享重借用、XACP 与原生组件整合

2026-10-28 · Xu v0.10.11

Xu 0.10.11 整合了已验证的开发分支与 0.10.10 原生组件基线，包含共享重借用检查、XACP 帧传输与 Screen 编组、Windows UI 边界修复、WASM 冒烟检查，以及 SDK 安装和更新的终端进度显示。

共享重借用与迁移

可写局部引用可以传给目标类型相同的共享引用参数。同一次调用中，共享重借用与可写父引用不能同时形成别名，参数顺序不影响诊断。请拆分操作，或在修改前结束共享借用。此规则不包含容器递归转换，也不对任意普通值自动重借用。

原生组件与 XACP

本版保留原生密码输入和指针单调时钟修复。继承的组件基线包含 Chart、RangeSlider、SplitView 和结构化菜单等公共 API，服务于随 SDK 提供的组件工作坊。XACP 客户端须使用帧化控制传输和匹配的伙伴仓库示例。

SDK 打包输入固定到完整伙伴仓库提交，并运行编译器、原生 UI、WASM 与安装后 SDK 检查。各平台二进制可用性以发行附件为准；交叉构建不等同于原生 GUI 验收。

安装与后续版本

请通过下载页一起升级编译器、标准库和工具。详细变更见0.10.11 版本文档；当前正式版及新的可变标记写法见0.10.12 发布说明。
