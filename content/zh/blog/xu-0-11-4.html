Xu 0.11.4：有界尾调用、字节处理与 XUN 正确性修复

2026-11-06 · Xu v0.11.4

Xu 0.11.4 改善符合条件的递归与字节处理代码，并修复 XUN 解析、序列化边界。请一起升级编译器、标准库和产品工具。

编译器与字符串操作

符合条件的 ARM64 整数／布尔兄弟调用会先恢复当前栈帧和保存寄存器，再执行尾跳转。递归结果只参与一次 wrapping 加法的纯标量自递归可转换为累加器循环。算术检查、有界只读字节扫描、部分字符串操作和已证明恰为八轮的 CRC 循环可使用对应优化路径；涉及所有权、地址、ABI、调试或插桩限制时，仍保留普通实现。

XUN 兼容性

duration 校验持续推进输入位置；根以下的容器嵌套最多为 64 层。多行解析在验证必要结构缩进后保留正文空白。带类型列表会验证继承的标量类型，并在序列化往返中保留容器和元素标签。

迁移：带类型列表的序列化拼写可能变化，但解析后的值保持一致。请更新依赖原始文本的快照；若文本拼写不是契约的一部分，可比较解析树。旧的非空 !s[...] 标量输入仍被接受。详见 XUN API。

实验性 ESP32 源码

固定 profile 的 Wi-Fi/BLE 共存与 CYD 状态应用以实验源码形式提供。主机局域网返回 EHOSTUNREACH 后，最终完整 MTU 的外部 ICMP 应答验收仍待完成。本次 SDK 发布不代表板级应用已通过生产验收，也不分发已烧录固件。

当前 profile 支持 WPA2-PSK/CCMP 和单个 legacy SMP Just Works peer。DHCP 续租／重新绑定、Group Rekey、DNS/TCP、SoftAP、WPA3/PMF，以及 BLE 连接期间的 Wi-Fi 重连均未实现。Just Works 不提供 MITM 防护或 LE Secure Connections。更换网络须联合重启。

下载与验证范围

原生验收覆盖 macOS、Linux、Windows 的 ARM64/x64；LoongArch64 和 RISC-V SDK 通过交叉构建提供。请从下载页获取完整 SDK，并核对 SHA256SUMS。完整变更与限制见发布说明。
