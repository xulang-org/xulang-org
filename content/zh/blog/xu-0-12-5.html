Xu 0.12.5 发布：纯 Xu SDL 后端、无宿主字体栈与 SoftBlob 内存安全模型

2026-11-17 · Xu v0.12.5

Xu 0.12.5 带来针对图形渲染、游戏引擎集成与无头回放测试的重磅架构升级，移除外部 C 驱动垫片，实现纯 Xu 编写的 SDL 后端与动态 FFI，构建无宿主独立字体解析与字形图集，并全面强化零 GC 内存安全保证。

纯 Xu SDL 后端与原生 FFI

标准库 #internal/sdl 全面转向纯 Xu 编写，配合重构的 ffi 原生调用框架，动态绑定 SDL 动态库，彻底废弃了以往的外部 C 胶水驱动代码。新增 Windows Win64 调用约定支持、c_callback 回调机制以及平台标量映射（Windows LLP64 c_long/c_ulong 宽度对齐），显著简化跨平台桌面与游戏运行时的打包与依赖链。

无宿主字体栈与无头渲染回放

新增官方独立包 #ui/font，提供纯 Xu 实现的 TTF 解析器、字形度量、字形图集（Glyph Atlas）与文本排版引擎，摆脱对系统字体服务或原生宿主字形 API 的依赖。配合 Frame.export_xdf() 与 phone.Canvas.export_xdf()，可将全部 UI 与渲染指令序列化为封印的 XDF1 二进制缓冲区，支持无头模拟器与跨进程回放，大幅加速游戏引擎与 XACP 协议的自动化验证。

SoftBlob 内存安全模型与图形增强

在 #gpu 模块中引入 SoftBlob 与 SoftBlobRef 结构，为 CPU 网格（mesh）与纹理数据提供带边界检查的内存切片视图，从根本上杜绝动态 FFI 与跨层通信时的指针越界与悬垂引用。同时，Window.present_rgba 提供了软件位图呈现接口，Event.touch_id 和多点触控输入队列使跨平台游戏与触控交互更加精准。

零 GC 编译器与生命周期强化

编译器全面完善了引用所有权模型：严格追踪闭包环境、接口盒子（interface boxes）、临时通道与通道元素的所有者；数组明确作为推入引用的持有者；针对条件分支移动的局部变量引入运行时 drop flags，避免双重释放或泄漏；Map 统一赋予安全深拷贝语义，确保在零垃圾回收器前提下拥有稳健的运行时一致性。

升级完整 SDK

六个主流平台（Linux x64/arm64、macOS arm64/x64、Windows x64/arm64）的原生产品级 SDK 与安装程序均已完成多层严格验证并正式发布。
