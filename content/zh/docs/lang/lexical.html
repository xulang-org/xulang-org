词法

扩展名 .xu，UTF-8。注释 // 与 /* */。无分号。标识符 [A-Za-z_][A-Za-z0-9_]*。

风格强制：类型 PascalCase；函数/变量/字段/const 为 snake_case。可见性用 pub，不用首字母大小写当导出。

关键字包括：fn struct enum const mut temp let if else match for while in as is or true false int bool string f64 i32 u32 u8 byte pub xu chan select map。没有 interface / import / return / break / continue。

字面量：42、0xFF、0b1010、1_000_000、3.14、"hi"、反引号多行串、[1, 2, 3]。
