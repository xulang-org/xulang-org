标准库边界

内核只保留无法用库表达或与编译器深度耦合的部分：println / args / read_file / xu_target_os 等。标准库走所有权模型。

标准库在 src/ 下，没有 std. 前缀。导入：#fmt、#net/http、#crypto/sm2、#ui/webview。

明确拒绝：unsafe、reflect、用户可见的 runtime 指针、任意 syscall 地址。中国商密算法（SM2/SM3/SM4/SM9/ZUC/GMTLS）是 Xu 附加包：纯 Xu 实现，非商密认证。

LANGUAGE.md §9 表格覆盖 104 个包。另外 src 里还有 11 个包未进该表，本站 API 一并收录：crypto/rand、crypto/tls、crypto/x509/pkix、io/fs、net/http/cookiejar、net/http/httptest、net/netip、os/exec、os/signal、os/user、testing/fstest。
