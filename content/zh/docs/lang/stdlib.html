标准库与扩展包边界

内核保留与编译器耦合的操作，包括 println、args、read_file、xu_target_os。公开标准库源码在 src/，不使用 std 前缀：#fmt、#net/http、#crypto/sm2、#ui/webview。

标准库已包含流式 I/O 与明确的读写进度契约、进程管道、HTTP/2、网络池、timer/rate 工具，以及 SQL 连接池和事务接口。生成的 API 页列出实际公开声明；存在 API 不代表所有目标平台支持范围相同。

具体服务驱动位于独立的 packages 模块。MySQL 使用 mysql #github.com/xulang-org/packages/mysql 导入，并在 require: 声明根模块；database/sql 仍属于标准库。SQLite 使用原生 C 桥接。

语言不开放 unsafe、reflect、任意 runtime 指针或任意 syscall 地址。SM2/SM3/SM4/SM9/ZUC/GMTLS 包使用 Xu 实现，不代表已经取得商用密码认证。

图形与窗口层面，#gpu 与 #gpu/layout 提供了无窗口 GPU 设备抽象、统一缓冲区/纹理传输、着色器与图形/计算管线录制以及精确回读；#window 与纯 Xu 事件包 #window/events 提供了原生窗口生命周期与按窗口输入事件队列（键盘、指针、滚轮与文本/IME 输入法）。底层原生驱动依托宿主平台（如 SDL 3.2+ 或 Metal/Vulkan/D3D12），无需在应用层编写 C 绑定代码。#encoding/binary 则提供了跨平台大端/小端显式编码与 binary32/binary64 浮点数存取。见 #gpu API 与 #window API。

#xacp 是 src/xacp 中与传输无关的安全核心：帧上限、权限、会话生命周期和 UI 适配器检查。导入它不会打开 stdio 或 TCP。这些钩子只在 hosted native 可执行程序使用 --xacp 或 --xacp-port 构建时插入。该包已包含在正式 {{xu_version}} SDK 提取结果与生成目录中。原生会话和 UI 运行验收仍待验。见 #xacp API 与命令行参考。
