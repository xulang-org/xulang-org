标准库与扩展包边界

内核保留与编译器耦合的操作，包括 println、args、read_file、xu_target_os。公开标准库源码在 src/，不使用 std 前缀：#fmt、#net/http、#crypto/sm2、#ui/webview。

标准库已包含流式 I/O 与明确的读写进度契约、进程管道、HTTP/2、网络池、timer/rate 工具，以及 SQL 连接池和事务接口。生成的 API 页列出实际公开声明；存在 API 不代表所有目标平台支持范围相同。

具体服务驱动位于独立的 packages 模块。MySQL 使用 mysql #github.com/xulang-org/packages/mysql 导入，并在 require: 声明根模块；database/sql 仍属于标准库。SQLite 使用原生 C 桥接。

语言不开放 unsafe、reflect、任意 runtime 指针或任意 syscall 地址。SM2/SM3/SM4/SM9/ZUC/GMTLS 包使用 Xu 实现，不代表已经取得商用密码认证。
