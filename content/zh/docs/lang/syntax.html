语法定稿

表面语法已定：>>/or、#path、控制流符号、struct@ / 名字#。语言面没有 Result / Ok / Err / ?。

主题定稿不做
错误>> expr + or (err) {}；or >> 是重抛糖用户代码 Result / 双返回值
控制流出口<< 返回、<<< 退出、-> continue、<- breakreturn / break / continue / exit 关键字
import行首 #errors、#xu/ast；别名 json #encoding/jsonimport "…"
整数int = i64；i32/u32/u8/byte 独立类型，无隐式拓宽，算术 wrap同槽别名
字符串双引号是主字面量单引号字符串

any / temp 是运行时盒子；# / @ / struct@ 是编译期分流。无约束写裸 名字# / 名字@，不要写 名字# any。
