Xu 是一门无 GC 的系统语言。三句话定调：

目标对语言面的要求
极速编译与部署静态 AOT、单文件可执行、交叉编译一等公民、包尽量简单
无 GC 的内存与线程安全所有权 + 借用；作用域结束确定性 drop。冲突在编译期拒绝。优化不得把未证明的越界/除零变成静默 UB
极简易读默认不可变、无分号、条件/循环无括号、控制流出口是符号、错误强制且不啰嗦、无全局可变状态

写起来轻；跑起来像系统语言一样可控；安全边界尽量在编译期关闭。

明确不做或后置

  • 完整动态 OOP / 开放世界反射（与 AOT 单二进制冲突）
  • 以 JIT 峰值吞吐为第一目标
  • 为了语法糖牺牲所有权可检查性
  • 用户可见的 Result / Ok / Err / ?
