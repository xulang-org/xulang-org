内存模型

Xu 采用所有权推断与确定性的作用域清理，不使用垃圾收集器。每个 owning 值同一时刻只有一个所有者；借用提供临时访问权，不转移所有权。这些规则不等于证明外部代码或原生宿主资源不会泄漏。

下列示例均使用官方 SDK v0.10.12 检查。每个代码块单独保存为一个 .xu 文件；完整程序使用 xu check，仅含函数的示例使用 xu check --lib。下列诊断均为实际编译器输出的子串。含 fn main 的程序可运行；文件示例须用本机 SDK。

Move：使用新的所有者

赋值、按值传参、返回值、写入 owning 槽都会转移 owning 值。Move 后应使用目标绑定；只有 API 明确提供复制操作时才进行克隆。

@main

fn main() int {
    text := "owned"
    next := text
    println(next)
    << 0
}

预期 xu check：通过。 xu run 输出（逐行）：owned.

@main

fn bad() {
    text := "owned"
    next := text
    println(text)
    println(next)
}

预期 xu check --lib：失败，诊断包含 use of moved value 'text'.

共享：读取时不改变所有者

共享引用可以共存。共享借用存活期间，不能修改、move 或独占借用所有者。借用可以在最后一次使用后结束，不必等到外层作用域结束：下例的赋值位于两次读取之后。

@main

fn main() int {
    $value := 1
    first := &value
    second := &value
    println(*first + *second)
    value = 2
    println(value)
    << 0
}

预期 xu check：通过。 xu run 输出（逐行）：2 / 2.

@main

fn bad() {
    $value := 1
    view := &value
    value = 2
    println(*view)
}

预期 xu check --lib：失败，诊断包含 cannot assign to 'value' because it is borrowed.

独占：同一时刻只有一个写者

用 $value 声明可写所有者，再取 $&value。独占借用存活期间排斥对所有者的其他访问。写者最后一次使用后可以再共享读取；两个重叠的写者会被拒绝。

@main

fn main() int {
    $value := 1
    writer := $&value
    *writer = 2
    println(*writer)
    view := &value
    println(*view)
    << 0
}

预期 xu check：通过。 xu run 输出（逐行）：2 / 2.

@main

fn bad() {
    $value := 1
    first := $&value
    second := $&value
    println(*first)
    println(*second)
}

预期 xu check --lib：失败，诊断包含 cannot borrow 'value' as mutable because it is also borrowed.

作用域释放：所有者结束，借用不能逃逸

普通 owned 值离开作用域时释放，正常返回也会清理；move 会转移清理责任。os.File 等带编译器管理 drop 钩子的资源类型会兜底关闭资源。若需要观察关闭错误，应显式调用 File.close()；兜底清理会忽略关闭错误。

仅限本机 SDK。 此程序会在当前目录创建 scope-release.txt。write_once 通过借用写文件，本地文件所有者在函数返回时清理。

@main

#os
fn write_once() int {
    file := os.create("scope-release.txt") or >>
    file.write("scope") or >>
    << 0
}
fn main() int {
    write_once() or (err) {
        println(err.msg())
        << 1
    }
    println("scope ended")
    << 0
}

预期 xu check：通过。 xu run 输出（逐行）：scope ended.

返回引用必须关联某个借用输入，不能指向返回时结束的局部值；即使函数另有一个引用参数，也不能返回该局部值的引用。

@main

fn dangling(seed &int) &int {
    value := 1
    << &value
}

预期 xu check --lib：失败，诊断包含 cannot return a reference to local data.

原生句柄：遵守显式 dispose 契约

Xu 值的作用域清理不能替代所有原生资源 API。例如，调用方不再需要 ui/draw.Surface 时必须显式 dispose，包括错误与取消路径。已接受的帧在 dispose 后仍持有不可变像素；释放调用方句柄不会抹去已接受的帧。

原生集成片段，无浏览器运行按钮。 对宿主提供的有效 surface，应传播 dispose 错误。Dispose 会更新句柄，因此此辅助函数需要独占访问。

@main

#ui/draw
fn retire(surface $&draw.Surface) int {
    << surface.dispose() or >>
}

预期 xu check --lib：通过。

共享引用不能调用这个可写方法：

@main

#ui/draw
fn retire(surface &draw.Surface) int {
    << surface.dispose() or >>
}

预期 xu check --lib：失败，诊断包含 through a shared reference.

漏掉 dispose 不一定编译失败：xu check 不是原生泄漏检测器。待验： 此辅助函数已做类型检查，但尚未在真实原生渲染器上运行分配与释放，也未实跑错误 / 取消清理路径。

宿主调度器的协程栈与信道元数据另有进程级生命周期策略；离开作用域不代表所有运行时分配立即回收。FFI 调用方还须遵守各外部 API 的所有权契约。
