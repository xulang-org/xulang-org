函数与表达式

fn add(a int, b int) int {
    << a + b
}

fn (c $&Counter) inc() {
    c.n += 1
}

可变参写末位 name <-> T，体内是 []T。错误不要多返回值，走 >> + or。

运算符：表达式里 << >> 仍是移位；写成语句才是返回/抛错。布尔或用 ||；or 只接错误。除零运行时 fail-loud。索引越界同样 fail-loud。

泛型类型参数

函数名后的 # 声明类型参数，调用时根据实参单态化。0.9.4 移除了泛型声明最多 4 个类型参数的限制，例如：

fn fifth#A,B,C,D,E(a A, b B, c C, d D, e E) E {
    << e
}

// fifth(1, true, 3.0, "four", 5) 返回 5

方法集约束与动态盒用法见泛型教程。
