EBNF

当前语法浓缩（用于对照，不是 parser 逐字表）：

Xu 核心语法 EBNF 规范定义
文法规则 (Rule) 语法产生式结构 (Definition) 语义与说明
File "@" PackagePath { CompileTag } { Import } { Decl } . 源码文件根结构，以包路径声明开头
Import [ Ident ] "#" Path . 模块导入；外部路径必须使用别名（写在 # 前）
ReturnStmt "<<" [ Expr ] . 函数返回值返回语句
ThrowStmt ">>" Expr . 抛出错误或异常向上传播
ExitStmt "<<<" Expr . 进程退出并返回状态码
BreakStmt "<-" . 跳出当前循环
ContinueStmt "->" . 跳至下一次循环迭代
RangeOp ":" . 半开区间运算符 [start, end)
XuStmt "xu" QualifiedName "(" [ Args ] ")" . 启动轻量级协程并发调用
Expr … | Expr "or" "(" Ident ")" Block | Expr "or" ">>" . 表达式、安全错误解包与向上传播
点击展开原始 EBNF 纯文本文法 
File         = "@" PackagePath { CompileTag } { Import } { Decl } .
Import       = [ Ident ] "#" Path  .
ReturnStmt   = "<<" [ Expr ] .
ThrowStmt    = ">>" Expr .
ExitStmt     = "<<<" Expr .
BreakStmt    = "<-" .
ContinueStmt = "->" .
RangeOp      = ":" . // [start, end)
XuStmt       = "xu" QualifiedName "(" [ Args ] ")" .
Expr         = … | Expr "or" "(" Ident ")" Block | Expr "or" ">>" .

PackagePath 使用斜杠路径，域名身份可用引号包围；域名中的点保留。导入别名写在 # 前，外部路径必须有别名。
