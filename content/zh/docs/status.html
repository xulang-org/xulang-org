官网与对应 SDK 版本：Xu {{xu_version}}。Xu 仍处于 0.x 阶段，已发布产物以 GitHub Releases 为准。

子系统状态支持范围与边界
内存与资源已实现单所有者、共享/独占借用、move 检查与确定性 drop；File/Conn 资源在作用域退出时自动关闭。
安全边界设计约束不开放 unsafe、reflect 和用户可见的裸 runtime 指针；越界索引与除零明确失败。
原生 AOT 与 WASM按目标验证支持 macOS arm64/x64、Linux arm64/x64/loongarch64/riscv64/arm32、Windows x64/arm64、WebAssembly (wasm32) 及 Thumb/RISC-V 裸机目标；生成支持不代表全部库均通过目标机运行验收。
模块依赖已实现，保留边界斜杠路径身份、显式 file/Git/tar 来源、SemVer 最低要求与 MVS、XUPROXY/私有路径绕过、内容锁、vendor 快照、离线/冻结构建与进程锁。
独立校验日志客户端已实现0.8.4 新增固定公钥 XUSUMDB 校验与 XUNOSUMDB 策略；公共 Xu 服务和独立见证仍待发布，未配置或 off 时保持首次使用信任。
网络与 I/O平台差异Unix 支持 TCP/UDP IPv4/IPv6 与 Unix 域套接字；原生 epoll/kqueue/IOCP Socket 就绪等待；已提供流式 I/O 和明确进度结果。Windows TCP dial/listen 仍未支持，raw IP 与 TLS 另有平台边界。
SQL 与扩展包独立模块database/sql 提供连接池、事务和驱动契约；SDK 内 packages 模块 1.0.0 提供 29 个服务集成包及共享 transport，MySQL/PostgreSQL 使用协议驱动，SQLite 使用原生 C 资源。
密码学按包说明包含 SM2/SM3/SM4/SM9/ZUC/GMTLS 的 Xu 实现；API 可用不代表已取得商用密码认证。
桌面 GUI需宿主工具链桌面打包已有 macOS .app、Windows .exe、Linux ELF 路径；提供人体工学 Screen 屏幕上下文抽象与统一样式控件；须有 GTK4/WebKitGTK 或 WebView2 及匹配工具链，并在目标机验证。
共享库导出基础类型签名--shared 支持 int、bool、string、f64、i32、u32、u8；原生 .a/.xulib 依赖有独立资源边界。
Map 容器已实现支持 int/string 键；缺键直接索引明确失败，需要允许缺键时使用存在性检查或库 API。
XACP 控制通道API 已发布；运行待验#xacp 已包含在正式 {{xu_version}} SDK 提取结果中。hosted native 启动控制使用 --xacp / --xacp-port，stdio 与 127.0.0.1 TCP 均采用 XACP/1 长度前缀。宿主未设置令牌时 hello 至多授予 INFO；宿主令牌匹配后可请求 PERM_ALL 的子集。proc.status 提供 pid 响应；输出/UI 操作需要相应权限和适配器。启动控制不注册 Screen。UI 附着需要注册和轮询，并有请求期限；调用方仍需进程/I/O 超时。没有 TLS 或非回环绑定；Windows 启动器 record 不可用。原生会话、UI 控制、截图和各平台运行验收仍待验。导入包不会安装控制通道。
工具与编辑器完全实现提供开箱即用原生 Setup 离线安装向导（支持 Windows/macOS/Linux 全局环境变量自动配置）；优先可执行文件探测标准库消除全局环境劫持；build/run/check/test/debug/install/get/fmt/map/doc/doctor/lsp 可用；up/update 支持直接下载官方二进制 Release 自更新；VS Code 扩展提供语法高亮与基于原生 xu-lsp 的完整语言服务（跳转定义、补全、悬停、实时诊断、大纲、重命名与引用）。

近期进展与待完成项

0.10.7 修复完整 SDK 覆盖重装，并让安装器与更新器共用校验、备份和失败恢复流程。见补丁说明。

0.10.6 将修正后的官方示例装入完整 SDK，并在安装后检查 UI、WebSocket 与 DNS 示例，修复 0.10.5 的导入常量迁移遗漏。升级与验证范围见修正版说明。

0.10.5 加入 xu debug 源码调试、编译器与标准库修复，以及保留文档 URI 的 LSP 诊断；提供原生安装器和标准库更新进度。常量迁移为 UPPER_SNAKE_CASE，包括导入的标准库常量；函数、变量与字段保持 snake_case。详见发布与迁移说明。

0.10.2 修复编译器与工具链自感知，消除全局环境劫持；带来原生非阻塞 Socket 就绪等待（epoll / kqueue / IOCP）、RFC1951 DEFLATE 压缩与人体工学 UI Screen 抽象。详见发布说明。

0.10.1 加入样式控件与统一主题切换、桌面异步请求及 Thumb-2 寄存器分配，并修复密码学、HTTP 请求接收、正则工作预算、JSON 数字转换与 DEFLATE 压缩。迁移：处理正则匹配、查找、分割和替换调用的错误；对并发 HTTP 处理器共享的可变状态进行同步；画布平移须显式启用。详见发布与迁移说明。

0.9.4 补齐借用检查的表达式遍历与循环回边活跃性，移除泛型声明最多 4 个类型参数的限制，并加入逐 pass MIR 验证、MIR 导出与后端模式命中统计；ARM64 循环内核使用 SSA 匹配与循环旋转。诊断用法见命令行参考。

迁移注意：此前依赖借用检查遗漏才能编译的程序，现在会收到诊断。请分离冲突借用，或在取得共享借用前结束可变使用。

模块依赖继续支持传递依赖、离线/冻结构建、MVS、代理和固定公钥校验客户端；提供原生 Setup 单文件离线安装程序与 WebAssembly 演练场。官网 API 从对应正式 SDK 提取，收录 {{api_standard_count}} 个标准库/UI 包（包含 #xacp）与 {{api_external_count}} 个扩展包，计数依据生成清单。47 项横测的实测版本、日期与六平台来源见基准页面。

仍待继续：公共 Xu 代理/校验服务、独立见证、vanity 仓库发现、目标平台的完整运行验收、共享文件系统锁与断电持久性。现有目标生成能力和 API 声明不替代这些验收。
