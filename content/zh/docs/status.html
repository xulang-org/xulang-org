限制与现状 (Status & Limitations)

XU v0.1.0 官方诚实清单 · 明确技术实现边界与演进路线

XU 坚持工程透明与诚实原则。以下清单详细记录了 v0.1.0 当前的技术完备状态、已知边界限制及设计约束。

核心子系统完备状态矩阵

子系统模块 当前状态 现状描述与支持边界 后续计划
内存与所有权 完备稳定 无 GC 暂停。单所有者模型、&T 共享借用、&mut T 独占借用，作用域退出时确定性 drop 析构。 长期语法冻结锁定
语言安全边界 设计约束 语言核心无 unsafe、无 reflect、无裸指针暴露，杜绝隐式内存越界与未定义行为。 核心安全原则保持不变
AOT 交叉编译 完备稳定 支持 macOS (arm64/x64)、Linux (arm64/x64/loongarch64/riscv64)、Windows (x64/arm64) 一键单文件原生产物。 持续优化机器码体积
网络与套接字 (Net/IO) 平台差异 Unix (macOS / Linux) 完整支持 IPv4 TCP、UDP、HTTP 与文件服务；Windows 平台 TCP dial/listen 当前返回占位错误。 v0.2.0 补齐 WinSock 原生后端
数据库 (Database) 纯 XU + 外部模块 database/sql 提供驱动契约；PostgreSQL 与 MySQL/MariaDB 是纯 Xu 协议包。 SQLite 等嵌入式驱动由外部 require: 模块提供。
国密与密码学 纯 XU 原生 SM2 / SM3 / SM4 / SM9 / ZUC / GMTLS 纯 XU 语言自研实现，高性能且零外部依赖；尚未取得商用密码认证。 持续进行软硬件加速与对标
桌面 GUI 引擎 macOS 支持 xu build --desktop 在 macOS 可直接产出 .app 原生包（集成 #ui/webview 与 #ui/draw）；Windows/Linux 报未实现。 完善 Linux GTK 与 Windows WebView2
共享库 FFI 导出 支持基础类型 --shared 动态库导出支持类型：int、bool、string、f64、i32、u32、u8。 支持结构体与切片跨语言导出
Map 字典容器 确定性设计 键目前支持 int 与 string；缺键索引采用 Fail-Loud 机制快速防御，安全无静默未定义值。 后续扩展自定义 Hashable 结构体键
开发工具与语言服务 规划开发中 xu build / xu run / xu check / xu fmt / xu doc 完备；xu doc --serve 可本地预览 XUDOCS；LSP（语言服务器）暂未开放。 语言服务集成于 VS Code 插件中

升级与版本维护

运行 xu up 会打印当前编译器版本与可用通道更新指引。详细升级日志请参考 官方博客 与 GitHub 发行记录。
