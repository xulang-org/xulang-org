VS Code / Cursor

扩展只做语法高亮（TextMate 文法 + 括号/注释）。不含语言服务器，也不在 Marketplace 发布。诊断请用 xu check。

对齐词法：控制流关键字、struct enum chan map any、mut pub const、以及符号语句 << >> <<< -> <-。不是关键字：interface import return break continue Ok Err。

在独立 vscode 仓库根目录执行 npm ci 和 npm run package 打包 VSIX，再用 Cursor/VS Code 的 Install from VSIX。然后 Reload Window。可把 *.xu 关联到 xu。不要依赖符号链接。

MIT。

独立的 vscode 仓库 当前扩展版本为 0.2.7，与 Xu 0.8.4 分别管理。hosted 产品编译器的 xu lsp 仍未实现，扩展中的配置项不代表已经提供语言服务器。
