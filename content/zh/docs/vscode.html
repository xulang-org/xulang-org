VS Code / Cursor 编辑器支持

官方 VS Code & Cursor 插件 · 基于自举语言服务协议 (xu lsp) · 语法高亮 · 实时诊断 · 智能补全 · 跳转定义与当前文件重命名

为了给开发者提供流畅、现代化的编码体验，Xu 官方在独立仓库 vscode-xu 中维护了官方编辑器扩展，原生深度兼容 Visual Studio Code 与 Cursor IDE。扩展由高精度的 TextMate 语法高亮文法与基于 Xu 编译器原生自举的语言服务协议（Language Server Protocol / LSP）双轮驱动。

1. 核心语言服务能力矩阵

基于编译器内置的 xu lsp（伴生工具 xu-lsp），扩展在编辑器中提供以下语言服务；查询与编辑范围见各项说明：

功能特性 快捷键 (macOS / Win) 能力与技术细节说明
精细语法高亮 实时高亮 基于官方词法规范定制的 TextMate 文法，精准着色控制流、所有权与类型（$、struct、chan 等）及特有符号语句（<<、>>、<<<、->、<-）。
实时语法与类型诊断 编辑时波浪线 在后台实时执行静态类型检查与所有权借用验证，在代码行内直接标红语法错误与类型推导不匹配，告别盲目调试。
跨文件跳转定义 F12 / Cmd+Click 支持结构体、函数、全局常量、方法及接口实现的瞬间穿透跳转，甚至可无缝跳转至标准库（Stdlib）源代码定义位置。
文档与类型签名悬停 鼠标悬停 (Hover) 悬停在任意变量、结构体字段或函数调用上，立即浮现其准确类型签名、可变性标记（$）以及 Markdown 格式注释文档。
智能上下文补全 Ctrl+Space 补全建议主要来自关键字、内置函数与当前文件声明。成员链和外部包的语义补全能力有限。
查找所有引用 Shift+F12 按标识符文本匹配当前文件及同目录的其他 .xu 文件；结果可能包含同名但无关的符号。
当前文件符号重命名 F2 仅为当前文件生成编辑，按标识符文本匹配。请检查编辑预览中的同名符号，并另行更新其他文件。
代码大纲与面包屑 Cmd+Shift+O / Ctrl+Shift+O 按层级快速罗列当前文件中的所有结构体定义、枚举以及函数符号，支持拼音或英文模糊搜索秒级定位。
保存时自动格式化 Cmd+S / Ctrl+S 保存文件时自动调用产品级 xu fmt 工具，严格规范缩进、括号布局与操作符两端留白，保持团队代码风格 100% 统一。

2. 插件安装方式

方式 A：从官方 VSIX 离线包安装（推荐）

解压 Xu {{xu_version}} SDK 后，进入其 editors/vscode/ 目录，使用其中的 xu-language-0.3.0.vsix。插件版本独立于编译器版本，可通过终端或 IDE 界面安装：

# 通过 VS Code 命令行一键安装
code --install-extension xu-language-0.3.0.vsix

# 或者通过 Cursor 命令行安装
cursor --install-extension xu-language-0.3.0.vsix

或者在 VS Code / Cursor 的扩展面板中，点击右上角 ... 菜单，选择 Install from VSIX...，选取下载好的 .vsix 文件后执行 Reload Window 即可。

方式 B：从源码本地打包构建

若希望参与插件开发或体验仓库最新提交特性，可自行拉取仓库并打包：

# 克隆官方插件仓库
git clone https://github.com/xulang-org/vscode-xu.git
cd vscode-xu

# 安装依赖并打包为 VSIX 安装包
npm ci
npm run package

# 安装刚刚生成的 VSIX
code --install-extension xu-language-*.vsix

3. 推荐编辑器配置 (settings.json)

在 VS Code 或 Cursor 中按下 Cmd+Shift+P（macOS）或 Ctrl+Shift+P（Windows/Linux），输入 Preferences: Open User Settings (JSON)，添加以下推荐配置项：

{
  // 指定 Xu 编译器二进制路径（若已加入系统 PATH，填写 "xu" 即可）
  "xu.languageServerPath": "xu",

  // 语言服务器调试日志级别（开发插件时可设为 "messages" 或 "verbose"）
  "xu.trace.server": "off",

  // Xu 语言专用编辑器配置
  "[xu]": {
    "editor.defaultFormatter": "xu-lang.xu-language",
    "editor.formatOnSave": true,
    "editor.tabSize": 4,
    "editor.insertSpaces": true,
    "editor.suggestOnTriggerCharacters": true,
    "editor.quickSuggestions": {
      "other": true,
      "comments": false,
      "strings": true
    }
  }
}
