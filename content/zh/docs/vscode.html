VS Code / Cursor

扩展提供语法高亮（TextMate 文法 + 括号/注释）及语言服务支持（基于产品编译器内置的 xu lsp）。在独立 vscode-xu 仓库 维护。

对齐词法：控制流关键字、struct enum chan map any、mut pub const、以及符号语句 << >> <<< -> <-。不是关键字：interface import return break continue Ok Err。

在独立 vscode-xu 仓库根目录执行 npm ci 和 npm run package 打包 VSIX，再用 Cursor/VS Code 的 Install from VSIX 安装，然后 Reload Window。可把 *.xu 关联到 xu。

语言服务能力：Xu 原生自举支持 xu lsp（伴生工具 xu-lsp），提供实时语法与类型诊断、格式化、跨文件/标准库跳转（F12）、Markdown 文档悬停、大纲（Cmd+Shift+O）、智能补全、查找所有引用（Shift+F12）与重命名重构（F2）。在编辑器的 settings.json 中配置 "xu.languageServerPath": "xu" 即可。

MIT 协议。独立的 vscode-xu 仓库 与 Xu 主版本分别独立管理。
