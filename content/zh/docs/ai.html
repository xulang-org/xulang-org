编译并运行示例

examples/llm_engine/main.xu 是零外部运行库依赖的纯 Xu Transformer 推理引擎，原生支持 Safetensors 与 GGUF v3（F32、F16、BF16、FP8 E4M3、Q4_0、Q8_0 及重排 p4k4 权重）。引擎通过 #tensor 管理紧凑混合精度权重与低精度分页 KV 缓存（--kv-dtype f32|f16|bf16|fp8_e4m3fn），突破 2048 隐藏维度上限，支持 GPT-2 字节映射与 tokenizer.ggml.merges BPE 分词合并，并内置基于 #net/http 的 OpenAI 兼容并发推理服务器。

XU_TENSOR_FUSION=1 XU_TENSOR_FAST_MATH=1 ./bin/xu build examples/llm_engine/main.xu -o llm_engine

# 使用 FP8 KV 缓存验证连续批处理与单请求数学一致性
./llm_engine verify model.gguf --kv-dtype fp8_e4m3fn

# 带 BPE 合并、Top-P 核采样与重复惩罚的文本生成
./llm_engine generate model.gguf "Hi Paris" 64 700 40 \
  --kv-dtype f16 --top-p 900 --repeat-penalty 1100 --seed 42

# 启动 OpenAI 兼容 HTTP 服务（/health、/v1/models、/v1/completions、/v1/chat/completions、/v1/embeddings）
# 支持 SSE 流式输出（"stream": true）与自定义停止词（"stop"）
./llm_engine serve model.gguf 127.0.0.1:8080 --kv-dtype bf16

常用命令行参数：

  • --ctx <N> —— 限制并配置最大上下文序列长度。
  • --kv-dtype <f32|f16|bf16|fp8_e4m3fn|fp8_e5m2|fp8_e4m3fnuz|fp8_e5m2fnuz> —— 指定分页 KV 缓存存储精度（将 KV 显存/内存压缩为 1/2 或 1/4）。
  • --top-p <milli>、--repeat-penalty <milli>、--seed <int> —— 可复现核采样阈值与重复惩罚系数（1000 表示 1.0）。
  • --ignore-eos —— 忽略 eos_token_id 停止标记以运行定长吞吐基准测试。

#tensor 模块与数值原语

标准库 #tensor 提供安全的纯 Xu 低精度标量编码、跨步视图、GGML 量化块与 src/tensor/ops.xu 中的 20 个通用数值算子：

层次公开 API职责
标量编码 F16、BF16、Fp8E4M3Fn、Fp8E5M2、Fp8E4M3Fnuz、Fp8E5M2Fnuz、DType 位精确 IEEE/OCP FP16、BF16 与四种 FP8 互转，及运行时 dtype_named 解析
视图与量化块 TensorView、MatrixView、Q4Block、Q8Block、read_q4_0、read_q8_0 零拷贝行列切片形状视图与带边界检查的 GGML 32 元素量化块解码
向量与相似度 dot_f32、axpy_f32、vadd_f32、vsub_f32、vmul_f32、vscale_f32、l2_normalize_f32、cosine_similarity_f32、argmax_f32 带偏移点积、FMA 累加、逐元素运算、L2 归一化、余弦相似度与最大值索引
Transformer 与量化 silu_f32、gelu_f32、rmsnorm_f32、layernorm_f32、softmax_f32、swiglu_f32、rope_f32、matvec_f32、matmul_f32、quantize_q8_0、quantize_q4_0_row 激活函数、RMSNorm/LayerNorm、Softmax、NeoX RoPE、GEMV/GEMM 与 Q8_0/Q4_0 行量化 
@main
#tensor

fn run_block(w &[]f32, x &[]f32) []f32 {
    n := x.len
    $normed := []f32{}
    $out := []f32{}
    for _ in 0:n {
        normed.push(f32(0))
        out.push(f32(0))
    }
    tensor.rmsnorm_f32($&normed, x, w, n, 0.00001)
    tensor.vscale_f32($&normed, f32(0.5), n)
    tensor.softmax_f32($&normed, n, f32(1))
    tensor.vmul_f32($&out, &normed, x, n)
    << out
}

编译选项与 MIR 张量融合

在 XU_TENSOR_FUSION=1 编译模式下，编译器 MIR 张量降级通道会直接识别 #tensor 与用户代码中的规范纯 Xu 数值循环，在保持冻结运行时 ABI 不变的前提下下沉为原生 ARM64 NEON / SDOT 与 x86-64 SSE2 / AVX2 机器码内核：

算子类别MIR 运行时内核符号目标指令集加速
向量算子 __xu_tensor_dot_f32、__xu_tensor_axpy_f32、__xu_tensor_vadd_inplace_f32、__xu_tensor_vmul_f32 ARM64 NEON fmul.4s/fmla.4s；x64 SSE2 mulps/addps
归一化与激活 __xu_tensor_add_sqsum_f32、__xu_tensor_norm_f32、__xu_tensor_swiglu_f32、__xu_tensor_softmax_scaled_f32 向量化平方和与指数规约流水线
矩阵与量化乘加 __xu_tensor_gemv4_f32、__xu_tensor_gemm4x4_f32、__xu_tensor_gemv4_q4_0_p4k4_signed_f16_q8_0_f32、__xu_tensor_gemm4x8_q8_0_p4k4_f16_q8_0_f32 4×8 分块微内核与 ARM64 sdot.4s / x64 FMA
分页注意力与 RoPE __xu_tensor_rope_f32、__xu_tensor_attn_scores_paged_f32、__xu_tensor_attn_vsum_paged_f32 覆盖 head_dim % 4 == 0（含 64、128、40 等）与双架构
  • XU_TENSOR_FUSION=1 —— 开启 MIR 张量模式匹配与硬件内核降级（fusion-strict 保持与纯 Xu 基线逐比特一致）。
  • XU_TENSOR_FAST_MATH=1 —— 启用重结合浮点规约、快速指数逼近与高吞吐量化展开。

基于 packages/metal 的 GPU 算力

在 Apple Silicon 平台上，官方外部包 packages/metal 提供显式 binary32 矩阵内存管理（F32Matrix）、MPS 矩阵乘法及编译期 Metal 计算着色器，通过非阻塞栅栏（Fence）同步并结合编译期借用检查与运行时形状/别名/设备守卫：

@main
metal #"github.com/xulang-org/packages/metal"
#errors

fn gpu_ffn_step(d &metal.Device, x &metal.F32Matrix, w &metal.F32Matrix,
                w_gate &metal.F32Matrix, w_up &metal.F32Matrix) metal.F32Matrix {
    $normed := d.matrix_f32(x.rows(), x.columns()) >>>
    f_rms := metal.rmsnorm_f32($&normed, x, w, 0.00001) >>>
    _ := f_rms.wait() >>>

    $g := d.matrix_f32(x.rows(), w_gate.rows()) >>>
    $u := d.matrix_f32(x.rows(), w_up.rows()) >>>
    f_g := metal.gemm_f32_nt($&g, &normed, w_gate) >>>
    f_u := metal.gemm_f32_nt($&u, &normed, w_up) >>>
    _ := f_g.wait() >>>
    _ := f_u.wait() >>>

    $out := d.matrix_f32(x.rows(), w_gate.rows()) >>>
    f_sw := metal.swiglu_f32($&out, &g, &u) >>>
    _ := f_sw.wait() >>>
    << out
}

metal/matrix_f32.xu 当前公开的完整 Transformer GPU AI 算子包括：gemm_f32（$A B$）、gemm_f32_nt（$A B^T$）、rmsnorm_f32、layernorm_f32、softmax_f32、gelu_f32、swiglu_f32、add_f32、mul_f32、scale_f32、rope_f32 与 causal_attention_f32。

向量数据库与智能体自动化（XACP）

围绕张量算子与本地推理引擎，Xu 生态还提供纯 Xu 客户端与内建智能体交互协议：

  • 向量数据库（外部包）：提供 qdrant、milvus、chroma 的纯 Xu HTTP/gRPC 驱动，可直接把 RAG 检索链路与本地模型推理编译进同一个零依赖静态二进制。
  • 智能体自动化（XACP 与 #xacp API）：为本地 Xu 桌面应用提供结构化界面树、受限采样与审计化自动化操控能力。
