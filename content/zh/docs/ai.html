编译并运行示例

examples/llm_engine/main.xu 是零外部运行库依赖的纯 Xu Transformer、DeepSeek MLA 与混合专家（MoE）推理与微调引擎，原生支持 HuggingFace 模型目录（config.json + 单文件或分片 model.safetensors.index.json + tokenizer.json/tokenizer_config.json，支持 F32/F16/BF16/FP8 E4M3）、单文件 Safetensors、PEFT LoRA 适配器（--lora 与 --lora-scale 覆盖 F32/F16/BF16 的 q/k/v/o/w1/w2/w3/lm_head，并提供基于 #tensor 反向传播、--max-grad-norm L2 梯度裁剪与 AdamW 的纯 Xu train-lora 微调与 SafeTensors 导出）、无损投机解码（--draft / --draft-k 批量校验与精确 KV 回滚）与 GGUF v2/v3（混合量化 Q4_K_M 与 Q5_K 含 Q4_K/Q5_K/Q6_K 与 --q8k-act 整数激活点积，以及 F32/F16/BF16/FP8 E4M3/Q4_0/Q5_0/Q8_0 分层 p4k4 SIMD）、DeepSeek-V2/V3/R1 MLA（kv_lora_rank、q_lora_rank、qk_nope_head_dim、qk_rope_head_dim、v_head_dim）、完整 MoE 路由与共享专家、YaRN NTK-by-parts RoPE 缩放、Gemma-2/Qwen3 扩展、自动识别聊天模板（ChatML、Llama-3、Gemma、Mistral）、低精度分页 KV 缓存、SentencePiece 与 GPT-2 BPE 合并、$O(L)$ 采样器与 logit_bias，并在 serve 模式下同时提供 OpenAI 兼容接口（/v1/completions、/v1/chat/completions 同步及 SSE <think> reasoning_content 与分块 delta.tool_calls、状态化 POST /v1/responses 支持 instructions/previous_response_id/max_output_tokens/tools/function_call_output 与 SSE 事件、批量 /v1/embeddings）和 Anthropic Messages API /v1/messages（同步与 SSE 流式、x-api-key 鉴权）。

./bin/xu build --tensor-fusion --tensor-fast-math examples/llm_engine/main.xu -o llm_engine
# （或使用 XU_TENSOR_FUSION=1 XU_TENSOR_FAST_MATH=1 ./bin/xu build ...）

# 使用 FP8 KV 缓存验证连续批处理与单请求数学一致性
./llm_engine verify model.gguf --kv-dtype fp8_e4m3fn

# 带 BPE 合并、Min-P / Top-P 核采样、LoRA 适配器与无损投机采样的文本生成
./llm_engine generate model.gguf "Hi Paris" 64 700 40 \
  --kv-dtype f16 --top-p 900 --min-p 50 --repeat-penalty 1100 \
  --presence-penalty 100 --frequency-penalty 50 --seed 42
./llm_engine generate model.gguf "Hi Paris" 64 0 40 --lora ./lora_adapter --draft ./draft.gguf --draft-k 4

# 纯 Xu LoRA 微调与梯度裁剪 + SafeTensors 适配器导出
./llm_engine train-lora model.safetensors "1,2,3,4,5" ./out_lora --lora-rank 4 --steps 20 --lr 0.05 --max-grad-norm 1.0

# 启动 OpenAI 兼容 HTTP 服务（/health、/v1/models、/v1/completions、/v1/chat/completions、/v1/responses、/v1/embeddings）
# 支持 SSE 流式输出（含 stream_options.include_usage）、批量嵌入、CORS 预检与 Bearer 密钥认证
./llm_engine serve model.gguf 127.0.0.1:8080 --kv-dtype bf16 --max-slots 4 --api-key secret

常用命令行参数：

  • --ctx <N> —— 限制并配置最大上下文序列长度。
  • --kv-dtype <f32|f16|bf16|fp8_e4m3fn|fp8_e5m2|fp8_e4m3fnuz|fp8_e5m2fnuz> —— 指定分页 KV 缓存存储精度（将 KV 显存/内存压缩为 1/2 或 1/4）。
  • --lora <path>、--lora-scale <f>、--lora-rank <N>、--lora-alpha <f>、--steps <N>、--lr <f>、--max-grad-norm <f> —— 加载 PEFT SafeTensors LoRA 适配器参与推理或运行纯 Xu train-lora（带 L2 梯度裁剪）训练并导出权重。
  • --draft <model>、--draft-k <N> —— 开启无损草稿模型投机采样与目标模型批量验证及精确 KV 缓存回滚。
  • --top-p <milli>、--min-p <milli>、--repeat-penalty <milli>、--presence-penalty <milli>、--frequency-penalty <milli>、--seed <int> —— 可复现核采样/Min-P 过滤与重复/存在/频率惩罚系数（1000 表示 1.0，支持任意正 top_k）。
  • --max-slots <N>、--api-key <K> —— 配置 serve 连续批处理最大并发槽位与 Bearer 密钥鉴权（/health 除外）。
  • --rope-type <auto|norm|neox> —— 指定 RoPE 配对布局（交错配对 norm 与拆半配对 neox；默认随 GGUF 架构自动识别）。
  • --ignore-eos —— 忽略 EOS 停止标记以运行定长吞吐基准测试。

@main
#tensor

fn run_block(w &[]f32, x &[]f32) []f32 {
    n := x.len
    $normed := []f32{}
    $out := []f32{}
    for _ in 0:n {
        normed.push(f32(0))
        out.push(f32(0))
    }
    tensor.rmsnorm_f32($&normed, x, w, n, 0.00001)
    tensor.vscale_f32($&normed, f32(0.5), n)
    tensor.softmax_f32($&normed, n, f32(1))
    tensor.vmul_f32($&out, &normed, x, n)
    << out
}

编译选项与 MIR 张量融合

在 --tensor-fusion（或 XU_TENSOR_FUSION=1）编译模式下，编译器 MIR 张量降级通道会直接识别 #tensor 与用户代码中的规范纯 Xu 数值循环，在保持冻结运行时 ABI 不变的前提下下沉为原生 ARM64 NEON / SDOT 与 x86-64 SSE2 / SSSE3 机器码内核：

  • --tensor-fusion / XU_TENSOR_FUSION=1 —— 开启 MIR 张量模式匹配与硬件内核降级（fusion-strict 保持与纯 Xu 基线逐比特一致）。
  • --tensor-fast-math / XU_TENSOR_FAST_MATH=1 —— 启用重结合浮点规约、快速指数逼近与高吞吐量化展开。

基于 packages/metal 的 GPU 算力

在 Apple Silicon 平台上，官方外部包 packages/metal（v1.9.0，导出 176 个原生符号并打包完整 6 平台 .xulib 切片）提供显式 F32Matrix、F16Matrix（MPSDataTypeFloat16）、原始字节写入（write_bytes）与六种量化权重存储——Q4Matrix（matrix_q4_0）、Q5Matrix（matrix_q5_0）、Q8Matrix（matrix_q8_0）、Q4KMatrix（matrix_q4_k）、Q5KMatrix（matrix_q5_k）与 Q6KMatrix（matrix_q6_k），并将单维/元素上限提升至 262,144 / 536,870,912；同时具备并发读锁隔离以及单命令缓冲区多算子批处理（Batch），配合非阻塞 Fence 与编译期借用和运行时形状/别名/设备守卫实现端到端 GPU 推理与训练：

@main
metal #"github.com/xulang-org/packages/metal"
#errors

fn gpu_ffn_batch(d &metal.Device, x &metal.F32Matrix, w &metal.F32Matrix,
                 w_gate &metal.Q4Matrix, w_up &metal.Q4Matrix) metal.F32Matrix {
    $normed := d.matrix_f32(x.rows(), x.columns()) >>>
    $g := d.matrix_f32(x.rows(), w_gate.rows()) >>>
    $u := d.matrix_f32(x.rows(), w_up.rows()) >>>
    $out := d.matrix_f32(x.rows(), w_gate.rows()) >>>

    $b := d.begin_batch() >>>
    _ := b.rmsnorm_f32($&normed, x, w, 0.00001) >>>
    _ := b.gemv_q4_0_f32($&g, &normed, w_gate) >>>
    _ := b.gemv_q4_0_f32($&u, &normed, w_up) >>>
    _ := b.swiglu_f32($&out, &g, &u) >>>
    $f := b.commit() >>>
    _ := f.wait() >>>
    << out
}

metal 独立调用与 Batch 模式共同公开的 GPU AI 算子涵盖：gemm_f32、gemm_f32_nt、gemm_f32_tn、rmsnorm_f32、add_rmsnorm_f32、layernorm_f32、softmax_f32、log_softmax_f32、silu_f32、gelu_f32、swiglu_f32、geglu_f32、add_f32、mul_f32、scale_f32、rope_f32、rope_interleaved_f32、rope_yarn_f32、qk_norm_f32、kv_cache_append_f32、kv_cache_append_f16、paged_kv_cache_append_f16、paged_attention_decode_f16、moe_topk_f32、moe_weighted_add_f32、融合 Top-K 加权 MoE 量化计算（moe_gemv_q4_0_f32、moe_gemv_q8_0_f32、moe_gemv_q4_k_f32、moe_gemv_q5_k_f32、moe_gemv_q6_k_f32）、LoRA/训练前反向内核（lora_add_f32、adamw_step_f32、cross_entropy_grad_f32、rmsnorm_backward_f32、swiglu_backward_f32）、基于 simd_sum/simd_max warp 规约的单遍在线 FlashAttention（causal_attention_f32、causal_attention_f16）与 FlashDecode（attention_decode_f32、attention_decode_f16）、embedding_f32、argmax_f32、gemm_f16、gemm_f16_nt、f16_to_f32、f32_to_f16 与寄存器即时反量化融合 GEMV（gemv_q4_0_f32、gemv_q5_0_f32、gemv_q8_0_f32、gemv_q4_k_f32、gemv_q5_k_f32、gemv_q6_k_f32）。

OpenAI、Anthropic、Gemini、MCP、Agent、RAG、向量数据库与桌面自动化

  • 混合 RAG 与向量数据库（外部包）：github.com/xulang-org/packages/rag 提供 chunk_text、标题层级感知的 chunk_markdown、delete_doc、基于 tensor.topk_cosine_f32 的稠密检索、元数据键值过滤（search_by_meta、search_hybrid_by_meta）、二次重排（rerank_hits）、Maximal Marginal Relevance（search_mmr）多样性重排、Okapi BM25 稀疏检索（search_bm25、search_bm25_filtered）以及 RRF 混合重排（search_hybrid、search_hybrid_filtered、retrieve_hybrid）与 save_json/load_json；配合 qdrant、milvus、chroma 的纯 Xu 驱动即可把混合检索与本地推理编译进同一个零依赖静态二进制。
