Xu 是一门无运行时垃圾回收（GC-free）的现代化高性能系统级编程语言。它融合了轻薄直观的语法设计、确定性编译期所有权与借用检查（Ownership & Borrowing），以及高效静态 AOT 原生编译。Xu 源码文件均采用标准 UTF-8 编码，文件扩展名为 .xu。

1. 安装与开发环境准备

你可以通过官方原生安装程序或解压独立 SDK 压缩包完成本地安装。详细安装与环境变量配置请参阅 安装指南。安装完成后，在终端打开并运行以下命令验证：

# 验证编译器主版本与底层构建信息
xu --version

# 查看全命令与规范排版帮助手册
xu --help

免安装体验：若暂未准备本地环境，可在浏览器中直接打开 WebAssembly 交互演练场，在云端直接编写、编译并运行体验 Xu 代码。

2. 创建你的第一个项目 (xu init)

Xu 推荐以目录作为模块单元进行工程化组织。使用 xu init 命令可在指定目录中快速初始化一个符合官方规范的新工程：

# 创建并初始化 myapp 项目
xu init myapp
cd myapp

初始化生成的标准项目文件结构如下：

文件 / 目录 类型 职责与规范说明
xu.xun 项目清单 声明模块名称、模块自身版本、所需编译器版本以及外部依赖 require:
main.xu 可执行入口 程序的顶层主入口源码，以 @main 开头并包含 fn main() 函数
xu.lock 确定性校验锁 运行 xu get 或 xu install 后自动生成，锁定依赖图与 SHA-256 完整性摘要
vendor/ 本地依赖快照 外部第三方扩展包的本地源码快照，支持无网络离线构建（--offline / --frozen）

3. 编写代码与语法速览

打开项目中的 main.xu，编写经典问候程序与基础错误处理：

@main
#fmt
#errors

fn calculate_ratio(a: int, b: int) int {
    if b == 0 {
        // 使用 >> 抛出结构化错误
        >> errors.new("division by zero")
    }
    // 使用 << 返回计算结果
    << a / b
}

fn main() int {
    fmt.println("Hello, Xu World!")

    // 调用可能返回错误的函数，使用 or (err) 捕获降级
    val := calculate_ratio(10, 2) or (err) {
        fmt.println("Error:", err.msg())
        << 1
    }

    fmt.println("Result:", val)
    << 0
}

4. 一眼能认出来的核心记号

Xu 舍弃了冗余样板关键字，采用更加直观、富有表现力的符号式语句设计：

记号 / 语法 功能分类 语义与设计规范
<< / << expr 控制流 函数返回语句（Return）。无操作数时返回空（void），有操作数时返回表达式值。
>> expr 错误处理 抛出 errors.Error 结构化错误对象（Throw）。
or (err) { ... } 错误捕获 尾随错误接住块（Catch），在表达式发生错误时执行分支降级或提前中断。
<<< expr 进程控制 进程立即退出（Process Exit），向操作系统返回指定的整数退出状态码。
<- 循环控制 循环中断跳出（Break，位于语句开头且无操作数）。
-> 循环控制 循环继续下一次迭代（Continue）。
mut name := val 所有权绑定 声明可变局部变量（默认变量绑定为不可变常量，修改需显式标记 mut）。
xu f(args) 轻量并发 派生轻量级协程并发执行函数 f，由底层无栈/轻量运行时统一调度。
chan<T> 并发通信 强类型通信通道，配合 ch << val 发送与 val := << ch 接收。
@main 包身份注解 位于文件第一行，指示当前文件属于可执行入口包，编译器将为其生成顶层 main 符号。
#pkg / alias #pkg 模块导入 # 开头导入官方标准库；外部第三方依赖使用 别名 #完整模块路径 显式导入。

5. 模块依赖与官方扩展包 (xu get / xu install)

在项目中需要接入数据库驱动、Redis 缓存或 S3 云存储等外部能力时，推荐使用一键安装命令：

# 一键声明、解析、下载官方扩展包至 vendor/ 并写入 xu.lock
xu get github.com/xulang-org/packages@v0.1.1

或者在 xu.xun 的 require: 节直接声明依赖后执行 xu install：

module: myapp
version: !ver 0.1.0
xu: !ver {{xu_version}}

require:
  "github.com/xulang-org/packages": v0.1.1

在源码中直接以明确的别名命名空间引用具体功能模块（如 mysql、redis、s3）：

@main
#fmt
mysql #github.com/xulang-org/packages/mysql

fn main() int {
    _ := mysql.driver()
    fmt.println("MySQL driver initialized.")
    << 0
}

6. 日常高频 CLI 常用工作流

Xu 提供了开箱即用的现代化命令行工具链，涵盖从编码检查到生产编译的全部环节：

命令示例 工作阶段 功能作用说明
xu run . 日常调试 自动分析当前目录依赖、快速编译并在内存中直接执行，开发体验极为流畅。
xu check . 即时检查 只执行语法、所有权生命周期和类型检查，不生成机器二进制，毫秒级快速反馈。
xu test . 质量保障 递归发现并并发运行当前目录下的所有 test_* 单元测试与基准验证。
xu fmt . 团队规范 自动格式化目录内全部 .xu 源码，遵循官方统一代码风格与缩进规范。
xu build -O2 -o bin/app 生产发布 启用最高级别机器码优化，生成独立且零依赖的原生静态可执行二进制。
xu lsp 编辑器集成 启动原生语言服务守护进程，为 VS Code / Cursor 等 IDE 提供智能辅助。
