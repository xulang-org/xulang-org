起步

Xu 0.8.4 文档。请安装完整 SDK，并用 xu --version 核对实际编译器。

Xu 是一门无 GC 的系统语言：薄语法、所有权与借用、静态 AOT。源文件扩展名 .xu，UTF-8。

  1. 安装本机 xu
  2. 写一个 Hello
  3. 按主题看 教程 01–16
  4. 需要细则时打开 语言规范

一眼能认出来的记号

语句含义
<< / << expr返回
>> expr抛出 errors.Error
or (err) { }接住错误
<<< expr进程退出
<-break（语句首、无操作数）
->continue

导入写 #errors。可执行包第一行 @main。协程写 xu f(args)，用 chan 传值。
