起步

Xu {{xu_version}} 文档。请安装完整 SDK，并用 xu --version 核对实际编译器。

Xu 是一门无 GC 的系统语言：薄语法、所有权与借用、静态 AOT。源文件扩展名 .xu，UTF-8。

  1. 通过原生 Setup 程序或压缩包安装本机 xu（或在浏览器直接打开 WebAssembly 演练场 免安装体验）
  2. 按主题学习 教程 01–16（从 01 hello 开始上手）
  3. 查阅 13 项实测跨语言性能与资源横测
  4. 需要细则时打开 语言规范

一眼能认出来的记号

语句含义
<< / << expr返回
>> expr抛出 errors.Error
or (err) { }接住错误
<<< expr进程退出
<-break（语句首、无操作数）
->continue

导入写 #errors。可执行包第一行 @main。协程写 xu f(args)，用 chan 传值。

模块与扩展包

项目使用 xu.xun 管理依赖。使用第三方服务驱动时，无需手写繁琐配置，只需在 require: 声明 "github.com/xulang-org/packages": v0.1.1 并执行 xu install，即可全自动解析并下载至本地 vendor/。详细指南见 官方扩展包使用指南、模块与依赖规范 与 原生模块与 .xulib 规范。

官方示例与教程命令在独立的 examples 仓库根执行，源码位于 examples/。
