命令行

产品入口是 xu。产品命令：build run check test fmt map doc doctor up。

命令作用
xu build <file|dir>AOT 编译。目录编全部 *.xu（不递归）。macOS / Linux 默认无后缀，Windows 默认 .exe
xu run <file|dir> [-- args]编译后执行，仅本机 target
xu check解析+类型+借用；末尾列死循环风险与退出位点
xu test只跑 test.* .xu 里的 fn test_*
xu fmt [-w]格式化
xu map源码流程图（默认 Mermaid；--graph 给画布）
xu doc [path...] [-o file] [--public] [--serve] [--addr A]生成 Markdown 声明文档；--public 过滤私有 API，--serve 启动本地 XUDOCS 页面
xu doctor检查本机桌面打包工具
xu up打印工具链版本
xu build file.xu
xu build file.xu --output out
xu build file.xu -O0
xu build dir/
xu run dir -- args
xu test file.xu -v
xu doc src/net --public -o net.md
xu doc src/net --public --serve --addr 127.0.0.1:6060

PowerShell 请用 --output。测试旗标：-run -v -count -failfast -list -short -bench。目录 build/check 跳过 test.*.xu。

xu doc --serve 提供 /、/docs.md 与 /health；语言服务器仍未实现。诊断请用 xu check。

目标优先级：--target > XUOS+XUARCH > 二进制名暗示的本机。
