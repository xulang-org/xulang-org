命令行

Xu 0.8.4 · xu --help

命令作用
xu build <file|dir>AOT 编译；目录须有 xu.xun，合并当前目录的源码，不递归
xu run <file|dir> [-- args]编译并运行，仅本机目标；默认清理临时产物，--output 保留产物
xu check <file|dir>解析、类型与借用检查，不生成可执行文件
xu test <file|dir>构建测试程序并执行 test.<name>.xu 中的 fn test_*
xu install [dir]解析 require:，校验依赖并生成 vendor；默认当前目录
xu fmt [path...] [-w]格式化；-w 原地写回
xu map [path...]生成流程图；默认 Mermaid，--graph 打开画布
xu doc [path...] [--public] [--serve]提取 Markdown 声明文档，或启动本地 XUDOCS 预览
xu doctor [--target T]检查本机工具链与桌面打包环境
xu up / xu update从 GitHub 下载源码，自举编译并更新编译器、工具和标准库；需要 Python 3.9+
xu --version显示实际编译器版本与本机目标

构建选项

build、run、test 默认自动优化。--no-opt 关闭优化；--debug-build 生成不优化且带 DWARF 行号的产物。--debug 保持优化并添加调试信息，--timings 打印阶段统计。

xu build hello.xu --output hello
xu run hello.xu -- arg1
xu build hello.xu --debug-build --output hello-debug
xu check app/main.xu --offline
xu build app/main.xu --frozen --output app/program
xu test app/ -v
xu doc src/net --public --output net.md
xu doc src/net --public --serve --addr 127.0.0.1:6060

目录 build/check 跳过测试文件。测试选项包括 -run、-v、-count、-failfast、-list、-short、-bench 与 --cover。xu lsp 仍未实现。

更新工具链

xu up --check
xu up
xu update --ref main
xu update --version 0.8.4
xu update --source /path/to/xu --prefix /path/to/sdk

默认选择 GitHub 最新正式版本；没有正式版本时选择 main。更新先锁定源码提交，再用当前产品编译器自举、验证定点并构建配套工具，全部通过后才替换安装。--check 只检查版本，--force 允许同版本重建或降级。开发仓库须用 --prefix 安装到独立目录，以免覆盖研发源码。Windows 在当前 xu.exe 退出后完成替换，结果见安装目录的 .xu-update.log。

--target > XUOS + XUARCH > 当前编译器的本机目标。PowerShell 建议用 --output。

--offline / --frozen: 模块与依赖。--desktop: UI / WebView。

xu doc --serve 提供 /、/docs.md、/health。诊断请用 xu check。
