02 · 绑定与常量

默认不可变。要改写必须写 mut。const 是编译期常量。禁止全局可变变量。

源码

@main

const max = 100

fn main() int {
    name := "Xu"
    mut age := 20
    age += 1

    println(name)
    println(age)
    println(max)
    << 0
}

编译（仓库根，按平台换二进制）：

xu run developer/examples/02_bindings
# 或：xu build developer/examples/02_bindings/main.xu
# mac/linux 默认写出 ./main ；Windows 为 ./main.exe
