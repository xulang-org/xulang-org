02 · 绑定与常量

默认不可变。要改写必须写 mut。const 是编译期常量。禁止全局可变变量。

源码

@main

const MAX = 100

fn main() int {
    name := "Xu"
    mut age := 20
    age += 1

    println(name)
    println(age)
    println(MAX)
    << 0
}

编译（examples 仓库根，使用已安装的 xu）：

xu run examples/02_bindings/main.xu
# 或：xu build examples/02_bindings/main.xu
# mac/linux 默认写出 ./main ；Windows 为 ./main.exe

在独立的 examples 仓库根执行；源码位于 examples/。
