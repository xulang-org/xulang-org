10 · 并发

xu f(args) 启动协程。xu.pkg.f 带点号是包路径调用。Channel 转移所有权，不要把借用送进协程。

源码

@main

fn worker(id int, ch chan int) {
    ch <- id * 10
}

fn main() int {
    ch := chan int{cap: 1}
    xu worker(1, ch)
    x := <-ch
    println(x)
    << 0
}

编译（仓库根，按平台换二进制）：

xu run developer/examples/10_concurrency
# 或：xu build developer/examples/10_concurrency/main.xu
# mac/linux 默认写出 ./main ；Windows 为 ./main.exe
