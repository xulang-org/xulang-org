01 · 程序骨架

目标

创建、检查并运行一个 Xu 程序，打印问候语后成功退出。

前置条件

按照安装指南安装你选定的 Xu SDK，并将它的 xu 命令加入 PATH。在终端中验证：

xu --version

只需一个空工作目录和文本编辑器，完整源码见下文。

步骤

1. 创建源文件

创建并进入一个空目录：

mkdir xu-tut01
cd xu-tut01

将以下完整程序保存为该目录中的 main.xu：

@main

fn main() int {
    println("Hello, Xu!!!!!!!!!")
    << 0
}

@main 标记可执行程序入口。println 打印一行，<< 0 从 main 返回成功退出码。Xu 使用 << 表示返回语句，不需要分号。

2. 检查并运行

在同一目录中先检查文件，检查成功后再运行：

xu check main.xu
xu run main.xu

预期输出

xu run main.xu 精确打印以下一行及末尾换行符，并以状态码 0 退出：

Hello, Xu!!!!!!!!!
