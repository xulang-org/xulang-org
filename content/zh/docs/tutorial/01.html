01 · 程序骨架

最小程序：打印一行并用 << 0 作为退出码。没有 return 关键字。无分号。

源码

@main

fn main() int {
    println("Hello, Xu!!!!!!!!!")
    << 0
}

编译（examples 仓库根，使用已安装的 xu）：

xu run examples/01_hello/main.xu
# 或：xu build examples/01_hello/main.xu
# mac/linux 默认写出 ./main ；Windows 为 ./main.exe

在独立的 examples 仓库根执行；源码位于 examples/。
