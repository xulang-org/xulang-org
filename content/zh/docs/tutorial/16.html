16 · UI + WebView

对应 #ui 窗口/菜单/托盘 + #ui/webview 内容槽。打包用产品 xu doctor / xu build <App> --desktop。

每个应用是独立项目根：

App/
  main.xu              # 入口（必需）
  www/                 # 本地 xu:// 静态页（有 WebView 时）
  brand/               # 至少一张 PNG 图标（不会回退到仓库根 brand/）

本目录下的应用：open 标准窗+WebView；shaped 异形窗；draw 直绘画布 #ui/draw；remote 远程 HTTP。

xu doctor --desktop --target macos-arm64
xu build developer/examples/16_ui_webview/open --target macos-arm64 --desktop -o /tmp/XuOpen
open /tmp/XuOpen.app

macOS 直接产出 .app。windows/linux 的 --desktop 本刀报「未实现」。
