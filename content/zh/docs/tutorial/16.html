16 · UI + WebView

对应 #ui 窗口/菜单/托盘 + #ui/webview 内容槽。打包用产品 xu doctor / xu build <App> --desktop。

每个应用是独立项目根：

独立项目根目录结构 (Project Root)
App/ 应用独立根目录
xu.xun 配置 模块清单与构建配置 (Module Manifest)
main.xu 必需 主程序入口源码 (Main Entry)
www/ 可选 本地 xu:// 静态 Web 资源（当包含 WebView 时）
brand/ 必需 至少包含一张应用 PNG 图标（桌面打包专用，不会回退到仓库根）

本目录下的应用：open 标准窗+WebView；shaped 异形窗；draw 直绘画布 #ui/draw；remote 远程 HTTP。

xu doctor --desktop --target macos-arm64
xu build examples/16_ui_webview/open --target macos-arm64 --desktop -o /tmp/XuOpen
open /tmp/XuOpen.app

macOS 产出 .app，Windows 产出 .exe，Linux 产出 ELF。桌面打包需要对应宿主工具链；Linux 使用 GTK4，WebView 另需 WebKitGTK 6.0。各平台运行验收范围见 UI / WebView。

命令在独立的 examples 仓库根执行。
