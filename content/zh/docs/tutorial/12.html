12 · HTTP FileServer

一行起静态文件服务：

http.listen_and_serve("127.0.0.1:8080", ".")

默认根目录是示例下的 www/，也可把目录当参数传入。

源码

@main

#net/http

//   http.listen_and_serve("127.0.0.1:8080", ".")
//
// 参数：要对外的目录。默认本示例的 www/（从仓库根运行）。

fn main() int {
    mut root := "examples/12_file_server/www"
    av := args()
    if av.len >= 2 {
        root = av[1] + ""
    }
    println("FileServer " + root)
    println("http://127.0.0.1:8080")
    http.listen_and_serve("127.0.0.1:8080", root) or (err) {
        println(err.msg())
        << 1
    }
    << 0
}

在独立的 examples 仓库根执行；源码位于 examples/。
