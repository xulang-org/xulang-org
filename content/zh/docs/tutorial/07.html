07 · 数组与字符串

动态数组 push。字符串切片 s[a:b] 采用半开区间 [a, b)，结果是拷贝。端点可省略：s[a:]、s[:b]、s[:]。插值 "hi $name"。

源码

@main

fn main() int {
    mut nums := [1, 2, 3]
    nums.push(4)
    println(nums.len)
    for n in nums {
        println(n)
    }

    name := "Ada"
    println("hi $name")
    s := "hello"
    println(s.len)
    println(s[1:4])
    << 0
}
