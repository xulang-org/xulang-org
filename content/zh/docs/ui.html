UI / WebView

#ui 提供窗口、菜单、托盘和事件循环；#ui/webview 提供 HTML 内容与 IPC；#ui/draw 提供立即模式画布。每个应用包含 main.xu、xu.xun、brand/，按需提供 www/ 资源。

桌面打包使用编译器同目录的 xu-desktop。macOS 通过 AppKit/WebKit 生成 .app；Windows x64/arm64 通过原生宿主与 WebView2 生成 .exe；Linux x64/arm64 通过 GTK4 生成 ELF，WebView 另需 WebKitGTK 6.0。须准备匹配的编译器、链接器和 SDK，先对所选目标执行 xu doctor。

# From the examples repository root
xu doctor --desktop --target macos-arm64
xu build examples/16_ui_webview/open --target macos-arm64 --desktop --output /tmp/XuOpen
open /tmp/XuOpen.app

brand/ 须有 PNG 图标。www/ 资源打包进原生产物并通过 xu:// 提供，也支持远程 HTTP(S) 内容。交叉生成成功不能替代目标机运行验证。XU_UI_SIM=1 使用进程内模拟；宿主未连接时返回 ui: host not available。
