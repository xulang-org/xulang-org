UI / WebView

#ui 是桌面壳：App / Window / Icon / Menu / Tray / 事件循环。内容槽可插拔：WebView、立即模式画布 #ui/draw、或空壳。

#ui/webview：attach 到窗口；load_html / load_url、eval、on/emit。本地 xu://（打包进二进制）或远程 http(s)。

应用目录约定见 教程 16。

xu doctor --desktop --target macos-arm64
xu build App --target macos-arm64 --desktop -o /tmp/XuOpen
open /tmp/XuOpen.app

brand/ 必须在应用目录内有 PNG 图标。XU_UI_SIM=1 走进程内模拟。host 未接时方法会抛 ui: host not available。
