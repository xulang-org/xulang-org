操作系统研发

使用 Xu 的裸机与 UEFI 编译模式，以原生 AOT 构建内核、引导程序、驱动和固件代码。核心基础库覆盖内存布局、硬件 I/O、ACPI/FDT/PCI、UEFI、中断与任务上下文切换。

Xu {{xu_version}} SDK 已提供裸机 ELF64 与 UEFI 编译目标。

构建内核与 UEFI 示例

安装 Xu SDK，然后在 Xu {{xu_version}} 源码仓库根目录运行以下命令：

xu build --profile=freestanding --target=x64-none examples/baremetal/kernel_poc/main.xu -o kernel-x64.elf
xu build --profile=freestanding --target=arm64-none examples/baremetal/kernel_poc/main.xu -o kernel-arm64.elf
xu build --profile=freestanding --target=riscv64-none examples/baremetal/kernel_poc/main.xu -o kernel-riscv64.elf
xu build --profile=freestanding --target=x64-uefi --no-sse --stack-size=65536 main.xu -o BOOTX64.EFI
xu build --profile=freestanding --target=arm64-uefi main.xu -o BOOTAA64.EFI

用 file kernel-*.elf 或固件校验工具检查产物架构。内核示例提供 x86-64 QEMU 运行步骤。支持 --no-sse、--stack-size 与可重定位 DWARF 调试信息。

硬件访问与 #core/* API

裸机模式构建的程序独立于宿主系统服务与 libc，源码可以通过 $freestanding 声明。项目配置和编译器参数见裸机模式参考。

  • 用 *raw T 表示硬件地址，在 unsafe { … } 中解引用；用 volatile_read / volatile_write 访问 MMIO，并可使用 @interrupt、@panic_handler、@weak、@naked、extern static 与参数化内联汇编。详见内存模型。
  • 用 @repr("C", align: N) 或 @repr("C", packed) 明确指定页表、GDT/IDT 与硬件描述符布局。
  • 硬件与固件库：#core/arch、#core/mem、#core/alloc、#core/sync、#core/task。
  • 固件、总线与现代设备库：#core/uefi、#core/acpi、#core/pci、#core/fdt、#core/elf、#core/mmio 与 VirtIO 1.0 Modern（#core/virtio）。

各目标平台的支持与验证范围见实现状态。
