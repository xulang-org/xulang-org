操作系统研发

使用 Xu 的裸机编译模式，以原生 AOT 构建内核、驱动和固件代码。内核示例覆盖内存布局、硬件 I/O、同步、中断和任务上下文切换。

Xu 0.14.3 SDK 已提供裸机 ELF64 与 UEFI 编译目标、中断/裸函数属性及固件驱动模块。

构建内核示例

安装 Xu SDK，然后在 Xu 0.14.3 源码仓库根目录运行以下命令。

xu build --profile=freestanding --target=x64-none examples/baremetal/kernel_poc/main.xu -o kernel-x64.elf
xu build --profile=freestanding --target=arm64-none examples/baremetal/kernel_poc/main.xu -o kernel-arm64.elf
xu build --profile=freestanding --target=riscv64-none examples/baremetal/kernel_poc/main.xu -o kernel-riscv64.elf

用 file kernel-*.elf 检查产物的架构。内核示例提供 x86-64 QEMU 运行步骤。同时支持 --target=x64-uefi 与 --target=arm64-uefi UEFI 应用生成。运行时需为目标架构配置匹配的引导环境、板级支持和硬件设置。

硬件访问与核心 API

裸机模式构建的程序独立于宿主系统服务与 libc，源码可以通过 $freestanding 声明。项目配置和编译器参数见裸机模式参考。

  • 用 *raw T 表示硬件地址，在 unsafe { … } 中解引用。用 volatile_read 和 volatile_write 访问内存映射 I/O；支持 @interrupt、@weak、@naked、@section、@align、@export、@noreturn、@panic_handler、extern static、严格 --no-sse、--stack-size 与多架构参数化内联汇编。详见内存模型。
  • 用 @repr("C", align: N) 或 @repr("C", packed) 明确指定页表、硬件描述符等结构体的布局。
  • #core/arch 提供架构相关的控制操作，#core/mem 提供底层内存操作，#core/alloc 定义分配器接口。
  • #core/sync 提供自旋锁和中断保护，#core/task 提供任务上下文和中断现场结构。
  • 0.14.2–0.14.3 新增核心与固件模块：#core/acpi、#core/addr、#core/ds、#core/elf、#core/fdt、#core/fmt、#core/mmio、#core/pci、#core/uefi，以及 VirtIO 1.0 Modern MMIO、HPET 与 UEFI MemMap 支持。

各目标平台的支持与验证范围见实现状态。
