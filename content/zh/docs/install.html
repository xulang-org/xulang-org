安装

本文对应 Xu {{xu_version}}。安装包是否可下载，以 GitHub Releases 的实际附件为准。

使用包含 bin/、src/ 和工具的完整 SDK。标准库源码是编译导入的必要输入；单独把编译器改名放进 PATH 不构成完整开发环境。

安装 SDK

从 下载页 进入 Releases，选择匹配本机的已发布归档。Unix 归档通常为 xu-v<版本>-<目标>.tar.gz，Windows 为 .zip。解压后在 SDK 根目录执行：

# macOS / Linux
./install.sh
# 在新终端验证
xu --version
xu doctor
# Windows PowerShell
.\install.ps1
# 重启 PowerShell 后验证
xu --version
xu doctor

默认安装目录为 ~/.xu。Unix 可用 ./install.sh --prefix /absolute/path 指定目录，或用 source env.sh 临时激活解压后的 SDK；PowerShell 对应 . .\env.ps1。

更新已安装版本

安装 Python 3.9+ 后执行 xu up 或 xu update，从 GitHub 下载正式版本源码并编译更新。xu up --check 只检查，xu update --ref main 选择最新开发源码。源码构建及运行验证成功后，才替换本机编译器、配套工具与标准库；更多选项见 命令行。

验证编译

xu check hello.xu
xu run hello.xu
xu build hello.xu --output hello

macOS / Linux 的可执行产物已有执行权限。PowerShell 中建议使用 --output 指定路径。

环境与源码构建

XU_ROOT 指向 SDK 或编译器仓库；XU_STDLIB_ROOT 可显式指定标准库 src/。XUPATH 追加搜索目录，不能替代外部模块的 require: 声明。工具 xu-fmt、xu-doc、xu-map、xu-doctor、xu-desktop 应与 xu 放在同一个 bin 目录。

源码位于 xu 仓库。make xu 使用已有 hosted 产品种子自举，并重建工具；清洁检出需要先准备产品种子及 bootstrap 伴随仓库，不能只凭源码直接执行编译器。packages、examples、vscode 分别维护在独立仓库。
