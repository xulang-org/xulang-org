安装

本文对应 Xu {{xu_version}}。安装包是否可下载，以 GitHub Releases 的实际附件为准。

使用包含 bin/、src/ 和工具的完整 SDK。标准库源码是编译导入的必要输入；单独把编译器改名放进 PATH 不构成完整开发环境。

原生安装程序（推荐）

Xu 提供开箱即用的原生 Setup 安装程序（无需 Python、脚本或第三方依赖），单文件离线内嵌完整 SDK，自动配置全局环境变量，安装后在系统任意终端均可直接执行 xu：

操作系统推荐安装包说明
Windows 下载 xu-v{{xu_version}}-windows-x64-setup.exe
或 xu-setup-windows-x64.exe		 原生单文件离线安装包，直接双击启动自绘图形向导，自动配置注册表用户 Path 与 XU_ROOT，无脚本执行策略拦截。终端亦可直接执行 .\xu-setup-windows-x64.exe -y 静默安装。
macOS 下载 xu-v{{xu_version}}-macos-arm64.pkg
或 xu-setup-macos-arm64		 macOS 原生图形安装向导，自动配置 /etc/paths.d/xu，系统所有终端全局立即可用；亦可下载独立安装程序 xu-setup-macos-arm64 免提权运行。
Linux 下载 xu-setup-linux-x64
或 xu-setup-linux-arm64		 原生单文件二进制程序，运行 chmod +x xu-setup-linux-x64 && ./xu-setup-linux-x64 -y，自动解压 SDK 并写入用户 Shell 环境变量配置。

离线 SDK 归档包安装

若从 下载页 或 GitHub Releases 下载了完整的 SDK 压缩包（Unix 为 .tar.gz，Windows 为 .zip），解压后根目录已内置原生安装程序：

# Windows：解压后在资源管理器中直接双击根目录下的 xu-setup.exe
# 或在命令行中执行：
.\xu-setup.exe -y

# macOS / Linux：解压后在终端运行根目录下的 xu-setup
./xu-setup -y

默认安装目录为用户主目录下的 .xu（macOS .pkg 默认为 /usr/local/xu）。如需自定义安装目录，可传入参数 --prefix /custom/path。在自动化 CI 脚本中，亦可继续使用 ./install.sh 或 .\install.ps1；若只需临时体验，可在解压目录下执行 source env.sh（PowerShell 为 . .\env.ps1）。

验证全局环境

安装完成后，打开新的终端窗口（CMD、PowerShell、Terminal 或 VS Code 内置终端），验证工具链全局可用：

xu --version
xu env
xu doctor

更新已安装版本

执行 xu up 或 xu update，直接从 GitHub 下载匹配当前系统的正式 Release 安装包并更新编译器、配套工具与标准库。xu up --check 只检查是否有新版本，xu update --version <版本> 指定安装特定版本。下载解压并验证通过后，才替换本机工具链；更多选项见 命令行。

验证编译

xu check hello.xu
xu run hello.xu
xu build hello.xu --output hello

macOS / Linux 的可执行产物已有执行权限。PowerShell 中建议使用 --output 指定路径。

环境与源码构建

XU_ROOT 指向 SDK 或编译器仓库；XU_STDLIB_ROOT 可显式指定标准库 src/。XUPATH 追加搜索目录，不能替代外部模块的 require: 声明。工具 xu-fmt、xu-doc、xu-map、xu-doctor、xu-desktop 应与 xu 放在同一个 bin 目录。

源码位于 xu 仓库。make xu 使用已有 hosted 产品种子自举，并重建工具；清洁检出需要先准备产品种子及 bootstrap 伴随仓库，不能只凭源码直接执行编译器。packages、examples、vscode 分别维护在独立仓库。
