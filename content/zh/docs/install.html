安装

面向用户的二进制名叫 xu。各平台预编译文件：

文件--target格式
xu.macos.arm64macos-arm64Mach-O arm64
xu.macos.x64macos-x64Mach-O x86_64
xu.linux.arm64linux-arm64ELF aarch64
xu.linux.x64linux-x64ELF x86_64
xu.linux.loongarch64linux-loongarch64ELF LoongArch
xu.linux.riscv64linux-riscv64ELF RISC-V
xu.windows.x64.exewindows-x64PE32+ x86-64
xu.windows.arm64.exewindows-arm64PE32+ ARM64

下载页：/download。放到 PATH 后即可：

xu build hello.xu
./hello

mac/linux 默认产物无后缀，已带可执行位，不必再 chmod +x。Windows 为 .exe。PowerShell 请用 --output（-o 会被吞）。

从源码编（次要路径）

在语言仓库根：make xu，得到 ./bin/xu。日常把下载页对应平台的文件改名为 xu 放进 PATH。
