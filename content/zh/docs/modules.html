模块与依赖

Xu {{xu_version}} · 0.8.4 签名校验日志 · 0.8.6 依赖图快照重构 · 0.8.8 跨架构依赖验证与构建分发规范

目录项目使用 xu.xun。module: 是模块身份，version: 是模块自身版本，xu: 是所用 Xu 版本。外部导入必须明确别名，并在 require: 中声明所属根模块。

声明与安装依赖（自动化解析）

普通项目推荐直接声明官方 SemVer 发布版本，无需手动克隆或手写构建参数：

module: app
version: !ver 0.1.0
xu: !ver {{xu_version}}
require:
  "github.com/xulang-org/packages": v0.1.1

在项目根目录运行 xu install，编译器将自动下载到 vendor/ 并生成校验锁 xu.lock。代码中使用显式别名导入需要的子包：

@main
mysql #github.com/xulang-org/packages/mysql

fn main() {
    _ := mysql.driver()
}

require 声明官方根模块 github.com/xulang-org/packages，代码中通过完整子路径导入具体包（如 mysql、redis、postgres）。完整清单见 官方扩展包 (Packages)。

版本选择与来源定位

除 SemVer 发行版外，还可以指定已审查的不可变 Git 提交，或在本地协同研发时使用相对路径：

# 方式 A：指定 Git 提交
require:
  "github.com/xulang-org/packages": git:https://github.com/xulang-org/packages.git@<commit>

# 方式 B：本地协同开发（让 app 与 packages 目录同级）
require:
  "github.com/xulang-org/packages": file:../packages

MVS（最小版本选择）读取全部可达版本的清单，为每个模块选择图中最高的最低要求，不查询 latest，也不接受浮动版本范围。v2 及以上模块使用匹配的 /vN 路径后缀。显式 file/Git/tar 来源继续支持，来源冲突会报错。

安装、锁定与离线构建

xu install app
xu check app/main.xu --offline
xu build app/main.xu --frozen --output app/program
模式行为
默认允许下载并建立锁条目；已锁定内容不匹配时失败。
--offline不下载，只使用本地来源、已校验缓存或 vendor；仍可建立锁条目。
--frozen隐含离线，要求已有匹配锁条目，不写依赖缓存或补锁；本地 file 依赖须先安装为 vendor 快照。

审查并提交 xu.lock。显式来源使用 v2 锁，版本图使用 v3 锁。xu install 在 vendor 中保留全部可达版本快照，支持离线重放 MVS 图。冻结依赖不冻结主项目源码或编译产物。install --frozen、build --desktop 搭配这两种模式会被拒绝。

代理与私有模块

XUPROXY='https://proxy.example.com,direct' xu install app
XUPRIVATE='example.com/private/*' xu install app

XUPROXY 支持 HTTP(S)、绝对 file://、direct 与 off，默认 direct。逗号仅在 404/410 后回退；竖线允许请求错误后回退。身份或完整性不匹配始终失败。直接版本发现支持 GitHub 仓库，其他主机使用显式来源或配置的 Xu 代理。

XUPRIVATE 是逗号分隔的模块前缀 glob 列表；XUNOPROXY 默认沿用它并控制代理绕过。不假定公共 Xu 代理已上线，Go 模块代理中的清单不能作为 Xu 清单。

0.8.4 独立校验

XUSUMDB 接受可信 Ed25519 verifier 公钥及可选服务 URL。对 SemVer 模块，客户端验证签名树头、模块摘要、包含证明和日志追加一致性后才接受依赖；未设置或设为 off 时仍是首次使用信任。XUNOSUMDB 独立控制校验绕过，默认沿用 XUPRIVATE。

原生模块与 C 互操作

除了纯源码依赖，Xu 支持在 xu.xun 的 native: 中声明 C/C++ 原生模块。编译器既支持通用的 .a 静态库，也支持自带 ABI 元数据与跨平台切片的 .xulib 容器。详见 原生模块与 .xulib 规范。

旧版本迁移

旧点式包路径改为斜杠路径，保留域名、版本号和字段/方法访问中的点。模块身份或旧锁格式发生变化时，审查后重新安装。不能为跳过内容不匹配而直接删除当前锁文件。
