Xuプログラミング言語とは何ですか？

Xuはコンパイル時メモリ安全性を備えた高性能システムプログラミング言語です。Goの簡潔な並行処理モデル（コルーチンとチャネル）と、C/Rust級の決定論的リソース管理（ゼロGC）を融合しています。

Xuのコアとなる設計目標は何ですか？

主な目標は、実行時オーバーヘッドの排除、自動所有権推論による簡潔な構文、ライフタイム注釈の不要化、自社開発ネイティブAOTコンパイラ、およびC/C++とのシームレスな相互運用です。

Xuはガベージコレクタ（GC）なしでどのようにメモリ安全性を保証しますか？

単一所有権と借用チェッカーを採用し、コンパイル時にリソースのライフタイムを追跡してスコープ終了時に自動解放（RAII）を行うため、メモリリークや二重解放を防ぎます。

Xuの借用チェッカーはどのように動作しますか？

不変借用 &T と可変借用 &mut T をサポートします。同一スコープ内では複数の不変借用、または単一の可変借用のいずれかのみが許可されます。

Xuの並行処理モデルはどのように設計されていますか？

言語組み込みの xu キーワードで軽量コルーチンを起動し、型付き chan<T> チャネルを介して安全な通信と同期を行います。

Xuでデータレース（競合）は発生しますか？

コルーチン間のデータ送信時には所有権の移動（Move）またはディープコピーが強制され、可変ポインタの共有をコンパイル時に排除してデータレースを防ぎます。

Xuコルーチンのスケジューリングと実行モデルはどのようになっていますか？

M:NハイブリッドスケジューラとOSネイティブの非同期I/O（epoll/kqueue/IOCP）を統合し、単一プロセスで数百万の並行接続を処理可能です。

Xuのエラー処理メカニズムはどのようなものですか？

従来の例外（try/catch）を排除し、記号的制御フロー（<< 成功、>>> エラー）と catch 式による明示的なエラー処理を採用しています。

Xuはオブジェクト指向プログラミングをサポートしていますか？

クラス継承ではなく「継承より合成」を重視します。struct でデータを定義し、メソッド拡張と interface でポリモーフィズムを実現します。

XuはOSカーネルやベアメタルファームウェアの開発をどのようにサポートしていますか？

XuはOSマイクロカーネル、組込みファームウェア、デバイスドライバのスクラッチ開発をネイティブでサポートしています。ランタイムGCに制約されるマネージド言語や、手動でのライフタイム注釈が複雑化する言語とは異なり、Xuは厳密に階層化されたシステムアーキテクチャを採用しています：

  • 通常のシステムコンポーネントやカーネルサービスでは、暗黙的所有権推論とコンパイル時ゼロGCの決定論的破棄を維持し、ライフタイム注釈（<'a>）を必要としません；
  • 最下層のハードウェア操作（コード全体の約5%）では、Freestandingモード（freestanding）、生ポインタ（*raw T）、揮発性MMIOバリア（volatile_read / volatile_write）、純粋静的コアライブラリ（#core）を通じて安全かつ精密に制御されます。

カーネル実装例は公式の kernel_poc 検証リポジトリ および Xu 0.14.0 リリースノート を参照してください。

Freestandingプロファイルとは何ですか？ホストOSへの依存を完全に遮断するには？

Freestandingプロファイルとは、ホストOSのシステムコール（Syscalls）、動的リンカ、C標準ライブラリ（libc）に一切依存しないバイナリを生成する実行モードです。Xuは3段階の設定方法を提供します：

  • ソースコードレベル：ソースファイルの先頭行に $freestanding コンパイルタグを宣言；
  • プロジェクト設定：プロジェクトマニフェスト xu.xun 内で profile: freestanding を指定；
  • CLIコンパイルオプション：ビルド時に --profile=freestanding または --no-std を指定。

このモードを有効にすると、ホストOSランタイムやデフォルトスケジューラが完全に除去され、極めて軽量な独立ベアメタルELF/PEイメージ（通常 1.9 KB 〜 2.4 KB）が出力されます。

標準ライブラリのないベアメタル環境で、#core はどのようなハードウェア抽象化を提供しますか？

Xuは、外部依存・ゼロシステムコール・ゼロ暗黙割り当ての静的基盤ライブラリ #core を提供します：

  • #core/arch：CPU特権命令（cli, sti, hlt, pause, wfi）、コントロールレジスタアクセス（CR0/CR2/CR3/CR4, VBAR, SCTLR）、8259A PIC再マッピング、8254 PITタイマー初期化、IDTディスクリプタ読み込み（load_idt）；
  • #core/sync：割り込み安全スピンロック IrqSpinlock および Spinlock、RAIIガード（IrqGuard, SpinGuard）によるスコープ終了時の決定論的アンロックと割り込みフラグ自動復元（EFLAGS / PSTATE）；
  • #core/task：アーキテクチャ共通の192バイト・16バイト境界整列 TaskContext、アトミックコンテキストスイッチ（switch_context）、TrapFrame 例外スナップショットとシステムコールエントリ；
  • #core/virtio：静的VirtIO MMIOドライバフレームワーク、VirtQueueディスクリプタリング、VirtioBlkDriver ブロックデバイス、VirtioNetDriver 仮想NIC；
  • #core/mem & #core/alloc：ゼロ割り当てメモリー基本関数（memset/memcpy/memcmp）とプラガブルな GlobalAlloc アロケータインターフェース。

カーネル内で物理メモリマッピング（MMIO）や生ポインタ操作を安全に行うには？

ハードウェアレジスタやMMIOデバイスメモリへのアクセスは、安全な構文境界によって分離されます：

  • 生ポインタ型 *raw T と unsafe { ... } ブロック：絶対物理アドレスの再解釈やポインタ演算を許可しますが、参照解決は unsafe { ... } ブロック内でのみ許可されます。所有権推論は生ポインタをスキップし、危険な低層操作が安全なカーネルロジックへ波及するのを防ぎます；
  • 揮発性MMIOバリア（Volatile MMIO）：組み込みの volatile_read および volatile_write により、コンパイラの不要コード削除（DCE）やループ不変量巻き上げ（LICM）を防ぎます；
  • 厳密なメモリーレイアウト制御：@repr("C", align: N)（PML4ページテーブル用の4096バイトアラインなど）および @repr("C", packed)（パケットヘッダ用のパディングなし配置）をサポート；
  • スキャフォールディングとエミュレーション：xu init --baremetal my_os によりマルチアーキテクチャのカーネル骨格・リンカスクリプト（linker.ld）・Makefileが一発生成され、make qemu で即座に仮想マシン上で起動・デバッグ可能です。

XuはC/C++ネイティブライブラリとどのように相互運用しますか？

ゼロコストのC FFI境界を提供し、Cヘッダーと静的/動的ライブラリ（.a, .so, .dylib, .dll）を直接リンクして利用できます。

XuはどのOSおよびCPUアーキテクチャをサポートしていますか？

macOS（ARM64/x64）、Linux（ARM64/x64/LoongArch/RISC-V）、Windows（x64/ARM64）、WebAssembly（WASI）をネイティブサポートしています。また、--profile=freestanding によるベアメタル・OSカーネル開発（x86_64、aarch64、riscv64 ELF）もサポートしています。

XuはWebAssemblyをサポートしていますか？

完全サポート。ネイティブバックエンドから wasm32-wasi バイトコードを直接出力し、ブラウザ内外で実行可能です。

Xuはモジュールと依存関係をどのように管理しますか？

プロジェクトルートの xu.xun で依存関係を宣言し、xu.lock でSemVerバージョンとチェックサムを固定して再現可能なビルドを保証します。

Xuには中央パッケージリポジトリがありますか？

分散型アーキテクチャとGit直接参照モデルを採用し、エコシステムカタログを通じて検証済みパッケージを提供します。

.xulib静的配布パッケージとは何ですか？

.xulib はXu独自のネイティブモジュール配布形式で、複数アーキテクチャの静的オブジェクトと型シグネチャを統合しています。

XuのネイティブデスクトップUI / WebViewアーキテクチャとは何ですか？

ネイティブGPUハードウェアアクセラレーションによるRetained-mode UIフレームワークと、組み込みシステムWebView連携を標準提供します。

XuはiOSおよびAndroidのモバイルアプリ開発をどのようにサポートしますか？

xu build --phone により、iOSフレームワークおよびAndroid NDKネイティブライブラリを直接生成可能です。

Xuにはどのような開発ツールとIDE統合が提供されていますか？

公式のVS CodeおよびCursor拡張機能（xu-lsp統合）により、定義ジャンプ、自動補完、リアルタイム診断、デバッグをサポートします。

Xuの現在の安定性とリリース状況はどうなっていますか？

現在0.x系列で積極的なリリースを継続しており、コア構文仕様は凍結済みで、6つのネイティブプラットフォームで全CIテストに合格しています。
